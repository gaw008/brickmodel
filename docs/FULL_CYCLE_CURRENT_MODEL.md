# 当前来源热容主机与适用域

P16已用已有USGS五项Cp替换四种气体及CaCO3/CaO背景线性热容。原形成焓/熵锚、液水/结合、石英/有效matrix、反应计量及工艺保持；h/s、容量和气体面携焓来自同一热容积分，没有新状态或额外反应热。所有系数、来源域、工艺和数值设置都在根文件。

同态正热容、h/s导数、非等温/等温/复数携焓核算通过。30个参考状态中，calcite/lime Cp最大偏差降为0.003533%/0.007975%，四气体对另一NIST来源的最大Cp偏差0.087619%–0.680257%；来源之间差异保留。石英和液水背景未改。形成焓绝对值可掩盖显热偏差，JSON同时保留原量和R/RTr分母地板。没有把0.1%守恒门槛当所有来源的实验精度门槛。

三档当前完整周期各运行一次：81项质量/元素/完整能量预算最大残差0.05587811%，108项气体预算最大0.04963337%；时间/网格各加密一次，规定四指标最大0.13141615%，加上额外压差指标最大0.36282222%。物理数值通过，三档工艺都失败：新名义干燥余水0.13602805%仍高于0.1%；历史0.13505646%保持为旧物性结果。原值近零负库存/熵项保留在声明数值库存预算内，无裁剪。

批次实际墙钟451.717373s，三次科学调用耗时分别158.180954, 151.217261, 450.775674s。首次在积分前因旧cp_slope元数据引用退出，失败原样保存；一次修正原机制案例和固定参数列表后通过。没有全周期重试、调容差、参数搜索或原始场落盘。

Calcite来源只到1200K；超过此温度按根明确声明作assumed多项式外推。新名义采样中有936个单元时刻超过上限，最高1223.149996K，此区最大单元calcite库存3.582e-20mol。库存很低不是外推准确性的证明，特别是反向反应亲和力仍依赖纯相性质。其他五种本项来源覆盖当前采样温区；采样不能证明节点间所有时刻。

P17复用同次轨迹登记温度、孔隙、应变、黏度和相态范围。当前名义气孔率0.192190–0.495189，永久压缩应变最大绝对值0.0067994，有效黏度最小1.3032e11Pa*s。正孔体积不证明连通；轴向黏度不可直接等同公开球孔模型的玻璃VFT。已有Wadsworth失败不重算、不用经验尾段掩盖闭合；本范围不新增整窑、裂纹、完整相图或闭孔机制。

同一DTU黄黏土参照圆片的三称量关系完全闭合：开孔率0.33600256、干密度1815.7520kg/m3、烧后干基吸水0.18471562kg/kg。它们共用三次称量，不能视为三个独立预测成功；表头m105的公式实际引用烧后质量，已留单元格证据。完整热历史/闭孔/几何SI声明缺失，因此不冒称重现该圆片。模型强度/缺陷/吸水指标保留为未校准代理，不能认证产品。

## 实际调用与严格二元极限

当前非零孔阻力分支直接在 `transport()` 中逐对交换，并不调用旧 `molecular_transport()`。以总体几何截面积 A 定义 J（mol/s），j=J/A；孔气浓度 c=P/(RT)=Σn/Vp（mol/m³孔气），不是 Σn/Vbulk。

设 χ=φ/τ，Dfree=fij Dref(T/Tr)^b Pr/P，Ki=χℓ√(RT/Mi)，Kij=2/(1/Ki+1/Kj)=χκij，则

```text
Dpair = χ / (1/Dfree + β/κij)
Ji = A Dpair c/d × (yLi yRj − yRi yLj)
严格二元归一：yLi yRj − yRi yLj = yLi − yRi
等温等压：ji = −c Dpair (yRi−yLi)/d → −Dpair ∂ci/∂x；jj=−ji
```

因此实际 Dpair 恰是这一定义下的有效 Fick 系数，没有额外2或组成因子；该有限面组成恒等式不要求小组成差。等压使Darcy项为零。内部面d=(wL+wR)/2，外面d=wL/2，w=Vbulk/A；ℓ是由原孔径和孔体积演化得到的长度，不是d。D和K均m²/s，ADc/d为mol/s。

φ/τ在D和K中各一次，整理后的Dpair整体仍只有一次χ。若改用整体体积浓度Ci=ni/Vbulk=φci，则ji=−Dpair ∂(Ci/φ)/∂x；只有φ恒定时可把Dpair/φ当作针对∂Ci/∂x的系数。

自由比较使用Dfree，不能在保留β后只除χ就称自由系数。此次只调用现有gas_diffusivity并去除返回的χ、乘原pair factor；不改变名义β=1，不把完整host设φ=1（Darcy式奇异），不把其余两种气体置零运行对数熵项。β=0旧分支和β→0当前分支语义一致；有限β时，即使factor都为1，各对孔阻力也因分子质量不同而不同。四组分pair求和不等于完整Maxwell–Stefan方程求逆。

上述为沿实际调用的纸面推导；旧PAIR_DIFFUSION和PORE_GAS已有二元极限/零β算术，不重复运行。

## 已知、未知与是否改核

限定六文件缓存和相关报告中，没有可直接对应的一手二元扩散实验点。NIST缓存是纯气体物性/黏度表，引用中的二元混合物黏度也不是二元扩散。旧LJ O₂黏度对照失败不能证明D失败，也不能转嫁给已经修正的P20黏度。

三对H₂O相关扩散仍未知；GRI有水偶极输入不等于现有零偶极模块适用。本次不套用非极性数据。真实孔阻力、壁面行为、多组分准确性和目标砖性能亦未由本对照获得资格。

当前发现的是来源模型之间的有限差异，没有已证实的量纲/接线错误，也没有实验不确定度或已约定的来源误差门槛。因此本P22不替换公式、不拟合factor、不改物理核。可考虑的后续候选是仅用既有LJ来源曲线替代三对pre-pore Dfree，以减少对该指定来源模型的差异；先明确>1200K、插值复数导数和水源边界，不能称实验精度提升。

若以后实施该候选，最小受影响核查为复用18缓存源值、必要的成对/孔阻力接线同态核算，再做原名义/半步/双网格各一次，共3完整前向，沿用根单例预算与0.1%/2%门槛。P22没有运行这些计算，也没有授权第二批UQ；P21统计只属于不变的d5fd9a2，不能悄悄升级或追加。

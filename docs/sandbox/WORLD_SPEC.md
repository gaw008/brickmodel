## 空间、库存与初态

对象是已成型的单块板状砖坯或孔砖壁段的半厚度。中心对称面通量为零，外侧具有显式炉气、炉壁、气氛和压力边界。侧向均匀是模型假设，复杂整砖与整窑流场不在本模型空间域。

实际积分器保存每格各物种的总摩尔数 N_i,k（mol）及总内能 U_i（J），均为广延量。未来固体、液水与气体沿用该库存基准；烧结/力学内部变量另列。参考体积浓度只能由 N_i,k/V_i,0 派生，当前气体浓度只能由气体库存除以当前开放气体积派生，不能直接累加到库存。通量进入积分器前转换为跨整个共享面的 mol/s、J/s；体积源先乘实际适用体积。早期参考体积状态提案没有用于当前积分器，本条据实际代码明确统一基准。

初始干料、自带水、成型额外加水分列。元素分析、氧化物分析、矿相、LOI 和近似分析是不同数据，不相加成为一个组成表。XRF 不唯一决定矿物相。

## 相容几何

采用参考半厚度 L₀、面积 A₀ 与均匀参考格。每格有法向伸长 λₙ,i，所有格共享面内伸长 λ∥：

`J_i = λₙ,i λ∥²`；`Δx_i = λₙ,i ΔX_i`；共享面面积 `A = A₀ λ∥²`。

固相体积和闭孔体积从 J 中扣除得到开放孔体积；再扣液水占据体积得到开放气体积。开放气体积为零或负时停止该定义下的计算，不能截到小正数。`geometry.py` 已实现该运动学和域检查，尚未提供真实烧结率或闭孔转换本构。

## 能量与物质交换

所有物种在相容参考态下定义包含生成能的 `u(T)`；理想气体满足 `u=h−RT`，其中 R 必须与状态方程一致；纯水真实流体满足 `u=h−pv`。总储能为各物种内能之和，加上世界实际保留的弹性和界面能。凝聚相、自由水与伪组分均需各自有依据的热化学；纯气体表不能填补这些缺项。

反应或蒸发改变物种库存后，在保持本步能量账本的约束下反解温度。已经在物种能量中表达的反应热/潜热不得再以显式热源计入第二次。

同一内部面仅计算一次：

`F_E = F_conduction + Σ_k(h_k F_g,k) + h_liquid F_liquid`。

对两侧单元使用严格相反符号。流入载气、氧气、水汽的焓同样计入。边界热由实际面积上的对流和灰体辐射组成，炉温与砖芯温度分开。对流体积输运采用上风焓；扩散焓采用同一面状态定义。

机械功与形变一致，由相同应力/边界约定给出；一般不能以每格孔压乘总体体积变化冒充全部功。只有证明均匀压力等特定简化成立时，才使用 `−p_ext dV/dt`。任何被忽略的储能或功须有独立量级依据；当前尚未完成全耦合能量闭合。

## 化学、热湿、气体与烧结

热解在无氧下仍可发生；残炭氧化消耗局部真实氧库存。每条路径的计量、产物分配、动力学和物性温区必须共同有依据。产物缺失不等于零排放。

气体包含必要载气，使用孔内气体积求浓度、分压和总压。起步的输运近似为质量平均扩散修正加 Darcy 压力流，适用性须检查连续介质、孔尺度、稀释/混合物和层流等假设。不得同时叠加已经包含粘性流的 DGM。压力必须反馈流量。

液水迁移、吸附/毛细水、蒸发凝结由材料支持的本构决定。缺少有效输运或相平衡数据时保持缺项；不能使用任意 Arrhenius 脱水率。气相扩散不能单独代表全部湿坯干燥。

新增的纯水化学势采用明确的混合近似：液相保留IAPWS真实纯水，气态H2O使用固定R的理想水汽热量桥；共同能量偏移与native熵参考不重复变换。固定标准压力1bar下，气体熵为s0(T)−Rmix ln(p_H2O/p0)，用两相mu=h−Ts相等求peq。该peq不是原生IAPWS真实蒸气饱和压：八温点独立对照显示500K约低11.24%。这一定义只提供相容的平衡驱动力，不提供泥中活度、毛细或相变速率系数，也不将可计算温区当作材料精度保证。

烧结率、开放/闭合孔分配、连通性、渗透率及冷却力学须共享材料身份和几何。液相分数、液相黏度、致密化速率是不同关系。无完整数据库覆盖时不生成任意液相曲线。

## 数值、边界和失败

采用有限体积共享面交换；所有化学源由同一反应进度乘计量矩阵得到。时间积分同步推进库存、能量和对应交换账本。网格、容差、步长是数值政策，不能伪装成材料参数。

不能通过无记录 clip、库存归一化、倒算边界热或改初值通过审计。候选进入未知物性域、失去气孔、耗尽所需反应物或求解失败时，保存实际状态并区分原因。时间区间结束但某诊断事件未达到，也必须明确记录。

强度、裂纹概率、合格判定等输出各自需要证据。模型可以给出有依据的状态量；未知性能为 unknown，不参加合格排名。单位砖净输入热不等于整窑燃料消耗。

原终端时钟、修正预算及事件/共同时间的 N/E/T/P/时间门槛保持。两个连续终端比较通过后，还必须从相同事件搜索根独立计算普通步长上限和实际安全库存比例均减半的路径，要求真实普通网格不同且原全部门槛通过。独立路径不参与最终提交；不通过时保留失败与已提交前缀。此检查仅覆盖局部接近误差，不替代整条轨迹的独立细化与公开实验验证。实际计算和复用分别计数。任意制造回调需显式确定性合同才能启用复用；该合同不是对任意 Python 副作用的自动证明。默认 `nested_approach=None` 保留原算法。

## 数值策略：液态/气态水 TP 密度求解的有界回退

`NUM-HEOS-TP-BACKTRACK-1` 保留同一 HEOS 状态方程、参考态、域/分支/来源守卫及最终完整状态检查。最多八个接受的密度状态；每次更新先核原完整 log-density Newton 步长，再从同一基点尝试 1、1/2、1/4、1/8、1/16、1/32。只有实际评估满足原动态门槛 `abs(p_native-p_target) <= min(1e-4,rho*1e-7)` Pa 或严格降低该归一化残差，才接受为下一迭代；仅降低残差不允许返回物性解。最多43次密度评估，已评估的接受状态直接复用；不增加第九个接受状态，不改压力目标、不平均 h/u/s。停滞和全部候选不改善明确失败；原无效状态/来源错误仍终止。诊断保留每次实际尝试及未能获得字段的原因。此项是数值政策，不是污泥材料本构或实验验证。


## NUM-AFFINE-TERMINAL-1：二阶耗尽末端数值策略

可选 `terminal_method=affine_midpoint` 从当前湿态以实际可表示中点时距 hm 构造 Euler 预测，获取一次真实源绑定速率。对每一项库存通量、反应、热流和机械功统一积分 `h*r0+h²*(rm-r0)/(2*hm)`；其多项式只定义局部数值近似，不是新增材料本构。以不可变 Fraction 二次库存证书定位首个严格下降根，选择最近的向下 binary64 端点，逐项检验账本与根时间上界。全部库存检查区间端点及内点极小值，其他活动液相不能提前耗尽；中点、源身份、取消或域检查失败均不提交事件。蒸发诊断对有符号线性相变速率的正部精确分段积分并向下取整，原相修正预算保持。

原 Euler 模式仍是默认。两次末端收敛、配置的独立普通网格细化和原比较/资源门槛保持；新方法尚须实际联合轨迹与完整回归，不由解析控制通过自动升级为材料验证。初始普通路径误差必须另行检验；局部事件比较无法证明其之前的共享积分历史精度。

## 已实现的多格共同横向形变约化分支

`FreeSolidSlab`当前以(N_i,E_i,n_i,t)作为实际动态状态。总能量E含热内能与既有制造弹性/界面能；各格压力由当前几何同次反解，再全局求共同t_dot。异质格的切向约束功C_i=2V0_i R_i t_dot逐格进入E账本，虽sum(C_i)在数值预算内为零，却不能删掉各格C_i。恒外压、封闭且外绝热时，整体sum(E_i+pe V_i)不变。完整定义、边界近似与实现见`FREE_SOLID_SLAB.md`及`research/free-slab-v1/MECHANICS.md`。这是固定固体、制造本构的约化相容模型，尚不授予真实材料、完整三维侧面牵引或全周期资格。


## 固定球形公开实验的程序热边界

球形几何是公开球形试样的验证域，最终板状砖坯全周期仍为必需目标。`ProgrammedSolidFluidHeat`复用传热主机的外面面积与半壳导热阻力，将对流/灰体辐射和格内温度闭合于同一无独立热容表面；导热流与气体供体焓分别进入原共享面账本。方程、灰体环境定义、退化情况及独立解析极限见[RADIAL_HEAT_GEOMETRY.md](RADIAL_HEAT_GEOMETRY.md)。移动板状主机继续传入当前构形transport，不以参考几何计算边界。

此接线不新增材料参数，不代表Nylen MSJ/CB原泥准入。球形径向液体输运及自由/规定球形变形仍未实现；纯水相变与多孔原泥吸附热的相容性必须单独建立。实际测试与支持范围以阶段报告为准。


## 来源质量比热与固定组成能量坐标

`ArlabosseMassCaloric`复用原35–105°C干基Cp与解析Δh。仅在显式恒组成、不可压缩且比容不随温度变化的近似下采用Δu=Δh；刚性容器本身不证明Cp=Cv。`FixedMassCaloricStorage`固定正干质量与域内参考温度，使用相对u(T0)=0，身份绑定质量/参考/来源/无反应选择。不同参考目标必须同步平移，绝不赋予绝对形成焓。反解使用整个源温区的最小名义热容与精确Fraction运算；源拟合和本构近似误差仍未知。float输入是其精确binary64值，Decimal/Fraction可表达精确域端点。

`ReactionDisabled`只表达本阶段不发生化学转化，输出按明确kg固体/mol气体布局的零化学源，不禁用独立液汽相变。此版本只有干物point，无固体质量迁移、湿容积闭合或完整反应网络；真实湿格接线须另保留水液汽参考、机械体积与来源不确定性。具体证据见[source-mass-caloric-v1](research/source-mass-caloric-v1/REPORT.md)。

# 精确事件时间与边界程序

实际四格试算的第二次液水耗尽因绝对浮点时间取整残余而超出原修正比例门槛，见 [失败诊断](research/ordered-packet-failure-evidence-v1/README.md)。本模块为一致的精确时间求解路径提供时间和程序原语；尚未让原生耗尽求解器通过。

`ExactEventTime` 以一个规范化 `Fraction` 秒值作为语义身份。不同原点加偏移构造的同一时刻具有相同的比较、哈希和记录；时间差使用精确有理数。显式 `from_float` 采用输入 binary64 的准确有理值，不把它改为其十进制字符串代表的值。

`display()` 只提供用于显示的浮点值及有符号投影误差；溢出时明确不可显示。两个时刻可以显示相同而语义不同。显示值不能送回求解器替代时间身份。本类型不提供隐式 `float()` 转换。时间及区间的版本化记录拒绝布尔、浮点分子/分母、非规范分数、非正分母、额外字段及倒置区间。

`ExactProgramView` 显式适配现有已校验的 `ScalarProgram` 或 `BoundaryProgram`。它以精确时间选择区段并计算线性权重，最后才把物理量输出舍入为浮点数；保留原组成校验，不偷偷归一化。整个程序可以按声明的有理秒数平移，原始程序保持不变。后续运行身份必须同时绑定原程序的完整定义和这个平移量；返回的原 `ProgramIdentity` 只表示来源身份，不能单独当作平移后运行的完整身份。

独立案例验证：显示同为节点的左/右时刻选择不同区段、准确节点命中、完整程序平移、凸组合列值、内部节点不包含区间端点、严格编码与显示溢出。源码及安装后各64项相关测试通过；69个实际安装模块与源码一致。原程序接口未修改。

下一步必须把这些时间语义接入阶段查询、全部求积端点、库存/能量/形变账本、事件根与比较、取消/资源预算及新记录/续算。不能只换根定位器，再把不同积分时长标记为旧浮点时刻。证据和审查见 [exact-event-clock-v1](research/exact-event-clock-v1/README.md)。这属于数值策略，不新增材料物理参数或扩大材料适用域。

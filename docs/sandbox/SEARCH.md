# 多代候选搜索

搜索在明确的输入域内生成候选、求解、检查目标与约束，再从已核查候选选择下一代父代。当前域只支持manufactured_verification；示例不是原污泥配方，也不输出产品合格结论。

每代包括父代和各因子的正/负坐标邻居，步幅按冻结的比例递减。越界点明确省略，不通过截断变成其他点；重复点不当作新信息。所有未改变的原料参数、网格与数值策略保持一致。记录父代、实际变化、全部候选失败、选取依据及停止原因。相同目标值保留父代；最小改善量和停滞代数是搜索策略，不是实验误差或产品标准。

目标必须来自已有可查的状态指标，方向与单位明确。约束是用户声明的设计筛选条件；例如样例的压力上限不等于材料破坏压力。计算失败、未取得结果、违反设计条件、未改善分别记录。未知强度、裂纹概率、材料合格率不进入评分。

全部代次与继续调用共用最大尝试数和活动wall预算。新一代只得到剩余额度；取消后继续原实验，不能重建以重置预算。运行时代码、来源、变量范围、目标、约束和策略冻结。无法核实的中断不根据保存PID擅自恢复。

在仓库根目录安装当前包后：

```sh
sludge-sandbox search-prepare data/sandbox/search/initial-temperature-search-v1.json --water-data data/sandbox/water --evidence-data data/sandbox --output /tmp/brick-search-new
sludge-sandbox search-run /tmp/brick-search-new
sludge-sandbox search-status /tmp/brick-search-new
```

运行时按Ctrl-C提交协作取消，再次search-run继续。完成一次有限搜索不证明存在全局最优点；模型或来源升级应新建搜索。当前单目标坐标搜索不等同完整多目标/Pareto、不确定性传播或真实材料优化。

示例只在300至301K之间改变第一格初温，第二格初温保持301K，最小化末态温差。这是检验多代父子选择的简单制造实验；不能据此推断实际烧成能耗、最优配方或质量提升。真实材料及全周期验收仍按原Goal推进。

实际两代运行和选中候选时间细化已完成，见 [验证证据](research/search-v1/README.md)。源码与安装各132相关测试通过，五次搜索求解和一次独立复算均正常回收。完整来源、轨迹、父代关系、预算与独立账本随证据归档。

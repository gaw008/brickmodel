# 显式共享参数族的事件比较

本实现将 [条件成对压力比较](PAIRED_PRESSURE.md) 接入自由形变耗尽事件的终端比较及独立细化比较。默认策略仍使用原独立点误差公式。新分支的科学含义是：在各路径报告温度下，已明确声明的固相/参考体积常数误差属于同一个共享参数盒。它不提供包含温度反解误差的联合温压保证，也不是原污泥材料验证。

## 输入与执行

Python 的 `DepletionPolicy.pressure_comparison` 可显式持有 `PressureComparisonPolicy`，包含全部单元、顺序固定、实际来源绑定的常数盒。缺省为 None，编码时省略，保留旧默认格式。

案例保留 `sludge_sandbox_free_event_case_v1` 根类型，将 `numerics.depletion.schema` 设为 `sandbox_depletion_policy_v2`，新增：

```json
"pressure_comparison": {
  "schema": "manufactured_shared_constant_reported_temperature_v1",
  "constant_box_declaration": "all_actual_declared_constant_volume_errors_are_shared"
}
```

这是明确采用新假设，不能自动添加到旧案例。案例已有物理数值及绝对误差不变；构建实际算子后才生成并绑定完整盒。若把含案例来源哈希的盒身份直接放回案例文件，会产生自引用，因此声明与运行时完整身份分开存储。只验证输入结构时的临时政策不用于执行；执行前必须有实际算子。

每个事件/共同终点保留当次解码的实际总储能反解，比较时不重复解码。所有单元均计算，取全体单元及事件/共同终点的最大界。原压力诊断与原温度/压力误差保留在记录中。取消/资源检查发生在每个端点调用前后；尝试计数在调用前增加，成功计数在返回后增加，失败调用仍计入累计尝试。未通过完整比较的分支不提交。

## 保存、审计与续算

新运行使用 `sandbox_depletion_result_v2`；旧默认仍为 v1。每次比较保存双方状态、实际闭合内容、全部单元的根区间/温度/原误差、完整端点样本及有理证书。审计核对：

- 实际算子派生的完整参数盒、来源、域、组分顺序和模式；
- 库存、当前几何和独立体积误差的重建，以及端点值转换；
- 证书算术与所有单元覆盖，原观察误差数组/名义差及 N/E/伸长差；
- 相邻细化分支复用、独立细化以及选中状态与提交轨迹关联；
- 端点完成数不超过尝试数，细化成本不超过累计成本。

数据审计不能重新证明真实 EOS 输出或 E→T 反解的物理正确性；来源身份和代数一致性不等于独立实验验证。续算重新审计原记录并绑定原完整政策，禁止中途变换误差族或重置成本。

## 验证状态

独立审查关闭了实际 WaterState 序列化形状不匹配及样本数值类型漏洞。安装后的 140 项相关检查通过（8.67s），65 个实际安装模块逐一与源码匹配。旧 v1 编码对同一实际制造轨迹保持 29,705 字节完全相同。控制流替身测试只用于验证取消、成本和快照连接，不能替代真实物性验证。

真实两格初态邻居探针：各格转移 2^-40 mol 液水到水蒸气，精确保持总水、能量与机械状态；完整 helper 比较和生产数据审计通过，8 次端点调用完成，最大条件界 3.7403908677e-5 Pa，原门槛 1e-4 Pa，耗时 3.18093s。

实际事件实验已完成（监督进程 exit0，352.383s；积分 348.660s）：原起止 0.5→0.50032s，30 个接受步骤、592 次算子评估、70 个包含弃用分支的试验 panel，24 次端点尝试全部完成。单元 1 于 0.5002686445571594s 耗尽，单元 0 于 0.5002848875613792s 耗尽，随后两格继续推进至原终点。每个事件均通过两次连续终端比较及独立细化比较，原六项门槛和修正政策不变。

新的最大压力差界 5.1791364410e-9 Pa；同一记录保留的原独立界约 0.005135/0.002784 Pa，仍高于 1e-4 Pa。成功只对显式新误差族成立，不把旧失败改判为通过。

生产完整记录审计通过。另经独立审查的标准库 Fraction 脚本实际重算所有接受前缀：最大 N 残差 5.58089e-16 mol，局部 E 残差 7.62853e-11 J，伸长残差 3.84743e-16；全局 E+peΔV−面能流−body 最大残差 9.99128e-11 J，约束功跨格和的累计绝对值 1.29891e-20 J，均通过原先登记的 2e-8 J 目标。蒸发总量与两个修正比例从实际保存的速率独立重算。恒定外压功检查包含数值截断误差，不冒称解析恒等式。

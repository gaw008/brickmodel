# 自由收缩案例与应用入口

新增 `data/sandbox/cases/reacting-wet-free-slab-v1.json`，模型ID为 `manufactured_reacting_wet_free_slab_v1`。机械初态包含逐格法向伸长与一个公共切向伸长，外部机械压力独立设置；没有规定伸长历史。当前案例的物性、动力学和骨架仍是明确制造参数，不具备真实原污泥材料资格。

严格配置读取、CurrentSolidStorage/FreeSolidSlab 反应模式、守恒初始能量和完整机械状态已连通。细网格继承父格伸长，库存和能量按体积分配；组成系数使用 beta/V0、微界面面积使用面积密度乘V0，新增父格额外误差也按子格数分配。非零 B 与均匀场补测证明这些构建规则，不代表空间轨迹收敛。

自由模型使用独立方程目录：20个方程、7个输出入口。温度、压力、库存、能量、完整机械向量、当前几何和自由力学诊断均能追到实际源码与参数。运行、重放和续算按案例选择目录，保留完整运行版本和封存校验；未知模型被拒绝。既有规定形变目录原始字节保留。

界面新增法向伸长（每格）和公共切向伸长（一个全局量）。切向不伪装成额外单元或空间分布；追查返回完整机械向量及原始结果位置。JSON编辑器可载入新案例，默认旧案例不被静默替换。界面脚本和API回归通过，尚未进行本阶段实际浏览器渲染验收。

真实水后端案例完成2步15次评价，耗时16.59秒；反应、两格蒸发、水蒸气扩散、传热和自由形变共同活动。独立逐步审计最大库存残差9.89e-17 mol、局部能量2.33e-11 J、全局外功1.46e-11 J。重放状态与账本逐位一致；在一个接受步后取消并续算，原前缀完整保留。

安装后93项计算/服务测试、22项本地接口测试、8项Node界面测试通过；61个实际安装模块和静态资源核对一致。首次本地接口测试受沙盒端口权限阻止，原错误和获准后的回归记录均保存。全部证据见 [research/free-case-app-v1](research/free-case-app-v1/README.md)。

本案例的约15微秒轨迹用于联合实现验证，尚不是完整烧成。下一步必须完成实际空间/时间细化、有限供氧/液体面流/耗尽组合、真实原污泥证据与三机制公开留出、全湿坯到冷却流程；Goal完成标准不变。

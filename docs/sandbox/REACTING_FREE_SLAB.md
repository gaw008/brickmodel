# 当前组成、反应与自由形变的耦合

`solve_free_slab_rates`和`FreeSolidSlab`现在具有显式`reacting_manufactured`固体库存模式。点存储、主机与速率必须采用一致模式；主机还要求独立的`reduced_common_tangent_quasistatic_reacting_manufactured`机械声明。原固定模式、来源守卫和原能量身份保持兼容。

## 同一状态与交换项

当前库存同时进入`q(N)`恢复能、固体占据体积和可用孔体积；总能量反解提供每格实际温压。反应配置重绑到本次当前存储后，再使用原共享面/反应装配器；二阶体积反应源明确使用当前单元体积，不能沿用参考体积。

制造本构将参考势、应力和黏性关系均乘以当前`q(N)`。自由速率的有效黏度因此为`q(N)*eta_reference`；共同切向伸长速率的分母为`sum(V0_i*q_i*eta_i)`。实现先由实际provider检查完整当前库存，再以精确Fraction构造正分母，保留已有应力区间与速率误差传播；不能只缩放应力或使用参考黏度。

逐格总能量右端保持“共享热/焓面流 + external_traction + mechanical_constraint + body”。组成恢复能导数已经包含在当前储能反解中，不重复作为外部热源。瞬时机械功率关系仍是固定当前组成的形变导数；完整恢复能导数另有组成项，不能混称。无反应网络时库存源为零，仍允许显式研究当前组成状态。

## 实际独立验证

七项新瞬时率测试含120位Decimal应力梯度、不同组成/黏度的Fraction加权分母、`q=1`数值对照和严格来源/域检查。主机测试检查本次真实存储/原始反解对象复用、当前反应体积、无重复热源、库存与能量身份以及动力学温区拒绝。

独立两格干态轨迹采用制造A→B、解析`A=2 exp(-0.1*time)`，初始305/306 K，共同与法向伸长自行演化。参考RHS独立构造初始能量、当前组成热量、孔隙、压力、恢复势、黏度、局部约束交换功及共享导热，不调用生产主机、反应、反解或自由速率函数。参考解逐个接受节点与实际积分比较。

0.1秒内两档实际23/32步，独立审计每前缀最大能量误差1.395e-6/7.266e-7 J、伸长误差3.173e-8/1.652e-8、解析A/B误差1.574e-10/8.058e-11 mol；整体外功残差8.026e-9/4.556e-9 J，均满足原门槛。遗漏局部约束功、错误使用参考黏度的独立负对照均可辨别。完整checkpoint/分量账本检查通过。

失败没有删除：最初300/301 K初态触及动力学300 K下界，返回越域且未接受时间步；另登记域内305/306 K后，粗数值配置虽积分完成，能量误差4.326e-6 J未过2e-6 J门槛。最终仅收紧内部相对误差和最大步长，未改变动力学温区、物理条件或外部精度门槛。瞬时反应体积负对照的第一版几何差异不足1%，另改明确制造几何以保持原1%辨别门槛，原失败也保留。

源码65项回归3.83秒及独立轨迹1项5.16秒通过；非editable安装104项14.01秒通过，61个实际安装模块逐字匹配。证据与两份独立审查见`research/reacting-free-slab-v1`。

## 当前边界

所有固相热量、本构和动力学系数仍明确为制造验证参数。没有宣称动力学与机械化学自由能的真实材料热力学闭合，也没有原污泥材料预测资格。该轨迹无液水、无气体面流，尚未覆盖湿反应与所有输运的联合过程。动态炉程、空间收敛、完整烧成/冷却以及三个机制组的公开材料留出验证仍为原Goal必需工作。

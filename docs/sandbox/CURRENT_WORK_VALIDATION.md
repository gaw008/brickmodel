#### 独立公式推导与实现对应

以下是对所读代码的独立代数核查，单位采用 mol、J、s、m、K。它们证明条件模型局部结构的相容性，不证明本构对真实砖坯准确。

1. **导热。** `exchanges.conduction_rate_w` 与动态 k 主机采用 `G=A/(dl/kl+dr/kr)`、`Q=G(TL−TR)`。G 的单位为 W/K；两格热熵率 `Q(1/TR−1/TL)=G(TL−TR)^2/(TL*TR)≥0`。这与当前半格串联热阻一致，没有将两侧 k 作不恰当的算术平均。
2. **凝聚水面。** W=kg水/kg干物，`rho_d=md/(A*cell_width)` 使用试件总体积，非流体孔体积。令 `K=A*rho_d*D/(M*ell)`，单位 mol/s；`X_T=1/TR−1/TL`、`X_mu=muL/TL−muR/TR`、`Y=X_mu+hface*X_T`。代码 `n=(Tf*K/Gamma)*Y`、`H=hface*n`，所以两格瞬时熵率 `H*X_T+n*X_mu=(Tf*K/Gamma)*Y²≥0`。同 T/P/本构下 `Delta_mu=Gamma*Delta_W`，回到 `n=K*Delta_W`。Γ 是有单位的 J/mol 干基含水导数/割线；非等温系数和算术 hface/Tf 仍是选择，不能据熵非负声称 Soret 效应真实为零。
3. **低 W 极限。** 两侧 W>0 时 `Llog=(WL−WR)/ln(WL/WR)>0`；加入接点和温差项 C 后，代码等价于 `n=(K*Llog/R)*(R*ln(WL/WR)+C)`。单侧 W→0 时 `Llog→0` 而其对数乘积保留 `WL−WR`，得到有限 `K*(WL−WR)`；无限化学势由命名极限表示。双侧零水采用无交换，不把这当成所有趋近路径的唯一熵极限。
4. **相变及外边界。** 正分压下 `r=Kph*(peq−pv)`、`Delta_mu=RT*ln(peq/pv)`，故 `r*Delta_mu/T≥0`。相变只把相同水从 Nc 转给 Nv。汽口在 cell T 取共同 hv：`nout=Kv*(pv−pe)`、`Hout=hv*nout`；另有 `Qin=Gheat*(Tbath−Tcell)`。储槽同温时汽口熵为 `nout*R*ln(pv/pe)≥0`，热浴项也非负。真空/零库存须按代码明示的极限解释。完整 U 已包含相组成能量，额外添加诊断脱附热会重复计热。
5. **BE 与分步。** 冻结系统为 `Nc'=-a*Nc+b*Nv`、`Nv'=a*Nc-(b+c)*Nv+f`。`det=1+h(a+b+c)+h²ac>0`，代码两池分子的每项非负；`J=h(a*Nc1−b*Nv1)`、`E=h(c*Nv1−f)` 逐项满足 `Nc1=Nc0−J`、`Nv1=Nv0+J−E`。`Delta_U=-hv*E`。随后慢算子只用内部 k/D 与热浴，旧相变和汽口不再累加。两个子步各 h，物理时钟前进 h，这是 Lie 分步；不等于冻结 ODE 的精确指数解或整个非线性系统的无条件稳定性。
6. **列守恒及平衡投影。** `_advance` 的 Nc、各气体及 U 用同一面在相邻格一减一加，相变只在水的两池相消。`equilibrium_transport.project` 先构造 Nt/U 目标，再由 flash 的凝聚水目标确定同一 J，最终写回与 flash 状态对应；有限率 phase 在该路径为零。列总水只减外排，列 U 只减外面 energy 并加有符号投影；将外面拆为 Q/H 时还须计入原分解残差。初始化的局部平衡是零物理时刻的投影，其费用不能再清零或算成1 s排汽。

#### 独立推导及源码对应

以下N以mol计，v为摩尔体积，Vg为气体总体积，R为混合气体常数。固定液量Nl、各气体量及刚性可用体积，且Ng>0；稳定液体满足vP=(∂v/∂P)T<0、Cv>0。推导要求同一光滑稳定支路覆盖所用区间，不能越过相变或失稳点。

1. **机械闭合和定温压力误差。** `G(P)=Nl*v(T,P)+Ng*R*T/P−Vavail`；`−G'(P)>=Ng*R*T/Pmax²=bmin>0`，所以根在支路上唯一。给定液体体积误差εv，`εP=(|Gcalc|+体积算术余量+Nl*εv)/bmin` 是条件根半径；区间全部在声明域内时，连续性与两端符号支持根存在。求解器对数值前向函数的二分括区本身不包括EOS误差。可用体积误差εV先以εV/bmin作全域包围，再用包围内P上界收紧；这与`wet_fluid_pressure_bounds`的顺序一致。纯气体支路不使用液体EOS项。
2. **刚性闭合热容。** 令`A=Vg/T+Nl*vT`，`B=Vg/P−Nl*vP>0`，则`P'=A/B`、`Cclosed=ΣNi*Cpi−T*A²/B`，对应`RigidStorage.evaluate_at_temperature`。对每个有正库存的可压缩成分令`ai=Ni*vTi`、`bi=−Ni*vPi>0`，由`Ni*Cpi=Ni*Cvi+T*ai²/bi`及Cauchy–Schwarz不等式，得到`Cclosed=ΣNi*Cvi+T*[Σ(ai²/bi)−(Σai)²/Σbi]>=ΣNi*Cvi`。丢弃稳定液体的正Cv贡献仍给下界，所以代码的`Σgas Ni*Cv_lower`在全域气体下界成立时有热力学依据，而不是仅靠某个点的导数猜测。
3. **干基及吸附项。** 加上`md*min(Cp_dry)`得到来源储能Cmin；当前干Cp斜率为正，325–338K内最小值取低温端。这里干相规定不可压缩且体积无T依赖，因此相对Δu=Δh；没有得到绝对生成焓。吸附包装的`Fex=md*[hex(W)−T*sex(W)]`在固定W时给出`Uex=md*hex(W)`，故规定的额外热容与体积均为零。保留干端常数符合共同能量参考；不能据此证明该吸附近似在实泥中准确。
4. **温度反解界。** 在全域Cmin>0、完整前向U误差εU已知并有有效根括区的前提下，`εT<=(|Ucalc−Utarget|+εU)/Cmin`。当前Newton/二分候选不改变这个条件。给定组成的εT不包括相平衡求解改变Nl/Nv产生的误差，也不包括材料参数拟合误差。`phase_storage`的一般单调路径则由调用方声明下界；有限点的增量检查和`energy_resolution_j`不构成完整物性误差证明。
5. **温度引起的压力变化。** 由`uP=−T*vT−P*vP`得`P'=(P/T)*[1−Nl*uP/(Vg−Nl*P*vP)]`。若全域`|uP|<=Bu`，则`|P'|<=L=Pmax/Tmin*[1+Nl*Bu*Pmax/(Ng*R*Tmin)]`。因此给定组成的反解压力半径为`εP_point+L*εT`。先用全域L确认包围仍在域内，才用局部温度下界/压力上界收紧。这个式子仍不包括组成误差。

#### C04-F01：低W内点的稳定性可推导，完整数值误差不能据此省略

令x为凝聚水mol，Nv=Nt−x，Ng=Ncarrier+Nv，R为当前共同理想气体常数；固定T、V、Nt和载气，0<x<Nt且W<.15。使用与C03相同的稳定液体支路，设液体摩尔体积v、`B=Vg/P−x*vP>0`。低W势函数给出`d(mu_ex)/dx=RT/x`。令`f=mu_liquid+mu_ex−mu_vapor`，则沿机械闭合有：

```text
P_x = (v−RT/P)/B
f_x = RT/x + RT*(1/Nv−1/Ng) + (v−RT/P)^2/B > 0
```

第二项非负，因为Ng≥Nv。第三项来自共享体积/压力响应，不能在刚性孔体积模型中把P当成与组成无关。该式支持**同一连通可行支路内**内点化学根的唯一性及固定T/V时自由能沿水分配方向的严格局部最小；不证明所有温度都有可行根，也不覆盖未访问的域孔、其他材料相或W>.15。Nt=0是无水特例，不能套用含1/x的式子。正总水的理想稀释干端和零汽端采用各自无限化学势极限；数值pressure预筛可能截断这些端点，不能由端点极限反推预筛区间必有根。

进一步，在同一光滑名义Helmholtz势`F(T,x)`内，`F_x=f`、固定组成热容`Cx=−T*F_TT>0`。内点f=0时：

```text
dU_eq/dT = Cx + T*f_T^2/f_x > 0
(d²S/dx²)_(U,V,Nt) = −(f_x + T*f_T^2/Cx)/T < 0
det d(U,f)/d(T,x) = Cx*f_x + T*f_T^2 > 0
```

这给出固定U/V的局部熵最大及局部联立可逆性，而不只是“μ差接近零”。推导建立在理想气体/液体/超额势的连续名义表达式上，没有调用或声称实现已计算一个认证的总熵。

数值上的缺口仍存在：当前flash对f使用名义符号，对能量只扣给定组成前向误差；小组成括区和小温度括区没有包含化学势/对数误差及组成传热。固定T有`U_x=f−T*f_T`，所以即使f接近零，组成误差仍可能通过`−T*f_T`改变U，不能删掉这个项。全局`|U_x|`、化学势误差和组成界须先有证据，才能传播到温度；C03的气体Cv下界与本轮正曲率不能替代它们。原三个完整误差字段保持unknown/null。

### C05-F01：计量和速率量纲成立，基准不能直接替换

`reactions.py`用有理计量数核对原子守恒，并单独用声明摩尔质量核对相对1e−12的反应质量残差。运行时计量矩阵和库存是浮点数，不能因此声称全轨迹精确守恒。`source_ids`只登记候选来源，没有自行证明物种/产物/参数适用于真实原料；源码始终保留`material_qualified=False`。

实际进度率为：

```text
r_j [mol/s] = Vbulk * A_j * exp(-Ea_j/(R*T))
             * Π [(N_i/Vbulk)/c_ref]^order_ij
Ndot = ν r
```

A的单位是mol/(m³·s)，各幂因子无量纲；不是常见的所有反应阶数共用s⁻¹前因子。实际`SolidReactionConfig`传入整个单元bulk体积，不能换成孔隙气体浓度、气体摩尔分数或固体表面活度后仍沿用原A。所有消耗物种均需正反应阶数；耗尽物种使相应正向率为零。这只定义一类现象速率近似，不涵盖所有机理。负表观Ea本身不构成错误。

库存步长上界按各物种的**总消耗**计算，不用其他反应的同时产出抵消；进度更新也不裁负值。该界只限制冻结反应率下的库存消耗，不能当作温敏动力学的稳定性/精度界。结合保存解析结果可以确认这一制造例的行为，不能把它提升为任意反应网络的证明。

### C05-F02：第一定律的账本正确，不足以保证第二定律

`solid_reactions.py`把反应物种绑定至同一个实际相provider、同一摩尔质量和能量参考；`solid_fluid_heat.py`组装库存反应源时，`cell_power_w`为零。`integration.Rates.derivatives`实际采用`Ndot=左面-右面+反应源`、`Udot=左面能流-右面能流+外功`。化学形成能已经在U(N,T)中，封闭绝热刚性反应改变库存后由原U反解T，不能再把`−ΔrH*r`加一次。

固相恒定摩尔体积近似也与参考态一致：`u_s(T)=h_s(T,p0)−p0*v_s`、`h_s(T,p)=u_s+p*v_s`，因此定组成`Cv_s=Cp_s`，不能像理想气体那样减R。`solid_fluid_storage`从bulk体积扣除当前固相占积后闭合流体压力和总U；这依赖明确的不可压缩、无热膨胀假设，未证明真实砖中相体积/相稳定性。声明的u/v误差依旧没有独立材料认证。

但反应率只依赖反应物库存、T和bulk体积，没有产品化学势/逆反应或亲和力输入。对局部热力学可定义、封闭刚性且无其他耗散的系统，由基本关系独立推得：

```text
dU = T dS - P dV + Σ μ_i dN_i
σ_reaction = -Σ_j (Σ_i ν_ij μ_i) r_j / T = Σ_j affinity_j*r_j/T
```

亲和力的符号定义与[IUPAC Gold Book](https://goldbook.iupac.org/terms/view/A00178)一致。由上式作出的审查推论是：如果某允许组成处`ΔrG_j>0`而对应正向率仍大于零，单独该反应就给负熵产生；配平和总U守恒无法排除这种情况。当前没有完整μ数据/反应域证据，**未对保存轨迹计算熵，也未声称这些轨迹实际出现负熵**。不可逆近似可以用于有依据的远离平衡范围，但现有代码不能据此声称全域遵循第二定律。此为后续实材反应准入的具体缺证据项，不能用人为截断、换标签或制造熵参数来关闭。

### C05-F03：kg伪组分参考能量的可辨识性处理正确，仍是制造桥接

`reaction_reference.py`以kg组分/kg反应进度表示B，各列满足总质量与元素质量守恒；q为产物减反应物的J/kg进度，解`Bᵀh0=q`。若存在反应循环`B c=0`，已知热效应必须满足`c·q=0`；缺q不是零。特别解中自由坐标取零只是表示方式，只有对所有剩余零空间方向不敏感的线性组合才可称已辨识。此处精确一致性是名义数值的代数结论，未包含文献量热不确定度。

`mass_storage_bridge.py`的首个桥接要求完整锚定，并将气体锚连到同温压的实际provider；没有伪造伪组分摩尔质量。制造反应只限A+O2→2B的kg布局，其速率为`k*mA*NO2/Nref`，O2由kg/s除摩尔质量回到mol/s。`chemical_reference_power_w=q*r`仅诊断，封闭积分只把`external_power_w=0`送入U，未再次加反应热。该桥接不能验证实际原泥产物、热值、挥发物组成或任意网络。

`reacting_skeleton_energy.py`的`q(N)=q0+Σw_i N_i`是显式制造关系；`∂E/∂N_i=w_i Eref`属于储能导数而非外功。本段只核对该缩放代数，底层几何/应力/总能主机留给下一段，故仍列部分审查。

# 自由模型的空间与时间细化研究

本阶段把严格自由模型案例扩展到2/4/8格，规定形变模型仍只允许2/4格。物理域保持半厚度0.02 m、参考面积0.01 m²；没有放大扩散率或修改初始阶跃来制造可见收敛。界面按模型更新网格选项，载入8格后不会再因空选项被转成0格。

八格初始化检查包括每父格分成四子格后的库存/能量守恒、9个机械状态、实际面位置、非零当前B的q(N)、界面能和父格误差缩放。这些是构建与分配检查，不能单独证明空间轨迹收敛。

实际案例时间区间仍是0.5到0.5000152587890625秒，即15.258789微秒。研究副本将每格库存、能量绝对容差及对应误差尺度乘2/cells，机械伸长容差保持不变。每个空间网格分别运行粗/细时间上限，保存实际接受网格、拒步与原始账本；源版本和案例ID差异明确记录。

4格粗时间运行32.52秒，4格细时间运行53.14秒；分别2/4个接受步、15/29次评价。8格粗时间运行58.90秒，2格细时间运行26.49秒。8格细时间运行106.55秒；六组全部完成，每组粗/细实际2/4步及15/29次评价。最后两组使用实际非editable安装包。

已有2/4/8格中心材料平面的热量及水蒸气交换积分近乎逐次翻倍，当前初始界面尚未空间解析。名义扩散尺度sqrt(D·dt)约0.391微米，而8格参考宽度为2500微米；这个量纲估计不替代耦合方程的误差证明。4格粗细时间输出温差约5.8e-12 K，低于配对反解误差界约8.24e-8 K，不能据此声称已达到该温度精度。

这里报告的是制造参数联合模型的数值研究。真实原污泥材料、公开三机制验证以及完整湿坯到烧成冷却的要求仍未完成。


统一审计按参考父格限制广延量、按参考体积加权温度，公共切向独立比较。时间细化后的2→4与4→8格父格温差分别为1.52254e-6 K和3.04496e-6 K，后者增大约一倍；两者超过可用时间变化及反解界的10倍门槛。因此本研究明确不支持当前网格的空间收敛结论，也不把计算完成冒充验证完成。

安装61项Python回归和11项界面脚本测试通过，61个实际安装模块及静态资源核对一致。完整六组输入、状态、分项账本、原始失败、来源版本和独立审计见 [research/free-spatial-study-v1](research/free-spatial-study-v1/README.md)。后续应处理真实相态事件及更长物理时间，并继续解决原污泥材料证据缺口；不通过修改扩散率或放宽门槛消除本次不收敛发现。

# 刚性固定液库存流体腔的共享面热/气体输运

本阶段仅连接固定几何、平界面液水与完整理想气体的储能/机械闭合和共享面热/气体流量；没有液水迁移、相变、毛细或固相，不能称完整湿砖模型。

实施前登记测试：两个独立闭合单元每次试探重解 T/P/气孔，密闭共享面各气体和总 U 守恒（绝对门槛 1e-11 mol、1e-7 J），实际积分至少一个两格案例，最大运行预算90s。独立面导热按两个半格串联（绝对1e-8 W），开放边界单气绝热排出检查供体h及 `n Cv dT/dt = R T dn/dt`（绝对1e-8 W）；该极限排除误用内能物流或重复压力功。检查库存顺序、几何、跨格同一气体完整热量身份、R/质量、来源与制造门禁、物性域退出及数值预算失败。测试值属于制造设置，不算材料来源覆盖。

## 输入、状态与实际闭合

`RigidFluidHeat` 明确给出每格独立 `RigidStorage`、气体顺序、液水列 ID、面积/格宽、导热率、各气体扩散率、渗透率/相对渗透率/黏度、各格温度反解括区及其数值政策。实际数组顺序由 `species_order=(liquid_column_id,*gas_species_order)` 给出，库存单位 mol，能量单位 J。首列含义固定为原 IAPWS 纯液水，即使调用者给它一个别名也不能改成其他液体。

`state_from_temperatures` 对每格用真实机械闭合生成 U；`decode_inverse` 在每次调用时从本次实际库存与 U 执行闭合温度反解，返回原始 `ClosedStorageInverse`。`decode` 提供其状态视图。`evaluate` 只解码一次，保存原反解残差、温度误差界/括区，以及每格水/气机械状态、数值 envelope、压力/能量预算和资格；不会将缓存旧温度套在改变后的气体库存上。

在本步组装中液水面通量、反应源项和额外体热源均为零。液体体积仍按当前 T/P 改变，影响气孔体积和压力；气体换格或进出边界后，下一次实际库存重新闭合。纯气温度反解没有被用来代替液水/气体总储能。

几何固定，`available_pore_volume_m3 <= face_area_m2*cell_width_m`；少掉的体积不被本模块自动解释为具有储能的固体或闭孔气体。所有材料传递系数为显式给值，来源/版本/类别必须登记。制造系数或任一制造气体物性均要求额外 `allow_manufactured=True`；来源登记尚不等于真实材料准入。

跨格同种气体须匹配完整热量模型的语义身份（包括源系数/锚/版本）、所选分段、完整 metadata/摩尔质量与 R，不只比较物种名或通用参考态字符串。原 Shomate 和连续派生使用不可变值记录；纯水 bridge 使用模型类型/方法、温区、R/常数源与推导、reference、源资产 hash 和数值政策，不比较独立加载时不同的私有 EOS 实例身份。各格液水参考态和原始资产 hash 也须一致。若需要跨模型气体转换，应另行推导和批准，不能在共享面上默认拼接。

## 面交换与符号

复用既有 `face_exchange` 的质量平均扩散修正及 Darcy 流；复用已审的半格系数串联辅助函数，不调用纯气 `GasHeatModel` 的温度/储能解码。面积、传输距离、两侧半格热阻和面插值权重与原共享面规范一致。气相 EOS 使用本次闭合得到的实际气孔体积和所有气体 mol 库存，P 反馈 Darcy 压差。

每个内部面仅计算一次，正号从左格到右格。每种实际气体的扩散焓用同一面温度、对流焓用实际供体温度；焓函数来自存储模型相同 `gas_phases`，不另添潜热/反应热或流动压力功：

`F_E = F_conduction + sum_k(h_k(Tface)*Fdiff_k + h_k(Tdonor)*Fadv_k)`。

`Rates` 两侧以相反符号使用同一值，液水列严格为零。`FluidHeatEvaluation` 同时返回 Rates、完整反解诊断与气体状态，用户可追查本次实际闭合。

外侧可指定静态完整 `GasState` reservoir，并提供来源 ID；其全物种、摩尔质量和 R 必须匹配。边界气体传输距离为最后半格，携入/携出焓只计一次。另可指定显式物体表面 Dirichlet 温度与来源 ID，以最后半格导热；该温度不是炉气温度。本模块没有把炉温直接当作物面，也尚未连接动态边界程序或表面对流/辐射串联求解。没有设置的外侧交换为封闭/绝热。

## 失败与当前范围

实际物性/机械模型超域（例如稳定水域、明确压力括区内无解、有效温度括区外能量）通过 `DomainExit` 交给积分器。形状/来源/身份错误、条件数值预算不足、方向不确定或数值无法解析保持 `RigidFluidHeatError`，不会将数值失败称为材料不可行。未预期的代码错误不被一般性吞掉。

固定液库存不意味着孔隙液体不影响过程，也不意味着已经实现干燥。这里缺少液水迁移、相间质量传递、固体热化学/反应、收缩、力学和有证据的砖本构。`scientific_status` 为 `conditional_fixed_liquid_rigid_fluid_transport_not_brick`，`material_qualified=False`。原 `DeclaredNumericalEnvelope` 仍是未经独立全域准入的条件合同。

## 实际验证记录

先登记上述门槛并写测试，模块不存在时实际发生 collection error，再实现。首批12项通过（37.13s）；加入两种不同摩尔质量的气体扩散面后13项通过（40.86s）。该双气测试故意使用非字母顺序 B/A，检查液列零通量、质量平均扩散总质量通量为零、每种物种按各自含生成焓曲线携能，未只用单气掩盖列映射问题。

实际两格积分为0.001s、有上限的制造传输案例，初始每格含真实IAPWS液水及制造理想气；液水库存保持，气体库存发生跨格传递、气体压力变化，每个接受状态总气体与总U通过原绝对门槛，每步能量变化与共享面账本相符。纯气开放边界例独立检查绝热排出的降温方向及供体焓公式。这些是耦合数值/解析极限测试，不是材料实验或多格时间/空间收敛结论。

```sh
PYTHONPATH=src .venv/bin/python -m pytest tests/sandbox/test_rigid_fluid_heat.py -q
```

最终完整反解诊断与语义身份修补后的冻结源码，已由独立 reviewer 实际复跑 **16 tests passed in 40.10s**，审查结论为当前限定范围 APPROVE。

另外补充实际物面 Dirichlet 半格热阻测试，以及连续 Cp 派生气体在3000 K外部供体超出其2000 K原域时的真实面焓入口退出测试。`ContinuousCaloricError` 原本继承 `ThermochemistryError`，已有异常分支已覆盖；此为新增覆盖验证，未修补不存在的继承漏接，也未改变域门槛。

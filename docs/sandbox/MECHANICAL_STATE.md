# 自由形变的积分状态

本阶段从 f7bfa7a 开始，把伸长作为显式状态与物质库存和总能量一起推进。`mechanical_stretches` 的前 cells 项是各格法向伸长，末项是共同切向伸长；这只是运动学表示，不是多格力学闭合证明。现有自由牵引本构仍仅支持制造单格。

每个 Euler 阶段、SSPRK2 组合、全步/双半步误差比较和最终域检查都包含伸长。伸长使用明确的无量纲绝对容差和尺度，不借用摩尔数或焦耳的误差尺度。只在完整接受后提交状态及伸长增量账本；负伸长拒步。账本记录求积舍入，原始初态累计审计防止续算重置误差预算。

旧固定几何和规定形变主机明确拒绝自由机械状态；耗尽积分器在事件路径真正同步实现前亦拒绝。单纯库存舍入回写保留机械字段。旧 JSON 记录继续读取，新增字段不得静默丢失，机械前缀须经过同一原始策略的审计。

事前验证方案：解析耦合 ODE、机械误差主导拒步与回滚、取消/续算、字段缺失/形状/正值拒绝，以及自由速率驱动的实际机械轨迹。后者用独立显式能量梯度和 DOP853 对照，初始 n=1.1/t=0.9，结束0.1秒，孔压0，外压分别0/100 Pa；参考 rtol=1e-12/atol=1e-14，伸长误差门槛2e-7、外功能量误差门槛2e-8 J。零外压下总能量严格恒定，恢复能下降。全部为制造参数，不作为污泥实验验证。

仍必须继续：从当前机械状态直接构造孔体积和储能反解，将温压反解、牵引闭合与输运统一到每一阶段；接入耗尽事件、多格相容、服务持久化/UI场景并完成湿坯到冷却验证。不能用本阶段普通 ODE 测试代替这些验收。

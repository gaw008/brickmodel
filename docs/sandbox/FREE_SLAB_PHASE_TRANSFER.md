# 多格自由形变中的水相间转移

`WaterPhaseTransfer`现在显式接纳`FreeSolidSlab`。来源检查读取参考存储中的真实水caloric/chemical身份；速率计算读取本次总能量反解得到的当前温度、液相压力及气体体积。每格源为`k*(p_equilibrium-p_vapor)`，液水与水蒸气等摩尔交换。保留原共享面能流和`external_traction / mechanical_constraint / body`，不另外添加潜热或机械耗散热。

该准入仍要求显式制造测试许可。共享面先拒绝跨格不一致的caloric身份，即使各格使用一致的错误水热量模型，相间转移自身的真实化学桥也继续拒绝。当前骨架、固定固相及动力学/输运系数为制造参数，不能支持原污泥材料预测。

源码实际验证：`tests/sandbox/test_free_slab_phase_transfer.py`四项44.25秒通过。一格300 K、1 mol液水、1e-5 mol蒸汽，另一格301 K、0.5 mol液水、0.001 mol蒸汽，原载气/固体库存保持。总时段1e-4秒，最大步长1e-4/5e-5秒，分别1/2接受步、8/15评价，实际积分13.156/25.099秒；既有精度门槛没有放宽。

两格终温约299.9999733606 / 301.0001927602 K；分别蒸发与凝结。每格每前缀水量残差最大5.407e-17 mol，全局`sum(delta E)+pe*sum(delta V)`最大1.360e-11 J。粗细步长的库存、能量、伸长及温度均通过事前登记门槛；完整checkpoint审计通过。原始JSON、XML、运行前源码身份和失败记录保存在`research/free-slab-phase-v1`。

`tests/sandbox/test_free_slab_gas_transport.py`另用两种相反压差做独立干态瞬时核查：当前面积、体积与半格串联流动阻力，线性面压力/温度的EOS密度，以及Darcy供体焓。错误参考几何和供体密度两种负对照均可辨识。相关35项干态测试0.68秒通过。

湿轨迹物质面流为零，干态Darcy测试没有时间积分。此阶段尚未验证多格耗尽、液态迁移、相变与非零气流的联合轨迹、空间收敛或完整烧成/冷却；这些仍是原Goal必需工作。真实水物性核查不是污泥骨架、动力学或输运参数的外部验证。

非editable安装后的97项测试61.68秒通过，含上述两格实际轨迹和旧单格活动相变；61个实际site-packages模块在测试前后与源码逐字节匹配。独立保存账本Fraction审计另确认局部能量残差1.4291e-11 J、机械累计残差1.1948e-16。

# 当前组成的点储能

`CurrentSolidStorage`增加显式`solid_inventory_regime`：默认`fixed_solid`保留原固定模式身份和数值路径；`reacting_manufactured`要求精确的`ManufacturedReactingSkeletonEnergy`类型与显式测试许可。新模式有独立模型身份及资格标签，不能把它当成实测材料模型。

实际当前固相库存进入组成因子`q(N)`、恢复能、固体体积和可用孔隙。总能量反解在当前几何/组成下扣除恢复能，然后反解热量存储；恢复能数值误差、体积表示误差和扣能舍入继续进入反解误差界。原参考库存仅定义参考势、完整物种集合与归一化，不代替当前库存。误差界条件于表示出来的当前库存，不包含真实组成不确定性或库存积分误差。

组成能量导数不是外部功或新增热源，不重复加入总能量右端。该点接口没有求解固体反应动力学，也没有完成多格自由速率：现有`FreeSolidSlab`在访问固定骨架属性之前，以明确错误拒绝反应组成点。

新增测试在禁止原生水EOS的条件下验证当前组成恢复能、孔隙压力、总能量温度反解、独立界面能导数、完整库存/目标/来源守卫与固定主机拒绝。源码39项3.68秒、非editable安装62项3.84秒通过；61个真实安装模块与源码逐字匹配。两份独立代码/物理审查无阻断，证据与原RED见`research/reacting-current-point-v1`。原旧版本固定数值/身份对照保留于候选阶段，生产回归中的默认对显式固定配置测试不冒称旧版本对照。

下一自由速率必须使用当前`q(N)*eta_reference`，包括共同切向分母`sum(V0*q*eta_reference)`，同时保留固定组成虚功与实际约束交换功。随后才能接当前反应源与完整温度/组成/几何反馈；本阶段不代表真实原污泥动力学、全周期或公开实测验证已完成。

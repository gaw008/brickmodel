# 原湿态的较长时间验证

本阶段保持原两格300/301K初始阶跃、物种库存、几何、导热/扩散、反应与机械参数。仍是制造材料配来源受控水物性的数值研究，原15微秒空间不收敛结论不变。

10毫秒pilot将终点改为0.51s、普通最大步长设为2^-9s。实际34步、2耗尽事件、620次评价、74个尝试panel，67.45s完成；耗尽后接受约1.95ms步长。原独立逐prefix审计通过，含外压功最大残差2.509e-10J。真实保存终态两次干态host评价与保存速率精确一致；未剖析样本约0.01719s。该样本不能保证长程成本或误差。

基于上述数据，保持原512个尝试步/800s累计预算及全部门槛，将两格终点延长至1.125s，即物理时长0.625s。粗网格时间运行实际349步、389个尝试panel、2825次评价、2事件，118.89s完成。原逐prefix审计通过，最大含外压功残差1.181e-9J。终温300.13847/301.02284K，法向伸长约0.97767/0.97772、公共切向约0.97591，保留原域检查。

半步长对照实际完成：refinement=1按原构建器把普通初始及最大步长减半。仅干段约640步，事前将资源步数预算由512改为1024，累计800s及全部精度/事件门槛不变。实际669步、709个尝试panel、5065次评价，173.59s完成；逐prefix审计通过，最大含外压功残差4.072e-10J。

独立标准库比较核对完整封存、原审计脚本SHA、全部实际策略及原初态。两组实际时间网格不同，事件时刻差为0；终态最大N/E/伸长/T/P差分别约1.398e-10mol、1.261e-7J、4.091e-9、1.309e-8K、9.872e-4Pa。温压差低于原点误差界，不能据此计算收敛阶。没有为终态差新增事后通过门槛；记录的比较合同通过不代表证明完整时间精度。

另一次当前实现的四格初态相变回调，实际两个最早候选的N/(-净液体率)精确相同，间隔为0，满足当前simultaneous_events_not_separated选择规则。只执行了这一次回调并重构选择算术，没有运行细格完整积分；这不证明真实事件同刻。后续须解决有证据的事件分离或联合处理，不能靠扰动对称初值或缩小门槛绕过。

0.625s仅对应粗估热扩散尺度与8格宽度相当，尚未提供空间收敛或气体迁移空间精度证明。真实原污泥材料、完整烧成冷却和公开实验验证仍未完成。

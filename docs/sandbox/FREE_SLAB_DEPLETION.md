# 两格自由形变的混合湿干事件与气体轨迹

本阶段没有修改生产求解器。新增真实水多格耗尽验证，以及非零气体输运的独立干态轨迹对照；两者分别运行，未声称已经验证全部湿干气液输运联合过程。

## 一格耗尽、另一格仍湿

`test_free_slab_depletion.py`使用已准入的真实水热化学桥和制造固定固相/骨架。第一格初始液水1e-8 mol、蒸汽1e-5 mol，第二格液水0.5 mol、蒸汽0.001 mol；300/301 K，同一共同横向伸长和两格法向伸长。共享导热、蒸发/凝结与机械交换功同时活动，物质面流为零。

实际运行439.44秒通过，积分436.173秒、305评价、19接受步。唯一事件发生于3.041741648041987e-5秒；终点1e-4秒，界面模式为`depleted_no_nucleation / existing_liquid`。两次连续终端比较和不同实际网格的独立细化分支通过全部原六项门槛（时间、库存、能量、温度、压力、伸长）。600秒积分与660秒外层预算根据先前实测成本设置；没有为通过结果放宽精度。

逐前缀精确有理数审计：每格水量残差最大3.841e-16 mol，局部能量与实际面流/功账本残差1.653e-10 J，整体`sum(delta E)+pe*sum(delta V)`残差1.061e-10 J。两格累计约束交换功绝对值各约4.2516e-6 J，确实非零；各步跨格和的累计绝对值1.582e-20 J。局部能量不应单独满足外压绝热恒等式，因为还存在热流和约束交换功。

终温299.9999002675 / 301.0001915935 K，终压249667.9948 / 247602.7014 Pa，完整三项伸长及初末实际反解、事件中点、所有分支与来源身份保留于`research/free-slab-depletion-v1`。运行期间163个源码/测试哈希保持一致，独立复核后才结束冻结。

## 气流、焓与自由形变的独立轨迹

`test_free_slab_gas_trajectory.py`在无液水条件下，用独立显式方程和DOP853参考解验证当前气体库存→温压→当前面流/供体焓→能量/形变反馈。参考RHS不调用被测主机、面流或储能函数；初始能量共享，初值正确性由既有独立点储能测试承担。

0.1秒轨迹的16/32步结果，对参考解的能量误差8.946e-7/2.236e-7 J、气量误差5.340e-11/1.336e-11 mol、伸长误差9.677e-9/2.417e-9。陈旧输运几何负对照气量误差4.0533e-6 mol；不同网格有实际辨别力。最初4.706e-6 J的能量失败、随后13/13步缺少有效网格细化的结果均保留；仅收紧内部控制和最大步长，外部门槛不变。

实际安装模块逐字匹配：61项。安装路径上的18项气流/机械耗尽/共同端点测试9.25秒通过；此前独立候选安装复核5项3.57秒通过。没有重复执行耗时7分钟的原生水事件，生产代码与此前安装版本一致。

这些是制造材料条件下的数值耦合证据。尚缺液态迁移与非零气流/相变的联合轨迹、组成相关多格自由反应、动态边界、空间收敛、全烧成冷却及原污泥三机制公开留出验证，原Goal继续保持未完成。

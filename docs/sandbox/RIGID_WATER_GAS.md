# 固定孔腔体积的平界面纯水—理想气体机械闭合

`rigid_water_gas.py` 新增给定温度下的机械压力/体积闭合。物理对象明确是：固体和闭孔之外的可用孔腔体积固定、液水及完整气体库存固定、液气平界面且无毛细压力。这一假设必须作为构造参数传入；未知砖毛细本构不会被默认为此模型。这里不计算化学相平衡、相变、热量反演、固体压缩或砖形变。

## 方程与单调性

所有库存用实际 mol，体积用 m³，压力用 Pa：

```text
p_liquid = P_gas
V_liquid(T,P) = N_liquid M95 / rho95(T,P)
V_gas = V_available - V_liquid
P_gas V_gas = N_gas R_mix T
F(P) = V_liquid(T,P) + N_gas R_mix T/P - V_available = 0
```

使用来源校验后的 `WaterProperties.state_tp(T,P,phase='liquid')` 的真实液压密度。原 IAPWS 固定 R 和摩尔质量保持不变，气体采用已登记的 `R_mix=8.31446261815324 J/(mol K)`，来源 ID `nist-codata-2022`，同当前气体热化学与水汽 bridge；R_mix 不开放为拟合参数。两者差异在结果保留 `liquid_native_molar_gas_constant_j_mol_k`，没有绕过现有气体兼容门禁或修改液水方程。

稳定液体的正等温压缩性给 `dV_liquid/dP<0`；正气体库存给理想气项导数 `-N_gas R_mix T/P²<0`。所以 F 在完整稳定液体压力括区严格递减。纯水适配器已在每次状态计算检查 EOS 的机械稳定性。单调性来自这一模型关系，不能用若干密度采样冒充一般材料证明。

选用体积形式 F 的好处是：低压试算时液体占据体积超过可用孔腔，也不需要计算负气孔的 EOS；该试算只用于求根，并非接受的物理单元状态。若液体压缩后能留下正气孔，仍可得到合法根。只有最终状态才以 `V_available-V_liquid` 检查实际正气孔并复算气体压力。

## 明确的压力与库存语义

构造器要求显式的稳定压力括区与数值政策。对活跃液水，括区两端必须都在原水 adapter 的稳定液态域；温度 293–500 K、压力不超过 100 MPa，以及饱和边界歧义等仍由原 adapter 检查。不会自动把用户给的无效括区改为另一区间。没有找到括区内根只表示在该显式域内不存在接受的闭合，不声称域外也不可能。

无液水时完全跳过液体物性和饱和压力查询，按纯理想气 EOS 解析计算；因此零液水状态不会受 500 K 水适配器温区限制。该分支只定义理想气压力方程，不给高温材料或非理想混合物资格。计算的气压仍必须在调用者明确给定的压力括区内。

气体物种名单由构造器明确登记，调用时映射必须包含全部物种（允许某种为零）；少一个载气、多一个未知物种、负/非有限库存或所有气体库存为零均拒绝。总量由全部库存求和，结果原样保留不可变库存及逐种分压。

`p_liquid` 是总机械气压，不是水汽分压。测试中的液水与 N₂ 可以共存，而水汽库存为零；这是固定相库存的机械试算，不是声明该状态已经化学平衡。蒸发驱动力、相间转移和稳定化学平衡须由后续模型处理。纯水 EOS 不曾用来计算混合气密度。

## 数值结果与失败分类

`PressurePolicy` 显式给体积绝对容差、压力绝对容差和最大迭代数。二分求根最终同时检查：

- `V_liquid + N_gas R_mix T/P - V_available` 的体积残差；
- `P - N_gas R_mix T/(V_available-V_liquid)` 的压力残差；
- 正气孔体积、分压和、压力括区宽度及浮点表示分辨率。

压力恰好在端点满足方程时仍接受完整数值检查。体积相消时，表示预算保留可用体积、液体体积、剩余气孔以及理想气体积的 ULP，并计入气体总量及 NRT 乘法的表示预算，再按压力对气孔的灵敏度估计压力分辨率；不会只因体积残差很小就宣称压力准确。此预算描述浮点数表示，不是完整物性算法误差界或实验不确定度。原水 adapter 的数值解验收是独立前提。

`RigidClosureDomainError` 表示输入、假设、相态/水域、库存或明确括区不满足模型要求；`RigidClosureNumericalError` 表示浮点溢出/分辨率不足、EOS 数值解失败、数值非单调或迭代预算耗尽。缺源问题保留来源加载器本身的类别。失败不通过剪裁体积、删水、补载气或改变容差恢复。

返回状态保存原压力括区、policy、迭代数、残差/分辨率、来源 ID、水资产 hash 和平界面假设；`qualification` 明确不代表污泥或液汽化学平衡。五个资产 hash 只覆盖水来源，CODATA 常数按当前项目登记另行声明。

## 最终数值括区诊断：实施前登记

新增诊断保留原输入 `pressure_bracket_pa`，另记录最终实际二分括区及其端点 F(P) 数值。预登记验收不改变已有求根门槛：一般液水分支要求实际最终区间宽不超过传入 `pressure_tolerance_pa`，返回压力位于该区间，端点残差具有原实现已验证的相反符号；端点残差按原 EOS 浮点计算重算，绝对比较门槛 1e-18 m³。独立 brentq 参考用绝对根容差 1e-8 Pa，并要求参考值位于测试实际最终括区（测试压力政策显式取 1e-3 Pa，避免把独立求根精度混成区间误差）。

解析纯气支路和原数值 F 恰为零的端点支路使用单点表示，分别标注路径；这种单点不代表包含 EOS/浮点误差后的严格真根或零物理不确定性。保留失败/精度门槛，失败不得输出成功括区；新状态字段保留默认缺项以兼容旧位置参数构造。

## 最终数值括区：实际接口与验证结果

`RigidWaterGasState` 在原字段之后增加四项，旧位置/关键字构造不受影响；没有新诊断的旧构造明确返回 None/`not_recorded`，不补造历史括区。

| 字段 | 语义 |
|---|---|
| `pressure_bracket_pa` | 原输入压力域，保持旧义 |
| `final_numerical_pressure_bracket_pa` | 实际成功时最后二分 lo/hi；特殊路径为单点 |
| `final_bracket_volume_residuals_m3` | 上述端点在原浮点 EOS 数值函数 F(P) 的已计算残差，依次 low/high |
| `pressure_solution_path` | `liquid_bisection`、`liquid_exact_numerical_endpoint` 或 `pure_gas_analytic_rounded` |
| `pressure_bracket_qualification` | 新计算固定为 `numerical_forward_function_only_excludes_eos_error` |

普通二分直接返回实际终止时的缓存端点及其残差，不倒推理想对称区间、不返回原输入宽区间冒充最终精度。原数值函数端点 F 恰为零并通过原完整验收时，返回该端点单点及两个零残差；纯气解析支路返回已舍入解析压力的单点，并保存该点实际体积残差。即使区间退化为一点，也不表示原 EOS 误差、算术误差或实际物理不确定度为零。该区间只能为后续数值敏感性传播提供压力求解过程记录，不能作为严格包含真根的 EOS 总误差界。

先登记前述门槛，再实际运行新增测试，得到 `2 failed, 18 passed`（缺少新增诊断字段）；添加实现和端点/旧构造案例后，实际 **23 passed in 1.99s**。新测试检查实际最终宽度和符号、独立 brentq 根在测试括区内、端点残差重算、原输入括区保留、上下两个精确数值端点、无液高温不查询液体 EOS、迭代失败不返回成功状态以及旧状态构造诊断保持缺项。原求根门槛、迭代更新与 EOS 核心未改变。

# 平界面刚性流体腔的闭合储能导数

状态：为下一步U→T解码准备的推导，尚非闭合能量求解器实现或真实泥坯资格。假设固定各相库存、共同T/P、固定可用流体腔体积、平界面机械平衡，无质量相变及界面/弹性能；气相为明确的理想混合气，液体为稳定IAPWS水。不得推广到未知泥中毛细关系或可变形骨架。

## 机械根及唯一性

定义每个独立体积贡献 `V_i(T,P)`，液水 `V_l=N_l M/rho95(T,P)`，理想混合气 `V_g=N_g R T/P`。求解

`F(P)=V_l(T,P)+V_g(T,P)−V_available=0`。

在合法稳定液体支路，`∂V_l/∂P<0`；有气体库存时 `∂V_g/∂P=−N_g R T/P²<0`，故F严格递减，合法连续括区内至多一个根。饱和支路、物性域端点及括区残差符号须实际检查。不能把所有低压试探下体积超出腔体都当成最终不可能，因为升压会压缩两部分体积；也不应通过截断负的剩余孔体积寻找根。

## 固定腔体的热量路径

记 `A_i=(∂V_i/∂T)_P`、`B_i=−(∂V_i/∂P)_T>0`，以及实际库存加权的 `Cp_i`。令 `A=sum A_i`、`B=sum B_i`。固定体积要求

`dP/dT=A/B`。

相容的基本热力学关系 `dH=Cp_total dT+(V−T A)dP`，加上 `U=H−PV` 和dV=0，给出

`C_closed=(dU/dT)_V,N = Cp_total − T A²/B`。

这个导数通常不等于在同一点简单相加的各相Cv：液体与气体会在升温过程中交换占据体积，即使总体积不变。

对各个热力学相容的稳定体积贡献，`Cp_i−Cv_i=T A_i²/B_i`。由加权Cauchy不等式

`(sum A_i)²/(sum B_i) <= sum(A_i²/B_i)`，

所以 `C_closed >= sum Cv_i > 0`。因此在固定库存、上述假设和有效连续状态支路内，闭合U(T)严格递增。此结论不自动给出整个区间一个已计算的正数下界，也不能代替浮点能量分辨率检查。

理想气整体按固定组成定义Cp/Cv，满足Cp−Cv=N_gR；不要把不同气体的混合体积重复计为完整气孔体积。固体骨架此处只决定给定可用体积，不把它的未知温压依赖/储能默认为物理上的零。后续加入固体及变形需重新列全系统能量与约束。

## 来源与实施限制

[IAPWS R6-95(2018)](https://iapws.org/technical-guidance/release/IAPWS-95) 原始PDF位于 `data/sandbox/water/IAPWS95-2018.pdf`，Table3给出Helmholtz导数、h/u/Cp/Cv关系；已审核水适配器检查正机械稳定因子及正Cp/Cv。此文的混合闭合及Cauchy步骤是从这些热力学关系作的显式代数推导，不冒充论文测得的砖材本构。

真实气体偏差、相平衡/水活度、毛细压和骨架变形均不在此证明中。若任一相越出稳定域或气孔耗尽，应停止该模型分支；不能利用这个单调性证明强制续算。源热物性函数本身的数值误差和压力闭合容差，必须传播到U→T误差预算，而不是只看最终浮点残差。

建议独立核对：真实IAPWS液水加已声明理想载气，改变T同时重解P，用中央差分检查dU/dT与上式，报告与sumCv的差；此文写入时尚未运行该新增验证。

## 新增数值核查预登记

采用真实水EOS与明确制造的理想载气（Cp=30 J/(mol K)、R=8.31446261815324 J/(mol K)；不代表特定真实气体）。三个(T,N_liq,N_gas,V)为(300K,2mol,.01mol,1e-4m³)、(450K,2mol,.01mol,5e-5m³)、(300K,5.5mol,.01mol,1e-4m³)。独立SciPy brentq压力根在1.001倍饱和压力至100MPa内求解，xtol=1e-5Pa、rtol=1e-12。T±0.01K各重解压力，中央差分U检查导数。比较门槛事前定为|ΔC|≤1e-4J/K，属于公式/求根数值检查，不是材料误差；每例还应满足C_closed≥sumCv及体积残差≤1e-14m³。IAPWS质量导数按登记摩尔质量换算，kappa从1/MPa换为1/Pa。

## 实际核查结果

上述预登记后实际运行3组独立求根和导数检查，均通过。结果存于 `research/rigid-storage-derivative-identity.json`，包含输入、实际压力、水源hash、导数与体积残差。最大导数绝对误差2.78893e-7 J/K，低于预登记1e-4 J/K；最大体积残差1.36e-19 m³。C_closed与sumCv分别相差约1.815、34.339、3.109 J/K，说明不能直接用sumCv当闭合路径导数。

本次数值检查使用已核读水EOS与独立SciPy压力根，没有调用新的RigidWaterGas求解器，验证对象是此推导，不计作新求解器测试或真实泥坯实验。独立审核已核查代数及适用边界，见 `research/CODE_REVIEW_RIGID_WATER_GAS.md`。下一步仍须把实际压力根误差和上游物性解误差传播到闭合储能反演。

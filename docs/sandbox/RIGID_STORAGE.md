# 沿机械闭合路径的流体储能

实现目标：每个温度试算重新调用RigidWaterGas求P(T)，在该液压下求液水U，气体按共同总压计算可加偏摩尔体积。限定固定流体腔、固定相库存和平界面，不含相变、固体、毛细或界面能。

## 数值合同与事前登记

本模块不把局部敏感度冒充全压力区间界。调用者必须显式提供覆盖温度/压力域的DeclaredNumericalEnvelope：液水摩尔内能/摩尔体积求值误差界、液水摩尔du/dP绝对上界、每种气体内能误差和Cv正下界、推导方法及来源ID。这是条件性数值合同，未经独立数值准入的声明不能称为严格证书或材料证据。结果保存原声明和条件性资格。源EOS残差应包含在声明的体积/热量误差预算里，不能自动视为零。

以B_min=NgRT/P_high²构造压力残差误差传播；温度/压力域指整个声明区间。气体的Cv下界提供C_closed下界，液体Cv的正贡献可忽略以得到保守界。每个实际点仍检查声明没有被观察到违反；有限点通过不证明区间声明成立。

事前验收：真实IAPWS液水+制造Cp=30 J/(mol K)理想气，固定2 mol液水、0.01 mol气体、1e-4 m³腔体，温度括区295–310 K、压力1e4–1e6 Pa。用独立SciPy压力求根计算300 K能量，反解温差≤1e-4 K，能量残差≤1e-5 J；严格门槛不因失败放宽。测试声明界为液水u误差1e-8 J/mol、v误差1e-16 m³/mol、|du/dP|≤1e-4 J/(mol Pa)，气体u误差1e-9 J/mol、Cv≥20 J/(mol K)，仅属制造数值验证合同。另测粗误差预算拒绝、巨大生成能量化、无液高温、未知气体/域/非有限输入、库存不变、H−U−PV与实际闭合路径热容中央差分（绝对1e-4 J/K）。独立压力根xtol=1e-7 Pa；中央差分温步0.01 K。

这些数值声明不替代IAPWS的全区间严格舍入误差分析；研究材料运行仍需可审核的数值预算准入。本模块的适用范围也不等于完整湿砖储能。

## 实际实现与验证

实际接口为 `RigidStorage.evaluate_at_temperature` 与 `temperature_from_energy`；构造绑定RigidWaterGas、完整IdealGasPhase映射和DeclaredNumericalEnvelope。当前只接受既有单分段Shomate或低温理想水汽桥的显式Phase适配；高温分段连续派生尚未加入此Phase适配。温度括区端点的能量符号若被数值误差覆盖，则拒绝该括区；调用者需提供可确立符号的更宽有效括区，不能把不确定端点强行当根。

误差预算使用Fraction对已表示输入作有向乘加除：Cv和压力斜率下界向下，误差上界向上；温度返回区间也向外取整。上游声明界本身没有因此得到证明。迭代采用保持已确认能量符号括区的Newton试探，无效试探回到二分；局部闭合热容只选试探，不代替条件全域下界或验收门槛。

实际18项测试通过（18.48 s），原始XML为 `research/rigid-storage-tests.xml`。新增真实积分用单格2 mol液水和0.01 mol制造理想气，制造电加热反馈10 W/K×(310 K−T)，0.1 s有界运行；每个operator试探调用真实闭合反解，逐步功账本与U变化以1e-8 J绝对门槛对照，固定库存逐值保持，最终T与独立嵌套压力/能量求根以1e-4 K绝对门槛对照。这是固定腔体热量反馈耦合，不是空间热湿输运或相变验证。

独立代码审核发现同名H2O跨相摩尔质量可不一致，已先实际取得回归失败，再要求与已核读液水摩尔质量一致，并显式核查气相共同摩尔基准/能量参考。审核另发现返回温度区间端点可向内舍入，已改为有向取整并增加Fraction回归。巨大生成能测试最初预期在新反解拒绝，但原PhasePoint的H−U−PV检查已更早拒绝；保留上游错误并修正测试预期，未放宽原门槛。

18测试还不能完成事前登记的全部扩展场景：多气体相消、气体接缝在本Phase适配中的连续反解、机械域中断的集成退出与完整湿砖尚待实施。当前数值合同声明并未获独立全区间IAPWS误差准入，不自动进入证据支持的材料预测。

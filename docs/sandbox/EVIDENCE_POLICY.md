# 证据与缺项规则（v0.1）

本文件落实 Goal §4–5；`evidence.py` 目前是声明元数据与依赖的校验器，不能验证一个作者是否说过某句话，也不能证明提供者真的核读过来源。原文件核对、派生代码审查和公开实验对照分别保留。

## 身份与链条

1. 原始来源记录作者、版本、稳定 URL/DOI、实际阅读状态、精确位置、获取日期、许可、缓存位置和字节身份。合法获取受阻时保存失败原因；网页提取文本不能冒充下载到的 PDF/HTML。
2. 数值、方程、设计和数值政策使用 Goal 的八种 `evidence_kind`。材料数值必须是有限数；缺项为 `unknown/null`，不以空容器、0 或非数值字符串代替。
3. 直接物理参数必须有 `support=value` 的核读引用；方程必须有 `support=equation`。背景引用不提供数值或关系证据。
4. 派生物理参数和派生方程均记录 `derivation` 和上游依赖。派生方程还须追到有直接依据的上游方程；使用过一个实测数并不能证明新造的关系。推导的语义、单位、数值实现仍需另行审查，文字或图结构存在不等于推导正确。
5. 设计选择、数值策略或制造值不能成为材料物性的唯一证据根。图中任何未知关键依赖阻断受影响的结果。JSON 重复键、循环、缺失节点、非有限值和未知单位均在求解前拒绝。

## 执行资格与输出资格

`evidence`、`exploratory`、`manufactured` 是不同运行模式。制造参数仅在最后一种允许，覆盖率仍不计作实证。探索仅允许有明确条件的适用性降级；不允许把未知变成数字或静默越过已声明物性温区。探索替代值须建立独立假设节点和实际入口，当前版本尚未提供此入口。

材料类别、气氛、几何及整个请求温压区间逐节点检查；缺失上下文不视为匹配。材料身份、批次、升温速率、粒度、气氛氧浓度及制样等更细字段目前仍需材料解析层落实，不能声称简版域校验已覆盖全部合同字段。

`traceability_coverage` 的分母为实际依赖中的物理参数和方程；上游缺证会传递。它不等于有效性分数或实验准确率。结果同时保留：

- 来源链覆盖率和精确位置；
- 材料/条件适用性及理由；
- 原始来源资产核对状态；
- 数值验证状态；
- 公开实验验证机制与独立层级。

当前 registry 的 `source_assets=not_checked` 与 `scientific_validation=not_established_by_registry` 不允许隐藏。运行资格解析器还需核对缓存及原值转换，才能用它支持完整物理预测。

## 当前真实来源

研究候选与提取值保存在 `data/sandbox/research/`，见 `research/SOURCE_COVERAGE.md`。该候选表的 schema 与运行时 registry 不同；尚未迁移、核准的论文值不得因为文件存在而自动加载为材料包。

Wang 2021 的 186 个干燥点是从论文图中实验符号数字化得到的派生读数，保留像素位置和读图误差；其未知实验散差不能由像素误差替代。Nowicki 的残炭制备、气氛基准问题和 Vali 的组成基准争议均保留隔离。Mohajerani 的终态与估计导热值分列。不能拼接不同材料来称为同一实测污泥砖。

文件哈希只证明身份，不证明适用性。无许可证明的再分发不得声明许可已通过；当前 Goal 只有本地研究与提交授权，没有公开发布授权。

`data/sandbox/.gitattributes` 对原始证据关闭行尾转换，保留其已核对字节。原文抽取的空白和CSV标准CRLF不按源码空白错误改写；源码与项目文档仍使用正常空白检查。这样不会改变任何科学/数值验收门槛。

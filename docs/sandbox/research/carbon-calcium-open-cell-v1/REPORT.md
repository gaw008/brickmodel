# 外部气氛与Ca/C/O反应单元交换

已有理想气体、常固相体积和局部瞬时平衡单元，现在与外部规定的CO/CO2/O2/N2气体库交换。气体库的组成由外部设备维持，不假定其中化学反应自行达到平衡；设备的制气/控温功耗在本系统边界外。沿用已独立核查的虚拟热/物种交换面，系数来源与局限仍在`parameters.carbon_calcium_exchange.json`，不视为实砖渗透率或燃烧速率。

设正方向从气体库进入单元，来源化学势`mu=h0-T*s0+RT*ln(yP/P0)`。单元得到能量E和元素J，外界熵率为`(-E+sum(mu_bath*Jgas))/T_bath`，单元熵率为相反收支除以自身T。两者之和与既有正二次型耗散对照；不能把单元自身熵减直接解释为第二定律违反。温度坐标通过已获资格的`dU=Cv*dT+U_N*dN`更新，真实来源U单独复算。

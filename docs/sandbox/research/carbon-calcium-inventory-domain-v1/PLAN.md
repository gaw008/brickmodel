# 正库存范围的静态推导阶段（未获资格）

当前动态求解器要求C>Ca、O>3Ca、N2>0。开放排碳可使C低于Ca，但这不代表CaCO3/CaO/石墨/CO/CO2/O2/N2的热力学模型必定没有状态。新阶段只研究C>0、O>Ca、N2>0的固定T/P平衡，先不修改任何已获资格的动态方程或来源表。

仍用原USGS来源、理想气体、纯固相、常固体摩尔体积。完整方解石端态只在C>Ca且O>3Ca时有严格正的余量气体；石灰端态在上述新域可算。端态的Ca反应亲和力决定是否需要共存相。相约束是物理可行性条件，不以浓度下限或截断修复数值。

## 共存相的气体直接解

用无量纲分压`p_i/P0`，记总压pi=P/P0，Ca反应的共存CO2分压为`b2=exp((g_calcite-g_lime-g_CO2)/(RT))`。g包含现有常体积固相压力修正。CO+O2/2⇌CO2的常数K3=exp(-(g_CO2-g_CO-g_O2/2)/(RT))，令B=b2/K3，气相关系为pCO*sqrt(pO2)=B。

石墨不存在时，将氧元素余额减去两倍碳余额，得到`2*nO2-nCO = D = O-Ca-2*C`。定义d=D/N2，s=pi-b2，临界氧分压z0=(B/2)^(2/3)。在正氮分压域，pN2=s-pCO-pO2。

- d>=0：取z=pO2，从方程`(2+d)*z-d*s+(d-1)*B/sqrt(z)=0`求z，物理根在[z0,s]；d=0时z=z0。再求pCO=B/sqrt(z)。
- d<0：取w=pCO，从方程`(d-1)*w-d*s+(2+d)*B^2/w^2=0`求w，物理根在[2*z0,s]；再求pO2=B^2/w^2。

可行区要求s>3*z0。前式在所给区间导数为正，后式导数为负；端点符号分别相反。需要在独立来源核查中确认本相可行，并保留不成立的相候选；这不是无条件存在性声明。气量由n_i=N2*p_i/pN2给出，再由碳余额求方解石。此时无需用C-Ca*f这种可能严重相消的量来重建正气体。

石墨存在时，CO2分压b2与石墨-CO2平衡直接给出pO2=b2/K2，再由pCO=K1*sqrt(pO2)求其余气体。仅正氮分压的候选有意义；由`nC=(2*nO2-nCO-D)/2`及`n_calcite=C-nC-nCO-nCO2`恢复固体。必须满足0<=n_calcite<=Ca、nC>=0以及所有来源亲和力/元素/压力/能量约束。不把不可行相候选改成零浓度。

## 验收次序

1. 先保存固定T/P原库存网格的完整旧输出，建立不改变旧域结果的对照。
2. 独立脚本原型实现上述直接气体解；先用高精度源积分和同时元素/化学势方程核查稀碳、缺氧、新域边界及旧域。保持原静态误差预算，失败保留。
3. 静态通过后才考虑提取共用热力学收尾与新增求解路径，复核原范围，以及新域定容U/H/S、Cv和库存导数。
4. 定容和导数通过之后才启动开放排碳全过程。当前仅推导，未实现新静态求解器，未扩展任何轨迹资格。

近零气体不能靠猜测分压下限或放宽来源预算解决。这里没有增加矿物种类、真实反应速率或材料参数；实际砖的资格与资料阻塞不变。

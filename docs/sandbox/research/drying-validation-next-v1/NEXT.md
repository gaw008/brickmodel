## 3. 先排除不解决结构问题的改法

### 只新增含水相关的局部D：仍不能跨过现有凸性反例

考虑比D1更一般的自主模型：

`u_t = ∂x[D(u)u_x]`，`D(u)>0`；`u(x,0)=1`；底部无通量；顶部`-D(u)u_x=k u`，固定`k>0`。

在通常的正则性、唯一性及比较原理成立的域内，常数1是上解，所以`0≤u(x,h)≤1`。自主演化的保序性继而给出`u(x,t+h)≤u(x,t)`。因此：

`M'(t) = -k u(L,t)/L`，故`M'(t+h)≥M'(t)`，即平均含水比M仍然凸。该结论不需要D对u单调。初边界不兼容可用t>0的解和t→0连续极限处理，不能借此抹去MR(0)=1。

所以，即使增加`D(u)=Dref exp[β(u-1)]`的一参数β、或更灵活的正D(u)，**在保留这套线性表面交换和初值时**，仍无法让D1报告中40°C/RH60%的0/20/100min三个读图区间同时相容；正的缺口为0.0046132 MR。它可以改变后段拟合，但不是消除这项结构障碍的优先项。该证明不覆盖动态边界、非局部本构、收缩几何或耦合热状态，也没有证明50°C偏差全由凸性造成。

### 直接新增X–T能量方程：需先识别有效组合

例如集总热湿候选具有干质量md、干固体/钢板合计热容量Cs、热导HA、质量交换常数KA、未知T0；储能可写成`Cs(T-Tr)+md X u_l(T)`，外部热流为`HA(Tair-T)`，质量流为`KA F(X,T,Tair,RH)`。相态储能、进出焓和压力近似必须进一步明确后才能执行。

即使同时测T和MR，变换`(Cs,md,HA,KA)→λ(Cs,md,HA,KA)`也保持归一化轨迹不变，因此绝不可能从MR识别这四个绝对量。应至多识别`Cs/md`、`HA/md`、`KA/md`和T0。它们是源条件下有效组合，不是已知Cp/h/D。

现有MR单输出是否能稳定区分这些组合尚无秩或剖面证据；每10min的采样可能根本看不清快速热启动。初始温度、蒸发冷却和交换阻力又会互补。不能由117点多于4参数宣布可辨，也不能直接接EOS进行大规模拟合。现阶段不选它作为第一个计算动作。

## 4. 唯一优先项：D1加一个表面交换启动时间，先做训练辨识探针

保留D1的空间扩散、原三个有效参数、固定几何和原温湿形式，只修改表面通量：

`a'(t)=(1-a)/τs`，`a(0)=0`，所以`a(t)=1-exp(-t/τs)`；

`u_t=D(Tair)u_xx`；底无通量；顶部`-D u_x=k(RH)a(t)u(L,t)`；`MR=(1/L)∫u dx`。

τs单位秒，τs=0明确退化为D1（t>0时a=1）；不是用一个极小正数假装零。新增自由度恰好一个，参数共`Dref[m²/s], kref[m/s], Ea[J/mol], τs[s]`。Dref/kref/Ea仍依D1定义和分类，不把旧上界解固定成新材料事实。

这一构成**是新提出的可检验动态表面交换假说**：有清楚的质量通量、状态和时间尺度；原文初段失水速率上升提供问题动机，但原文并没有给这个微分方程、a(0)=0或τs。a表示无量纲交换启动程度，不是实测湿表面积、核心温度、热容或热流。不得将它改名“已验证升温模型”。它还没有热方程，因而不满足Goal的真实热湿全耦合要求。

加入a后`MR'=-k a u_surface/L`，a的上升可使初段失水加快，从而打破上节的凸性限制。是否实际解释观察、τs能否识别，须由训练检查决定；不能事先判为正确物理原因。

**实施顺序与有限工作量：**

1. 在独立候选目录冻结形式、训练40/60°C八曲线、评价规则和有限资源预算。50°C不用来选择τs范围、初值、损失或形式。不得改D1冻结资产。
2. 使用一个保守有限体积时间变系数Robin小求解器；不接完整主沙盒或EOS。设`dx=L/N`，顶部单元中心值uc的外流为`J=k a uc/[1+k a dx/(2D)]`，内部面按`D(ui-ui+1)/dx`，底流为0。这样保留顶部半格阻力及离散总质量收支。不能将时间变k直接塞进旧的常系数模态解，也不能随时重启模态并忽略已有场。
3. 先只作τs=0回归，和现有`mean_curve`比较；再对非零τs做空间/时间加密。拟合前确定MR数值目标与失败规则，证明实际比较点的误差显著小于读图界；无法做到则以数值未就绪结束，不发布材料误差。
4. 第一轮仅使用训练117点，做有限的τs尺度探针和四列敏感度矩阵。可预登记`τs={0,30,60,120,300,600,1200}s`，对应0到两次采样间隔的数值探查，不是材料先验；同时比较不同差分步长，报告尺度归一化Jacobian奇异值和列相关。零值作为D1边界模型，不用其不存在的双侧τ导数。设置单次总墙钟上限，不按网格/起点重置预算。
5. 对最有信息的训练尺度才做τs剖面：固定τs，重新优化原三参数，报告全部目标、边界命中及MR轨迹。不能只固定D1的旧D/k/Ea看τs残差便宣称新参数独立可辨。剖面若平坦、τs在采样以下完全不可分、或与D/k/Ea互补，则记录“现有MR不足以分辨”，到此结束该候选，不继续扩展EOS或新指数。
6. 只有数值精度、训练辨识及预登记选择规则均就绪后，才有限联合训练四参数、锁定结果，预测未参加该次拟合的50°C四条曲线57点。保留逐工况RMSE/MAE/max/bias、逐点残差及原读图界。50°C属于温度插值且已经在D1公开，报告名称必须含“复用条件”，不是新的盲检。失败保存，不改门槛。

新增τs没有显然的纯时间伸缩退化：若把D、k同乘λ并把τs除以λ，模型轨迹变成原轨迹在λt处的值；实际观测时钟固定，因此不能把这当同一预测。但这也不是四参数严格结构可辨证明。D/k在表面控制或扩散控制极限会变得弱可辨，τs很短时也与0不可分；以上实际敏感度和剖面是运行前必须完成的最小证据。

这个动作成功最多支持“一个可辨的有效表面启动模型在复用未拟合工况上的MR预测”，不会自动支持真实温度/热量或收缩机制。若最终需要判断热启动的物理原因，Wang中没有独立温度可验证；Nylen的同材料温度数据路线必须保持自身材料、边界和观测角色，不能将其数值移植到Wang。

## 6. Weibull仅为必要时的经验参照，不是优先执行项

原Wang Table1（印刷p9）给`MR=exp[-(t/b)^a]`，时间单位min，a无量纲、b为min。重命名为n和τ并转成秒，可提出四参数跨工况形式：

`MR(t,T,h)=exp[-(t/τ(T,h))^n]`；

`τ(T,h)=τref exp[B(1/T-1/Tref)] [(1-h)/(1-href)]^(-p)`。

T/Tref用K（Tref323.15K）；h/href为0..1（href0.45）；τref秒；n、p无量纲；B单位K。B/n/p是新模型有效条件系数，原文Table1没有提供它们的跨温湿定律，B也不是实测活化能。MR(0)=1，τref>0、n>0。若实施，则沿用40/60训练、50复用检查；原作者按全部曲线求得的Table3/4/5参数不得参与初始化或充当留出真值。

对0<MR<1，令`y=log[-log(MR)]`、`zT=1/T-1/Tref`、`zH=log[(1-h)/(1-href)]`，则

`y = n log(t/1s) - n log(τref/1s) - n B zT + n p zH`。

因此若设计矩阵`[1,log(t/1s),zT,zH]`满秩且n≠0，四个线性系数可唯一逆映到该经验参数。训练的交叉温湿标签与各曲线多个不同时间使这一理想设计具备满秩条件：固定T/h内改变t可排除logt列；剩余交叉T/h排除温度、湿度及截距的线性依赖。这里是限定形式下的结构等价论证，**不是实测数据的良好条件数、非线性MR损失唯一最优或小参数不确定度证明**。本轮没有计算秩/剖面，没有拟合参数，也不删去不在(0,1)的原读数来迎合变换；实际拟合若做应使用原MR尺度损失，变换至多给结构分析/初始化。

即使它复用预测较好，也只能给有效干燥响应基线，不能替代所需热湿守恒和内部温度验证。本轮建议root先决定并执行第4节有限训练辨识探针，而非并行开展这些经验拟合和完整EOS重写。

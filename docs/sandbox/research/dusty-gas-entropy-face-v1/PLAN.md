# 多孔气体有限面：事前资格计划

2026-09-25 UTC。局部Dusty Gas的648状态与108纯气限通过后，先限定同温600K、明确直管束参数与1cm距离，独立核查相邻控制体之间的数值面，不直接称为真实孔道的稳态解。

定义c_i(s)=exp[(1−s)ln(c_i,L)+s ln(c_i,R)]，g_i=Δln(c_i)/d。每个节点的P=RTΣc_i、x_i=c_i/Σc_i，D依已核对1/P关系变化，η由已核对Wilke规则变化。共享面通量取∫N(s)ds；Δln(c_i)恒定，故面熵−RΣN_face,i Δln(c_i)=d∫Π(s)ds≥0。分子、孔壁和Darcy三项分别记录。

这是一条声明的熵变量数值路径。两端压力相等且组成不同，路径中间压力也可能改变；不能把这一插值路径当作观测到的内部压力场。未来整列必须另外验证空间收敛；本次高精度积分一致只验证离散面定义的实现。

源参考使用60位原始非对称DGM浓度方程、直接全对Wilke权重和自适应积分。冻结零跃变、纯压力跃变、等端压组成跃变和大压力/微量组分跃变；8/16/32/64阶Gauss全部用同一预算比较，保留未达标阶数。反向交换应流反号、熵不变，三项熵均非负。

单气体另有独立稳态解析通量 N=−[D_K(c_R−c_L)+(κRT/(2η))(c_R²−c_L²)]/d。四种纯气分别与此关系比较，不能仅与同一个求积算法互相核对。实际砖孔、非等温和反应资格均不在结论范围内。

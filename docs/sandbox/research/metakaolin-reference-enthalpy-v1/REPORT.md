## 可重建的参考态计算

打印配比为煅烧黏土:氢氧化钙:石膏=1:0.25:0.1。每摩尔偏高岭土在声明的最大钙矾石阶段消耗3mol石膏。取明确记录的石膏摩尔质量172.17g/mol，以0.1g纯石膏/1g煅烧黏土计算，反应程度为0.000193607093764mol/g。量热释热69.4±1.6J/g对应反应焓−358.45794kJ/mol及仅由该热量范围传播的±8.26416kJ/mol。

按原表生成焓作计量加和，Ca/Si=1.67和1.33分别得到偏高岭土生成焓−3487.54526、−3489.52366kJ/mol；均落在作者报告−3487±8、−3489±8范围内。Ca、Al、Si、S、O、H逐项残差为0。70位Decimal和独立浮点加和最大差1.3643e−12kJ/mol，通过事前1e−9数值预算。原表打印精度及物性协方差未纳入总不确定度，不把上述纯算术精度称为测量准确度。

另保留一种质量基准敏感性：若0.1g是供应石膏材料总质量，并按表2的95.3%石膏相计，则两值变为−3469.86685、−3471.84525kJ/mol，超出作者所报范围。**论文配比是否预先按纯度修正未明确取得，不能据此认定作者算错**；这个结果明确了继续核对所需的信息。全文提取中的式3乘积符号也未目视确认，不能当作原文错误；本复算直接使用热力学所要求的计量和。

## 对烧砖热量模型的含义

固定同一USGS高岭石−4119kJ/mol和水蒸气−241.8kJ/mol参考后，Muzenda报告值给出脱羟参考反应焓148.4kJ/mol，而Cantisani打印值给出424.4kJ/mol，差276kJ/mol。此前Cantisani自己的父相参考给424.99kJ/mol；两处父相焓相差0.59kJ/mol，未混为同一版本。

这不是两次同材料直接脱羟测量的差异，也不证明哪一个数可无条件用于高温。Weise2024的−3478kJ/mol目前只读到Muzenda的转引；其原始推导未取得，不算独立核验。偏高岭土结构定义、高温Cp、绝对熵、来源基准兼容性和与动力学试样的对应仍缺。因此只保存参考焓候选与敏感性，尚未连接变温F3热量方程。

# 有限碳氧库存的恒压升降温：限定数值资格通过

现在可以模拟一个1bar、封闭C/O/N库存、仅与外界换热的虚拟平衡量热器：初始300K，热源1150K保持1200s，再换为350K冷源直到2400s。库存是C=.0015mol、O元素=.002mol、N2=.004mol；导热连接.005W/K是明确虚拟设定，未从真实砖反推。过程图见[完整升降温记录](cycle.png)。

初始态已经处于所选化学平衡，主要为.5mmol石墨、1mmolCO2和4mmolN2。升温使石墨与CO2更多转为CO，约108.8575756s石墨耗尽，此后主要是1mmolCO、.5mmolCO2和4mmolN2。切换冷源后约1212.1165229s石墨重新出现，末态约350K。这个时间来自虚拟换热速率，933.23974K边界来自该库存/压力/物种集合，不能称为碳的普遍燃尽温度或污泥焦燃烧时间。

## 物理定义与来源

采用[有限碳氧静态资格](../carbon-gas-equilibrium-v1/REPORT.md)和[USGS来源核查](../carbon-gas-thermochemistry-v1/REPORT.md)中的纯参考石墨、理想CO/CO2/O2/N2。每一时刻都取受限Gibbs最小值，无反应动力学。C/O/N库存封闭，压力固定为来源标准压力；气体体积随组成及温度变化，报告的体积只含气相，没有提供总活塞体积、固体热胀或机械功预测。

恒压且只有热交换时用dH/dt=G(Twall−T)。H含来源生成焓与Cp积分，因此化学能已进入总焓，不能再额外叠加一份反应热。平衡Cp严格为正，H(T)单调，可反解T。内部相分配满足平衡，热接触的合计熵产率为Q(1/T−1/Twall)≥0；外界熵流为−Q/Twall。采用H相对初态变化坐标，未把热量账恒等相同当作独立能量验证。

全部接受步、观测点、相事件及2/4阶稠密积分节点，分别从原来源多项式原函数、元素摩尔量、分压和化学势重建H/S、元素、固相单侧条件及气相平衡；热量和熵积分在保存稠密多项式上重新计算。来源重建不调用运行时的来源积分函数；稠密求积仍共享已单独核查的H→T平衡解码器，这一依赖明确保留。

## 已执行结果

基础档1249步，最大累计热量误差4.38041e−6J，超过冻结1e−6J预算。尽管时间比较和其他项通过，基础档仍为失败，完整记录未删除。

精细档1509步与更细档1864步通过全部原预算。两者分别核查3913/4268个保存状态及9054/11184个稠密节点；最大累计热量误差7.13513e−7/1.31396e−7J，最大累计熵余额7.36362e−10/1.26873e−10J/K。最大来源H重建误差1.70531e−13J，H反解来源余额2.44427e−11J，元素误差≤6.15827e−17mol，化学势平衡/单侧条件余额≤5.23869e−10J/mol。记录及稠密节点的熵产率均非负；接近末态的逐步总熵差存在约1e−14J/K浮点余额，在原1e−10J/K允许值内。

2400个共同观测时刻，精细/更细最大温差6.64450e−7K、组分量差≤9.06094e−13mol，低于原1e−4K和1e−10mol目标。最终系统+外界熵增约.47730513J/K。

另在每个独立60位Gauss节点求解三元log摩尔量的元素/化学势方程，再直接微分这些方程求组成温度导数及Cp，积分Cp/[G(Twall−T)]到已独立求出的相界。这条参考没有复用运行时标量/二次组成根或反应基Hessian。32/64阶热量时间积分均通过，升温/冷却事件与更细轨迹差1.29906e−8/6.54391e−10s；节点Cp最大差4.06175e−15J/K。高精度是数值算术核查，不提升原文献有效数字，也不是实验不确定度。

三档完整轨迹分别压缩为1212311、1373132、1587768字节，逐字节还原相同。保存了首次审计调用缺少root参数、首次误用单文件归档接口的stderr；修正调用后重新完成对应步骤。这些执行错误未被描述为物理失败或已通过。未新增/运行软件测试，未生成或比对SHA。

所有根目录parameters.carbon_gas_cycle*.json均可检查；运行入口为examples/sandbox/run_carbon_gas_cycle.py，完整收支入口为audit_carbon_gas_cycle.py，独立60位事件积分入口为review_carbon_gas_cycle_decimal_time.py。所有轨迹及报告保持material_qualified=false、training_eligible=false。仍缺真实焦的组成/活性/速率、真实砖孔结构与输运、含水气相、其他反应物种及同材料测量，不能据此宣称已完成真实烧砖全过程。

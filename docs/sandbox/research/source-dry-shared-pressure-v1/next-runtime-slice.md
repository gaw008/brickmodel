# Next executable slice: one selected source-cell depletion with real internal liquid transport

Read-only study of current source modules. No production/test changes, new controller, EOS, model construction or test execution. This is a proposed next scope, not completed support.

## Recommended smallest complete increment

Generalize the existing terminal/candidate path to N cells, one uniquely earliest liquid root at cell k, and actual paired internal liquid transport with the existing donor enthalpy ledger. Retain a strictly positive, separately observed evaporation term at the selected cell and the original phase-correction budgets. Initially require every inventory to start positive, no simultaneous/tangent/competing first root, no liquid donor reversal on the selected terminal interval, one event only, and a predeclared dry-side mobility law that evaluates to zero at zero saturation. Run both actual paths through the event to the same positive end using integrate_exact.

This covers a net depletion rate that includes substantial liquid drainage, while the tiny terminal residual correction still has its original bounded **numerical phase correction** meaning. It does not cover general pure-transport depletion with zero evaporation. Supporting that larger case requires a separate transport correction contract, described below; deleting the current phase guard would mislabel removal as evaporation.

## What is already N-dimensional and reusable

- source_net_panel.build_source_panel already binds actual N-cell SourceExactEvaluation observations, N+1 shared faces, four fluid inventories per cell, disabled chemistry, fixed source kg, and all cell energies. Liquid boundaries are no-flux. Each cell's liquid polynomial is Nl0 + integral(Jleft - Jright - E); energy is U0 + integral(Qleft - Qright).
- source_net_roots.order_source_panel_roots already orders every liquid/gas inventory root with exact Fraction coefficients, including the actual cell label. source_approach and source_root_comparison carry that label through the two actual paths and compare exact absolute clock intervals. Reuse these rather than fitting a second root model or creating a new adaptive controller.
- source_net_prefix.build_source_prefix integrates each face once and inserts the same represented face amount/energy with opposite signs into adjacent cells. Its exact integrals, signed projection errors, full residuals and liquid-enthalpy diagnostics already exist. audit_source_prefixes and source_root_comparison._joined_reference_residuals demonstrate complete N-cell accumulation from one origin; their arithmetic can guide a small extraction, not a second independent ledger.
- exact_depletion_writeback already accepts cell_index and works on the full ConservedState. In the recommended positive-evaporation subset, keep it unchanged, pass k and the original gross evaporation evidence, preserve every other cell and the entire U array, and retain the existing DepletionRoundoffTotals.
- ExactSourceColumn.with_depleted_cells and SourceWetColumn.with_depleted_cells already accept an explicit tuple of indices. Selecting (k,) changes only the interface mode/operator identity; the fixed source masses and energy identities remain bound.

## Minimum interface changes

1. Extend SourceTerminal with an explicit selected_cell_index derived from the unique earliest ('liquid', k, 0) label, plus retained checks/records for the participating liquid faces. build_source_terminal can retain its present signature: derive k from the checked order instead of accepting an independent caller claim. The existing root_index argument identifies coarse/shifted path 0/1 and **must not** be repurposed as a cell index.
2. Replace only the N1 indexing assumptions: initial shape becomes (N,4); require the initial mode of every cell to be existing_liquid for this first slice; use initial[k,0], local phase[k], face[k], face[k+1], and exact_depletion_writeback(cell_index=k). The complete source panel/prefix stays N-dimensional. Require every unselected liquid/gas polynomial to remain positive through the selected clock interval, not merely at its endpoints.
3. For each active internal LiquidColumnFaceRate in the two actual samples, bind face incidence, the actual saved liquid_exchange donor/status, both decoded liquid states, source identity, relation/connection configuration and actual donor enthalpy. Recompute Q_liquid = J_liquid * h_donor in exact represented operands and retain the recorded projection residual. Require the full affine J interval to have the same nonzero sign for this limited terminal slice; donor reversal/endpoint ambiguity is an explicit unresolved/unsupported condition, not permission to select whichever donor is convenient.
4. SourceDryCandidate pressure_endpoints must become two time rows of N bound records. At each actual event/common endpoint, route a cell with exact Nl=0 to the checked dry enclosure and a cell with Nl>0 to the checked wet enclosure. The two compared paths must agree on selected cell and mode pattern. Compare N/U/T/P for **every** cell. The same-time source endpoint helper can be reused at the common end; event-time samples require the existing explicit unequal-clock comparison because measure_source_endpoint_pair rejects unequal times.
5. Generalize source_dry_transition._audit_path from its current cell-0 four-element arrays to N×4 inventories and N energies. Preserve both represented and full exact prefix accumulation, ordinary pre-approach segments, one shared origin, original tolerances, explicit correction at (k, liquid/vapor), and local plus global water/element/mass/U audits. Do not restart the budget at the terminal or at the shifted path's second segment.
6. If the current shared-dry pressure evidence is used, bind a declaration to the actual storage of cell k on both paths. It cannot declare different spatial cells to share one parameter just because their V/eV values match. Other still-wet cells retain the current full-temperature wet bounds. Failure of any original P gate remains a real failure to certify; a dry-cell improvement does not waive the wet-cell gates.

## Limits that cannot be removed as implementation shortcuts

- source_terminal.py:107–140 currently enforces N1, no liquid transport, cell 0, positive evaporation and a unique cell-0 liquid root. Some indexing can be generalized; the evaporation proof cannot simply be deleted.
- ExactAffineSamples already stores the complete signed (left face, negative right face, local source) triple, but ExactAffineEvidence and exact_depletion_writeback still impose delta <= gross_positive_evaporation × correction_fraction_evaporated. They transfer delta from local liquid to local vapor at fixed U. E=0 therefore permits only an exactly zero residual; it supplies no general transport projection.
- mass_wet_writeback is not a source transport alternative: it requires the unrelated two-solid AB layout and explicitly enforces zero liquid face terms. Do not fabricate solid mol/kg components to enter it.
- LiquidColumnFaceRate stores actual liquid J and enthalpy power Q. SourcePrefix integrates their two-sample affine histories separately. Even when Q=J*h at both observations, the product of affine J and affine h is generally quadratic; the independently integrated affine Q is a numerical quadrature record, not proof of a continuous constitutive product over the whole panel. Retain actual path refinement and endpoint comparison.
- An empty liquid_direction_reversal_faces tuple excludes only a strict affine J sign crossing. It does not prove the physical donor or full inverse-pressure direction. The current transport record explicitly says fixed_decoded_temperature and full_inverse_direction_certified=false. Preserve those qualifications.
- liquid_face_exchange checks zero mobility before requiring positive liquid on both sides. Thus an already declared SaturationMobilityTable containing saturation 0 with zero exact mobility can support an explicit dry zero-flow branch. The current frozen test table has positive mobility at zero and will instead raise active_face_requires_existing_liquid_both_sides. Do not silently set a connection to disabled after the event or replace its table in the dry adapter.
- A continuously vanishing mobility may cause purely hydraulic depletion to approach zero asymptotically rather than have a finite event. A finite zero of an affine numerical surrogate alone cannot settle that physical question. Positive evaporation in the first slice avoids pretending that the missing pure-transport event law has been established.
- Existing positive-prefix/root guards reject zero initial inventories. After the single event, integrate_exact can advance the explicitly mixed dry/wet mode, but this slice must stop before a second depletion. General repeated events/rewetting remain separate work.

## One independent manufactured validation

Use one actual SourceWetColumn/ExactSourceColumn with **N=3 and selected cell k=1**, which catches both cell-0 assumptions and omission of a downstream recipient. Start all inventories positive, use source caloric storage with the existing explicit manufactured liquid seam and nonzero original eV/eT, keep source kg fixed, and set a genuine internal pressure difference driving liquid from cell 1 to cell 2. Keep the other liquid face explicitly disabled from construction. Declare a saturation table whose zero-saturation mobility is exactly zero, and give cell 1 a positive actual phase-transfer coefficient so its net-loss polynomial has one unique first liquid root. Use real source evaluations, not a fabricated SourcePrefixTrial.

An independent Fraction audit should reconstruct from saved actual observations: hydraulic resistance and donor-selected J; donor enthalpy Q; the signed liquid triple for each cell; the integrated single shared-face amount and energy with exact opposite recipient signs; local phase removal versus transported liquid; every full prefix residual; the selected root label/clock; all-cell writeback differences; and final whole-column water and U balance. Verify gas/energy transport remains in the total face decomposition. The tiny residual vapor increment must equal only the original phase writeback record, never the transported face amount.

Execute both existing coarse/shifted candidate paths to one common end, preserving their original budgets and callback failure records. At the first dry evaluation, assert only cell 1 is dry, its adjacent active liquid face returns the already-declared zero_mobility branch, and recipient cell 2 stays wet. Compare actual event/common N/U/T/P across all three cells and retain numerical event rejection if any original bound fails. Add one negative variant of the same fixture with positive mobility at saturation 0: it must retain the DomainExit and completed prefix rather than manufacture a successful dry step. Source/material qualification remains false throughout.

## Later pure-transport extension, explicitly outside this smallest increment

A genuine E=0 transport correction would have to move a residual liquid amount to an identified adjacent recipient, with the same donor enthalpy energy transfer and signed corrections to both U values, plus recipient and donor projection errors and global budgets. It cannot increment local vapor. That needs a dedicated face-correction evidence/policy contract bound to the saved face history and a non-evaporation clock budget; the current evaporation-fraction limit gives no authority to invent one. Reuse the existing exact root isolator and original face/prefix ledgers, retain the phase helper unchanged, and obtain a separately reviewed mathematical contract before implementing this case.

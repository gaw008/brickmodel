# 来源干态的共享体积压力界与实际湿→干比较

基线 `c684bce`。本阶段实现显式共享恒定体积下的完整温度区间压力比较，
接入实际来源湿→干执行入口。新实际水物性案例通过原数值门槛；同材料
原污泥的反应、烧结、冷却与公开实验验证仍未完成，材料资格保持 false。

## 实现与适用范围

`source_dry_shared_pressure` 从实际已检查的来源 storage/volume 对象生成
显式声明。两端必须共享这两个 live 对象及原来源、固定干质量、体积与误差。
同值或同 digest 的独立存储拒绝准入。每次保存的声明包含过程内对象身份，
但 JSON 本身不能重建 live 对象关系。

在固定干物、无液水、关闭化学反应、理想气体储能不依赖 V 的合同下，使用
两端独立完整 T 区间和一个共同 V 区间，对 NgRT/V 压力差取精确 Fraction
角点。每端保留实际流体误差、原总误差投影和完整箱内的机器算术舍入界；
严格重建原 global/extra/total 分解，不猜测或删除未知误差。
完整绝对 T/P 域不足时保持 unresolved。[推导](DERIVATION.md)说明公式和边界。

只选用新的 joint bound，原独立界原值旁列。两种界尚未证明覆盖同一个
完整机器误差目标，不能任意取最小值。零 eV 的实际制造反例使旧 min 草稿
出现 RED；修复选择逻辑后通过，原草稿和失败保留。

`evaluate_source_dry_transition(..., shared_volume=declaration)` 显式启用新界，
执行前核对声明属于原路径。默认行为保持原两个独立 P gate 的逻辑合取。
两套 P 数值及旧 gate 均保存；新模式仅改变选用的压力证据，原 clock、N/U/T、
每个前缀累计账本和原 1e-4 Pa 门槛不变。没有修改原机械压力比较政策。

# 质量基准反应能量参考

本阶段新增 `reaction_reference.py`，在明确的组分质量和元素质量分数上求解 `Bᵀh₀=q`。逐反应检查质量与元素配平，检查已知反应热循环的一致性，保留完整零空间；未知反应热不当成零，只有不受剩余自由度影响的线性输出才允许求值。

这使伪组分可以使用 kg 基准的反应热约束，无需人为指定其摩尔质量。参考温度、压力、相态、基准、来源声明、未知值和不确定性声明随原始不可变 network 保留。锚点必须与网络参考状态一致，不能静默跨温压或相态转换。

## 物理边界与下一步

这是精确的名义代数关系及制造测试，不是原污泥材料参数包。来源 ID 是保留的声明，不代表已验证正文；没有传播测量不确定性，`material_qualified` 保持 false。数学循环不一致也不自动等于带实验误差的测量互相矛盾。

尚未提供组分 Cp、体积、温度反演、实际反应动力学或热湿输运。下一步将质量固体库存与摩尔流体库存显式分开，在同一总内能和参考约定下耦合反应、温度、压力及有限氧库存；反应热不可同时计入储能和额外外部热源。既有摩尔物性准入规则保持。

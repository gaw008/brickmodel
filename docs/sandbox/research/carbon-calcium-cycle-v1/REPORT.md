# 方解石、碳与气体共同升降温：全过程限定数值资格通过

本阶段完成一个封闭Ca/C/O/N库存的1bar虚拟量热器，初态300K，外界1150K保持1200s，再切换350K直到2400s。方解石分解与C/CO/CO2/O2组成通过同一个CO2化学势共同求解；[过程图](cycle.png)直接来自精细轨迹。库存和.005W/K换热系数都是明确的虚拟设定，来源化学数据、适用域与同相/相界推导见[静态耦合报告](../carbon-calcium-equilibrium-v1/REPORT.md)。

初始2mmol方解石、约1.5mmol石墨、1mmolCO2及4mmolN2已经处于所选平衡。升温中的方解石分解、石墨耗尽、方解石完全耗尽分别在约243.329432、689.675261、1004.919397s；切换冷源后按逆顺序发生相事件，约1209.535590、1260.425281、1360.448245s。冷却末态350.000805K，方解石恢复约2mmol、石墨约1.5mmol。这是瞬时平衡极限，不能解释为真实砖在这些时刻燃尽/回碳，也没有加入材料反应速率。

## 能量与熵定义

恒压、仅换热时dH/dt=G(Twall−T)，来源生成焓已包含反应能量，不重复叠加反应热。内部统一温度的平衡反应贡献进入Cp，所有相量随H反解共同变化。外界熵流−Q/Twall，热接触总熵产率Q(1/T−1/Twall)非负。气体体积按理想混合气报告，未给固体体积或活塞机械功预测。

每个保存状态及所有2/4阶稠密求积节点都从保存的USGS原始相参数重新计算H/S、Ca/C/O/N、分压、气体化学势、方解石与石墨单侧相条件。源码来源积分和运行时来源积分分别实现；稠密求积共享已经单独完成静态/热容/相界资格的H→T解码器。相事件引用独立相界只用于记录，不改变过程微分方程。

## 已执行结果

基础/精细两档分别1397/1731接受步，全部完成2400s并通过原冻结预算。来源核查覆盖3805/4139个记录状态以及8382/10386个稠密节点。最大累计热量余额7.96432e−7/1.88521e−7J，低于1e−6J；最大累计熵余额7.65850e−10/1.79738e−10J/K，低于1e−8J/K。最大来源H误差1.36425e−12J、H反解余额6.34373e−10J，元素余额≤1.02349e−16mol，化学势条件余额≤6.98492e−9J/mol。所有节点气体量正、固相量非负、熵产率非负。

2400个共同观测时刻的最大温差6.22380e−7K、组分量差3.19970e−12mol，低于1e−4K/1e−10mol目标。相事件数、方向所属段和每种边界的唯一对应均核对，六个事件的温度、消失相量和独立热量时间积分均通过。

另以60位算术在32/64阶Gauss节点解同时元素/化学势方程，直接在log气体摩尔量及方解石比例坐标微分，重建平衡Cp。这个参考不调用运行时嵌套标量组成根，也不复用反应基Hessian。积分在每个相界分段后累加到六个事件，最大事件时间差1.15891e−7s，最大Cp差6.20471e−12J/K，32/64阶时间差≤1.48037e−17s；各节点相稳定条件及正热容同时成立。数值精度并非原始热化学数据或真实材料的实验精度。

全程结束净吸热约17.2308414J（初末温度不同），系统与两个外界阶段合计熵增约1.88572844J/K。每阶段大量吸热与放热相抵，不能只用最终净热量代表窑炉燃料消耗。

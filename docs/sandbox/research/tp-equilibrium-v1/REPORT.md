# 受限 CHONS 高温平衡：来源、实现与实际验收

新增 `sludge_sandbox.tp_equilibrium` 和中文示例
`examples/sandbox/run_tp_equilibrium.py`。给出 C/H/O/N/S 元素库存、温度和固定
1 bar 压力后，计算18种理想气体与纯石墨的终态平衡组成，保存初态、终态、
元素残差、热化学来源和 Gibbs 检查。它提供了一个实际运行的高温组成模块；
完整原污泥烧结砖、有限反应时间、矿物和烧成能量闭合仍未完成。

## 物理与来源

温度域800–1200 K，压力100000 Pa；公共库存使用mol原子，内部Cantera库存
使用kmol并显式换算。气体为H2、H2O、CO、CO2、CH4、O2、N2、NH3、HCN、NO、
NO2、N2O、H2S、SO2、SO3、COS、CS2、S2，凝聚相为纯C(gr)。该相集、元素池及
工况是明确的研究设计；理想气体、NASA7多项式和固定体积石墨是有来源的模型。
焦油、矿物、其它固碳和未选硫物种的影响保持未知。

系数原件取自[Cantera v3.2.0](https://github.com/Cantera/cantera/tree/v3.2.0/data)，
原文件、BSD三条许可、所选记录和原始SHA均保存在
[来源包](../../../../data/sandbox/research/tp-equilibrium-v1/README.md)。
[NASA TM4513](https://ntrs.nasa.gov/citations/19940013151)第1–2页规定1 bar
标准态，但分发YAML缺省参考压力会由Cantera解释为1 atm。此版本保持全部
系数，显式给19个物种添加100000 Pa参考压力，分支名
`NASA1993_1BAR_EXPLICIT_REFERENCE_V1`。原分发文件不改。

已实际核读NASA方法页及N2/H2S/石墨代表原表；未声称逐原表复核全部18气体，
更未重新验证底层JANAF/TPIS/TRC实验。历史NASA气体常数与本次Cantera常数的
差异有记录，拟合误差、协方差及材料误差不填猜测数值。1000 K等号使用低温段；
原拟合两支存在约10⁻⁶量级的无量纲跳差，保留原值。

独立数学参考使用原打印十进制系数、精确binary64系数及120位Decimal对数，
分别计算19物种在800/1000/1200 K的Cp/R、h/RT、s/R、g/RT。它区分系数量化
和实际运算舍入；实际比较容差是名义算术检查，并非材料不确定度。

## 实际数值验收及保留的失败

初始算法为显式`gibbs`。第一次1000 K求解正常返回，但C/H/O/N/S残差分别为
−3.866e−9、−6.447e−9、−1.931e−9、−5.552e−10、−2.301e−9 mol，超过原门
`1e-10*(1+abs(b_e)) mol`。状态为`postcheck_failed`，后三个点没有启动。
物性与同池Gibbs检查通过，不能抵消元素失败。原代码、输入、输出与退出1记录
保留；监督9.884995792秒，进程已回收。

官方源码显示Gibbs分支对微量组分单独更新，退出条件只检查反应自由能，提供了
调查元素漂移的具体依据；没有内部迭代轨迹，不能认定全部残差的唯一成因。
新策略显式选`vcs`，保留`gibbs`供显式研究使用，禁止自动选择和回退。
VCS具有元素检查和修正，但仍必须通过相同外部验收门。

**VCS的TP实现未使用传入的`rtol/err`。**结果同时记录请求1e−10与实际内置
主/微量容差1e−8/1e−6、副容差1e−10/1e−8，不把请求值冒称有效原生容差。
元素、活跃物种化学势、石墨条件、Gibbs下降及下界检查全都保持原门。

新独立系列使用虚拟池C/H/O/N/S=1/1.6/0.6/0.1/0.01 mol，四点均通过：

| T (K) / 初猜 | 求解包装耗时(s) | scaled Gibbs gap | C(gr) (mol) |
| --- | ---: | ---: | ---: |
| 1000 / 元素基 | 4.763008 | 2.50858e−9 | 0.513505194 |
| 1000 / CH4替换 | 4.239975 | 2.64060e−9 | 0.513505194 |
| 800 / 元素基 | 4.256576 | 6.39663e−10 | 0.697117908 |
| 1200 / 元素基 | 4.248193 | 8.25917e−12 | 0.406064217 |

这些库存不是每kg污泥的产率。末态元素最大绝对残差3.76910e−16 mol；两个
1000 K初猜的最大物种差3.57909e−11 mol、G差1.58605e−10 J，均通过事先门槛。
四点初/末608项独立物性比较通过。独立保存审查81组通过，没有新增物性求解。

总驱动17.58784725秒、监督22.660594208秒，退出0且回收；1218项输入前后
不变。每调用10秒、驱动40秒、监督50秒加5秒清理的预算保持；这些是执行
资源限制，不是物理反应时间或内核级实时保证。

Gibbs下界使用实际读回的元素池计算同池gap，另列原请求池下界及精确残差
修正。其数学性质不能消除数值物性、对数和省略相的未知误差；只报告名义
计算检查通过，`material_qualified=false`、`training_eligible=false`。

## 软件验证与使用

最终VCS模块SHA为`da382eead7211e5a91a1630fbe30a75a8c7feca9cb1af6814398c57f8914849c`。
独立Python3.12.13环境非editable安装，187包文件/180模块与源逐项一致；
20项正式安装测试通过0.100秒。原快照同步、部分读取和薄驱动计时/保存的
真实制造反例保留，并有针对性修复；没有把制造反例称为旧原生物性失败。
既有低温物性环境未更新，也未重跑未改变的整库套件。

安装本项目的`equilibrium` extra后，在仓库根目录运行：

```sh
python -I examples/sandbox/run_tp_equilibrium.py --source-root . \
  --output /tmp/new-tp-result.json --temperature-k 1000 --solver vcs \
  --carbon-mol 1 --hydrogen-mol 1.6 --oxygen-mol .6 \
  --nitrogen-mol .1 --sulfur-mol .01 --basis-id virtual_CHONS_C1_mol
```

输出须为新文件，失败返回非零且保存已返回对象。模块内部预算只在调用边界
检查，实际验收另使用已有进程监督器。没有提供自动恢复原生平衡进程的承诺。
Python入口是`TPPool`、`TPPolicy`、`solve_tp`；结果直接包含来源和名义数值
诊断。这一示例不属于已有动态轨迹`run/replay/resume`目录协议。

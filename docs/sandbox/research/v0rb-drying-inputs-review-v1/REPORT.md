## 下一具体决定

1. **结束本轮MSJ公开入口补查与复核。** 保留已冻结的部分观测及来源资格；没有新链接、数据或作者说明时，不重跑同一批检索，也不继续把它当作已齐全的D1材料包。
2. **下一独立F0-C限定为完整公开干燥基准的可得性筛选，优先砖坯/黏土试件。** 先复用现有来源目录，只对确有新增信息的候选补查。筛选依据是数据与物理问题相容，而非曲线容易拟合；任何替代均作为新候选记录，保留MSJ原包及其角色。
3. **候选需提供或有依据地限定以下最小组合：** 材料/制样与几何；温度或失水的完整时间序列及重复/误差说明；初温和湿/干质量基准；与方程对应的热风温度、速度、水汽含量/压力和干扰协议；必要同材本构或可辨识的有效参数及独立评价数据。缺完整误差时可以报告偏差，但不能宣布“实验精度内通过”。
4. **若候选仍不足，交付明确的数据获取或最小实验方案。** MSJ路线需要作者提供原始记录及缺失协议；联系作者须取得发送授权。新实验须明确材料批次，不伪称原研究重复。本轮没有发信、安排实验或切换运行材料。

因此下一阶段应产生新的可用数据或明确可执行的获取方案。物理假设、必要输入与验证依据通过后才进入D1；本次附件复核本身不证明干燥、烧结或整砖过程准确。

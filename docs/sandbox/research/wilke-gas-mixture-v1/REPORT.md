# 混合气体黏度来源计算资格

2026-09-25 UTC。以已核对的CO/CO2/O2/N2纯气体Lennard–Jones黏度作为输入，增加Wilke低密度混合规则。来源为[Cantera 3.2官方方程说明](https://www.cantera.org/3.2/cxx/d8/d58/classCantera_1_1GasTransport.html)及本地保留的同版本GasTransport.cpp第60–101行，官方归引Poling 2001方程9-5.13/9-5.14；源码和BSD许可保存在gas-transport-source-v1/source。

生产实现按源码计算三角配对权重，再用互易关系填充另半矩阵；80位独立参考逐一用完整源公式计算所有有序权重。300/600/1200K，各3组四气体组成、4个纯气极限和6个等摩尔二元组，共39状态全部通过原预算。最大黏度误差1.241083e-20Pa·s，权重误差4.620388e-16，反向排列物种后黏度差2.032880e-20Pa·s；12个纯气极限误差为零。

全部参数、纯气输入、实际权重、80位参考及每项判据保存在根JSON与 `data/sandbox/research/wilke-gas-mixture-v1/source-review.json`。这是混合规则的来源算术资格。纯O2的旧实验表偏差、自由气体碰撞模型误差不会因为混合计算通过而消失；没有新的混合物实验或材料资格，也未推导实际砖渗透率。只用于后续独立的等温多孔气体输运阶段，未接入反应列。

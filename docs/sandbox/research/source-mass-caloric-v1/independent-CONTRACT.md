# 来源干基比热到固定质量储能：独立物理合同

本审查只读现有arlabosse_caloric.py、mass_storage_bridge.py、mass_wet_storage.py及已保存Arlabosse元数据，不重新搜索论文、不改仓库。本合同是适配器正确性界限，不代表完整湿储能/材料验证已经完成。

## 1. 最小可接受物理定义

材料必须固定为Arlabosse2005原混合来料的干物，来料85%工业/15%市政、所述曝气沉降/气浮/离心处理。其Cp关系不能按名字改为Nylen MSJ/CB、Wang、纯市政污泥、粘土混合砖、char或ash。源元数据及资产保持既有provider检查，输出必须保留source_id、节点、干基单位、材料身份、域和未知拟合误差。

来源关系为Cp(T_C)=1434+3.29T_C J/(kgK)，仅35–105°C。在显式“固定干物质量、无化学反应、刚性不可压缩固体、常比容、无机械形变”的模型假设下，使用来源定压焓差作为内能差：

`u(T)-u(T0) = h(T,p_ref)-h(T0,p_ref)`。

这里常比容使p_ref*v在差值中抵消；并不是来源测得了一条一般Cv关系，也不是刚性容器自动让所有实际物质Cp=Cv。若后续允许固体热膨胀、可压缩性、可变含水复合比热或机械形变，此推导不能原样继续。当前纯干物适配器无需数值比容即可计算差值，也不应为此填造密度、固体摩尔质量、形成焓或湿格孔隙体积。

T0可由用户/模型显式选择，但必须在35–105°C内。定义u(T0)=0是保守固定干物能量坐标，输出最好标成`reference_relative_internal_energy_j`或明确reference_coordinate，避免暗示绝对能量。298.15K在来源域外，不能为了旧WetMixedStorage参考约定进行外推。

## 2. 推荐的最小API与拒绝边界

- 构造参数：明确的`ArlabosseDryCaloric` provider、真实来源材料ID、固定正干物质量kg、显式域内reference_temperature及单位、显式`ReactionDisabled`、固定上述本构假设ID。所有这些进入模型身份；不要接受一个任意source label把外部多项式包装成该来源。
- forward(T,unit)：调用既有provider.delta_h(T0,T)，乘固定质量；返回精确来源关系值/数值表示、点值总热容、材料/坐标身份、数值舍入界、物理fit uncertainty=unknown。signed相对U合法：T<T0时可以为负，不得剪裁。
- whole_bracket_minimum_heat_capacity(a,b,unit)：要求完整闭区间在来源域内且a<b，按正斜率取m*Cp(a)，返回严格数学下界。不得拿查询点Cp充当整段下界。zero_mass应在构造拒绝，否则逆解不唯一。
- inverse：接收带同一模型/质量/anchor身份的能量目标、完整域内括号、明确数值公差和最大迭代数。输出温度、能量残差、数值温度误差上界、最终括号/迭代数；目标超括号或数值符号不分辨时拒绝，不剪裁至端点。精确端点目标可以按明示端点成功处理。
- ReactionDisabled：表示本阶段无化学转化，固体质量变化严格0，化学气体生成严格0，反应参考功率严格0；不得构造虚拟A/B、reaction[0]或氧参考。它不声称现实污泥在任意温度无反应，也不自动关闭后续湿模型中的水相变。
- 现阶段不暴露WetMixedStorage-compatible假身份，不自动生成体积、压力、流体库存或N格积分结果。该适配器可用于后续公共储能内核，但不能直接宣称已接通完整湿格。

若选择把质量作为forward参数而不是构造属性，也必须在每个能量目标中绑定实际固定质量与身份；同一演化轨迹中改变质量必须拒绝。不同独立样本使用不同质量是合法新问题，但不能利用reference gauge不变性声称固体质量输运/反应已经闭合。

## 3. 能量坐标与反应禁用的必要约束

固定质量m时，anchor从A改为B会给所有温度的U增加同一常数`−m*delta_h(A,B)`。只有同步变换目标和模型身份，温度结果才不变。把旧能量数值原样送给新anchor会产生不同温度，必须由身份门阻止无意混用。

当固体质量变为m(t)，anchor平移产生`k*dm/dt`项。物质流入/流出必须携带一致参考焓，反应必须有可识别的反应参考差。因此本适配器**不得**提供“任意反应/固体质量变化仍可忽略参考”的方案。ReactionDisabled不能成为绕过质量变化检测的装饰字段，也不能接受额外非零reaction source后继续工作。

## 4. 误差必须分开

provider把来源十进制系数作为精确Fraction做运算，这是“该已声明拟合关系”的数学精确性，不是材料Cp无误差。未知拟合残差和参数不确定性保持None/unknown；不得为未知物理误差填写0，或把数值误差上界包装成真实材料置信区间。

若全程Fraction，可严格评价forward值及整体导数下界；若输出binary64，需要独立记录该转换舍入。反解可用残差绝对值加数值误差除以整段正C_min得到数值温度上界，并配合括号检查；这个界不包含未知fit error。Arlabosse provider默认float输入按最短十进制解释，主机如采用binary64精确状态，应显式传Fraction.from_float，不能无声混用两种解释。

## 5. 独立精确参考例（无需调用被测函数推期望值）

选择m=1/5kg干物、A=40°C、真实目标T=80°C。直接积分线性多项式：

`delta_h(40,80)=1434*40+(329/200)*(80²−40²)=65256 J/kg`。

所以`U_A(80)=65256/5 J =13051.2 J`。全35–105°C括号：`Cp_min=Cp(35)=30983/20 J/(kgK)`，总`C_min=30983/100 J/K=309.83 J/K`。80°C点Cp为8486/5 J/(kgK)，大于括号下界；若实现误用点Cp，这项能区分。

独立反解写`c*T²+b*T−Q=0`，b=1434、c=329/200，`Q=c*A²+b*A+U/m=125248`。判别式`b²+4cQ=72012196/25`，其正平方根`8486/5`。用稳定正根`2Q/(b+sqrt(discriminant))`得到严格80°C。实现的数值inverse必须覆盖此真值并满足声明残差/温度门槛，不能只做forward→inverse自我一致测试。

改anchor为B=60°C：`delta_h(60,80)=33286 J/kg`，`U_B(80)=33286/5 J=6657.2 J`。坐标差`m*delta_h(40,60)=6394 J`，故`U_B=U_A−6394`；两个适配器反解各自匹配身份的目标，温度都应为80°C。将旧anchor目标不加转换给新模型应明确拒绝身份不匹配，而不是拿另一温度宣布anchor不变。

本例数值已用独立标准库Fraction计算核实，没有依赖被测adapter实现。额外必要拒绝项为：域外T/anchor、零或负质量、非有限输入、非来源材料ID、非ReactionDisabled、目标身份错配。当前工作完成意味着来源干基固定质量储能适配与数值反解可用；并不意味着Nylen材料预测或原泥完整烧结过程已完成。

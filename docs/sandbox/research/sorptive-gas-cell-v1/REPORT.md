# 吸附水与共同气流：单元条件过程完成

2026-09-22。按[事前合同](CONTRACT.md)落实低含水吸附储能、H₂O/O₂/N₂共同交换和完整U。它复用已有来源模型，新增无需SHA执行的记录入口和压力/库存消元；没有新拟合材料常数。

**新的限定能力是计算含吸附水、可共同通气的单元脱水，保留吸附能与干端参考。它不是实际砖坯干燥预测，也未完成原M1材料Goal。**

## 来源与模型边界

Arlabosse2005的[原论文](https://doi.org/10.1590/S0104-66322005000200009)给出干物Cp与95°C活动度/总解吸热曲线。本窗口重新目视核对本地原公式/两图，并核查出版方检索文本中的Cp关系与35–105°C范围；直达HTML访问失败也不影响已有原件记录。未重新拟合或改读图值。

使用已有W=.15接点及以下条件：低W理想稀释形状、零过量Cp/体积、温度延伸、固定干质量和瞬时局部平衡。误差未知；尤其当前330K过程并非95°C实测干燥轨迹。原料为混合工业/市政废水来源活性污泥，不转移为MIA3或黏土砖。

独立分段积分与准备值最大焓差2.48e−10J/kg干物；接点活动度差1.12e−16，解吸热差0。12个温湿状态的自由能/化学势/偏摩尔焓导数关系在1e−5J/mol数值目标内。同曲线W=.10活动度预测0.345712，读图区间[0.342169,0.387019]；这是同曲线有限留出，不是独立实验。该点实测解吸热仍未知。

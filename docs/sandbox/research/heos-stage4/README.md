# HEOS stage4: TP density refinement and bounded numerical coverage

Isolated research candidate only. Production remains Python IAPWS1.5.5, commit6dc5aa9 source. This packet adds actual high-pressure TP solve refinement and broader validation. It does not qualify a sludge material, prove continuous-domain accuracy, admit mixture/storage hosts or measure speedup.

## Implementation and unchanged gates

Native PT flash chooses a stable branch and supplies a density seed. Its phase must pass before any imposed-phase update. Log-density Newton solves pEOS(rho,T)=the original requested pressure, with derivative rho RTD, positive slope/branch checks, at most8 evaluations and step magnitude<.1. Acceptance target min(1e-4Pa,rho*1e-7J/kg) is an explicit numerical policy beneath the original1e-6J/kg energy identity budget; no parameter is a material uncertainty. Native h/u/s are never reset, and output pressure remains the requested pressure. All original Table3, Gibbs, pressure, caloric, heat-capacity and response gates remain in force.

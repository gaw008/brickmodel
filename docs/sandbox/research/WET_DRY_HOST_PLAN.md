# 实际固液气主机的湿→耗尽→干态继续积分（事前）

首例使用现SolidFluidHeat与ProgrammedSolidFluidHeat、真实源门禁水/理想水汽和完整库存列。制造固体2mol、Cp50、v1e-6m³/mol；初始H2O汽1e-8mol、液1e-6mol、载气fixture0.001mol，初温300K，bulk1e-4m³。活跃相间K=1e-6mol/(s Pa)是制造值且全程保留，不改为0；只有事件记录授权existing_liquid→depleted_no_nucleation。首例strict低温模式，保留凝结/未知退出规则。

一侧受热：k=.1W/(m K)、半厚.005m、面积.01m²、膜h=10W/(m² K)、epsilon=0。源方程给G=.01/(.005/.1+1/10)=1/15 W/K；炉气在0、1/64、1/32s为330、340、335K，载气/水汽库完整但D与permeability为0，故边界只交换热。实际程序节点不能跳过。运行到1/32s，事件应在节点前；这是制造有界过程验证，不是材料实验。

验收：完整求解状态completed且终时精确1/32；只一次真实耗尽事件，开始Nl>0、终态Nl=0而K仍1e-6，实际dry模式出现且后段时间增加。水相总mol误差各prefix≤1e-12mol，载气/固体不变，M和H/O由原水摩尔质量/公式独立核算，绝对质量误差≤1e-13kg。逐StepLedger及全prefix的总U差与共享边界热/功账本≤1e-7J，事件数值修正与存储舍入单列加入审计；没有重复潜热。最终T减去条件反解界应高于耗尽后T加界，证明真的继续升温，不能只比较名义浮点值。

另在保存的每个普通/事件Euler stage检查表面热流与独立G(Tgas−Tcell)或相应记录误差一致；如果接口不保存stage，独立复评保存的状态点并限定为该时刻诊断，不将端点梯形面积当实际账本。气、液、固温度仍在共同293–310K内；本例不跨高温或证明EOS独立正确。事件时间和共同后续时刻的数值误差由独立恒/时变汇oracle及真实host细化比较共同检查，不能将同一event算法自报差值当全部证明。

初始事件政策建议time1e-7s、库存1e-10mol、U1e-6J、T1e-5K、P1Pa；这里是积分政策，不是上述结果门槛/实验不确定性。每run墙钟120s、max500steps/100reject；先一条实际运行，依据实测成本再增加两个细化版本，不默认长积分重跑。任何失败产物保留，不能因失败放宽结果门槛。第二例目标是两格有液面/反应的非同时事件，待第一实际单格通过再在原合同下实施，不把这一个例子称为完整多格湿砖验证。

attempt01在120.56s/1009评估时退出，未提交事件；运行期间源码变化，其末尾hash只作post-run快照，不是执行绑定。attempt02把干态共同时间续算与湿终端cap分开，保留普通adaptive精度，仍在120.63s/235评估退出；保存各level差值和成本。第二次仅test_depletion_integration.py在运行期间新增测试，全部生产src前后相同，但不宣称完整冻结执行绑定。

第三次把terminal_window从1/1024s收紧到1/16384s，让普通湿前段先推进并只保留一次，其后再做局部终端细化。time/amount/U/T/P各门槛、common horizon1/256s、墙钟120s与输出验收全部不变。现有实测显示重复湿前段反解占成本，这项修改收紧终端步，不是放宽比较门槛。另修复初始tau小于window时相邻level会使用完全相同terminal的缺陷：细化base cap受初始tau约束，后续必须真实缩短cap。普通湿段累计误差仍由普通积分政策控制；局部事件细化指标不是全轨迹ODE误差证书，独立非线性制造反例见depletion_cubic_probe.json。

# 相同通量的来源积分表示

原力 Y=μL/TL−μR/TR+h平均(1/TR−1/TL)。由理想气体μ=h−Ts+RT ln(p/p0)，逐项消去来源常数得到 Y=Δs−Δh(1/TL+1/TR)/2−R ln(pR/pL)。Δh=∫Cp dT，Δs=∫Cp/T dT，积分区间均为TL→TR。Cp沿用USGS同一a+bT+c/T²+d/√T+eT²，数值实现对温差用因式分解，对近单位压比用log1p；不存在新物性、库存截断或输运系数调整。

70组面包括五组正反向虚拟气体状态、两条已保存前缀在五个指定时刻附近的末端四面及内外表面。以相同二进制输入提升到50位，独立原势函数及展开矩阵作参考。来源积分写法最大力差1.52253e−14J/(mol K)、物种率2.46509e−18mol/s、携能率9.37164e−13W，全部达到预登记算术目标；原相减写法分别3.01445e−13、3.35909e−17、1.10979e−11。改进只说明这些状态的算术误差减少，尚不能证明原极小步长只由相消引起。

新显式入口同时用于内部面与零储量表面，解析导数采用相同已计算力。冷态、热梯度、冷却、总碳耗尽附近四场的守恒、熵恒等式及守恒导数通过；普通双精度中心差分仍失败并保留。独立50位三档中心差分共12项全部达到原1e−5预算，最坏8.314e−7，未改验收门槛。旧均匀算子在相同输入下完整静态输出完全复现；首次比较误用了不同差分步长，false记录和纠正参数均保存。

# 同研究残留固体燃料能量与材料准入

实际核读 GNEST DOI `10.30955/gnj.003738` 已缓存原文的实验方法、Eq.2、3.2节和Table4，复核原始文件身份及干基、氮气、10 K/min和端点对应。仅对该研究的制备污泥作名义计算；独立试件配对及联合误差未知。

按报告的固体产率乘干固体低位热值，570°C与960°C分别得到5.376063、2.951553 MJ/kg初始干进料。Root使用Fraction独立复算，与作者Decimal计算一致。两者差2.424510 MJ/kg是固体保留燃料能量的变化，不是热解反应热或炉体热需求。

实际数据见 `data/sandbox/research/gnest-char-energy-v1`。四节点来源链保留原读数、真实MJ/kg单位、显式SI转换与乘积推导；实际安装包已完成四节点查询。初稿缺上游依赖被现有注册表拒绝，RED与修复保留。新MJ/kg单位仍禁止与无量纲或J/mol直接转换；单位及来源测试42项通过，获独立代码审查。

当前仍不能把该研究接入实时混合热反应模型：反应系数的质量缺口、完整元素/相态基准、同组分Cp和体积数据尚未闭合。未知误差没有填零，也未从其他污泥样品拼接参数。详尽准入表、来源记录、实际计算、独立复核和追溯输出见归档；不转载许可存在冲突的论文全文。完整材料验证保持未完成。

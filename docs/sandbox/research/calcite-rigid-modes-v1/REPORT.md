# 解析空间算子与共存静止族

从熵Hessian和迁移率矩阵独立重组的连续扩散矩阵，与实际柱Jacobian在4/8/16/32格、余弦波数1/2、三个守恒坐标方向上的作用一致，最大缩放算子残差5.93e−15/s，低于预定1e−10/s。三个参考相态的扩散特征值均为非负实数（浮点预算1e−15m²/s）：

| 参考态 | 三个扩散特征值（m²/s） |
|---|---|
| 纯方解石+气体，900K | 1.662758e−8、6.928758e−8、8.233516e−8 |
| 两固相共存，1000K | 0、7.316944e−8、9.058395e−8 |
| 纯CaO+气体，1150K | 3.958942e−8、1.851700e−7、8.730235e−7 |

这些值由声明虚拟输运参数和指定状态推导，不能称为真实砖测得的扩散系数。离散波数平方满足标准封闭均匀网格公式，随加密趋近连续值；这是线性化算子核查，不能替代强非线性、相变和初始突变过程的网格资格。

共存态确实存在保持温度及两种气体分压固定的组分变化方向，解析零方向残差1.33e−23m²/s。在16格上施加总碳密度±10mol/m³的精确余弦单元平均，同时按该方向改变N2和U：所有格仍为共存，温差3.76e−12K、压差1.63e−9Pa、最大物种流3.37e−21mol/s、能流1.42e−14W，全部满足预定目标。

因此，在这个没有骨架应变能和毛细能的条件模型中，热/气体平衡可以对应不同的局部固相比例。不能错误地把“最终C/N/CaO不完全均匀”一律判为质量泄漏，也不能反过来将这种非唯一性当作真实砖结论。实际骨架、孔结构和界面能仍是单独的未闭合问题。

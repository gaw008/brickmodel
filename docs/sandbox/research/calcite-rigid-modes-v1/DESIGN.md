# 刚性反应柱的解析模态与共存静止态

令z=(C/V,N/V,U/V)，熵密度s(z)，w=∇s=(−μC/T,−μN/T,1/T)，H=∂w/∂z。固定均匀参考态下，气体迁移率矩阵L=λb xxᵀ+λd vvᵀ，v=(1,−1)。令P的三行为(1,0)、(0,1)、(hC,hN)，则完整守恒量迁移矩阵M=P L Pᵀ+diag(0,0,kT²)。所有系数来自本算例根参数文件的声明虚拟值。

通量J=M∂xw，故线性化方程∂tz=D∂xxz，其中D=−MH。单元库存熵Hessian乘该单元V才是密度坐标H。D不必对称；由M正定、H半负定可知本构内的扩散率为非负实数。以声明密度尺度做相似变换只为改善数值条件，不改变特征值。此阶段独立从熵梯度与迁移矩阵重组D，再对照已实现交换面和柱Jacobian的实际作用。

封闭绝热区间长度L下，cos(mπx/L)符合两端零梯度。连续衰减算子是−(mπ/L)²D；均匀有限体积网格的离散算子是−[4 sin²(mπ/(2N))/dx²]D。记录每格余弦的精确体积平均，不用采样误差替代网格误差。核对4/8/16/32格、m=1/2的全部三个守恒坐标方向，并记录离散谱趋近连续谱的二阶误差。

两固相共存时H具有零方向。这不是负扩散或漏写反应：在相同T、CO2/N2分压下，固相比例和气孔体积可共同变化。令ρg=g/Vg、ρn=N/Vg、d=vc−vl，则保持这三个强度量固定的路径满足dg/dC=−ρg d/(1−ρg d)，dN/dC=−ρn d/(1−ρg d)，dU/dC=(uc−ul)+ΔU dg/dC+un dN/dC。三者关于C均为仿射关系，在库存仍允许两固相共存时构成有限幅度的精确静止族。核查其零方向和空间起伏下的同温/同压/零流，避免错误要求所有局部固相比例趋于相同。

这套不可压固相、无应变能、无毛细能的声明模型允许这种非唯一性；真实砖的骨架约束和界面能可能破坏它，目前未有数据闭合，不能把数学零模态当作实材结论。

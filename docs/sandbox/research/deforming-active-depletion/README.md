# 规定形变、活动蒸发与耗尽续算的组合验证

本实验使用真实来源水物性与明确制造的固体/界面系数，沿用 integration-clock-correction 的运动、几何和骨架模型。目标是检验湿态到耗尽再到显式干态时，总能量身份、当前几何、相变和机械功账本在同一实际主机中保持一致。它不授予原污泥材料适用性，也不是自由烧结、完整砖烧制或独立轨迹真值。

## 预登记与单次回调

从既有 wet_dry_host 取液库存1e-6 mol、相变系数1e-6 mol/(s Pa)、逆解1e-6 J/1e-6 K/120次；其他库存为固体2 mol、水汽1e-8 mol、载气.001 mol。此案例保留规定运动和封闭外部面，没有把 wet_dry_host 的炉温边界也移入。所有人工量明确为 manufactured_test_fixture。

实际安装包运行 callback-attempt01，exit0/外部1.988353041s。初态.5s、300K，回温299.999999999856K、总能残差−1.437729224562645e-8J；非零蒸发率.0035312221883480213 mol/s，液汽源精确成对。五项功与基底完全一致，未重复加入潜热。实际安装Python文件与源字节核验、监督输入前后绑定及数值审查保留。

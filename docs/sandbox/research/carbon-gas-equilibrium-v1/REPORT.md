# 有限碳氧平衡和热容已通过限定数值核查

目前可在298.15–1200K、100000Pa下，根据有限C/O元素量及惰性N2量，计算纯石墨、CO、CO2、O2、N2的受限平衡组成、焓、熵与热容。物种数据全部来自[USGS Bulletin 2131](https://pubs.usgs.gov/bul/2131/report.pdf)，来源页、表值、适用温区和另一来源的差异见[热化学来源报告](../carbon-gas-thermochemistry-v1/REPORT.md)。这里的100000Pa就是来源标准压力，未加入固体压力/体积延拓。

这是封闭元素库存的瞬时化学平衡，不给着火或反应所需时间；纯参考石墨不代表污泥焦。气体视作理想混合物，氮气在所选物种集合内惰性，排除了氮反应和其他碳物种。极低的连续体痕量O2（部分算例约8e−73mol）是热力学活度的数学结果，不能理解为有限容器里可数出的分子测量。

## 组成与平衡

标准化分压pi/p0进入μi=gi°+RT ln(pi/p0)，纯石墨活度为1。石墨存在时同时满足C+O2/2⇌CO、C+O2⇌CO2；耗尽时仅气相反应CO+O2/2⇌CO2保持等式，石墨形成方向的单侧Gibbs条件决定固相不能自行出现。元素C/O/N逐项守恒，N库存指N2摩尔量，元素N为两倍。

石墨存在分支由氧平衡和压力归一导出稳定二次根。耗尽分支使用氧气/氮气摩尔比z的单调标量方程，求根两端由元素差额解析推出，未设置浓度下限。理想混合气的Hessian为RT[diag(1/ni)−11ᵀ/ng]；Cauchy不等式使其半正定，固定正N2排除整体缩放零方向，在受限气相可行空间严格凸。固相项线性，结合单侧条件说明得到的是所选物种集合的Gibbs最小值；并不证明遗漏物种也不稳定。

3组明确虚拟库存、8个温度的24组状态，使用60位原Cp/Cp/T直接积分及独立三元log摩尔量方程复核，全部达到冻结预算。所有正气体都比较相对误差，没有忽略痕量：最大相对误差2.08793e−13，最大绝对量误差5.47522e−17mol。元素、总压、化学势条件以及来源H/S/G同时通过。

## 热容与相界

在恒压平衡态，以反应进度ξ为独立变量，M=∂²G/∂ξ²，平衡约束微分给出M dξ/dT=Δh/T，因此Cp_eq=Σni Cpi+ΔhᵀM⁻¹Δh/T。正定M使反应贡献非负。石墨存在采用C+CO2→2CO和C+O2→CO2为基，避免相减两个含极小O2的大矩阵项；耗尽时只剩气相反应。组成导数同时满足每个元素导数为0。

18组同相状态、3档温差共54次60位独立差分，Cp=dH/dT及Cp=T dS/dT全部通过原预算。最大误差分别5.44164e−10和6.23899e−10J/K，组成导数最大绝对误差6.34089e−15mol/K。极小物种导数的相对误差也完整保存，但未设相对通过预算，不将其标记为资格。

C=.0015mol、O=.002mol、N2=.004mol的虚拟库存，在933.2397397463666K石墨耗尽。独立四变量元素/化学势方程与实现温度差4.84398e−13K。H与S连续；热容两侧约.8850020和.1883736J/K，发生跳变，不能跨相界要求普通导数连续。1e−3/1e−4/1e−5K三档两侧投影和独立导数均通过冻结目标，最大H投影误差1.81560e−10J，S误差3.13528e−13J/K。

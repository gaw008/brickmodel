# 有限碳氧体系：逐阶段资格

1. 采用已核对的同一USGS 1995石墨、CO、CO2、O2、N2参考数据。在来源标准压力下限定物种集合，先完成元素守恒、气相反应平衡和石墨存在/耗尽的Gibbs最小值条件。
2. 分别验证同相区的Cp=dH/dT=T dS/dT及组成导数；相界独立四变量求解，检验H/S连续与两侧热容。完成后才能以H作为升降温状态坐标。
3. 冻结虚拟封闭、恒压、仅换热的升降温参数；保存两档时间精度的全部接受步、稠密输出和相事件。对全部记录重建来源、物质及能量/熵收支，做独立区间求积、相事件时间积分和时间比较。
4. 上述数值通过仍只限定于纯石墨与理想气体的瞬时平衡；真实污泥碳不能由此替代。后续任何真实碳反应动力学必须另有同材料/同过程的可追溯数据。

初始元素量、换热系数、容器程序均是明确虚拟选择。没有高温水、有机裂解物、其他碳物种、表面反应速率、着火时间或真实砖传质数据；没有给材料或训练资格。

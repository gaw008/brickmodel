## 来源与定义

原文是[Septien等2020](https://doi.org/10.1016/j.jece.2019.103652)的VIP粪污研究，不同于Arlabosse泥料。实读JATS Table 2同30% MIR制样支路：湿基23±6%时k=.056±.001，47±2%时k=.062±.002 W/(m·K)。名义坐标转换为W=23/77与47/53，声明线性插值，实际模型域W=.30–.80。原k测量温度未知，制样85°C不能替代它；35–95°C保持同W下k不变是额外假设。原90%区间不变成插值或跨材料误差范围，后者仍unknown。

来源分类、实读日期、原文SHA、列/行文字、单位及变换可机器读取，见[参数包](../../../../data/sandbox/research/septien-conductivity-v1/README.md)。构造及公开读取复核原XML、事实/模型pin和真实表格对应。初次原件点值核对得到k(330K,W=.5)=.05805375；随后分类元数据更新仅改变来源记录和依赖身份，原物理值不变并有深比较记录。当前native使用最终来源/模型版本。

新支路明确选择`mixed_source_exploratory`，静态WetFace导热系数必须均为0，所有实际导热由来源接口提供；其它气体传输、相变系数和几何仍是制造值并单列来源。N=1也逐格检查有效域及来源，不能利用无内部面绕过准入。旧默认纯水/吸附分支保留，旧exact/programmed协议未开放新来源导热执行。

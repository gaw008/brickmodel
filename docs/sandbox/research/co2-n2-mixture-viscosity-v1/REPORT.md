# CO₂–N₂ 混合黏度的来源偏差

Vogel、Bich 与 Hellmann 2023（DOI 10.1007/s10765-023-03233-y）表1提供253.17–473.30K的8组准等温数据、3个N₂摩尔分数，共24个混合黏度值。它们由Humberg2018的密度序列测量外推至零密度，CO₂纯气值来自Schäfer2015；不是直接零密度测量。原测量k=2扩展不确定度0.14–0.49%，不能直接当作截距的完整传播不确定度。

在计算前冻结0.5%加表列末位舍入的筛查范围。Wilke算术由80位独立公式核对，48组全部通过；但使用CO₂2017/N₂2004参考纯气关联式时，24/24超筛查范围，最大偏差1.9648%。改用同表纯气截距也24/24失败，最大2.1537%。因此偏差不能归结为当前浮点算术或仅仅纯气物性，不能通过增加网格消除。

根参数`parameters.co2_n2_mixture_viscosity_source_review.json`保存所有原表读值、定义和预算；`review.json`保存全部正负偏差。来源PDF在`data/sandbox/research/co2-n2-diffusion-source-review-v1/source/`。表1已经人工视觉核对。

600K不在这些测量数据内。本结果指出Wilke近似有已知误差，没有证明600K具体误差幅度。相关旧轨迹保持原物性，新的600K参考物性孔隙柱暂停空间加密。

# 反应库存与CO2/热交换共同账

承接封闭混合物热化学，将每格总碳C改为可输运状态；每格Ca与N2固定，H为包含全部相的总焓。两个等压可动边界单元之间是显式假定的CO2选择透过膜及热接触，对外无物质和热交换。目标是验证反应与输运接线，并不声称膜模型或迁移系数是砖孔事实。

在给定T、C、Ca、N2下先求peq。若peq≥总压或C不够达到平衡气体量，全部Ca为CaO，气体CO2=C。否则平衡气体量ceq=N2 peq/(P−peq)；若C−ceq大于Ca，全部Ca为CaCO3，CO2=C−Ca；其余两固相共存，CaCO3=C−ceq，CaO=Ca−CaCO3，CO2=ceq。保留直接计算的极小正CO2，不能先做C−CaCO3大数相减来丢掉平衡气体。在共存分支，∂H/∂C|T=hCaCO3−hCaO；在纯固相分支为hCO2。

交换面以左到右为正。hface=(hCO2,L+hCO2,R)/2，Y=μL/TL−μR/TR+hface(1/TR−1/TL)，NC=L Y，JH=G(TL−TR)+hface NC。L和G是根参数中明确声明的虚拟系数；这是满足热力学方向的条件现象学关系，不是分子输运或真实砖的实测关系。对应组合产熵为G(TL−TR)(1/TR−1/TL)+L Y²。每格接收同一NC/JH的相反数，没有额外重复反应热。

静态阶段先核20组T/C的元素、平衡稳定性、dH/dT、dH/dC及dH−T dS=μC dC，再做正反/相等状态面。对CaCO3与CO2同时平移每mol碳的H/S参考零点，要求物理状态、NC、产熵不变且JH只改变常数乘NC。它检验完整反应生成焓在共同库存中使用的一致性，不是修改材料热化学。

随后记录双单元全程及两档精度，核总碳、总焓、各单元通量积分和组合熵；用独立面公式及二/四点时间积分审查。没有现实砖材料资格，没有有限反应速率；每格气相体积仅为理想气体占据体积，缺失的固相体积/砖孔隙关系不填造。

# 当前共同气流列的凝聚水迁移

2026-09-24，阶段开发。复用旧 `sorption_moisture_face` 的熵驱动力代数；旧适配器限制W=.30–.80且绑定旧主机/来源流程，不能直接用于现在的低W、共同气流可续算列。旧模块及其历史证据不改。

## 决定

本阶段只接W≤.8的原来源/低W势函数。高W纯自由水分支的原曲线热量对照已经失败，不用它作为本阶段已验证材料输入。新的迁移率在根参数明确声明为虚拟值；不使用Mäkelä由总失水反推的表观D，同时开启气相与凝聚相传输，因此不把同一个实验总通量重复分配两次。

按已有局部平衡解的同参考完整凝聚水μ及偏摩尔h构造一个共享面：

```
X_T = 1/T_R − 1/T_L
h_face = (h_L+h_R)/2
Y = μ_L/T_L − μ_R/T_R + h_face X_T
L = A/ell * mobility_density
J_N = L Y
J_U = h_face J_N
sigma_condensed = J_U X_T + J_N (μ_L/T_L−μ_R/T_R) = L Y² ≥ 0
```

正迁移率是声明的线性响应本构。耦合不可逆过程的一般依据见[Onsager1931](https://journals.aps.org/pr/abstract/10.1103/PhysRev.37.405)；具体常数、温湿依赖及忽略其他交叉系数都不是该文提供的污泥事实。即使在离散状态下上述名义代数非负，也不据此证明真实材料远离平衡时符合此近似，或整个积分器必然满足第二定律。

若把共同能量参考加常数c，则μ和h同时加c，Y中两项抵消、流量不变，能流只增加c J_N；结合共享库存更新，物理温度及熵不因参考选择而改变。这一参考不变性需要独立数值核对。

## 库存、接口和验证

每个内部面分别保留气相面与凝聚相面记录，再相加到唯一H2O总库存和U更新。凝聚水边界封闭；外界失水仍通过现有气体边界。局部相分配在每次反解时完成，不加新的水库存或潜热源。干质量固定，无收缩/毛细/重力或反应。

依次完成同参考代数及参考平移、四格完整过程、两档时间精度、独立来源和面率/逐单元N/U/完整熵审查，再做必要空间比较。审查独立复算纯液标准和来源过量μ/h，不直接以保存的新μ/h为真值。原误差预算继续适用。数据输入不足或失败均保留，所有材料及训练资格为false。

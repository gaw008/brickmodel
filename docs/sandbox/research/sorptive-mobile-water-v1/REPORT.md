# 凝聚水与共同气体迁移：开发及进行中的验证

已接入同一H2O/U库存的独立凝聚相迁移通道，气体输运保留。当前只使用原来源W≤.8与既有低W延拓，迁移率在根文件明确是虚拟常数。它提供可审查的多通道机制；尚不能给出真实砖干燥速度。公式、单位、能量参考和范围见[设计](DESIGN.md)。

五组实际平衡端点的独立Fraction面算术、左右反转、共同μ/h参考平移核对通过既定预算；名义与实际舍入通量对应的熵产生均非负。参考平移1e6J/mol后最大流量差约1.93e−20mol/s，扣除参考库存携能后的能流差约1.37e−14W。输入EOS在此项仍共享，不能以此项代替来源物性复核。

四格1200s干燥两档精度实际完成（561/789接受步）。2401个共同保存时刻的最大格温差4.26220e−5K、总水差2.34777e−12mol、W=.1时刻差6.91828e−8s，均在原时间比较预算内。基础过程W=.1约378.787086s；相同原气体路径此前约421.210517s。差值只说明声明迁移率对这个虚拟装置的作用，不能解释为生产提速。

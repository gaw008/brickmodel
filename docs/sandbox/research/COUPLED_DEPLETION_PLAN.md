# 两格液迁移/反应/炉温耦合耗尽验证（事前）

目标：在同一个完整库存/总U求解器内，让两格先后发生液水耗尽，期间液水面通量、气体扩散、有限氧反应、固体占积反馈和炉温加热实际活动。真实IAPWS低温水及理想水汽provider保持原来源门禁；固体feed/char、O2/CO2热量、动力学和输运系数来自明确manufactured测试fixture，不是污泥或真实氧化热参数。

初始两格T=300/301K，列(char,H2O汽,H2O液,fixture,O2,feed,CO2)：(.01,1e-8,1e-6,.001,.0001,.001,0)及(.01,1e-8,4e-6,.0012,.0001,.001,0)。原bulk1e-4m³/cell、A=.01m²、dx=.01m。两格K=1e-6mol/(sPa)保持；制造液相表S=(0,1e-5,1)，k=1e-14m²，krel=(0,1,1)，mu=.001Pa s，明确线性S插值且S=0零mobility来自本测试声明，不能推作泥料本构。连通状态全程connected不关闭；零液库存时不会捏造液h/v。

气体H2O/O2/CO2的D=1e-7m²/s，惰性fixture的D=0、Darcy气相k=0。边界总压3e4Pa，气体比例按(fixture,H2O,O2,CO2)为(.9,.005,.095,0)。炉温/壁温在0、1/512、1/256s为330、340、335K；固体有效k=.1W/(mK)，外膜10W/(m²K)，辐射epsilon=0。终时1/256s，节点必须实际保留。

先只核初始完整diagnostic，确认两格蒸发、液面、内部热流、两反应及O2外流均非零，然后才运行积分。资源依据上轮单格224eval/86.82s，首次两格最多360s、1500接受试算panel、150拒步；每个真实失败保存，不把计算超时当材料失败。初始terminal_window=1/16384s，common horizon=1/256s刻意覆盖候选第二事件以检验共同时间重选；time1e-7s、amount1e-10mol、U1e-6J、T1e-5K、P1Pa。普通rtol1e-7、amount atol1e-12mol、U atol1e-8J，与已通过单格相同，不为本例放宽精度。

验收：completed到准确终时，两次事件cell身份不同且严格有序、最终两格均精确NL=0且K不变。每段的完整库存与U对原face/source/work+显式pair/storage修正独立Fraction重建，所有前缀amount误差≤1e-10mol、U≤1e-7J；系统外边界水mol/C/H/O及独立惰性示踪mol收支≤1e-10mol，质量≤1e-12kg（包含fixture实际.028kg/mol及其面通量，其他质量由实际声明provider及反应组成）。不假定开放系统总水/总氧恒定。每个共享面只记一次，外部水/氧/碳物流不被误算为反应产生。

# 材料能量闭合：参考约定与必需物理数据的分离

结论：可以放宽“每个原泥伪组分都必须提供真实分子摩尔质量和标准生成焓字段”的表示约束，而不放宽能量守恒或来源门槛。质量基准库存、明确的参考约定，加上同材料、完整计量反应的实测反应焓，可以构造闭合的能量差模型。真正不可省略的是反应方向上的能量差、全部物质去向、各组成状态的显热/体积关系和适用性证据；不是一个可观测的“绝对能量零点”。当前仓库证据尚不足以完成真实原泥反应材料包，但不应把缺一个绝对生成焓字段本身当作永远无法实现的障碍。

本报告只读现有代码/证据，外部只核读以下两份一手机构/项目文档；无 EOS、材料参数填造或源码修改。

- Cantera 官方文档说明焓和内能参考约定可不同，常用元素标准态零点的目的在于反应能量差一致，不能把不同来源的零点直接混用。[Cantera thermodynamics FAQ](https://www.cantera.org/3.1/userguide/faq.html#thermodynamics-equilibrium)
- MIT 反应系统第一定律教材以组成守恒和进出焓差计算热量，明确水产物液/气相改变放热量，并需要把非参考温压条件的显热差计入。[MIT 15.4 First Law Analysis of Reacting Systems](https://web.mit.edu/16.unified/www/FALL/thermodynamics/notes/node110.html)

下面的质量基准矩阵与接口建议是基于第一定律的本报告推导，并非上述文档给当前污泥材料提供了新数值。

## 1. 应纠正的依赖关系

现有 `material-closure-next-v1/AUDIT.md` 的核心结论仍成立：GNEST 产物未闭合，Arlabosse 是不同样品的低温干基 Cp，不能拼成完整反应材料。应将其技术依赖表述从“必须有每个伪组分的标准摩尔生成焓”改为：

> 必须有能约束全部被允许反应方向的、同一材料身份下的反应能量差及状态关系；可采用一致的标准生成焓表示，也可采用质量基准反应热约束与明确参考约定。

`PhaseMetadata/PhasePoint` 当前以 mol 和 `nist_298.15K_element_standard_formation` 为合同。`SolidShomateCaloric` 要求 formation_enthalpy_298_j_mol；`solid_reactions.py:113-115`、`solid_fluid_storage.py:101-106` 拒绝其他参考/基准。这些保护是当前实现的一致性条件，应继续保留；它们不意味着所有合法热化学模型都必须采用这一表示。新质量基准模型应单独显式建模，不能把 kg 数据塞进 mol 字段或把任意常数伪装成实验生成焓。

标准生成焓本身也是相对于指定元素标准态的焓差，并非测得的绝对 H。未知生成焓与未知反应热不是同一个问题。

## 2. 可自由选择什么，不能自由选择什么

设质量基准库存向量为 m（kg），反应进度 ξ 的单位明确选为 kg 初始干料转化量；B 的每列给出每单位进度对各库存的质量增减。质量与元素组成矩阵 A 必须满足 A B = 0。氧气等外来反应物必须包含，不得只检查干料固相输出。

在指定 T_ref、p_ref 与相态下，令各组分参考比焓为 h0（J/kg），实测反应焓向量为 q_ref（J/kg 进度；产物减反应物，放热为负）：

    B^T h0 = q_ref.

因此不必先独立测得每个 h0，才可满足反应热约束。求解结果必须带可识别性、剩余自由度与测量误差说明，不能声称唯一辨识出了所有伪组分的真实生成焓。

合法参考平移 h0' = h0 + g 满足 B^T g = 0。特别地，g = A^T λ 只是对守恒元素/质量库存加常数，反应能量差不变；闭合系统内只平移总能量坐标。在存在输运时，相同偏移也必须进入边界与内部携带的焓，参考变换后的第一定律才保持一致。

反例：把每种反应物/产物的 h0 都设为零、保留原总能量方程且不计反应热，会强制所有 q_ref=0，抹掉真实放热。这不是参考自由度。尤其不能把原泥 h0 设零、保留 NIST 水和气体参考不变，再忽略原泥与这些产物之间的能量偏置。需要从实测反应热求得兼容偏置，或采用下节的显式热量坐标转换。

多步反应必须可积：若 B c = 0 构成闭合反应循环，则要求 c^T q_ref = 0（按实测不确定度检查）。不满足时不能用一组状态比焓重现所有热量；应报告来源/阶段定义矛盾或不可辨识，不能自动调整热值使其闭合。单个总燃烧热只约束一个反应组合，不能唯一分配给任意六个分解阶段。

## 3. 两条可执行路线

### 路线 A：继续存总能量，增加质量基准参考网络

采用 `MassPhasePoint(T,p,u_J_kg,h_J_kg,v_m3_kg)` 与显式 `ReactionReferenceNetwork`。通过 B^T h0=q_ref 求得兼容参考偏置；保存全部数据来源、参考选择、余自由度及与已有气/液参考的桥接。总焓写为各库存乘参考比焓和显热/压力修正；总内能仍按 U=H−pV（多相压力分别求和），再加入实际模型的弹性/界面等储能。

在反应源改变库存而总 E 不凭空增减时，温度反解自然体现反应热。不能同时另加同一反应热到 `cell_power_w`，否则双算。这个路线较接近现有“形成能已在状态中，不再额外加热”的模型。

已知气体仍可用真实摩尔基准：气体反应质量通过其已知摩尔质量转换为 mol。原泥伪组分保留 kg 库存，不需要虚构一个分子量。若为了算法使用“每 1 kg 干料的计算单位”，必须明确是计算进度单位，不得标记 `mol_of_declared_species` 或声称真实分子质量。

### 路线 B：显热坐标加显式参考反应能

定义 H_s = Σ m_i Δh_i(T,p)，其中每个显热差都在同一指定参考态为零；另外用 H_chem = h0·m，或在固定原始组成的可积反应网络中用 H_chem = H_chem,0 + q_ref·ξ。总能量包含 H_s+H_chem 再转为 U。

若数值状态只存显热而不存 H_chem，能量方程必须显式加入对应的 −q_ref·dξ/dt 项，并对参考焓输运做一致转换。它是总能量坐标变换后的内部化学项，不是外部供热。能量账本必须同时报告储存化学能的变化，使全局守恒仍可核对。不能在当前总 E 方程上直接加这个项。路径变量若不能由组成唯一恢复，必须随状态和检查点保存；有循环时仍须满足可积性，不能无限循环放热。

优先建议路线 A，以减少当前总 E、源项和账本语义迁移；路线 B 是合法替代，但实现工作并不只是“添加一个热源”。

## 4. 同材料实测反应热可以提供什么

对一个完整定义的反应，把反应物和产物在同一参考温压、确定相态下的测量焓差作为约束即可，不要求另有每个伪组分的绝对形成能测量。但最低限度还需要：

1. 明确材料批次/处理历史、干基/湿基/无灰基，反应进度与量热归一化基准；氧化、热解、脱水、碳酸盐分解等不能互换。
2. 相同材料与工况下各反应物/产物的完整质量与元素去向、气/液相态和分支产率。不允许用无来源剩余物种填 GNEST 的 0.050 缺口。
3. 量热的条件、热损失/仪器基线/显热/蒸发与吸附贡献的处理，以及不确定度。DSC 曲线总热流不自动等于纯化学反应焓；不同转换过程的热量不能重复归入反应和相变两边。
4. 足够独立反应的焓差，使所运行网络反应方向可识别；只测完全燃烧终态不能保证中间分解温度响应。
5. 实际反应物、固体残留和产物在运行域内的 Cp/显热关系；不能把未转化原泥的 Cp 不变地赋予所有中间焦炭/灰分。对一般状态路径还需体积、可压缩性、热膨胀等，使 h/u/pV 与实际储能导数一致。
6. 从量热条件转至运行条件：定压量热与定容内能变化的换算需要 Δ(pV)；只有相应假设下才能用理想气体 Δn_g RT。温度改变时 ΔH_r(T) 要包含产物减反应物的显热修正。不能把低温 Cp 当高温反应 Cv，也不能无据外推。
7. 动力学、反应物供应、传质及几何机械耦合仍需独立证据。只补能量参考不会证明这些过程。

这里讨论第一定律的闭合。若要计算化学平衡、可逆速率或化学势驱动力，还需要熵/自由能及相应活度模型；实测 ΔH 不能单独关闭第二定律/平衡问题。

## 5. 现有材料证据的实际推进边界

Arlabosse Eq2 已经提供原样品干基 Cp 与 35–105°C 内 Δh；对固定组成的低温显热模型，可直接采用质量基准 Δh，无须补摩尔质量或形成焓。应保留来源限定、误差 unknown 和 material_qualified=false。若包含含水变化，还缺同样品的水活度/吸附热及迁移关系；若包含化学分解，则缺对应产物和反应热，参考选零不能补出它们。

GNEST 现存证据报告 R5/R6 产物质量各缺 0.050，TG3 终点合计0.9507，且总热值不能直接分给各阶段。改用质量基准只消除不必要的伪摩尔接口，不能修复这些实际数据缺口，也不能与 Arlabosse 不同样品拼接。

因此下一项可实现工作是“质量基准反应参考网络/桥接器”的数值与来源合同，而不是宣称现有原泥材料立刻可运行。该组件可以用明确 manufactured 测试验证：参考平移不改变反应热与温度解；含量流的参考变换保持总能量闭合；循环不一致反应热拒绝；不完整质量/元素计量拒绝；同一热量不能同时作为储能和源项；混用未桥接 NIST 参考拒绝。实际材料参数保持待证据填入，不给制造值冒充文献。

建议替换依赖表述为：

    原泥能量闭合 = 同材料完整计量 + 反应方向能量差 + 各状态显热/体积关系
                   + 显式参考桥接 + 不确定度/适用域

而不是：

    原泥能量闭合 = 必须查到每个伪组分的真实摩尔质量和“绝对形成焓”。

这纠正的是表示层约束，不是放松科学门槛，也不改变当前材料尚未取得全周期资格的事实。

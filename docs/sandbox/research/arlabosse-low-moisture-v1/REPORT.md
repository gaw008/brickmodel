## 同一库存与干端参考

唯一凝聚水库存仍为 `Nc`，`W=Nc*Mwater/md`，蒸气库存为气相 `H2O`。干物质量、可用流体体积和原水热化学参考保持各自含义。零水点不再假装存在液相压力或液体体积；局部吸附与迁水所需的纯液化学标准态在实际干态 T/P 下假想计算，不占实际体积或质量。

在原 Arlabosse 湿态源曲线接点 `Wj=.15`，用原表示节点算出 `hj,sj,bj,cj`。低W分支为：

```
psi(W) = W*ln(W/Wj)-W+Wj
h_ex(W) = hj+bj*(W-Wj)
s_ex(W) = sj+cj*(W-Wj)-(R/Mwater)*psi(W)
f_ex(T,W) = h_ex(W)-T*s_ex(W)
mu_ex(T,W) = Mwater*(bj-T*cj)+R*T*ln(W/Wj)
partial_h_ex = Mwater*bj
Gamma = R*T/W
```

`W=0` 使用解析极限，保留一般非零的 `h0=hj-bj*Wj` 与 `s0=sj-cj*Wj-(R/Mwater)*Wj`。总能量始终是 `Ubase+md*h_ex`；不删除剩余水，不在零端切回丢失偏置的 `Ubase`，不额外增加一项潜热。有限正W与源分支使用同一摩尔常数。对数和活度读数为名义浮点值，未虚构其数值误差界；h_ex 的表示输入代数为精确有理数。

`W=.10` 的原 Fig.1 活度点没有参与构造或拟合。95°C 新延伸的名义活度约 .345712，原读图中心约 .364681，读图区间约 [.342169,.387019]。这支持“与同一条曲线中留出的读数相容”，不属于独立实验验证；Fig.2 的 q(.10) 仍未知。来源接点与读取记录由两个新模型 JSON 连接到已有来源，不修改原始 facts。

## 内部输运与外部收支

低W导热采用独立标识的 `k(W<.30)=k_original(.30)`，其余复用 Septien 源供体。D 继续取 Mäkelä 原供体的 `8.56e-9 m²/s`，低W延伸和凝聚水路径分配单独标为选择；内部蒸气扩散和 Darcy 并行路径关闭，避免重复使用同一表观总失水D。

凝聚水面采用完整 µ/h 及同一参考焓，正含水源分支检查所有跨越分段的 Γ 为正。双低W用对数平均的稳定代数；单侧零W的解析流为 `n=K*(WL-WR)`，其中 `K=A*rho_d*D/(Mwater*ell)`，`H=hface*n`。双侧零W为无交换。单零态的瞬时无限熵极限使用命名标记和 null，不用浮点 infinity/NaN 或人为 epsilon 替换库存。完整名义 µ 驱动力与稳定代数读数的差、实际舍入 n/H 的瞬时熵收支分别保留。

外边界是一个明确的虚拟装置：选择性水蒸气储槽温度跟随外格T，规定蒸气分压 `pv_env` 和正接触系数 `Kv`；另设独立热浴及有限有效热导 `G`。它的实际方程是：

```
nout = Kv*(pv-pv_env)
Hout = nout*hv(Tcell)
Qin = G*(Tbath-Tcell)
dNc = -r + internal condensed-water exchanges
dNv =  r - nout
dU  = Qin - Hout + internal energy exchanges
```

两向蒸气交换使用同一 T 和相同水热化学参考。当前参考下 Hout 可为负，不能拿 Hout 的符号判断能量是否守恒。每步记录预测与中点的实际物性结果、共享面、局部phase、边界 n/H/Q、投影费用和接受状态，负库存试步被拒绝且接受前缀保留。未知界面模式显式拒绝。

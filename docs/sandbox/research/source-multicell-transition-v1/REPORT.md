# 三格来源湿→干执行与真实液流账本

基线 `3fdea98`。本阶段把原单格终端扩展为 N 格中的唯一单元耗尽，
接通实际液流及供体焓、逐格/全域累计账本和混合湿干压力比较。
三格实际水物性运行完成，但湿邻格压力门槛仍失败，整体数值事件未接受。
这是极短时间的制造输入数值实验，不是实际污泥砖烧成验证。

## 实现与原合同

`source_terminal` 复用全 4N 库存竞争，从唯一首根取得空间格 k，保持原
粗/移位路径索引及共同细化预算。新 `source_terminal_liquid` 被动绑定
实际液体观测、原连接/几何/迁移关系，并重建 Darcy、供体焓及投影。
在完整仿射面板排除供体换向；这个条件不等于连续真实轨迹的方向证书。

当前要求选定格的总蒸发始终为正。仅 k 的液水/蒸气允许原有界微量写回，
其他库存和所有格 U 不变；液体净排出不计入蒸发预算。仅 k 切换干模式，
原液体配置不变。预先声明 kr(0)=0 的制造表实际走零迁移；正 kr(0) 的
独立测试仍由真实干回调退出域，未在耗尽后关闭连接来制造成功。

`source_dry_transition` 的两个时刻现在分别保留全部 N 格压力记录，并
绑定实际格 storage/state/inverse。旧选中格兼容视图也保留。独审发现
该旧视图曾接受同值但不同 storage，实际 RED 已保存；补上 live storage
绑定后同一探针通过。若后面的湿格评估失败，已完成的部分行、回调和
完整参考路径均保留。

累计账本从同一原初态贯穿普通湿段、精确终端、写回和实际干续算。
每格与全域同时使用原绝对 N/U 预算，不乘 N。独立反例分别检验逐格
相消错误和各格小误差累加超全域预算。新共享压力只作用于 k；湿邻格
继续使用原湿态完整温区条件，失败会阻止整体接受。[推导](DERIVATION.md)。

# 非等温自由分子小孔交换：来源与静态核查

已实现CO₂/O₂/N₂两个平衡气体库之间的薄孔分子流。它适用于孔径远小于平均自由程、孔厚可忽略、气库内部保持Maxwell分布及内部模式热平衡的条件。这里的气库/小孔是明确研究装置，没有等同于烧结砖中的有限长度孔道。

来源为Cleuren、Van den Broeck、Kawai2006（[公开作者预印本](https://arxiv.org/abs/cond-mat/0606141)，DOI10.1103/PhysRevE.74.021117）的式3–5、13、20–21；第3页已经视觉核对。热迁移压力比同时核对[得州大学的推导](https://farside.ph.utexas.edu/teaching/355/Surveyhtml/node224.html)。原文处理单原子理想气体，本项目对内部模式的推广单独写明推导，未冒充论文直接给出的多原子结论。

单向摩尔通量为Γᵢ=A pᵢ/√(2π MᵢRT)。穿孔速度加权使平动能为2RT，相比气库平动均值3RT/2多RT/2；热平衡内部模式不受速度选择，因此携带能量eᵢ=uᵢ+RT/2=hᵢ−RT/2。热量不能直接按普通连续流焓代替。h、Cp、标准熵采用保存的NIST Shomate系数和SI气体常数，当前300–450K不跨任何所选物种的拟合分段。

净通量Jᵢ=ΓLᵢ−ΓRᵢ，E=Σ(ΓLᵢeLᵢ−ΓRᵢeRᵢ)。组合熵产生Π=E(1/TR−1/TL)+ΣJᵢ(μLᵢ/TL−μRᵢ/TR)。同一物种的任意常数能量参考同时改变e和μ，Π不变，已经独立核对。

80位独立计算采用数值Maxwell速度矩积分、直接源Shomate表达式及非负分解。8个等温/非等温、正反向、近均衡及无净物质流场景全部达到冻结预算。最大净摩尔率差3.9335e−26mol/s、能流差2.3351e−20W、熵率差4.8102e−23W/K；这只是公式与实现核算精度，非实测气体误差。

无净物质流示例TL=450K、TR=300K、pL/pR=√1.5、孔面积1e−8m²：各物种净流约零，但热能流1.861816e−6W、熵产生2.068685e−9W/K仍为正。这是两端恒温维持的热流稳态，不能叫绝热孤立系统的最终平衡。

非负性可逐物种推导。记β=1/T、Δβ=βR−βL、I=∫βL^βR e(β)dβ，则Πᵢ=R(ΓL−ΓR)ln(ΓL/ΓR)+ΓL(eLΔβ−I)+ΓR(I−eRΔβ)。de/dT=Cp−R/2>0时每项非负；本例使用单一连续Shomate分支。v3进一步对300–450K整个区间逐项界定Cp−R/2，CO₂/O₂/N₂的保守下界分别29.2701/19.8586/23.8815 J/(mol K)，均为正。该代数区间界不是只检查8个样本，也没有截断负熵。

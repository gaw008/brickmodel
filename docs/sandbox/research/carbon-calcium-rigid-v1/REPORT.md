# 封闭定容Ca/C/O/N混合物：状态、内能和七个相边界通过

在[压力反馈阶段](../carbon-calcium-pressure-v1/REPORT.md)已核查的纯相/理想气体及常体积固相近似内，本阶段实现给定T和总V求共同反应压力，再实现给定U/V求T。体积取明确虚拟100cm³，三组Ca/C/O/N库存沿用前阶段，不能解释为实际砖孔尺寸。

## 定容方程

总V=Σsolid nᵢvᵢ+ngRT/P。气体物质的量在N2与N2+Ctotal+Ototal/2之间；固体体积不超过Catotal·max(vCaCO3,vCaO)+Ctotal·vC。输入V大于这个固体上界，因此用这些元素界限直接导出正压力括区，而不是给压力加任意下限。已核查的同相VP<0及相界V连续性支持此处唯一压力反解。

U采用固相h°−p°v、气体h°−RT，化学生成能已在h°中。固定V时dP/dT=−VT/VP，组成导数为nT+nP·dP/dT，Cv=Cp+T·VT²/VP。来源正冻结热容和稳定平衡反应响应给出本模型热稳定性；实际数值状态又逐项复核Cv>0。没有重复添加反应热或将Cp直接充当Cv。

## 静态与同相导数

36个300–1190K状态覆盖全部六种Ca/C相组合，压力约124813–933680Pa。独立60位方程同时解三个气体log摩尔量、log压力及必要的方解石比例；同时满足来源化学势、元素和总体积，不复用运行时嵌套P根。最大压力差1.84435e−7Pa、体积差3.23093e−17m³、U/H/Helmholtz组合最大差1.02275e−10J、S差9.97616e−14J/K、元素差8.67362e−18mol。全部相条件与正气体相对误差预算通过；U反解最大温差2.41017e−11K。

每个状态用.001/.0003K两档独立源方程差分，72组全部保持相分支并达标。Cv−dU/dT最大1.72467e−10J/K、Cv−T·dS/dT最大1.47427e−10J/K，压力导数差1.25842e−7Pa/K、物种导数差9.43147e−16mol/K。比较目标在执行前冻结，没有用误差结果反调阈值。

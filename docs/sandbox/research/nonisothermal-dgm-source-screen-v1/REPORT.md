# 非等温多孔气体输运：来源筛选，尚未接入升温模型

2026-09-25 UTC。当前 Dusty Gas 柱完成的是等温限定模型。温度梯度下的热渗流与伴随能流必须另有来源，不能仅把等温 D、黏度换成随 T 变化就称完整非等温模型。

| 原始来源 | 本次实际取得 | 对后续开发的作用 |
|---|---|---|
| [Sandia SAND2012-5961](https://www.osti.gov/servlets/purl/1113858)，Shugard/Robinson，2012 | 完整 30 页；相关式 (1)、(23)、(29)、(31)、(34) 核读，页 15/16 图像核读 | 支持当前等温库存和 Darcy–Knudsen 稳态核对；报告明确等温，不能闭合温度梯度项 |
| [Dragon Project Report III](https://www.osti.gov/servlets/purl/4104094)，Truitt/Evans/Mason，1962 | 官方公开扫描全文 | 页 14 说明热渗流与温度梯度有关，但该段没有足以直接接线的完整热输运系数 |
| [Malinauskas/Mason，1971](https://doi.org/10.1039/TF9716702243) | 出版商摘要；浏览器全文入口停在安全验证页；[NASA 记录](https://ntrs.nasa.gov/citations/19710064687)无可下载文件 | 摘要明确单原子与多原子气体及混合气的差异；没有从摘要补造参数 |
| Vignoles 等，非等温纯气动理学均匀化：[第一篇](https://hal.science/hal-00269369/document)、[后续验证篇](https://hal.science/hal-00270403/document) | 定位到作者公开存档标识，但本次官方入口返回拒绝访问 | 暂未核读完整公式和适用条件，不把检索片段当作已接入的四气体热流模型 |

下一步需要取得可完整核读的质量/能量交叉系数、气壁散射假设、压力适用区间，并确认它们对 CO/CO₂/O₂/N₂ 内部自由度的处理。局部互易性、熵增和动理学极限应先核对，再做变温动态开发。保持当前等温模块和现有高温虚拟交换系数的来源边界。

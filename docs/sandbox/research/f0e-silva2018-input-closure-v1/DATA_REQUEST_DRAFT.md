## 如果现有资料不足，才考虑针对性表征

本节只列需要解决的问题，不安排实验，也不规定无依据的测点数、精度或采样频率。

1. **储能与导热：** 在计划干燥温湿域内确定同材料储能/热容和导热的水分依赖、体积基准及不确定度；自由水参照不能替代束缚水贡献。
2. **水分状态和输运：** 先选定总水或液/汽分相闭合及所需状态势，再获取与其匹配的吸附/保水及迁移数据，避免只用一条总质量曲线同时拟合全部内部阻力和表面阻力。
3. **边界与读数映射：** 补充能判断恒定/均匀边界近似是否可接受的空气与试件测温记录；保留取出扰动。表面与必要内部读数用于判断空间近似，不能默认整块均温。
4. **独立预测对照：** 在冻结方程、参数来源、用途误差和对照划分后，再指定独立试件/工况。数量和时间分辨率应由可辨识性与误差目标决定，本阶段不给任意“最少几组”的保证。

这些是小范围定向补证据的候选，不要求建立长期产线数据库。若关键资料暂不可得，成果保留为来源证据和经验拟合档案；不把缺项填成默认物性并宣称准确。

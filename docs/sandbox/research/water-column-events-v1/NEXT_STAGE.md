# 下一阶段：先解决冷凝边界库存的空间定义

本文件是两小时窗口的剩余任务记录，没有创建新的原生Goal，也没有把未实施内容标为完成。

## 可继续开发，不依赖材料作者回复

当前明确问题：70s虚拟冷凝/再干燥的32→64格表面温差0.25211K，出现/耗尽时刻差0.12097/0.04150s，仍超过原目标；34s末格液水占比从16格59.47%变为64格57.42%，未随末格体积减半。原边界把净凝聚水留在末格，缺少跨格液体运动。现有证据仅提示边界库存集中，尚未证明其连续极限。

下一项有意义的目标是：**给出并实现具有明确空间含义的冷凝边界，再核对同一物理问题的守恒、热力学和网格误差。** 不重复建立另一套水物性、气体热化学、检查点或事件引擎。

顺序如下：

1. 从现有逐格水量/U方程推导边界控制体缩小时的库存与通量尺度，分清表面液膜库存、有限厚度多孔层和体内液体输运三种不同物理定义。判断现有问题需要哪一种；不能把数值平滑当物理扩散。
2. 固定最小模型合同。若采用独立表面液水储库，应明确其面积、液体体积占用、温度、压力/化学势、蒸发冷凝和流焓/机械功；若采用体内液体输运，必须有对应关系与系数来源。未知材料系数不能由这条虚拟轨迹反向充当实测值。
3. 只实现选中的控制体关系，复用当前来源、守恒和事件接口。旧局部滞留模型及失败证据继续保留，新模型有独立标识；不同物理定义不能称为同方程求解优化。
4. 先核质量/能量/化学势和必要熵关系，再做干燥、冷凝、反向转换的时间/空间比较。原0.2K、1e−6mol、0.02s空间目标先保留；如模型改变了观测量，应在运行前说明对应关系，不能运行后改目标。
5. 区分原固定网格误差、物理模型改变与同材实验准确度。只有通过限定核算后，才考虑将此通用关系接入有资料支持的砖材料。

不应继续的做法：仅把候选压力表扩到更高压力、把扫描/求根容差缩小、无限增加均匀网格或以守恒残差小代替空间精度。这些都没有自动定义缺失的液体空间运动。

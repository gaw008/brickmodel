# 碳酸钙与碳氧反应的压力反馈：静态和同相导数通过

本阶段将已核查的[Ca/C/O/N共同平衡](../carbon-calcium-equilibrium-v1/REPORT.md)扩展到给定总压力。三组虚拟库存在0.1、1、10bar及298.15–1200K的108个状态，均通过独立60位来源积分、同时元素/化学势方程、相稳定条件和体积重建。另54个同相状态、两档扰动共108组压力/温度导数与热力学恒等式通过。此处尚未授予固定体积热过程或跨相动态资格。

压力确实改变所选体系的相分配：以总C=4.5mmol、Ca=2mmol、O=8mmol、N2=4mmol、1000K为例，0.1bar时方解石和石墨均耗尽；1bar时约0.338563mmol CaO、0.534737mmol石墨；10bar时全部钙仍为方解石，石墨约1.133107mmol。这个对比是明确的纯相理想气体模型结果，不能作为真实砖在相同压力下的实测结论。

## 来源与状态定义

相热化学仍来自[USGS Bulletin 2131原始资料](https://pubs.usgs.gov/bul/2131/report.pdf)，沿用前阶段的Cp、生成焓、熵和来源气体常数。石墨摩尔体积在印刷76页/PDF82页实际渲染并目视核实：5.298cm³/mol，另印0.5298J/bar/mol；表页未列该体积不确定性，不自行赋值。方解石36.93、CaO16.76cm³/mol沿用此前已核查的同一来源表页。

这些是常温来源体积。运行EOS明确将三种固相视为无热膨胀、无压缩的纯相，属于模型近似，高温/压力误差未知。必须同时使用：固相μ=g°+(P−p°)v、h=h°+(P−p°)v、s=s°、u=h°−p°v；气体μ=g°+RT ln(pᵢ/p°)、h=h°、u=h°−RT。气相体积ΣnᵢRT/P与固相体积Σnᵢv共同进入总V和U=H−PV。不能只改气体压力而遗漏固相压力功。

## 方程与导数

给定T/P后，保留同一元素库存的嵌套单调平衡根。石墨存在时以q=√(pO2/p°)和π=P/p°解正二次根；耗尽时以z=nO2/nN2和氧过量解单调气相根。外层方解石量以CaO、CaCO3和CO2共同化学势决定端点或共存。无人工反应热、经验燃尽时刻、剪裁或反应率补项。

在活动相分支内，以来源中平衡反应计量矩阵ν建立Gibbs曲率M=RT[νgᵀdiag(1/n)νg−ΔngΔngᵀ/ng]。解MξT=Δh/T、MξP=−Δv，Δv包括固相v和气体RT/P。由此得到组成导数、Cp、VT与VP；VP的冻结气体项为−ngRT/P²，反应项为−ΔvᵀM⁻¹Δv，均不正。再由Cv=Cp+T·VT²/VP和固定V时dP/dT=−VT/VP定义局部响应。

纯相压力修正是组成线性项，理想气体混合Gibbs的组成曲率半正定；固定正N2库存与本阶段独立反应基使所用反应曲率正。满足元素约束、活动相平衡与缺失相单侧条件，给出允许相集合内的平衡极小。这个结论不包括未加入的矿物、气体种类或真实非理想性。

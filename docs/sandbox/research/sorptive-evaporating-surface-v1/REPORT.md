# 无储量蒸发表面：开发与核查进行中

新增独立条件边界：内部气相和凝聚相都可把水带到表面，表面转成外侧气相交换；用三物种与总能流四个等式求表面T/P/W/载气分率。表面没有虚构水库存，没有另加一遍潜热，旧封闭凝聚水边界与其空间失败保留。见[推导/来源/范围](DESIGN.md)。

四组静态工况（同态、来源区干燥、低W加湿、低W干燥）已完成直接IAPWS/原势函数独立复算。两侧质量残差≤3.127e−17mol/s、能流差≤7.692e−12W；表面μ/h来源差≤2.096e−9/1.194e−8J/mol，各段名义熵产生非负，满足事前预算。它们不构成全域根存在/唯一性证明。

# 无储量平衡蒸发表面：独立边界增量

当前凝聚水列的最外半格只有气体出口，4→8→16格的W=.1时刻差约13.4/6.23s；这个观察不证明唯一误差来源。这里单独定义另一个物理边界，使内部凝聚水可到达表面转为水汽，避免把该最后相转换全部放入有厚度的末格。旧模型及失败保留。

## 来源、物理定义与未知

[COMSOL湿表面文档](https://doc.comsol.com/6.3/doc/com.comsol.help.heat/heat_ug_mt_features.10.34.html)明确多孔侧的水分通量包括汽相和液相贡献，蒸发/冷凝对应热效应；[耦合说明](https://doc.comsol.com/6.3/doc/com.comsol.help.heat/heat_ug_multiphysics_interfaces.11.36.html)另列汽相扩散携焓。这里只以这些原始实现文档支持所需的质量/能量边界类型，不复制其特定经验蒸发公式或系数，更不声称其纯水覆盖面适用于本污泥。

本项目采用同来源吸附平衡μ_v=μ_c，允许未饱和活度。假设表面没有额外质量/热容量、没有迟滞或有限吸附动力学、无辐射、无流出液滴。表面是材料势函数的迹值，不新增一个有体积的单元，不设置任意附加水库存。外界膜系数及内部迁移率仍为根文件明确的虚拟条件。

未知量为T_s、P_s、W_s、载气O2分率（N2为余量）。内部半格由现有气体面+凝聚相面+导热构成；外部膜只有气体面+导热。每个物种与总U满足：

```
J_inside[O2,N2,H2O] = J_outside[O2,N2,H2O]
J_U_inside = J_U_outside
```

气液同一μ参考、各自偏摩尔h；汽/液携焓差已在两边完整能流中表达，不另叠加潜热。凝聚水可正反向交换，边界冷凝同样需实际求解。该代数系统代表零储量近似，不保证任意给定外界都有域内解；失败直接保留，不降级回旧边界。

## 数值与审查

用根参数声明的尺度求四元根；能量残差可减去共同参考h_ref乘物种残差以改善条件数，该行变换不改物理零点或守恒条件。保存真实有量纲两边差值、表面状态及两段通量。ODE仍只有原各格N/U；一个选定的共享边界率更新末格及外界账，界面根误差另单列审查，不能由全局账自动抵消而隐藏。

先静态多组端点（含同态、干燥、加湿）分别复核局部相平衡、来源、两侧N/U、同参考能量和熵；随后一格/四格动态时间比较、完整独立审查，再空间比较。预算沿旧逐格/源/熵目标，新增界面残差预算在执行前固定。未经审查不认定数值精度或物理适用性提升。所有material_qualified/training_eligible均false。

# 精确记录的无损数值恢复

`restore_exact_projection` 消费外部实际算子绑定后的规范字节，按固定数值类型白名单恢复状态、时间、账本、事件、历史尝试与累计资源。各模式算子由实际原算子构造；不从记录反序列化任意类或物性 provider。历史 Observation 保持显式 EvidenceNode，不伪装成实时逆解。

已提交终端按精确时间、完整账本和前后状态唯一匹配到接受步，再恢复 Python 同一对象引用。这使原 `audit_commit` 的 `id(ledger)` 关联能保留原修正；重复/缺失/数值不符及修正单元/时钟错配均拒绝。完整 pack 值前后必须一致。返回值固定 `resume_authorized=false`。

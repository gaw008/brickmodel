# 氢气、水蒸气与 C/H/O 反应的同一能量基准

本阶段补齐 H₂ 与理想气态 H₂O 的标准热容、焓、熵，并与已有 C、CO、CO₂、O₂、N₂ 共用 USGS 1995 的参考态。来源为 Robie 与 Hemingway 的 [USGS Bulletin 2131](https://pubs.usgs.gov/bul/2131/report.pdf)。已逐页核对 PDF 第 48、54、95、200 页的系数和表值；完整转录、页码及打印精度保存在 source.json。

采用 298.15–1200 K 共同温区、1 bar 标准压力，以及原书 R=8.31451 J/(mol·K)。储能焓是 h(T)=ΔfH(298.15 K)+∫Cp dT；表中的 ΔfH(T) 还扣除了元素在 T 时的显热，不能直接作为单个物种的储能。水蒸气在低温下属于理想气体标准参考态，本阶段未建立液水稳定性、饱和蒸气或吸附闭合。

80 位独立积分与生产解析式一致：H₂/H₂O 最大焓误差分别为 8.18e−12/1.48e−11 J/mol。两种气体共 22 个温度行的 Cp、S 和 [h(T)−h(298.15)]/T 均落在原表末位半单位内。H₂O 的生成焓、生成 Gibbs 能与 log₁₀K 经 H₂、O₂ 一致相减后，也都落在打印系数、参考量及表值共同产生的算术包络内。打印舍入包络不代表实验或物性拟合的不确定度。

以精确有理数 Bernstein 系数核查所用浮点系数的整个温区，Cv=Cp−R 下界为 H₂ 19.1113、H₂O 23.6945 J/(mol·K)，均为正。

新增标准反应函数支持 H₂+½O₂→H₂O、CO+H₂O→CO₂+H₂、C+H₂O→CO+H₂。共 33 个温度反应点通过元素守恒、独立 ΔH/ΔS/ΔG/lnK、dG/dT=−ΔS 及 van't Hoff 导数核查。1000 K 水煤气变换的 ΔH=−34.8512 kJ/mol、ΔG=−3.48613 kJ/mol、lnK=0.419283；K 基于无量纲标准活度。

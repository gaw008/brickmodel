## 原文不能直接准入的原因

| 项目 | 实际读取及代入结果 | 处理 |
| --- | --- | --- |
| 化学身份 | 2024式2和2025式6写作 Al₂O₂·2SiO₂·2H₂O；标准高岭石为 Al₂O₃·2SiO₂·2H₂O | 两边元素守恒并不能证明物质身份正确；保留原文，不静默改写作者模型 |
| 三阶速率 | 定义 c=n/V、单位 mol/m³，却以 s⁻¹ 系数乘 c³ | 得到 mol³/(m⁹·s)，不是体积摩尔速率；原文未说明缺少的归一化 |
| 固相体积 | 表2按打印的 m³/mol 代入，初态仅高岭石加偏高岭土就占7.3508296 m³/m³；入口为18.04765124614 | 无法再加入非负石英和气体而满足总体积；未擅自解释成 cm³ |
| 热容温区 | 高岭石表1止于700 K；文中反应区450–700°C，即723.15–973.15 K | 两温区无交集；不将低温拟合外推为反应区合格物性 |
| 参考态 | 有生成焓，缺绝对熵；具体 FactSage 条目/版本未识别 | 不供应化学势、反应亲和力或可逆化学资格 |

2025作者版仍含上述打印式，不能当作已经纠正的来源。纸面高岭石 Cp 在298.15 K比已保存USGS函数低2.39195%，700 K低1.11897%；来源版本不同，未将差异直接归为错误，也没有误差范围可用来授予兼容性。

18个声明温点的 Cp、相对 H、相对 S 已分别用70位独立求积核查，最大差为1.7053e−13 J/(mol·K)、1.0186e−10 J/mol、2.2693e−13 J/(mol·K)，均在事前预算内。偏高岭土只按表内298–1800 K函数进行算术核查，不能据此推断整个温区内结构稳定或测量准确。打印生成焓与既有USGS水蒸气参考焓混合计算得到298.15 K反应热424990 J/mol，仅是明确来源组合的算术结果，未认定为实测或供耦合使用。

## 已实现的有限开发

现有 `RecordedThirdOrderDehydroxylation` 新增明确物质库存的摩尔速率接口。在一个前驱体对应一个非挥发产物、总公式单元池 N=nK+nM 为正且守恒的条件下，F3关系为：

`dα/dt = k(T)(1−α)³`，`R = N·dα/dt = k(T)·nK·[nK/(nK+nM)]²`。

R 的单位是 mol/s；标准脱羟计量为 `nK'=-R, nM'=R, nH2O'=2R`，Al/Si/O/H残差全部为0。该推导独立说明如何连接已存在的转化率律，不是作者确认过的原文修复。输入池必须按这些公式单元定义，不能把任意粉体质量或具有不同前史的产物直接并入。

使用 [Ptáček2010出版摘要](https://www.sciencedirect.com/science/article/pii/S0040603110000055)可见的410°C以上 F3 参数，仅在其研究温区内取420、450、500°C，完成54组库存比例和尺度核查；70位参考、摩尔量缩放以及不同体积表示均在声明的数值预算内。极小未反应比例直接用库存比求值，避免通过 `1−α` 相减损失。原实验全文曲线未取得，该算术核查不是独立现实验证。

复算入口：

```sh
.venv/bin/python examples/sandbox/review_cantisani_clay_source.py --parameters parameters.cantisani_clay_source_review.json
```

输出采用独占创建，已有证据不可覆盖；重跑应在参数文件指定新的输出目录。原始结果在 [review.json](../../../../data/sandbox/research/cantisani-clay-source-v1/review.json)。未新增或运行软件测试、未生成或比对SHA；本阶段仅来源、量纲、元素和独立数值核查。`material_qualified=false`、`training_eligible=false`。

# Fernandez2019 有限速率来源与单位审查

[原论文 DOI](https://doi.org/10.1039/C9RE00361D)的[开放许可接收稿](https://www.researchgate.net/publication/336656934_Calcination_kinetics_of_cement_raw_meals_under_various_CO_2_concentrations)全文已通过网页工具读取；最终出版社索引的表3与接收稿表4给出相同系数和单位。直接HTML/PDF下载返回403，未取得本地PDF或图像核对，不绕过访问限制。论文使用CC BY3.0；本记录只转录复算所需数字、单位和定位，未改写为本项目测量数据。

式3–4的无入口CO2模型为`dX/dt=k1*Sg*(1-X)`及`X=1-exp(-k1*Sg*t)`。表2的BET单位为m²/g，拟合前因子单位为mol/(m²·s)，所以直接用两表数字得到的指数仍有mol/g量纲，不能作为可执行物理定义。Compostilla的前因子11.7e6、CP2面积4；Calcare前因子11.9e6、面积1.4；活化能195kJ/mol是作者借用的值。数据与位置保存在根参数，运行不依赖网络。

`review_calcite_fernandez2019_units.py`只复算单位解释：840°C/1s的CP2直接代入数字为.032577，Calcare为.011721，这两项的指数有量纲，明确标为无效解释。若把面积乘以[NIST方解石摩尔质量100.087g/mol](https://webbook.nist.gov/cgi/cbook.cgi?ID=B6004659&Mask=80)，则分别为.963661/.692732；CP2在790°C/1.3s为.798071。与论文图7文字的接近完全、约.70、低于.80方向相符，但不能由此证明作者对混合试样使用了这一质量基准。

此处乘摩尔质量是明确的纯物质解释；BET实测以每克试样计，而反应转化以其中CaCO3计，实际混合试样需要碳酸盐库存、有效面积归属及作者的归一化说明。没有把XRF的全部CaO自动视为CaCO3，也未拟合任意倍率。粗文字锚点没有误差条，不能当作独立留出验证；暂不设通过判据，不添加过程动力学。

后续解锁条件：取得式中Sg的摩尔/质量归一化原始说明或可复现作者代码；取得可读曲线/原始点及不确定度；确认材料成分、入口与沿程CO2定义，再按来源独立复现。含CO2时的式12和其经验平衡压力还必须与热力学来源一致性分别审查，不能直接替换本项目USGS平衡。当前仍`material_qualified=false`、`training_eligible=false`。

# 等温四气体孔隙柱：全浓度与压力联合演化

本阶段把已按 Cantera 3.2 原始 Dusty Gas 方程核对的局部通量推进到封闭一维孔隙柱。先完成纯 Knudsen 柱的解析解资格，再运行四气体柱；静态独立参考的资格可提前完成。

所有输入和预算预先写入 `parameters.dusty_gas_four_species_column.json`。T=600 K，长 0.02 m、总截面积 0.005 m²、孔隙率 0.3、迂曲因子 1、孔半径 1 μm、κ=3.75e−14 m²。该 κ 是声明的直圆管束模型 εr²/8，不是实测砖坯数据。

CO/CO₂/O₂/N₂ 初始分压均值为 10/20/30/40 kPa，余弦振幅为 2/12/1/5 kPa；使用解析的格平均。四个浓度分别演化，总压为 RTΣc；不施加零总摩尔通量。通量按总体截面积，库存为 εV c。两端封闭，温度固定；无热方程、反应或温度梯度。

熵取 −RΣnᵢln(cᵢ/c_ref)，c_ref=100 kPa/(RT)。它包括压力均衡产生的密度熵，省略的各物种线性项在封闭总账中抵消。这不是绝对热化学熵，也不代表已打通湿砖与高温反应的能量参考。

生产面采用已核对的 16 点对数分浓度路径积分。独立参考直接解原始非对称总通量方程，采用 64 点积分，并先与已保存的 60 位精度积分锚点比较。分子摩擦、壁面碰撞和 Darcy 耗散分别核对；原始方程残差预算 1e−9 mol/m⁴，面通量差 1e−12 mol/(m² s)，面熵率差 1e−11 W/K。

每级网格先检查全记录、每个接受步的 2/4 点时间积分、局部/累计物质与熵账，再比较两档时间容差。全局与局部库存预算 1e−12 mol，熵预算 1e−10 J/K，时间浓度差 1e−7 mol/m³。通过后方可细化下一网格；同体积父格浓度差预算 1e−4 mol/m³。达到预算即停止细化。保存未通过证据，不改变预算迎合输出。

源自近似气体物性与声明孔模型的数值资格不等于真实砖体资格。始终 `material_qualified=false`、`training_eligible=false`。

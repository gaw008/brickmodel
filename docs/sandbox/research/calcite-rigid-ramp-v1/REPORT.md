# 连续升温、保温和冷却：四格限定数值核查通过

开放反应列现能接收连续的外界气温、墙温、总压和CO2/N2组成程序。当前虚拟装置从300K开始，6000s升至1180K，保持2000s，再于14000s降至400K，保持到18000s。外界初始压强和组成从本装置初始平衡态推得（79137.4719Pa、CO2摩尔分数.0004997501）；后续100000Pa和组成节点均为明确的虚拟选择，没有冒充窑炉测量。

气体与辐射通过原无储量表面连接一维列；相分配仍是USGS同源纯方解石的瞬时平衡。这个新温程不替代原骤变边界的空间失败，也没有加入实际反应速率、砖孔结构或材料资格。

实现复用现有BoundaryProgram的连续分段线性输入，在每个节点重启积分。求解器虽使用逐步局部时钟，每次RHS和Jacobian调用都通过已接受时长恢复实际时刻；稠密求积节点也恢复实际时刻。只插值T/P/组成，再重算同源气体h/μ；墙的熵流使用当时−Qrad/Twall。规定外界状态所需的设备功/供热不在列系统边界内，不能把列的热量账解释为整座窑能耗。

五组固定时刻的守恒关系、相分支内导数及独立50位重建通过：普通差分最大尺度误差2.77151e−6，50位参考最大9.97722e−11，原目标均为1e−5。原恒定边界四组静态完整结果逐项精确相同，见original-static-equality.json。

两档18000s过程分别19475/20125接受步。全部保存状态、稠密区间的逐格C/N/U、局部/整体熵、内外表面收支及2/4阶求积通过原预算。基础/精细最大累计单元U残差3.36676e−7/7.91851e−8J（目标1e−5J），最大局部熵余额9.04409e−10/1.23500e−10J/K（目标1e−7J/K）；节点表面能量率余额≤9.05888e−12W（目标1e−8W）。这仍是共享状态反解下的独立通量、来源和积分核查，不是实验对照。

9001个共同记录时刻的最大格温差6.74802e−7K、格压差.00141958Pa、总CaO差8.52944e−14mol、表面温差4.47148e−7K，时间目标全部通过。每个记录时刻还从原程序、独立50位仿射运算和原Cp积分重建外界h/μ及辐射：温差≤1.122e−13K，化学势差≤2.133e−10J/mol，辐射差≤5.203e−15W，达到冻结目标。

# 有限速率来源有界筛选

为解释独立薄膜onset偏移，核读两项公开原始实验来源：Sanchez-Rodriguez薄膜2024/2025和Li等流化床2022，第三项KAUST2025仅获得搜索线索，未核全文，未取其参数。

薄膜来源的实际观测已经用于独立对照，偏差见calcite-film-onset-v1。其完整可复现速率前因子和观测形状映射尚未建立，不能直接用活化能填满速率模型。

[Li、Wang、Li2022](https://doi.org/10.3390/catal12121661)原PDF已下载并实际查看表1及p14/15。表列S0=22.80m²/kg，正文p15列22.80m²/g，相差1000倍；Eq20与S0成反比，不能无声消去差异。Eq17把熵前因子写成ΔS/R，与热力学指数关系不一致，拟合a表达式不能自动证明该推导。来源Peq是另一个经验式，尚未与当前USGS同源自由能兼容性核查。表中速率数值仅记录来源，不接入宿主。

决定：两项资料可用于观测/假设审查，目前不足以直接准入同材有限速率—能量—反向反应闭合。所需下一证据是参数单位/公式解释、对应样品与热历史，以及保留独立评价数据的识别方案。本轮没有发消息索取资料，没有把其他材料系数改名为MIA3或砖参数。

可独立继续的是已通过物理核查的刚性共同气流宿主空间耦合；它仍以瞬时平衡作为明确极限，不能替代被阻塞的动力学。

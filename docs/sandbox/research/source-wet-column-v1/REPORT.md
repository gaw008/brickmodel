# 来源干质量的封闭一维热湿多格模型

`SourceWetColumn` 已把原 Arlabosse 干质量比热、水气机械储能、液汽相变和气体/能量共享面接入同一 N 格时间推进。相变和面通量来自旧 `WetPair` 提取出的共同函数，旧 A/B 反应入口与完整黄金结果保持。此版本固定干质量、固定几何、关闭化学反应，两端明确为无通量边界。液体跨格迁移、开放炉程、耗尽事件与全周期尚未接入此来源路径。

软件基线为 `4ff9572`。原材料比热来源和温区未变；几何、可用流体体积及输运系数仍是明确的 `manufactured_test_fixture`，`material_qualified=false`。该增量没有取得同材料干燥预测或真实烧结砖资格。

## 方程与实现

- 每格保存固定干质量、液水摩尔数、O₂/N₂/H₂O 气体库存和总内能 U。一次逆解同时给出本格温度、压力、气体体积及相变需要的状态；不另加潜热源。
- N 格有 N+1 个有方向的面；内部面 f 连接格 f−1 与 f，一次求值由两格以相反符号使用。非均匀格宽与实际半格热阻一致；可用流体体积及误差上界不得超过该格几何体积。
- 固定中点法先从旧状态计算半步预测，再以中点通量从旧状态推进完整步。每个库存的 `旧值 + 左面 − 右面 + 相变` 用 Fraction 聚合后只投影一次到 binary64，投影差逐格记账。固体质量不参加相变更新。
- 完整终点评价通过后才保存该步的状态、时间、观测与账本。取消、资源限制、数值失败和域退出均保留之前完整接受的前缀；没有静默截断库存或自动归零。
- 预测舍入和接受步舍入分开。累计绝对投影/面能量分解预算不等于时间离散误差、逆解传播误差或材料物理误差；守恒审核使用接受步的带符号舍入。

公共 `evaluate_wet_phase` 校验实际液水模式及同一机械点的水汽库存，保留原化学来源/参考约束。公共 `evaluate_wet_face` 复用质量修正扩散、Darcy、供体焓和串联导热。独审发现初版可接受互换的 O₂/N₂ 焓函数和任意假回调；现已在焓评价前验证真实相适配器、叶类型、物种、摩尔质量、气体常数和能量/摩尔基准。完整左右储能的气体热量来源一致性由多格调用者额外绑定。

## 真实水例子的明确条件

原 `source-wet-storage-v1/run_native.py` 构造来源储能与 HEOS 水、NIST O₂/N₂ 和来源绑定的理想水汽函数。三格干质量各为 binary64 `.2` kg，可用流体体积各为 `.001 ± 1e−12` m³。格宽为 `.25/.3125/.375` m，公共面积 `.01` m²；这些只是测试几何，未声称实际砖坯密度或孔隙率。

初始液水各 `.25` mol；格 i 的气体库存为 `(.125+.03125*i, .25, .00390625*(i+1))` mol，温度为 `331.25+1.25*i` K。面热导率、扩散系数、渗透率、黏度及相变系数在脚本中明确标为制造测试输入。逆解政策为 `1e−5 J / 1e−6 K / 100 次`，模拟时长 `1/1024 s`、一个中点步；原算术预算 `1e−8 J / 1e−12 mol` 未改。先实测三格评价 2.347864 s，再登记 45 s 积分/60 s 外部硬限，未因结果调整精度门槛。

实际累计绝对算术用量为约 1.83392e−11 J 和 2.15587e−16 mol。独审确认保存的全局 U、O₂、N₂ 变化及对应带符号修正均为 0；总水保存值变化为 `−5/576460752303423488 mol`，约 −8.67e−18 mol，恰由接受步的带符号舍入解释。故守恒余额精确为 0，但不能称保存的总水数值绝对不变。

这需要记录中已安装的包、实际水后端和合法来源缓存。例子会保存失败前缀，脚本退出 0 本身不是通过：还须读取 `run.status=completed`、`len(run.ledgers)=1`、`evaluations_completed=3` 和 `ledger_checks=20`。完整 CLI/UI、重放/续算尚未准入新来源多格模型。

## 证据与恢复

本目录提供实际例子、安装 XML/身份、源与安装 native 结果，以及两份独审和保存结果审核。`raw-evidence.zip` 保留完整原始 RED、修复前源码、旧黄金数据、作者/独审脚本和日志；`archive-manifest.json` 列出成员长度/SHA-256，打包后已逐成员读取核实。审核记录中的临时路径是实际运行路径；复现独审脚本时可按压缩包前缀恢复原对应目录，并保留其与正式测试 fixture 的依赖。Hash 只证明记录字节一致。

下一个实际软件任务是把既有程序气体库及串联对流/辐射边界复用到该 N 格来源路径：显式时间节点、外界气体组成/温压、流入/流出焓与表面热量都进入同一面账本，先验证开放单格/三格极限。之后迁移精确耗尽事件与记录/应用接口，保留现有质量基准和误差合同。不得仅放宽旧 A/B 或固定两格类型限制。

同材料可用体积、吸附/液体迁移/有效输运、原泥反应、烧结与冷却本构仍需公开证据。Arlabosse 低温 Cp 不能外推到完整烧成域。三机制公开实测、全周期空间/时间验证、来源完整原泥案例、多代实验和应用验收继续必需未完成；Goal 保持 active。

## 必须保留的来源异常

1. **Nowicki的A与浓度基准**：Table2在10%O2、500°C的ks为2.221e-4/s；Table3 A=1.16e4/s、E=114kJ/mol。A exp(-E/RT)=2.305e-4/s；按Eq3再乘0.1^0.88变为3.039e-5/s。只允许把“依据Table2重新拟合的固定参考气氛模型”作为新的derived模型登记，不能擅自把原文更正为y/0.1。Eq6微分时系数是3ks(1-alpha)^(2/3)，不能漏掉3。原Eq1及其delta-m定义给出反向conversion；CO2的E正文223与表227kJ/mol也不一致；蒸汽Table2第三个温度950°C与图示温区不一致，该行暂不用于拟合。
2. **Araújo的Arrhenius数值**：p12 D0=2.577e-9m²/s、Ea=101562.96J/mol代入p8-9 Eq15，在100°C给出1.564e-23m²/s，Table2为1.55e-5m²/s。表格D与原论文总水质量变量的重参数化需单独处理，不能以疑似指数笔误静默修正。
3. **Zhang2022原料基准**：污泥Al2O3正文15.42%、Table1为16.42%；高岭土正文41.53%、表42.53%。污泥氧化物（含Other）合计100.46%，另列LOI37.64%。不能把二者当同一干基相加，或自动将LOI全部当有机质。粘结剂还引入额外水和有机物。
4. **Vali2021元素基准**：Table1把CHONS列标为as received，五项合计99.1%，却另有10.6%水和干基21.1%灰；当前不能构造可靠元素守恒伪组分。Table3未标k0时间单位，且A/n按各升温速率拟合；暂不作为任意温程真实速率定律。
5. **Mohajerani终态口径**：控制砖Table3初始干燥/烧成/总直径收缩分别1.26/3.24/5%，不能简单重算对账；WTP17-29高度2.6/3.2/5.7%也应保留原值。Table4导热由密度经验式估算（p12），不能归类实测。不能沿用文中热节能估计充当本沙盒的能量守恒验证。
6. **Wang2021文本阈值矛盾**：p5与p6关于40°C/RH30%和60°C/RH60%达到MR0.1的时间相差10min。本轮保留原图符号作为上游，阈值不从互相冲突的文字硬编码。样本中的dust-loss可能影响所谓水分损失，后续模型残差需如实解释。

## 完整材料域仍缺什么

| 必需项 | 缺口与对Goal的影响 | 最小下一步公开证据方向 |
|---|---|---|
| 原泥组成→多步产物与反应热 | 没有同身份材料的可闭合干基元素/矿物、各阶段char/tar/gas产物分配与焓；不能把挥发物全部换成CO2 | 优先原泥同批次多速率TG/DSC、元素分析、定量气/焦油产率及char后续氧化；记录未标定组分。 |
| 湿坯热湿物性 | 真实单污泥薄层有干燥观测，混合黏土湿坯的吸附/毛细、有效扩散、k/cp(T,M)和初始成型孔隙未知 | 选择有明确组成的biosolids—黏土域，再找同体系测量；跨域只可做明确探索或单模块测试。 |
| 有限供氧与排气 | 粒级char氧化有参考数据，砖坯开放孔隙/曲折度/渗透率随温度和收缩演变无成套来源 | 同基料的渗透/扩散与压汞/显微/膨胀仪联测，至少明确开孔→闭孔边界。 |
| 动态烧结与几何 | 终态收缩、孔隙和密度不唯一识别动态致密化/黏度/连通性 | 多热历史膨胀曲线和密度/开孔观测；SSA样品仅可验证对应无机域。 |
| 冷却应力 | 未找到同成分/孔隙状态热膨胀、模量、粘弹参数与边界数据 | 对声明材料域寻找膨胀、弹性/蠕变曲线；缺失应力输出保持unknown且仍是Goal未完成项。 |
| 全周期耦合验证 | 已找到成对配料和炉温程序及终态砖数据，但未找到同试样的全过程内部温湿、氧/残碳和压力观测 | 可先尝试上述已配对原污泥砖终态，再明确仅终态比较、不等于内部全场获验证。 |

可继续：证据运行时准入、通用守恒离散与解析极限测试、分域真实干燥/char验证、材料/热历史留出设计、UI未知项追溯。当前并不是必须先取得本厂几个月数据，而是必须保留公开证据不能闭合的具体材料依赖。首轮检索已包含多种公开数据库、出版商全文及论文引用回溯；尚不能据此宣布相关证据在全世界不存在。

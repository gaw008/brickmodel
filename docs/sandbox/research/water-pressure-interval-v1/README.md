# 来源绑定水状态方程的局部压力区间研究

本研究为补齐湿态U反解温度误差→压力误差传播。已读原IAPWS95-2018第4页Eq6/Table2及压力关系，使用已批准HEOS Water JSON，SHA a10a0da6与原native descriptor完全一致。源码在证据包，尚未进入生产模块。

interval_eos28bcfac0：Decimal定向区间运算与二阶密度Jet，对51幂/指数、3Gaussian、2非解析残差项求p及dp/drhomolar；不以采样极值作全区间界。coupled185f8dfb：全T/V矩形的两密度端面严格异号、全矩形导数正，包围一个局部唯一数学根。显式液体占积scale=Mpublic/Mnative，保留原后端摩尔质量一ULP差别，不替换物理常数。

初始密度括区±.01无法确定端面符号，失败完整保留。经区间诊断改为明确数值搜索括区±.2，原方程/门槛未改；10项组合pure1.142秒通过。独立原区间/Jet、合成耦合根与非unit scale分别通过5/4/7项纯测试，代码审查通过。

读取先前fine轨迹8步×2格的原始端点，按各自T反解误差、原bulk和液体体积误差进行16个局部区间计算。修复版实际1.413235750秒，原10秒预算内；最大P区间宽约0.00559134 Pa，含原fixed-T误差的最大保守半径约0.00326856 Pa。此为保存数据上的新增数学计算，不是新原生轨迹。独立Fraction审计核对全部16组输入/质量换算/源与实现SHA/矩形条件/半径上界，通过。

原研究result01在Decimal最终半径汇总中8/16项发生向下舍入，精确差额、原脚本/结果保留。result02用Interval上界修复，并锁定全部源与实现SHA前后验证；未覆盖原失败。旧FREEZE均是当时历史版本，最终快照以FINAL_STUDY_FREEZE及本目录manifest为准。

边界：当前结果只包围指定密度邻域内的数学根，不认证稳定液相分支、原生内部浮点误差、材料实验误差或全周期。液体体积误差仍为原制造数值包络下的条件结果。后续必须完成实际provider、分支域和误差合同衔接后才能接入湿态事件门槛。CoolProp许可随证据保存；原IAPWS PDF等不重复分发，路径和SHA可追查。

# 定容Ca/C/O同相库存与能量导数

18个状态、六种钙/碳相组合的解析导数已通过独立60位来源差分。温度两档差分共36组，C/O/N库存两档差分108组。

直接对log(CO/CO2/O2)、可选CaCO3分数、log(P)联立化学势/元素/定容约束求导；这不改变原已核查的平衡求解器。元素域和常体积纯固相近似全部沿用。求得固定T,V的库存导数，再由`dU=Cv*dT+sum(U_N*dN)`转换为固定U,V的温度、压力、相量与气体化学势导数。

固定T/V库存扰动会改变气体总摩尔数，N2对气体摩尔分数和压力的显式贡献进入所有相关化学势约束；石墨存在时C库存对固相体积的显式贡献也计入。不存在的固相量导数在同一相区为零，不能用该导数跨越相边界。

独立参考为既有60位联立源平衡、Cp积分与体积方程。温度差分1e-4/3e-5K、库存相对扰动1e-7/3e-8事先冻结；所有邻点保持原相组合。最大温度导数误差：压力1.309e-9Pa/K、U1.841e-12J/K、S1.445e-15J/K²、相量1.007e-17mol/K、气体μ5.283e-12J/(mol K)。库存导数最大压力6.189e-5Pa/mol、U3.871e-10J/mol、S5.234e-12J/(K mol)、相量4.600e-15mol/mol、μ3.517e-5J/mol²，全部在既定单位预算内。

额外恒等式最大`U_T-T*S_T`4.663e-14J/K、`U_N-T*S_N-lambda_N`6.069e-9J/mol，与既有Cv差4.175e-14J/K。坐标正反链式矩阵乘积与单位阵最大差5.821e-11，预算1e-9。

结论仅为同相局部导数资格，尚未给面Jacobian、多单元时间积分、相变跨越、空间收敛或真实材料新增资格。原物理来源、虚拟输运及材料依赖不变。

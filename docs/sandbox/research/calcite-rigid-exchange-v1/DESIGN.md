# 两个刚性反应小室的气体与内能交换

状态为每室[C总量,N2,U]，固定各室Ca、总V；瞬时平衡使用已核刚性小室势函数。dU=T dS+μC dC+μN dN，两个刚性外壳之间无需外部p dV功。气流通道携带完整物种焓，固定控制体中的流动功随焓计入一次。

定义di=μi,L/TL−μi,R/TR、θ=1/TR−1/TL、hi为两侧来源气体焓算术平均。Yi=di+hiθ；xi为两侧气相摩尔分数算术平均。主体流力B=ΣxiYi、等摩尔反向力D=YCO2−YN2。采用显式虚拟正系数Lb,Ld，主体摩尔流J=Lb B，反向流j=Ld D；NC=xC J+j、NN=xN J−j。能流E=G(TL−TR)+hC NC+hN NN。每种库存和E只在面上算一次，左负右正。

两室总熵导数Eθ+ΣNi di=G(TL−TR)θ+Lb B²+Ld D²≥0。对应物质响应矩阵Lb xxᵀ+Ld vvᵀ，v=(1,−1)，对称正定；本次不是目标砖实测系数。等温同组成时Yi=R ln(pL/pR)，因此反向流为零、主体流方向与压降相同；此处没有声称等价完整Darcy定律。Onsager原始文献支持近平衡结构，不保证这些虚拟常系数的远离平衡延拓具有实际材料准确性。

先核变化N2的势导数、来源参考零点不变性、正反/零流与等温压差，再执行双精度完整过程、独立逐步能/物质/熵积分。最终平衡上界由合并总Ca,C,N2,V,U的同源模型给出；不可把接近该上界称为真实砖验证。开发进行中。

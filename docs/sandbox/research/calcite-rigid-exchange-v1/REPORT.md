# 刚性反应小室的CO2、氮气与内能共同交换

两个固定1cm³小室现已接通共同气体通道与导热。状态为每室总碳、N2、U，Ca和外壳体积固定；反应相分配随温度、库存和压力改变。完整流焓进入固定控制体内能账，没有把流动功漏掉或重复加成反应热。[定义与推导](DESIGN.md)。

气体交换矩阵为Lb xxᵀ+Ld vvᵀ，x是面气相摩尔分数、v=(1,−1)，Lb/Ld为显式虚拟正系数，G为虚拟导热系数。[Onsager原文](https://journals.aps.org/pr/abstract/10.1103/PhysRev.37.405)支持近平衡对称响应结构，不提供本算例系数，也不能据此把有限驱动力延拓说成实测砖传输定律。此处已证明声明结构的总熵产生非负；等温同组成气流按压降方向，但不是经标定的Darcy模型。

## 已完成核查

- 18组变化T/C/N2状态核对dU=T dS+μC dC+μN dN、有效Cv、U反解、化学稳定；对保存的原固定N2模型15组/4角点重新计算，原预算全部通过。
- 4组初始、反向、零流、等温同组成压差检查通过；两种守恒元素参考H/S零点平移后，温度、库存、物质流及熵产生不变，能流只改变应有的参考焓输运。不是另拟物性。
- 基础/紧容差轨迹分别6021/6030个接受步，均到6000s。每步重新展开来源U/S/P及反应势；两阶密集时间积分独立展开气流矩阵和携焓，核每室物质、内能、熵及总熵上界。两条完整轨迹均通过原先预算。

## 这个算例能说明什么

左/右初始1100/900K、4.3504/1.1913bar，左侧纯方解石，右侧方解石/石灰共存。通道打开后，左侧先失去CO2，随后出现CaO；右侧同时发生再碳酸化与温度改变。N2先有逆向净流，随后换向，体现压力和组分梯度的共同影响，不是仅按总压给每个组分同一个方向。

6000s累计左至右传输CO2 10.1838μmol、N2 5.00116μmol、能量119.875J，总熵增加0.01267677J/K；最后温度约1001.9697/1001.9556K，总压204281.6/204183.3Pa，仍有小梯度，未称严格达到平衡。合并总库存/总V/U的平衡温度1001.96265K，为同一理想模型的最大熵上界，全过程未越界。两室最终固相比例可以不同。

# 变温孔隙：压缩功、耗散热与热交换

已把球形孔隙运动与温度变化耦合。气体为封闭、定量的理想 N₂，采用已核对的 USGS 1995 热容及标准焓熵数据，沿用该来源的 R=8.31451 J/(mol·K)。基体体积固定，黏度、表面张力及体积热容恒定，气体与基体共享均匀温度；外界施加恒压，可通过给定总热导与热浴换热。上述基体和几何参数均是显式虚拟输入，尚无真实砖材料校准。

令 C=n(Cp−R)+Cm，孔体积变化率为 V̇，黏性耗散为 D，热浴输入 Q̇=G(Tb−T)。受力方程沿用已核查的有限球壳关系，温度方程为

C Ṫ = Q̇ − pg V̇ + D。

总内能 U=n[h(T)−RT]+Cm(T−Tref)+γA；外压功输入为 −pout V̇，因此 U̇=Q̇−pout V̇。γ 不随温度变化，模型内的表面熵为零。气体及基体的熵变化率为 Q̇/T+D/T，气体、基体和热浴的总熵产生率为 D/T+Q̇(1/T−1/Tb)≥0。未忽略压缩功，也未把耗散能重复计入热输入。

54 组温度、半径、初始气量和热浴温度状态通过 60 位独立核查。参考程序用两侧法向应力联立求解、径向耗散积分、热容直接积分，以及 U、S 的偏导重建能量和熵变化率；温度参考式从总能量梯度计算，未调用生产模型的温度式。最大能量变化率差 8.979e−25 W，熵变化率差 1.432e−27 W/K。原恒温模块改为共用纯力学函数后，24 个状态及 3 个来源恒等式点再次通过核查。

四种情形各计算 20,000 s，并各以两套容差重复：初始孔压 100 或 300 kPa，分别施加 1100→750→1000 K 的热浴程序或绝热边界。初始温度 800 K、孔半径 10 μm、孔隙率 0.35。所有记录状态、各接受步内的 2/4 点 Gauss 状态、局部和累计功热收支、熵收支、法向应力及基体定容均通过冻结预算；未新增或执行软件测试。

时间比较共 64,538 个联合节点，最大半径差 1.471e−14 m、温度差 1.703e−8 K、压力差 8.134e−4 Pa。最大整体能量收支差 2.440e−18 J，熵收支差 4.200e−18 J/K；这些是声明模型的数值差，不是实物预测误差，也不是连续时间误差上界。

绝热收缩终态温度为 800.018599 K，孔半径 8.348401 μm；绝热膨胀终态为 799.957426 K、12.674364 μm。独立联立 U+poutV 守恒和机械平衡得到相同终态，终态温度最大差小于 6.4e−10 K。结果说明在该研究条件下压缩、膨胀与黏性耗散确实参与温度变化，不能把绝热简单等同于恒温。

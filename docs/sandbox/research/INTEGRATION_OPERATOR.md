# G2 守恒时间积分器

实现：`src/sludge_sandbox/integration.py`。这是数值基础设施，不提供材料参数，也不表示湿砖全周期已完成。

状态保存每格实际物种 mol 和总内能 J。每个内部面只保存一份正向通量；反应源和外部功率独立存储。算子在每个试探状态重新计算。采用 SSPRK2，接受两段子步，只把其实际积分权重写入账本。拒绝步不进入轨迹。形成能已经包含在内能状态时，反应源不得再添加反应热。

误差估计使用实际可表征时间：令宏步 h=end-start，两个子步分别 h1=mid-start、h2=end-mid。二阶方法局部误差主项为 C h³，细分后为 C(h1³+h2³)。因此 q=(h1/h)³+(h2/h)³，细解误差估计为两解差乘 q/(1-q)；等分时退化为除以3。这是光滑算子的渐近估计，不是严格上界。每个回调使用实际端点，通量权重使用同一端点之差；不能因绝对时间很大而让回调越过终点或积分多算时长。无法表示内部时刻或非零权重时明确退出。拒步必须使可表征端点下降，否则用向起点的相邻浮点端点；不会重复同一个实际试算耗尽预算。

误差尺度由调用者明确提供，不能用巨大的绝对生成能作为温升误差归一化尺度。非负性靠试探步拒绝保证，不裁剪库存。零库存的净流出是算子错误，立即返回 numerical_failure；已声明物理域退出单独返回 domain_exit。未预期的程序错误继续抛出，不伪装为材料失败。

独立初审发现的反例已经保留在测试中：

- 同时流入流出 1e20 的单元会因顺序相加丢掉初始 1 mol / 1 J。现在先用 fsum 形成净交换，再与库存相加。
- 在 1e20 J 储能上输入 1 J，浮点状态无法表示变化，而误差估计可能为零。现在独立计算每次更新的 `after-before-increment`，超过明确的绝对数值容差即报 unresolvable_energy_increment，不通过缩步隐藏。物种同样检查。
- 普通小数步长及最后一段小于自适应最小步长时曾提前失败。现在区分自适应步长下限与强制终点/节点裁切；末段真正积分，记录实际交换，不仅改时间戳。
- 最后一次算子回调中发生取消/超时曾仍提交。现在回调前后及提交前检查，保存最后完整状态。

后续复审补充了宏步与累计残差反例。两个子步各自通过绝对容差并不足够：合并后再次核对宏步账本；另用 Fraction 精确累加每个已接受浮点面交换与源，逐前缀核对初始到当前库存的差。这只检查浮点数值账本；物理元素/质量配平与热化学重建仍由独立审计负责。失败提案不会更新累计账本。普通小数步长和不同绝对时间原点均有回归，微小终点余段只在量化尺度内合并且真正积分。

时间断点仅用于连续外部程序的分段。跳变边界要求分段重启并给每段正确的单侧算子，本接口不宣称已解决不连续强迫。显式方法面对刚性反应可能耗尽步数或时间限制；这类结果不是材料不可行。持久化、身份核对及恢复由后续应用层实现，目前仅能从返回的末状态和时间开始新积分。

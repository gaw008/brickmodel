# 有限库存双气室：先固定验证合同

2026-09-25 UTC。在已通过静态核查的小孔分子流关系上接有限CO2/N2库存与同源完整内能。两气室各自瞬时均匀平衡，固定1/1.5L体积，初态1100K/1Pa/.1 CO2与400K/.2Pa/.6 CO2；小孔面积1e−9m²是声明虚拟几何，不授予实际Knudsen适用性。系统无外界功、热或物质。

每室积分两物种摩尔量及U，两室同一面流反号，并单列累计物种/能量和总熵账本。气体温度由USGS生成焓+Cp积分减RT后反演，不能将出流能量误写成h。冻结两档BDF精度、全程逐室2/4点积分、源Cp独立展开、熵上界和最终全局平衡对照；根参数parameters.effusive_gas_chambers.json。全局平衡独立由合并库存、总体积和守恒U求温度，平衡时各室物种按体积分配。

初次程序60000s及20s共同观测提前声明；若尚未达到平衡预算应保留失败，不能把有限时间末态叫平衡。此阶段不加入固相、不改既有砖孔模型、不运行软件测试。

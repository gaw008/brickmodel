# 开放空间反应列：独立开发与核验

在已核的封闭反应柱和开放单元基础上，构造2cm长、1cm²截面的虚拟刚性平板列，左端绝热/不通物质，右端接无储量气体与辐射表面。总体积2cm³、Ca密度10000mol/m³；300K初态每m³额外气相碳.01mol、N2为20mol。每一网格都有同一个来源热化学和几何方程；总库存不随网格数改变。没有真实砖配方或孔径校准。

内部中心距离为dx，最外格中心到物理表面的距离为dx/2；共用相同的面积和密度输运系数。每一内面C/N/U通量以相反符号进入两格；表面单独平衡两种气体和能量。所有库存均计完整生成能，辐射输入与最外侧气体能流分账。4000s按既有开放单元程序切换库，不给格内状态或库存施加瞬时跳变。

每格积分δ=C−Ca、ln(N2/Nref)、U，并在恒定边界段平移BDF局部时钟。仅外部账本增加10个ODE量，避免把每个内面再作为被动物理自由度；后续完整审查仍独立积分每个内面并逐格比较C/N/U，不能用总量守恒替代局部核查。

解析Jacobian先在物理库存坐标按面装配，再变换到积分坐标。令D=diag(1,N2,1)，则Jz=D⁻¹JyD，并在log-N2对角额外减去fN/N2。外部熵的导数由同一库化学势及单元熵Hessian给出；被动账本列严格为零。静态选定状态要检查全部物理坐标差分、三个步长、分支、守恒导数及熵率恒等式后才进入时间积分。

冻结原单元时间/局部物种/U/熵和表面预算，再比较几何相同的1格专用单元与空间装配，四格数值/解析导数路径，两档时间精度和逐格完整独立积分。随后按共同观测比较相邻网格，保留初始快速过程，不丢弃不利时刻。所有失败前缀和重算协议分别保存；科学数值资格、空间误差和材料适用性分别判断。没有软件测试或校验和操作。

# 普通来源轨迹跨进程恢复：实际结果

基线45287fe，2026-09-12。新增 `source_trajectory_record` 和独立 `source_execution_worker`，将已暂停的普通来源轨迹保存、关闭原会话，并在新进程恢复原控制器继续计算。原父研究的历史控制器仍不授予恢复资格。接口见 [USAGE](USAGE.md)。

保存包保留原初态、精确时钟、政策、检查点、完整观察、事件原字节、来源及累计物质/能量账本。恢复保留旧工作额度并记入新的读取、核查、重建和计算成本；离线等待只作诊断。未完成保存、取消、额度用尽及被篡改的记录均保留失败，不能发布为可用恢复点。局部一次性 claim 不等于防止复制整个目录，也不提供来源认证。

代码证据：冻结153源码模块；非editable安装153模块/160包文件逐字相同。源码回归185项通过1.517秒；安装集成240项通过216.89秒。独立最终7项反例探针通过0.322秒。早期真实RED、修复前代码和后续结果分别保存在 `review/prior`、`lifecycle`、`execution`；不把不同测试轮次加总成一次全绿运行。安装01/02的缓存/网络失败保留，安装03仅重装本模型包，运行依赖未升级。

按 [原预登记](NATIVE_PLAN.md) 执行一次真实HEOS对照，无重试：四个独立进程分别做父研究、连续三步、另一分支暂停一步并保存、恢复后余下两步。驱动123.549081833秒，监督124.649336250秒；原510秒共同预算、180秒普通预算、97 RHS/16湿求值上限及三步比较门槛保持。监督记录输入前后相同，原进程组已清理、leader已回收；不声称能约束逃离该进程组的程序。

实际总计76 RHS、16 HEOS构造、3初始能量求值、8湿压力请求；恢复只增加14 RHS和4构造。连续与恢复的完整数值结果、观察及七行累计账本一致；各普通路径3接受步、0拒步、22观察。四次租约实际覆盖32/22/8/14 RHS。三格温变约5.70e-6、−1.10e-6、−4.61e-6 K，均超过对应两端反解数值界之和；三个普通步的全域能量差为8.64e-12、−8.19e-12、−1.05e-11 J，低于原0.001 J门槛。原物理时间区间仍只有3/64秒。

773个输出文件共33,313,972字节按原字节归档，34份私有来源资产副本不再分发；完整文件清单与排除项见 [NATIVE_ARCHIVE](NATIVE_ARCHIVE.json)。公开归档因此不是可直接恢复的完整包，实际含资产的原包留在 `/private/tmp/brick-source-resume-v1`。全暂存区空白检查报告旧测试日志/XML/diff的原尾空格及已执行比较器的末尾空行；为保留实际证据字节不清洗这些文件。生产源码、测试和当前说明文档的限定空白检查通过。

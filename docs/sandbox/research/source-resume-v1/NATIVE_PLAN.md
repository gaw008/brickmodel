# 普通来源轨迹跨进程保存恢复预登记

起点45287fe；本次仅验证新的ordinary source恢复生命周期。原研究记录仍不授予历史controller恢复，材料、完整烧成与训练资格均false。

冻结后非editable安装，使用四个独立隔离Python进程分别运行：新父研究、连续三步、另一分支暂停一步并保存关闭、从保存目录重建并续算余下两步。驱动自身只读数据、启动进程并比较保存值，不导入物理实现。

物理及数值案例与原source-nonstationary-heos-v2完全相同，仅切换明确的新resume v4执行profile、manifest。选择父候选1，普通区间原末时加3/64秒，初始/最大步1/64秒；容差、普通180秒、最大步/拒步、源510秒与97 RHS/16 wet限额不变。共同实验从driver入口起510秒，每个进程携带已执行其他分支的真实counter差额，observer在下一真实请求前检查共同预算；监督570秒、清理1秒。不得只在进程之间检查总回调限额。

父只算一次；预期父32 RHS，连续22 RHS，暂停8 RHS，恢复14新RHS。原恢复前8回调不重算，恢复多4个真实HEOS构造；全比较预期76 RHS、16 HEOS、3初U、8 wet。实际记录优先，失败不得伪装成此预期。其他分支成本属于driver声明并在末端独立对照journal，不声称它是受认证历史。

保存计费S包含原在线暂停和所有保存/最终化成本；恢复计费S+A保留新读档、被动校验、重建、求解、发布及在线暂停。关闭后的离线等待D仅作诊断。最终化保守allowance是显式数值记账策略，不是声称实测耗时。FINALIZING哨兵存在时不可恢复；原packet的一次性restore claim在昂贵校验与重建前写入，失败/中断不能用旧点免费重试。

结果前固定比较：

- 父completed且原numerical_event_accepted=true。
- 连续/跨进程恢复的全数值状态、精确时钟、全部步及完整Rates观察相等，仅排除elapsed；均3接受步/0拒步/22观察。
- 原暂停完整数值checkpoint、前8观察、旧事件原字节保持；新进程实际追加构造与余下14观察。
- 全部实际source返回逐字段一致；七行完整历史守恒账本一致。逐格逐步重新计算能量差与通量；逐步总U残差满足原0.001J门槛，N不变。
- 非零内部导热；至少一格实际温变超过两端保存inverse数值误差界之和。不给定最低人为物理温变。
- 四次实际lease（父32、连续22、暂停8、恢复14）完整关闭、每次RHS逐provider入口/出口检查通过；保存/暂停无活跃权限。
- 原case字节SHA与canonical config SHA分别正确命名；版本化实际执行身份一致，监督输入前后未变且子进程已回收。

driver或比较器失败也保留原数据、原脚本与日志。不得自动重跑；先定位实际原因。初次比较器若仅有字段读取错误，修正后只能被动重读同一保存结果，不能为字段命名重做EOS。本实验不声称材料三机制留出、全烧成、空间收敛或工厂部署已完成。

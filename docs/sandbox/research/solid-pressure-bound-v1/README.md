## 证明与实现

以固定表示温度和气体摩尔量定义 Q=NgRT>0，体积误差为 ε，原流体压力误差为 e0。先计算原全局额外界 d0=ε phi²/Q 和向外总界 r0=e0+d0，保留原 p±r0 的完整域拒绝；不能用新窄区间挽救原拒绝输入。

原区间已包住基准与体积扰动根，取其精确有理上端 U=min(phi,p+r0)。稳定液体的非负压缩性与理想气体保证整个连接区间的 |dV/dp|≥Q/U²。因此额外界可收紧为 d1=ε U²/Q≤d0，最终界为原e0加向外d1。实现仅一次bootstrap，使用Fraction与既有向外舍入；同一d1用于液体压力导致的内能误差传播。没有用名义p冒充已证明的区间上端，也未减少ε或e0。

实现位置：src/sludge_sandbox/solid_fluid_storage.py；独立解析测试：tests/sandbox/test_solid_pressure_bound.py。新关系是原适用域内的数值误差传播，不是新增物理本构或实验不确定性数据。

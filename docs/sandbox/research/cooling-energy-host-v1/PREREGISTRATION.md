# 原生总能量状态接入：运行前方案

本增量将已验证的干态参考半板冷却方程接入项目原生 `ConservedState/Rates/integrate/StepLedger`。当前只有候选实现和纯代数测试，**未执行本研究的任何时间积分**。正式运行须在储能反演和宿主独审关闭后，冻结源、安装包、驱动及本方案。

数学与边界依据见 [COUPLING_NEXT](../cooling-spatial-v1/COUPLING_NEXT.md)。新储能使用真实热弹内能 `u=C(T−Tr)+M(e+αTr)²−Mα²T²`，共同应变满足零膜力。逐格总E的全局反演使用能量映射的Jacobian；温度率矩阵还包含局部约束功的消去，两者不能互换。温度、应变和能量不作域外裁剪，不修改目标E。

## 固定物理问题与比较来源

完全复用 [两格冷却B路径](../cooling-stress-v1/PREREGISTRATION.md) 的物理定义：M=1e9Pa、α=1e−4/K、C=1e5J/m³/K、k=1W/m/K、Tr=300K；半厚度0.02m、参考面积0.01m²、N=2；中面绝热，外表面固定300K，初温两格304K。T域290–310K、共同／本征／差应变域±0.01，固定参考几何和对称自由平面应力。物理时段0–10秒。

比较直接读取已完成、已独审的B路径原 `fine.json` 和独立组装2×2热矩阵的 `reference.json`，不重跑这些温度状态轨迹、不产生新参考解、不把参考称为现实实验。参考与候选使用不同状态变量和不同时间算法，但仍是同一制造物理问题。必须保留参考身份及原独立性边界。

原生积分接口要求非空库存。本测试显式提供每格单列 `[2.0, 3.0] mol` 的冻结记账输入；该输入不参与常C体积本构、反应、输运或压力，**没有对应分子组成或化学质量资格**。不能用它推断真实密度或补气体EOS。它属于接口测试数据，不补充或变更B路径热力系数。必须原字节保存，不允许宿主自动填入库存。输出资格始终制造／离线，`material_qualified=false`、`chemical_mass_qualified=false`、`full_cycle_qualified=false`。

## 储能解码与原生积分

每次RHS把当前已表示的逐格binary64 E作为精确解码目标，目标输入不确定度显式为0J；这不是宣称积分截断误差或物理参数误差为零。初始化T→E的函数求值舍入单独保存，积分目标E保持原值。每次实际返回T后的能量返算、目标误差和数值解码误差分别记录。

解码政策固定：逐格合并能量残差容许值 `1e−10 J`，全向量温度L∞误差容许值 `1e−9 K`，最大200次标量迭代，平方根有理区间160位。J_E正定下界与实际残差决定条件温度界，不以迭代次数或相邻迭代差代替误差证明。这两项解码容许值均比下表对应轨迹门严格至少三个数量级；它们不是材料精度声明。若无法给出所需域内存在／数值界，明确失败，不为运行调整政策。

仅执行两条完整原生轨迹：原 `integrate` 接受两次半步SSPRK2，以丢弃的整步估计时间误差，实际分量功与每步交换量由原 `StepLedger` 保存；全部接受状态和时刻分别来自 `IntegrationResult.states/times_s`。与旧普通服务共用积分器本身，不用SciPy外部轨迹冒充原生接受账本。

直接读取旧B路径 `fine.json` 中101项 `times_s`，要求 `reference.json` 的时间数组逐项完全相同；内部99项作为原生分段节点。原数组的浮点计算方式在35项上与重新计算 `k/10` 不同，因此不自行生成替代时间、不插值或重跑参考。取得这些确切时间上的101个比较状态，不从别的求解器插入状态数据。保留全部接受状态及步骤账本，而非只保存101点。两档初始化E相同，并由同一显式库存和自由能定义生成。

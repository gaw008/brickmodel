# Wang2021 一维有效干燥模型的预注册来源审核

结论：可以开展这项有明确近似的、同一实验来源温度整组留出的检验。它检验三参数有效扩散/边界损失模型能否预测未用于调参的50°C四个RH条件，不要求事先闭合全湿砖热学，也不能凭通过推断已识别真实材料D、表面传质系数或湿砖全周期模型。以下最小约定需在拟合和解锁留出值前固定。

## 哪些是证据，哪些是建模近似

2mm层厚、钢板载样、实验标签和MR定义有原文依据。底部钢板不透水、顶部暴露占主导而侧边损失忽略，是与装置相容的近似，并非作者测出的严格通量边界。若污泥覆盖整板，侧面/顶面面积比约4L/0.2=0.04，能为薄层近似提供几何量级解释，但具体覆盖面积仍未直接测定；不把4%当已知误差上界。

令x=0为钢板侧、x=L=0.002m为顶面。采用u_t=D u_xx，u_x(0)=0，−D u_x(L)=k u(L)，u(x,0)=1；观测MR=(1/L)∫u dx。在这个坐标约定下顶面通量符号正确，平均量满足dMR/dt=−k u(L)/L，没有底部水通量。均匀初值在t=0不满足有限k的经典边界相容条件，但可作为正常弱/半群初值；无需人为延迟时间或删掉首个非零采样点。

平均u对应干基MR需额外假设干物质分布/基准不变，且u为相对初始含水率；固定区间同时忽略收缩、开裂与移动边界。顶面k u把液水活度、外部传质与平衡吸附压缩为有效损失系数，RH比例并不是由原文独立测定的传质定律。k(RH)=kref(1−RH)/(1−0.45)只能作为本次预注册假设，RH用0..1小数。

D=Dref exp[−Ea/R(1/Tair−1/Tref)]中T全部用K，D单位m²/s、k单位m/s、Ea单位J/mol，时间从CSV分钟乘60。建议Tref固定323.15K，仅为参数坐标；使用50°C为参考温度不意味着使用其观测值。Dref>0、kref>0以及是否要求Ea≥0须预先声明；正Ea可作为“温度促进有效扩散”的模型限制，不能冒称来源给定活化能。明确R的固定数值/来源。不得增加温度相关k、RH相关D、时间偏移或条件独立振幅来追拟合后仍称三参数模型。

空气温度是有效实验标签。模型没有解内部温度、蒸发降温、钢板热容/接触热阻或能量守恒，因此不能把D(Tair)解释成已知局部等温物性。该限定不妨碍进行归一化水分曲线的分机制实测检验。

## 独立数学可检验性及识别限制

无量纲数为Fo=D t/L²与Bi=kL/D。该问题独立分离变量给μ_n tan μ_n=Bi，μ_n位于(nπ,nπ+π/2)，n=0,1,...；平均解为Σ A_n exp(−μ_n²Fo)，A_n=4sin²μ_n/[μ_n(2μ_n+sin2μ_n)]。这可作为随后数值实现的独立解析检查，并需证明截断/求根误差明显低于数字化读数尺度，不能用训练残差掩盖数值误差。此处未执行求根或预测。

小Bi时主导速率约k/L，D很难识别；大Bi时主导速率约Dπ²/(4L²)，k只能给下限。末期曲线通常只约束Dμ_0²/L²，所以D/k可互补。多个RH与两个温度有助约束却不自动解决识别性；需只用训练集做边界命中、多起点一致性与参数轮廓/敏感性检查，报告平坦谷和相关性。稳定的留出预测可以与不唯一参数同时出现。

该固定线性模型的所有A_n为正，因此MR递减且在t>0凸，水分损失速率随时间递减。来源Sec3.2却定性描述初段干燥速率增长，可能来自热启动等被忽略机制。此为事前可预见的结构性限制，不必因此取消试验；若训练/留出出现系统性初段偏差，应报告该机制不足。不能事后移动t0、删早期点或改初始分布来“修复”这一次检验。

## 必须冻结的最小检验规则

1. 固定40/60°C全部RH为训练，50°C全部RH整组封存。按数字化脚本的既有点数，排除每条件来源定义的t0后预计训练117点、留出57点；这是采样元数据计数，不是读取留出MR结果。全部t>0点保留，不能按MR阈值或残差筛掉末期/初期。
2. 固定训练目标、参数范围、初始搜索规则、优化收敛条件及求解精度。建议每个条件先取均方误差再八条件等权平均，防长时序条件因采样点多支配拟合；这只是可选的明确目标，root必须在计算前选定一种。像素界不是独立实验σ，不能称加权χ²有统计检验分布。
3. 锁定最终训练参数、实现版本与所有数值设置后，仅一次解锁50°C四组评估。预先报告每条件/总体MAE、RMSE、最大绝对误差、带符号时间残差，以及读数界外差值；不把像素误差覆盖率叫实验置信覆盖率。没有来源支持的总预测误差上界时报告结果，不事后发明二元通过门槛。
4. t0仅为来源归一化定义而排除；它仍固定初始条件u=1。不把三次重复件或同曲线各点随机拆训练/验证，不以Midilli拟合曲线补点。元数据和源资产哈希先固定；当前CSV原列calibration_role保持原样，split另存清单。

若失败，可以说明这个固定几何、零平衡含水、线性RH边界、有效恒温扩散三参数族在该来源数据上预测不足，也可能受图读数/未知实验散差影响。不能据此否定扩散物理本身、宣称某一个遗漏机制已被独立识别或证明所有污泥模型失效。若通过，只支持该来源温度插值条件下的有效MR预测；不能推断真实水活度、材料Cp/k、反应热、真实湿砖或厂级可部署性。

因此建议按上述小修正开展预注册留出检查，不新增搜文门槛；钢板热学、吸附和收缩保持明确未解。它是可被真实数据否证的一步，而不是完整材料闭合的替代。

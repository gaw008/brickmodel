# Wang2021 薄层污泥干燥：真实温度留出检验

**本次三参数有效扩散模型未满足事前登记的图示读数一致性条件。** 计算和来源记录可复核，不代表模型符合真实材料。不能把拟合收敛、程序正常退出或独立审计通过写成材料验证成功。

## 实际检验了什么

来源为Wang等的Qixingba市政脱水污泥实验：[Energies 2021,14,7722](https://doi.org/10.3390/en14227722)。原文p3–4给出2mm污泥层、钢板载样、风速1.5m/s和温湿条件；p4 Eq2近似采用干基含水比MR=Mt/M0。图3的实验符号已有数字化记录，初始MR=1来自定义。没有使用论文拟合曲线代替实验观测。

待检验假设D1：固定2mm全厚，底部无水通量、顶部Robin交换，一维线性扩散；D随环境温度按三参数方案中的Arrhenius形式变化，表面有效系数随1−RH变化。环境温度只是有效系数的实验标签，模型没有求解内部温度、钢板热容、蒸发冷却、吸附或收缩。该形式是明确待检验的近似，不是已证实的污泥本构。

40°C和60°C的八条曲线、117个非初始点用于拟合；50°C四条曲线、57个点整组留出。原始12个t0定义点不作为独立观测进入拟合，但模型初值仍固定为1。重复件原始散差未知，不把时间点随机拆分冒充独立实验。

事前方案在Git提交`088a841`中固定。九个起点、三参数搜索域、八曲线等权MSE目标、数值精度和读图比较规则都在查看留出结果前登记。训练参数先保存并在外部固定SHA256 `288564642ecee9f99c561b806493c2276a638569f2fbcbc0d3f3a0a44efb03fd`，随后才一次性解锁50°C。

共103次优化器nfev、96次njev，实际残差调用391次；有限差分调用单独计数，没有把max_nfev=200误称为每起点最多200次真实残差调用。训练内部约0.299s、外部监督0.643s；留出内部约0.032s、外部0.382s，两次均exit0、无超时并已回收。训练和留出各120s预算，外部各135s，未重置训练预算给多个起点。

解析模态截断目标为1e-9MR。独立高精度对照在实际校准点的最大差约1.89e-13，在实际留出点约5.97e-13，均远低于1e-6数值目标。这是本次点位的独立一致性检查，不是全部参数域的机器误差定理。另有不使用真实曲线的有限体积网格和高精度数学验证。

## 为什么不能只继续扩大参数范围

D1的平均解是正系数指数衰减项之和，必须递减且凸。事后结构诊断独立检查了所有三点组合：仅使用t>0时，没有找到读图区间的凸性不相容见证；不能夸大为所有实测曲线都违背凸性。

加入仍固定的定义初值后，40°C、RH60%的0/20/100min三点给出一个明确见证：20min的下界0.913845，大于两端上界按时间插值得到的0.9092318，精确差为11533/2500000=0.0046132MR。每点都保守加入1e-6余量，t0也如此。该模型保持初值和凸性时，扩大正D/k或Arrhenius参数搜索也不能让这三个区间同时满足。

这是对图示中心曲线及读图包络的事后数学诊断，不是新的独立留出检验。50°C没有同样的凸性见证，不能据此解释其全部偏差，也不能由此确定热启动、吸附、收缩或其他机制中的哪一个是实际原因。真实实验散差仍未知。

将来源已逐项核算的CO₂稀薄黏度2017、N₂稀薄黏度2004、CO₂–N₂扩散2018接入封闭等温Dusty Gas孔隙列。温度600K，长度2cm、截面积50cm²、孔隙率0.3、理想直管半径1µm，渗透率3.75e−14m²。初始各分压均值50kPa，余弦振幅分别+15/−10kPa。其余根参数、完整物性来源副本均保存在轨迹首行。

2、4、8格的基础与精细轨迹均完成，独立原始非对称Dusty Gas方程、逐格及全局物质和理想密度熵、2/4阶时间求积与两档时间对照全部达到冻结预算。时间比较使用接受点、2/4阶稠密节点和观察点并集；8格4112点最大格浓度差9.768e−9mol/m³、总压差7.826e−5Pa。此处只核对等温非反应库存和相对理想气体熵，未加入高温反应或变温交叉输运。

空间比较同样扩至两个轨迹的节点并集：2→4格4350点的最大父格平均差0.0696061mol/m³，4→8格4588点为0.0247646mol/m³，均超过1e−4预算。它不是连续时间上确界。6条轨迹已分片压缩并逐字节回读一致。

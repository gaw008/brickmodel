# Nowicki 2011：Figure 2(a) 500°C 实线的八个图示交点

已直接从原 PDF 第 4 页、期刊页 696 的 Figure 2(a) 提取 `alpha_plot=0.1,…,0.8` 的水平交点。原图是作者标为实验结果的连续曲线，**不是带有原始采样时刻的散点数据**。本提取没有读取 Table 2 的率常数、拟合曲线、反算 `ks` 或运行 500°C 预测。

采用 [Nowicki et al. (2011), The kinetics of gasification of char derived from sewage sludge](https://doi.org/10.1007/s10973-010-1032-1) 的本地原 PDF。材料仍限定为 Lodz 消化污泥在 Ar 下制备的 1000°C 焦，图示条件为 500°C、10 vol.% O2 in Ar。该图值不升级为原湿泥或砖内焦的材料事实。

## 原图核读与路径身份

实际查看了原第 4 页的 180 dpi 全页渲染，以及 600 dpi 的 Figure 2(a) 裁图。图例明确：450°C 为虚线、500°C 为实线、550°C 为点划线。使用左上图 10 vol.% O2 in Ar，不把右上 Figure 2(d) 的重复工况当另一实验。

原 PDF 是可提取矢量图。`pdftocairo 26.07.0 -origpagesizes -nocenter -noshrink` 导出的第 4 页 SVG 中，将带显式 `stroke-width` 属性的 `<path>` 按文档顺序从 0 编号，共 1608 条。500°C 实线主路径为 **553**，其 `d` 字符串长 8695；路径 554 是高转化后续尾段，八个指定水平都在 553 内，因此不使用尾段。路径变换为：

```text
matrix(1, 0, 0, -1, 254.62, 149.644)
```

主路径的父裁切范围为原页 `x=[254.621094,309.4375] pt`、`y=[64.433594,149.785156] pt`，包含全部本次读图区间；完整原裁切指令也已保存。图元原线宽 `.597 pt`，约为 600 dpi 渲染的 4.975 像素；轴刻度原线宽 `.34 pt`。没有把加密渲染产生的像素当成新增实验分辨率。

原页尺寸为 `595.276×790.866 pt`。600 dpi 裁图相对于完整页面像素的 `x,y,width,height=(1900,450,1400,980)`，故 `x_crop=x_pt×600/72−1900`、`y_crop=y_pt×600/72−450`。`facts.json` 同时提供 y 向上的 PDF 底部原点坐标 `y_bottom=790.866−y_top`。

坐标核对中发现：不带上述三个选项的初稿 SVG 默认缩放并居中，虽然仍写原页尺寸，却不能直接把其点坐标换成原 PDF 渲染像素。已解压原 PDF 的 page object `193` 所指向的 content stream `152`，实际原始指令为 `q 1 0 0 1 254.62 641.222 cm 0 0 m`，给出曲线底部原点；`790.866−641.222=149.644` 与最终 SVG 矩阵一致。重新导出后，八个中心交点四舍五入后的像素均落在原图深色实线上（灰度 20/255）。初稿坐标文件保留在 scratch 的 `initial-coordinate-*`，不作为最终事实；转换的量化差异使两个中心值舍入后改变 1 s，最终值以本表和 `facts.json` 为准。

## 标尺及时间界如何得到

中心读数采用端点线性标定，不通过任何动力学关系选取位置：

```text
x0 = 254.62109375 pt       x18000 = 382.890625 pt
y_alpha0 = 149.64453125 pt
y_alpha1 =  62.4921875 pt
t(x) = 18000 * (x-x0)/(x18000-x0)
y(alpha_plot) = (1-alpha_plot)*y_alpha0 + alpha_plot*y_alpha1
```

横轴标尺为 `140.32950634954472 s/pt`，纵轴为 `0.011474160727892072 alpha_plot/pt`。横轴采用刻度路径 8/33 作为端点，另记录 13/18/23/28 对应 3600/7200/10800/14400 s；纵轴刻度路径 35–45 对应 0.0–1.0 每 0.1 一级。所有原坐标和相对于端点线性映射的残差都在 `calibration.x_ticks/y_ticks`。

图上刻度不完全等间距。横轴最大残差 `0.09609375000002274 pt`，纵轴最大残差 `0.08632812499999432 pt`。保留它们为读图不确定性的组成，不反向调整实验曲线以匹配模型。

本次采用以下可复核、偏保守的读取规则。每个 600 dpi 像素宽 `0.12 pt`，半像素为 `0.06 pt`；这项是人工图像核对的额外分辨率余量，矢量计算本身不需猜像素中心。

| 组成 | 计算方法 | 半宽/pt |
|---|---|---:|
| 曲线坐标半盒 `r_c` | 原页半线宽 + 半渲染像素 | 0.3585 |
| x 标尺端点半界 `r_x` | 轴半线宽 + 半像素 + 最大 x 刻度残差 | 0.3260937500000227 |
| y 标尺端点半界 `r_y` | 轴半线宽 + 半像素 + 最大 y 刻度残差 | 0.3163281249999943 |
| 水平读取搜索半带 | `r_c+r_y` | 0.6748281249999943 |

先在目标 y 的上述半带内求原中心线的全部 x 极值，包含 Bézier 的内部极值、线段端点和带边交点；不假设曲线严格单调，也不以局部斜率代替搜索。将 x 极值分别扩展 `r_c`，形成保存于每行的二维读图区间。最后枚举 x 区间与 `x0±r_x`、`x18000±r_x` 的全部角点，经上述标尺函数取时间最小、最大值，并向外取整到秒。该方法同时保留纵坐标定位对时间的影响。

半线宽、半像素和刻度残差采取线性相加，并以矩形包络实际圆角描边，因此给的是明确声明的保守读界，不假设这些误差彼此独立。它仍不包含仪器误差、作者画图前的数据处理、原实验重复件差异或未知采样时刻；这些原始实验不确定度依然未知。

## 可复现方法与文件身份

从仓库根目录运行：

```sh
python3 data/sandbox/research/nowicki2011-oxygen-interpolation-v1/extract_figure2a.py \
  --scratch /private/tmp/brick-nowicki-oxygen-v1
pdftoppm -f 4 -singlefile -r 600 -x 1900 -y 450 -W 1400 -H 980 -png \
  data/sandbox/research/raw/nowicki-2011-char-kinetics.pdf \
  /private/tmp/brick-nowicki-oxygen-v1/fig2a-600dpi
```

执行环境为 Python 3.14.2、Poppler 26.07.0；无需新增 Python 包。脚本先检查原 PDF 完整 SHA，再仅转换第 4 页；对选定 M/L/C 指令应用原仿射矩阵，对三次 Bézier 按导数极值划分单调区间并作 60 次二分求交。脚本不加载训练 `training.json` 或预测程序。表中几何方法中的“二分”是求图形交点，不是动力学拟合。

Poppler 报告 `Syntax Warning: Invalid shared object hint table offset`，但 PDF 正常转换、相关原图可见且矢量路径可提取；该警告完整留在 `facts.method.conversion_stderr`。未因警告改写源 PDF。全页 SVG 和渲染图只留 scratch，仓库新增的矢量资产只保留这一条所需曲线和标尺。

## 保留的定义限制

原 Eq1 的打印式和其质量差定义合并后给出递减剩余比例，而 Figure 2 和 Eq6 使用递增量；这个矛盾没有在本次读图中解决。响应名始终为 `alpha_plot`，仅代表图上递增坐标，不据此给出碳元素转化、干基质量、m0/mk、耗氧、CO/CO2 分配、产品产率或反应热。本文档的八个交点可供后续预先固定的来源条件比较，不能作为这些物理库存的证据。

选取 0.1–0.8 沿用事先确定的范围；没有查看预测残差后删选交点、移动时间原点、修正纵轴归一化或平滑曲线。这里只完成来源提取，尚不代表后续预测通过。

## 模型与真实实验的区别

只用原Table2的450/550°C作者拟合缩核斜率，通过逆开尔文温度的log(k)直线计算500°C速率，再按原Eq6计算图示进度达时。所用两个端点是作者拟合量，不是本项目重新拟合的原始实验时序；500°C未参与这次定参，但资料与模型形式此前已查看，不能称新的独立盲留出。

主要对照来自原Figure2(a)的500°C实验实线。独立提取作者从原PDF矢量路径求八个固定水平交点，保留线宽、刻度残差和图像核读分辨率造成的时间读取界；没有从500°C打印常数反推观察值。原图是连续发表曲线，不是八个独立重复件。来源/几何说明见[EXTRACTION.md](EXTRACTION.md)，独立原图/数学复核见[SOURCE_MATH.md](review/SOURCE_MATH.md)。

材料是Lodz消化污泥在Ar中1000°C制备的<70µm预制焦；约20mg试样、常压、10 vol.% O2/Ar、50cm³/min。它不是原湿泥、MIA3或砖内低温原位焦。原Eq1的归一化方向与图示递增conversion矛盾没有被修补：响应始终为`alpha_plot`，不输出质量库存、碳摩尔转化、耗氧或反应热。

## 使用和结果追查

Python和CLI说明见[USAGE.md](USAGE.md)。从已安装环境、仓库根目录运行：

```sh
python -m sludge_sandbox char-oxidation-times \
  --source-data data/sandbox/research/nowicki2011-oxygen-interpolation-v1 \
  --temperature-c 500
```

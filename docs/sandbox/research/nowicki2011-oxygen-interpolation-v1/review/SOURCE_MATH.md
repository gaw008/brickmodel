# Nowicki 2011：独立来源与数学复核

结论：下列最终资产的原图提取及预登记数学可供这一次固定气氛、等温图示响应比较使用。八个中心时间、读取上下界均已独立复算；本审查没有计算真实 500°C 动力学预测，没有据观察值改参数，也不判定后续预测成功。Python/CLI 的实际数值结果须另行核验。

## 原始来源、图和样品

核读 [Nowicki et al. (2011)](https://doi.org/10.1007/s10973-010-1032-1) 既有原 PDF，实际查看第 3、4、6 页原图及第 4 页 Figure 2(a) 的 600 dpi 裁图。原 PDF SHA256 为 `b1970f72bb595e31c67276860886545d337130587991a88d8c321c6d25aebb23`。检查针对这篇研究本身，不声称已阅读它引用的全部上游论文。

- Figure 2(a)，PDF 第 4 页／期刊 696 页：500°C 为实线，450°C 为虚线，550°C 为点划线；横轴为时间 s，0–18000，每主格 3600；纵轴为递增 Conversion，0–1。Figure 2(d) 的 10% O2 曲线是同一条件的重复呈现，不能作为新增独立实验。
- 样品是 Lodz 消化污泥在 Ar 中以 100°C/h 升到 1000°C、保温约 120 min 制备并冷却筛至 <70 µm 的焦。原实验约 20 mg、常压、10 vol.% O2／90% Ar、总气流 50 cm³/min，氧化铝坩埚直径 5 mm、高 3 mm。此域不能直接转移为原湿污泥、砖内原位焦或 MIA3。
- 第 6 页／期刊 698 页 Table 2 的 `ks / s⁻¹` 列：450°C 为 `7.044×10⁻⁵`，550°C 为 `7.0611×10⁻⁴`；它们是作者拟合缩核斜率。500°C 打印值 `2.221×10⁻⁴` 已公开可见，只能按预登记在预测锁定后作次要对照，不能称本次盲未知量。
- 第 3 页 Eq1 印为 `α=(Δmk−Δm(t))/Δmk`，同时定义 `Δmk=m0−mk`、`Δm(t)=m0−m(t)`。代入得到递减的 `(m(t)−mk)/(m0−mk)`，与图和 Eq6 的递增量不一致。提取及预测必须继续叫 `alpha_plot`，不能凭猜测修正原式并输出绝对失重或碳摩尔转化。

## 已纠正的坐标问题

第一稿把 Poppler 默认缩放、居中后的 SVG 点直接称原 PDF 点，造成约 2–4 px 的原 PNG 定位偏差。作者在审查期间发现并修正，最终转换显式使用 `-origpagesizes -nocenter -noshrink`。本审查独立运行转换，所得 SVG SHA256 为 `7183ef47542d86f669bc585ff9771dd953cb9f0f640915fdc0fea12240f672fe`，与作者最终资产一致。

另外独立读取 PDF page object 193 的 `/Contents 152 0 R` 并解压内容流；原实线的局部平移为 `(254.62,641.222)`，以 PDF 左下为原点。页面高 790.866 pt，因此对应左上原点 `(254.62,149.644)`，与最终路径矩阵 `matrix(1,0,0,-1,254.62,149.644)` 一致。原页面 595.276×790.866 pt、无旋转；现在的左右方向、y 翻转及 600/72 像素换算成立。

最终路径仍为按显式 `stroke-width` 筛选后的 0 基序号 553，共 1608 条；最终 `d` 长 8695。独立重建中的全部选中轴属性与曲线属性逐项等于矢量资产。实际祖先 clip-25 为 `x=[254.621094,309.4375]`、`y=[64.433594,149.785156]` pt，所有八个读取盒均在内部，未处理裁切不会影响这八点。路径 554 的高转化尾段不参与所选范围。最终记录保留了 clip 的原始末尾 move 指令。

以原 600 dpi PNG 检查八个最终交点：每点所在像素灰值均为 20，与实线黑色一致；最近暗像素中心距离最大 0.596 px。这是原图定位复核，不是给时间精度增加六位小数。

最终 x 端点为 254.62109375／382.890625 pt；y 的 α=0／1 端点为 149.64453125／62.4921875 pt。独立得到内刻度最大残差 x=0.096093750、y=0.086328125 pt，保留它们作为读图余量合理。图线宽 0.597 pt，轴宽 0.34 pt，600 dpi 半像素 0.06 pt；因此曲线半盒 `rc=0.3585`，x 标尺半界 `rx=0.32609375`，y 标尺半界 `ry=0.316328125`，水平搜索半带 `rc+ry=0.674828125` pt。

对给定 α∈[0,1]，两 y 标尺端点各 ±ry 对目标 y 的影响最多 ry，因此搜索半带包含纵坐标标定及描边。带内 x 极值再扩 ±rc，得到 `[xl,xh]`。令 x 轴端点为 a、b，则 `t=18000(x−a)/(b−a)`；本次全部盒满足 `a<x<b`，所以 `∂t/∂x>0`、`∂t/∂a<0`、`∂t/∂b<0`。最小值在 `(xl,a+rx,b+rx)`，最大值在 `(xh,a−rx,b−rx)`；此独立单调性计算与作者枚举角点一致。

圆角描边被矩形半盒包住，线宽、半像素和刻度残差作线性相加，是一个透明且偏保守的**声明读取包络**。它不能保证包含作者制图前的数据处理误差、仪器偏差或未知实验重复性。八点同出一条连续发表曲线，且共用坐标轴误差，不能当作八个独立重复件或据此计算实验置信区间。旧稿因坐标修正而有少数秒级取整变化，后续应只读取最终资产，不混用旧数字。

## 两端插值和 SCM 达时

原 Eq6 为 `Φ(α)=1−(1−α)^(1/3)=ks t`。在 `0≤α<1`、`ks>0` 下它严格递增，故 `t=Φ(α)/ks`，单位 s。微分满足 `dα/dt=3ks(1−α)^(2/3)`；漏掉 3 会改变原模型。`−expm1(log1p(−α)/3)` 是等价且避免相减消去的实现形式。使用 α≤0.8 在预登记保守范围内，不代表高转化段也获得支持。

在固定气氛下设 `ln(ks/(1 s⁻¹))=a+b/T`，T 用 K，则 500°C 的权重严格为：

`w=(1/773.15−1/723.15)/(1/823.15−1/723.15)=16463/30926`，
`1−w=14463/30926`，两者均在 (0,1)。

所以 `ln k500=(1−w)ln k450+w ln k550` 是逆温坐标内插；不是摄氏温度算术中点的几何平均。两端确定唯一的 a、b，却没有残差自由度用于估计噪声、曲率或统计区间。原 `ks` 已包含固定 10% O2 条件，再乘 `0.1^n` 会重复施加浓度作用；Table 3 A 的既有争议不应引入此计算。

独立的非来源数值控制：T=400／800 K、k=1／4 s⁻¹，在 T=1600/3 K 的逆温中点得 k=2 s⁻¹；取 α=0.578125，Φ=0.25，达时精确为 0.125 s。此控制只检验公式，不计算 500°C 预测。预登记要求真实八点实现与高精度达时相差 <10⁻⁶ s，是可执行的数值政策，不能用作实验容差。

源提取脚本只处理图形、源文件身份和几何，不加载 Table 2 CSV、训练文件或动力学模型；未发现把 500°C 率常数反用于生成观察值的路径。预登记划分、固定零时刻及误差输出语义合理：不得在看残差后平移起点、改变归一化或剔除点。读取界包含关系仅是图示尺度对照，没有根据将“落入几项”升级为材料模型合格门槛。

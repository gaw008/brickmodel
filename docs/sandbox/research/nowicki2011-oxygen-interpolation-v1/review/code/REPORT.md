## 计算与来源

- 温度先限定 450–550°C，转换为 K 后以逆温线性插值 log(k)。原 450/550 标签精确保留 `7.044e-5` / `7.0611e-4 s^-1`。原始 Table 2 CSV 的这两行与 training 一致；训练 CSV 和源 PDF 的实际 SHA256 分别匹配 training/source_metadata 所列摘要。
- `phi=-expm1(log1p(-alpha_plot)/3)`，达时 `phi/k`；微分 `3*k*(1-alpha_plot)^(2/3)` 保留因子 3。支持的图示响应域 0.1–0.8、固定气氛 10% O2/90% Ar 均随结果返回，未暴露气氛外推参数。
- 数据标签是原作者拟合斜率，不是原始逐时测量。返回预制焦材料身份、原文与方程定位、Eq1 方向矛盾、插值的派生身份。未知反应热、氧耗、产物计量为 null；没有以零热量假装能量闭合，也没有生成摩尔库存或温度方程。
- 数值输出 trace 的目标和每个 dependency 都能从实际返回 JSON 解析到真实值；rate/phi/坐标率的源 ID 和 locator 存在。运行期只读取固定 `training.json` 和 `source_metadata.json`，验证它们的准确字节摘要，既不读取 Figure 2 facts，也不采用 Table 3 A 或浓度幂。

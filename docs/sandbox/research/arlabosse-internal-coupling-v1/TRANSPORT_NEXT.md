# 有界内部输运设计（3个审查页）

## 1/3：库存、来源与 Fick→迁移率

**结论：可继续实现条件跨材料输运；推荐先把动态 k(W) 接入现有非等温主机，再接以下独立凝聚水面关系。它们均不升级材料验证。** 本设计读取当前实际 API，未执行 EOS、积分或拟合；文件版本见 `READ_SNAPSHOT.json`。

每格保留 `WetMixedState.liquid_water_mol=Nc` 这一份凝聚水库存，`W=M Nc/md`；气相水另在 `gas_amounts_mol[2]=Nv`。新增迁水更新 Nc，不另建“结合水”“可动水”库存。固定干质量 md；封闭边界总水为 Σ(Nc+Nv)。原 `ArlabosseSorptionStorage` 已含 Uex=md Hex(W)，本地凝聚/蒸发只在 Nc/Nv间搬水，不能再添加一次脱附热。

来源及直接可用分支：

- [Mäkelä2016](https://doi.org/10.1016/j.watres.2015.12.043)，作者稿 PDFp22 Table1脚注/摘要：未水热处理纸厂混合泥 D0=8.56×10⁻⁹ m²/s；正文p10打印8.57×10⁻⁹。保留两处读数及所选表格分支，不把差异当置信区间。105°C空气下的收缩修正表观均值，冻结到35–95°C及不同W是误差unknown的迁移假设；不是孔道本征水扩散率。
- [Septien2020](https://doi.org/10.1016/j.jece.2019.103652)，原XML Table2同30%MIR分支：湿基23±6%时k=.056±.001、47±2%时k=.062±.002 W/(m K)。名义节点W₁=23/77、W₂=47/53，选其线性插值；首期W∈[.30,.80]。原测量温度unknown；85°C为干燥制样区温度。温度独立是声明近似。原样重复测量90%置信条不包住跨材料误差。VIP粪污并非Arlabosse活性泥。

令 m₀(W)=现有95°C `wet._m`、b₀=L₀−`wet._q`、T₀=368.15K。现有每kg水的 μex=(T/T₀)m₀+(1−T/T₀)b₀。在固定T、P下，完整摩尔化学势 μc=μliquid(T,P)+Mμex 的热力学因子为

Γ≡(∂μc/∂W)T,P = M[(T/T₀)m₀′−(1−T/T₀)q₀′]，单位J/mol。

源Fick形式 jn=−(ρd D/M)∂xW（mol/m²/s）对应 jn=−Λ∂xμc，Λ=ρd D/(MΓ)，单位mol²/(J m s)。ρd=md/(A Δx)为**显式受控总体积**中的干质量密度；`storage.volume`只是可用流体体积，不能拿来代替。不得凭孔隙率/干固体密度猜ρd。

需要Γ严格正且有限；当前`_excess`只排除负斜率，零值仍须新增拒绝。用合并m/q节点划分线段，保留单侧导数；不可在拐点任挑导数或加epsilon。等T等P时，可用跨W的正割线Γsec=Δμex,mol/ΔW处理跨节点面；同W取已声明的单侧/连续极限规则。均匀ρd、D时，Gμ=AρdD/(MℓΓsec)，n=Gμ(μL−μR)，恰好还原有限体积Fick通量。多材料/不同ρd须声明面阻力平均；本阶段先限定同一受控ρd。

## 2/3：非等温面能量与熵

以下是根据已有热力学公式推导的**候选闭合**，不是新文献实测Soret关系。面正向L→R；βi=1/Ti，XΤ=βR−βL，Xμ=μLβL−μRβR。使用同一水参考、实际格压下的完整μc，不能只用μex跨温度比较。刚性格固定体积/干质量时，凝聚水和面能量贡献满足

σface = JE XΤ + n Xμ，单位W/K。

摩尔偏焓必须为 h̄c(T,P,W)=hliquid(T,P)+M b₀(W)。当前点只公开excess部分；可在已解码实际T/P上通过`chemical.liquid_tp`配对，不得用`wet.evaluate`的固定1bar液体值替代。选择并记录单个对称面焓h*=½(h̄c,L+h̄c,R)，定义可测热流Q=JE−h*n及驱动Y=Xμ+h*XΤ。则

n=Lm Y； Q=Lq XΤ； JE=Q+h*n； σface=Lm Y²+Lq XΤ²≥0。

Lm>0、Lq≥0。傅里叶导热取GK=A/(dL/kL+dR/kR)、Lq=GK TL TR；Q=GK(TL−TR)。等温匹配令Lm=Tface Gμ；非等温Tface可声明为正的算术平均，再以该T的源模型正割因子确定Gμ。P差只进入完整μ；这一压力扩展同样未由源D标定。

这在(Q,n)表示下**假设交叉系数为零**，没有填写未知Soret数值；但它仍是额外构成假设，不能称“证明Soret不存在”。在(JE,n)表示下的矩阵为[[Lq+h*²Lm,h*Lm],[h*Lm,Lm]]，对称正半定。连续极限里 h̄=−T²∂(μ/T)/∂T|P,W 使均匀W/P的纯温度项抵消；有限面用算术h*有离散余项，不能宣称有限温差下严格零热迁水。必须记录该选择及网格误差，或后续使用有审查的热力学积分平均；不默默修正为测得的Soret。

每面只生成一次共享(n,JE)，两格取相反号。U已经含完整吸附储能：h*n为所选运输能量，不是额外体积脱附热；反解更新后的U/N，不覆写T，也不另加pΔV功。刚性体积的能量/摩尔数守恒是代数账，σface是瞬时名义构成检查；两者都不自动证明离散整步总熵增加或数值/物性误差有界。

原`liquid_face_exchange`以ΔP、K kr/viscosity和供体纯液焓工作：等P不同W时流量为零，缺Γ/μex/吸附偏焓，且需要未测连通性与饱和度关系。只改系数不能复用。可复用共享面账与库存更新结构，但应新增明确的sorption面类型/配置，不能解除旧类型守卫后伪装成Darcy。

## 3/3：最小可交付阶段与后续接线

**先实现K阶段：35–95°C，W=.30–.80，原显式90–110kPa子域、固定md/几何、封闭边界。** 每次`column.evaluate`先完成全部`storage.invert`，用各格Nc算W并求k(W)，再替换这一新分支的导热项。冻结首次k后跑到结束不合格。保留本地`evaluate_sorption_phase`：Q改变U→T，相变改变Nc→W→k，形成真实的主机反馈。凝聚水格间通量先关闭；为独立热熵核验可同时关闭气体面通量，本地相变仍可保留原明确制造系数。以后开启原气体面通量必须继续单列其制造来源，不能把全列输运统称文献验证。

实际需扩展：新provider绑定两原件SHA、插值/温度冻结选择；新分支face输出动态k、W、GK、Q与QXΤ；原`transport_classification=='manufactured_test_fixture'`及固定`WetFace.conductivities`应有明确混合来源分支，不全局放宽。`ColumnFaceRate.conduction_w`及总能量分解接共享账，重新求U逆；W/P/T越域拒绝，不能clip。原exact/saved协议继续拒绝未经适配的新类型。

D_eff由总干燥失水反推，并非凝聚液相专测。D首个主机阶段关闭原气相格间扩散/Darcy，保留本地Nc↔Nv相变，避免未经分配就把表观湿迁移与另一气相迁水通道并联重复计算。重新开启两相格间输运需声明并审查有效D的路径含义；这不等于断言实际污泥没有蒸气输运。

随后D阶段可直接采用第2页有熵保证的条件闭合；它是可计算路径，缺测量总误差并不禁止实施。先用等T/P叶子核验Γ与Fick一致，再做非等温共享面/能量接线。**仅初温相同不构成等温动态验证**：迁水/储能会使T、P变化；若只交付等温D主机阶段，必须另列控温浴供热并记入账，否则每个实际面须拒绝越出等温条件。最省新增边界的路线是K主机完成后接上述非等温面。

预登记必要检查：两节点/域外拒绝；k随本地相变更新；Γ零/负/跨节点；等T/P的解析Fick限；交换左右时n、JE反号而σ不变；同μ/T与β时零流；非等温σ代数非负；去掉吸附偏焓/只用μex的负控；每步Σ(Nc+Nv)、ΣU共享账和实际逆解；对真实新通量做网格/时间收敛。能量参考整体平移c时μ→μ+c、h*→h*+c、JE→JE+cn，Y与σ应不变（重要单位/参考负控）。不把供体D原拟合质量曲线同时充作留出验证。

产物资格保持`material_qualified=false`、`training_eligible=false`。K阶段推进非等温内部传热和本地湿热反馈，D阶段推进同一凝聚库存的内部迁水；同泥资格、真实砖边界/收缩/连通性、独立T/W剖面与全周期仍缺。节点读图/实验条、打印差异、插值/温度/跨材料误差分别记录，unknown不改为零。

# 同源吸附热力学接入一维湿柱的有限架构审查

结论：推荐在原刚性内能储存上添加同源过量自由能，首版接通一维传热、气体/蒸气迁移和局部凝聚水—蒸气相变；新支路明确拒绝 Darcy 液流及干界面。该构造在声明的零过量体积近似内热力学一致，可以开始有界实现与验证。它仍是条件性模型，不能据此宣称真实湿污泥变孔压性质、砖内液水迁移或全周期烧成已经得到验证。

本轮只读代码与已经保存的数学参考，未修改生产、构造水 EOS、积分、安装或重跑 native。审查起点为 `2541b32`；检查时工作树无已跟踪差异。本文是接线建议及验证设计，不是新实现或物理验收的通过报告。

## 内能与定压焓：要保留的物理边界

原柱的状态变量是每格总内能 U。固定外部可用体积并不意味着孔压固定：温度、凝聚水量及气体库存都会改变 P 和气相体积。气体跨面迁移携带焓，已包含流动功；刚性封闭格没有另加外边界体积功的理由。

`ArlabosseWetThermodynamics.inverse_enthalpy` 解的是给定 W、固定 P0 的 H(T,W)。不能把它替换原 U 反解，也不能对它简单减去 `P*V_available`：该 H 包含干物料与凝聚水，不包含柱中的 O2/N2/H2O 气相；可用孔隙体积也不是湿物料整体积。这样替换会错配系统边界和能量基准。

新支路应继续保存 U。定压对照只比较相同干质量、相同能量参考下的差分：去掉独立气相 U 后，在 P0 下满足 `ΔH_wet = ΔU_condensed+dry + P0 ΔV_liquid`，其中固定干骨架的常数参考项相消。干相体积仍未知，不应补出具有材料意义的绝对总 H 字段。原干热容接口明确是相对显热坐标；首版统一干参考温度到 95°C 最简单，若采用其他原参考，则必须显式保留其常数能量差。

## 推荐构造及必须写出的新推导

记 `m_d` 为固定干质量，`M_w` 为同一水提供者的 kg/mol，`W=M_w N_c/m_d`。`N_c` 是唯一的凝聚水库存，包含此条件模型统一表示的吸附影响；它不是独立的“束缚水池”。不得另外再给同一份水添加一个自由水库存。

沿用已有湿模型的原始节点、插值与基准：

- `T0=368.15 K`，`W0=0.8`；`m0(W)=R_s T0 ln(a_w,95(W))`。
- `b(W)=L95-q95(W)`，`G0(W)=∫[W0,W] m0(w)dw`，`H0(W)=∫[W0,W] b(w)dw`，单位均以干基/水基区分。
- `g_ex(T,W)=H0(W)-T[H0(W)-G0(W)]/T0`，单位 J/kg_dry。

明确新增的假设是：这一过量势不依赖体积或压力，故过量体积为零。以原纯液水/理想气体机械闭合所对应的 Helmholtz 势为基底，定义

`F_new(T,V,N_c,N_g;m_d) = F_base(T,V,N_c,N_g;m_d) + m_d g_ex(T,W)`。

原模块没有一个已经实现的公共总 F 回调；上式是应在新模型说明中给出的构造，不能把原数值 U 输出称作已验证的总自由能。原液气体积分配达到机械闭合；新增势不依赖该分配，所以原压力方程保持不变。

由同一个势求导得到：

1. `U_ex = m_d(g_ex-T∂g_ex/∂T)=m_d H0(W)`，与温度无关。
2. `μ_ex = ∂g_ex/∂W = (T/T0)m0(W)+(1-T/T0)b(W)`，单位 J/kg_water；摩尔修正是 `M_w μ_ex`，不能遗漏质量—摩尔换算。
3. `a_w=exp(μ_ex/(R_s T))`，`μ_c=μ_liquid(T,P)+M_w μ_ex`，`p_eq=a_w*p_eq,pure(T,P)`。纯水项必须查询当前已解码液压 P，不能仍用 P0。
4. 凝聚水偏焓 `h̄_c = h_liquid(T,P)+b(W)`，单位 J/kg_water；过量偏体积为零。
5. 固定 `N_c,N_g,m_d,V_available` 时，新增项的温度导数为零，故原闭合热容与其下界不变。这不意味着相变过程中库存随温度变化时的有效热容不变。

局部相变依然只做 `dN_c/dt=-J_phase`、`dN_v/dt=+J_phase`，总 U 无局部潜热源。吸附能改变体现在每次用新库存重新解码 U；不能再额外加 `q*失水率` 或 `b*失水率`。颗粒接触干燥的 `aW+b` 整体速率也不能当成一维单元的材料相变系数，其面积和试验传质环境不等于内部界面。

数学交叉核对仅使用父任务已经保存的 Cantera HMWSoln 文档“Temperature and Pressure Dependence of the Activity Coefficients”（`cantera-HMWSoln.html:521–567`）：活度温度导数决定偏焓，压力导数决定过量偏体积。本建议没有引入其电解质/Pitzer 参数，未把数学恒等式作为污泥零过量体积的实测依据。

## 最小实现接线

1. **同源过量项接口**：在原 wet 模型旁暴露或提取一个受同样来源门约束的窄接口，返回 `g_ex,H0,μ_ex,b,a_w` 及原来源/基准；不重复拟合、补空 q 节点或另造曲线。`arlabosse_wet_thermo.py` 的现有定压公开行为保持。该接口不需要每次先构造一整个 P0 下的 H/G/S 状态才能计算过量项。
2. **`arlabosse_rigid_sorption.py` 包装器**：组合真实 `SourceWetStorage` 和原湿模型，添加 `m_d H0`。明确新能量身份、条件域和零过量体积假设。`W` 在所有初态、试算及接受态均须留在原域内；本期不允许零液水或自动切换干界面。
3. **移位反解**：固定库存先计算 `E_ex`，以 `U_target-E_ex` 调用原刚性基底反解，再恢复完整 point 的 U。保留完整目标和残差，不把基底残差冒充最终残差。目标减法、`m_d H0` 的积分/乘法及最终加法的数值误差必须计入现有数值门；若减法失去可分辨性或所需区间超出域，明确拒绝。旧压力误差门仅在其原假设及域保持时复用，新的物理近似误差仍为 unknown。
4. **`arlabosse_sorption_phase.py` 局部相变**：沿用真实当前 T/P 和气相水分压，以新 `p_eq` 计算原非负系数下的成对速率；化学驱动和熵产生用同一 `p_eq`。气相水分压为零时沿用明确的未定义驱动记录，不伪造有限熵界。
5. **`source_wet_column.py` 显式分支**：列入新 storage 的确切类型，检查同一干模型、气体参考及实际水提供者；只替换存储/相变调用，复用原面通量、守恒更新和账本。本期新分支只接受 `liquid_transport is None` 与已有液体界面；拒绝配置液流，不静默吞掉配置。原纯水柱保持可用的液流路径。
6. **先直接柱集成，后接运行入口**：首轮不必同时修改程序边界、CLI、恢复包和完整调度器。若后来接 `ExactSourceColumn`/`source_run_builder.py`，再在原固定类型与绑定路径中登记新语义及来源，让旧能量身份拒绝新状态；复用现有监督和记录机制，不建通用 hash/审核框架。

实际水提供者是一个当前接线差异：原 wet 模型固定 Python IAPWS；现有 managed `source_run_builder.py` 使用 HEOS。首版要求基底与 wet 内部水的实际 type、implementation、reference、assets 和 M/R 相同，因此采用 Python 路径。不能把 Python 下的 L95 校准无说明地搬到 HEOS 基底，然后宣称仍在同一原参考下精确恢复 q95。父任务已确认首版采用上述相同提供者门。

## 为什么液水和机械暂不接入

新凝聚水的化学势具有 W 依赖，因此即使两格 T/P 相同，仍可有吸附化学驱动。现有 Darcy 核只认识压差，上游焓还是纯水焓；直接复用会缺失化学驱动与 `b(W)` 携带能量。首版关闭它是可执行的封闭条件，不表示已有液流实现被删除。

恢复新支路液水迁移之前，必须选择并推导一种相容的描述：单一凝聚水相需由同一自由能得到驱动力、正确偏焓以及相容的迁移率/非等温通量；或引入独立自由水/束缚水池，但后者需要有来源的分配、毛细/保水关系及相间交换律。原 W 数据没有提供这套池划分，不能直接将原 W 改名为束缚水量。仅添加一个 `P_capillary` 同时保留原液压等于气压闭合，也不构成一致模型。

体积/机械方面已有可复用结构，而非所需材料参数：

- `deforming_solid_storage.py:191–252` 已能用运动几何更新总体积、减去给定固体摩尔体积得到流体体积，并把弹性和界面储能加到热内能、反解时再减去一次。
- `thermoelastic_energy_host.py:99–129` 已能将板模型给出的约束机械功作为明确能量功率分量接入守恒宿主。
- 这些模块使用其他固定相/制造骨架及明确体积、变形假设；`ArlabosseMassCaloric.specific_volume_m3_kg` 当前为 `None`。不能据此获得本材料的密度、热膨胀、弹性、吸附膨胀、烧结收缩或孔隙率演化。

因此本期保留刚性可用体积和零新增机械功。以后接变形须同时推导流体可用体积、骨架/界面自由能及外力功，避免把气体焓中的流动功或可恢复能量再次计入。

## 可执行的集成验证顺序

1. **制造边界测试，不调用 EOS**：确认原来源/水后端不匹配、新支路液流、干界面、越 T/W 域均拒绝；原分支路由不变。试算越界保留失败/拒步记录和已接受前缀，不作裁剪或伪造 completed。
2. **独立过量项算术**：从原节点独立积分，检查 `∂W g_ex=μ_ex`、`g_ex-T∂Tg_ex=H0`、`∂W H0=b`；内部节点用两侧导数；原 q 的空值不被补成观测。检查 `∂P g_ex=0` 是模型假设字段而非测量结论。
3. **一格正反解及移位误差**：在多组固定库存/制造体积下对照原压力和闭合热容；验证完整 U 正反解和原目标残差。包括大基底能量与相反符号 E_ex 的消减、精度不足拒绝以及域端点。原误差门不改宽。
4. **P0 还原和变量 P 对照**：同一提供者下在 P0 对照原 wet 活度、q95 和上述 H/U 差分关系；改变制造体积使 P 改变，证明纯水化学势/平衡压取实际 P，过量项仍保持声明的压力独立性。
5. **封闭绝热局部相变**：气相欠饱和/过饱和两方向及平衡点；每步成对水量守恒、O2/N2 固定、U 不因局部相变获得额外热源；温度由完整新 U 解码。针对“只改活度不改 U”和“再加一次 q”设置算术/制造负控。
6. **两至三格真实耦合最短路径**：非均匀 T/W、正气相库存、内部热/气体迁移、液流为零。每面一次签名账本，逐格/全柱水、气体元素及 U 守恒；记录各格实际 T/P/W 与 μ/平衡压。初值远离原域边界，预登记运行和监督预算、来源/安装身份及原阈值；失败保留，不运行旧 native 来替代新验证。
7. **空间/时间离散验证**：制造导热/扩散极限采用解析或独立解，在相同实际厚度、面积和总干质量下细化网格并缩放每格质量、孔体积及局部相变系数；另做时间收敛。增加输出采样点不等于网格或时间收敛。相变系数按体积/界面积缩放的假设必须明确，不能将原全局 `aW+b` 复制到每格。

先通过 1–5 再做唯一一次预登记的新 native 耦合路径。数值守恒、构造热力学一致和源身份通过，仍不能升级上表的材料资格；含毛细液流与变形的后续阶段需要自己的新推导和数据门。

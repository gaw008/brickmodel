# 液水势函数快速表示的来源与验证

直接IAPWS调用在空间隐式求解中反复嵌套，成为实际运行瓶颈。精确状态缓存只减少部分重复计算，因此另行开发、验证一个有明确域的数值物性表示，再接入通道；不改变材料系数或放宽通道精度目标。

## 定义与热力学一致性

`parameters.liquid_gibbs_table.json`在运行前固定300–345K、50–180kPa、温度12阶/压力4阶和误差预算。用65个Chebyshev-Lobatto张量节点的原生IAPWS95纯液体g(T,p)拟合一个Gibbs多项式，保存原节点、系数、参考偏移及后端版本。没有拟合不同物性的独立曲线，没有添加实验材料参数。

所有量来自同一个势函数：s=−∂g/∂T，v=∂g/∂p，h=g+Ts，u=h−pv，Cp=−TgTT，Cv=Cp+TgTp²/gpp，κT=−gpp/v。共同能量偏移只加到g/h/u，熵和体积不受它影响。因此h−u=pv和Maxwell关系来自定义，并非通过分别调整曲线强行满足。

用保存多项式的Chebyshev系数三角界限（|Tn(x)|≤1）检查整个矩形：v下界1.80424e−5m³/mol；gpp上界−7.92228e−15m³/(mol·Pa)；Cp下界65.2335、Cv下界59.7017J/(mol·K)。这些界限支持该多项式本身的正体积、正热容和正压缩率；不是对它与IAPWS之间的连续域近似误差作区间证明。

## 独立取点比较

另取31×11个等距状态，341点网格与拟合节点组不同（域边界等部分节点重合），直接调用IAPWS比较。最大差及预先预算：

| 量 | 观察最大绝对差 | 预算 |
|---|---:|---:|
| g，J/mol | 4.71829e−10 | 1e−5 |
| h，J/mol | 2.20200e−7 | 1e−4 |
| u，J/mol | 2.20316e−7 | 1e−4 |
| s，J/(mol·K) | 6.38757e−10 | 1e−6 |
| 摩尔体积相对差 | 1.93450e−9 | 1e−6 |
| Cp，J/(mol·K) | 4.18543e−7 | 1e−3 |
| Cv，J/(mol·K) | 7.92874e−4 | 1e−3 |

全部满足本次取点预算；Cv的二阶压力导数误差明显大于Cp误差，保留实际值。只说明数值表示与同一EOS的这些比较一致，不是新的实验准确性或第二套独立EOS认证。原生IAPWS是温压域内的稳定液体；未扩展到饱和线上或高温、低压域。

## 接入主机后的交叉复算

4格、40s完整程序的321个共同采样节点，直接IAPWS加精确缓存与Gibbs表示的最大格温差1.18314e−9K、表面温差1.12152e−10K、总水差1.35163e−15mol。相同案例保存的耗时315.82s与9.33s；这是本机实际观察，运行并发状况不同，不作为普遍性能保证。

精确缓存本身与未缓存4格轨迹最大温差4.41537e−9K，小于声明的积分比较预算；缓存重复使用相同N/U的已求解状态，数值反解的初始猜测和自适应步因此有微小舍入差，不能声称全部轨迹逐位相同。

最终细化入口显式使用`parameters.equilibrium_water_column_gibbs.json`，原`parameters.equilibrium_water_column.json`仍选直接物性。超域直接报错，无外推或隐式回退；运行依赖本地表，不联网。较慢的8/16格直接EOS部分记录归档为主动中断，未伪报完成或数值失败。

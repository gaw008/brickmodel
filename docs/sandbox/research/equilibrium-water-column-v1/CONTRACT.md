# 一维液汽通道与储热体：开发及验证合同

2026-09-22 UTC。用户授权按依赖连续开发剩余阶段；V-B3已完成限定复核后，本增量只建立可变载气/液汽单元的空间共同通量和程序化热边界。材料主线仍为真实黏土砖干燥M1，最终目标仍为含污泥砖。此条件通道不替代它们。

## 世界、方程和来源

- 一维刚性流体通道，左端封闭、右端与有明确温度/压力/组成的环境交换。每格O₂/N₂为气体，H₂O库存为液水加水汽；液体局地滞留，仅气体跨格输运。无毛细水、吸附水、液流或固体迁移。
- 每格沿用V-B3的纯液水IAPWS与理想载气/水汽近似，在库存和总内能下反解共同温度、压力、气液体积与相分配。水汽采用IAPWS理想项，同一能量基准；混合物R桥接近似及液体稳定性适用域继续有效。
- 外置固定石英储热体与该格流体等温。根参数指定总摩尔数和330K储能零点；NIST低温段Shomate积分给出显热。恒体积、不考虑热膨胀的本构近似取Δu=Δh°，固定参考pV项抵消。未从石英密度推造通道孔隙率或黏土组分。
- 对格i和组分k：dNᵢₖ/dt=Fᵢ₋½,ₖ−Fᵢ₊½,ₖ；dUᵢ/dt=Qᵢ₋½−Qᵢ₊½，最外格另计辐射。一个内部面只算一次，邻格用相反符号。F为已登记的混合扩散和Darcy近似，Q含Fourier热流及气体携焓。
- 表面温度独立求解 kA(Ts−Tlast)/(dx/2)=hA(Tgas−Ts)+εσA(Trad⁴−Ts⁴)。先前把末格中心当辐射表面的试算已归档；最终热边界只计一次膜对流和辐射，气体携焓另外计入。气体边界仍用原面状态近似，没有新增热扩散/Knudsen机制。
- 水、NIST石英Cp及σ来源见根参数和`source_readback.json`。几何、储热体量、初态、输运系数、发射率和40秒升温—保持—冷却程序均为显式虚拟设计值，不是实测砖参数。

## 数值与验证顺序

1. 固定根参数后开发共享面中点积分，保存每次库存/U、通量、精确有理数包及浮点投影差。重建逐格及全局收支，查相分配和储能反解。
2. 时间细化与空间细化分开。保存完整采样轨迹，细格按相同控制体体积平均，再比较温度、物理表面温度和总水量。研究目标在计算前为：时间0.02K/1e−7mol，空间0.2K/1e−6mol；不是实验误差。
3. 1→2→4格空间差未达标，原结果保留，不放宽门槛。为细网格加入BDF，使用同一物理构造和面通量。与4格细显式轨迹交叉比较，再逐次细化空间。BDF同时积分外界累计物质/能量通量，从保存值重建全局守恒，不能称其有理数精确守恒。
4. 隐式误差参数在首次运行前写入根文件；仅有显式base/refined精度选项，无失败后自动改算法、删水或温度裁剪。每个边界程序拐点终止一段积分。
5. 独立重建表面热平衡、石英显热和若干状态的流体储能。独立计算方法并不代表不同EOS后端或第三方认证。相界时间只报告采样区间。

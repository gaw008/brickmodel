# 方解石有限反应速率：两个新来源尚未准入

继续采用原始论文而非把热重曲线当作现成速率常数。Slaoui与Bounahmidi(2004)提供实际石灰石的五个等温温度及四个CO2分压序列，具备后续复现价值；但平衡压力式未明确归一压力，按符号表的Pa直接解释会与实验分解方向冲突，且正文42.54kPa与图表46.59kPa不同。粒径只给50—125μm范围，不能悄悄选一个半径来代入面积速率。参数标准差没有协方差，不能当成独立正态误差。

Rodriguez-Navarro等(2009)提供同一类方解石单晶在2/5/10/15K/min空气升温下的转换曲线。Table2的F1参数只在2K/min识别，r²=.8083，作者也明确没有单一反应形式覆盖全过程。Table2未标A时间单位，正文对lnA附s⁻¹、实验升温率采用K/min；须直接复现后才能判断能否使用。后续先做固定原参数的秒/分钟解释比较，不调参，不把更贴图的一种解释自动升级为作者确认。

来源事实、页码、模型表达式与未解问题分别记录在sources.json。原Baker1962的出版社全文本次不可取得，题名中的atmospheres只能作线索，不能凭二手引述修正文中系数。以上均不提供实际污泥砖的同材料反应率，也没有解除M1和全周期材料依赖。

来源：[Slaoui2004](https://comptes-rendus.academie-sciences.fr/chimie/item/10.1016/j.crci.2004.01.011.pdf)、[Rodriguez-Navarro2009作者原文](https://www.ugr.es/~grupo179/pdf/CRNavarro%2009a.pdf)、[Baker1962出版社记录](https://pubs.rsc.org/en/content/articlelanding/1962/jr/jr9620000464)。

固定参数复现已经完成。Navarro的12个宽读图区间来自原PDF内嵌465×672像素图，保留像素轴、矩形范围、±.01转换范围及重叠歧义。按正文秒单位解释，12/12均不相交，最大至区间距离197.760K；按分钟的替代解释只有5/12相交，最大距离10.946K。后者并非作者确认的单位修正，也未通过全部图示一致性。没有调A或E，没有把读图区间当作真实测量置信区间。源参数本身来自2K/min，因此该曲线是原拟合复现，另三档才是转移比较。解析Arrhenius积分与独立quad求积最大相对差3.983e-15，数值积分通过不能覆盖来源/模型失败。

[对比图](navarro-f1-units.png)已生成并目视核查。低速原曲线的系统形状差也与作者“单一形式不足”的说明一致，但不能据此唯一识别缺失机制。

Slaoui的五个源温度也完成了字面压力单位复算：以符号表Pa直接代入Eq8，再与16.71kPa实验CO2代入Eq9，五项均得到负的分解驱动力。这否定的是该字面组合可直接使用，不能替代对作者实际所用归一压力的查证。原图间时间尺度疑点尚未完成数字化比较，继续保持未定量状态。

# 固定体积的分解、压力反馈与再碳酸化

本阶段完成1cm³虚拟刚性小室的热化学平衡循环。采用0.01mol总Ca、0.01000001mol总C、0.00001mol N2，从300K受1180K热库加热8000s，再接300K热库8000s。面积、换热导度和库存均为声明算例，不是砖坯材料测量。

## 来源与模型

- USGS1995原PDF打印p25/p15：方解石与石灰298.15K摩尔体积36.93/16.76cm³/mol，原表各±0.01cm³/mol。本次查看原页并保存页图；[官方原文](https://pubs.usgs.gov/bul/2131/report.pdf)。
- 明确采用恒定固体摩尔体积近似。[Cantera官方StoichSubstance](https://cantera.org/3.2/cxx/d3/d50/classCantera_1_1StoichSubstance.html)的同类状态关系为h=h0+(p−p0)v、u=h0−p0v、s=s0。这不提供目标砖高温膨胀数据。
- CaCO3/CaO/CO2/N2完整标准生成焓、熵、Cp来自此前逐页核对的同一USGS来源；气体内能使用h−RT。总U包含反应能一次，刚性外边界满足dU=Q。压力也进入固相化学势，反应平衡没有仅改气体分压而忽略固相压力项。
- Helmholtz极小条件、唯一共存根和有效Cv的推导见[定义](DESIGN.md)。参数分别在根目录parameters.calcite_constant_volume_source.json和parameters.calcite_rigid_equilibrium.json。

## 已执行的科学核查

15组静态状态及4个C=Ca角点核对了元素、U反解、Cv、dU=T dS−p dV+μC dC、相稳定性和H−U=pV。首次较大碳差分步的μ恒等式误差0.124689J/mol超过0.1预算，失败记录static-review.json保留；将差分步1e−8收紧到1e−9mol后，最大误差0.001377J/mol以内，其余预算不改。原因是纯方解石分支残余气体仅约1e−6mol，原差分相对气体步长1%，g ln(g)的中央差分截断项RT(dc/g)²/6在900K约0.1247J/mol。修正记录static-refined-review.json。

两档完整热循环及8001个共同时间观测均通过预定数值预算，证据为data/sandbox/research/calcite-rigid-equilibrium-v1/review.json：

## 算例结果与限制

- 分解共存起点838.375697792K，升温事件365.213430211s；冷却回到纯方解石事件8341.336392056s。这是热量控制的平衡极限时刻，不是有限反应速率预测。
- 8000s时达到约1180K，形成CaO 8.423519789e−6mol，占初始Ca约0.0842352%；总压286673.2224Pa、CO2分压131155.8683Pa。有限空间内CO2积聚抑制进一步分解。
- 加热输入1000.71935844J；冷却8000s结束仍为300.04703935K，因此全循环剩余约0.0394394J，没有假称恰好返回初态。材料与两热库合计熵增加约2.487663932J/K。
- 298.15–1200K内没有完全分解的相界根，结果如实保留，不向来源有效域外推温度。
- 固体热膨胀/压缩率、真实气体逸度、实际孔隙网络及有限速率误差均未知。极小产物的角点仅是连续热力学极限，不能当作少数分子成核预测。material_qualified=false、training_eligible=false。

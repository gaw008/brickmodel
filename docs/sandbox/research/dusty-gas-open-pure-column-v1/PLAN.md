# 两端等温通气：纯 N₂ Darcy–Knudsen 柱

目的：在已核对的孔隙通量基础上，支持给定两端压力的持续供气与排气。先核对纯气稳态解析关系和开放能量/熵账，再执行从均压初态到稳定贯通流的动态过程。四气体闭列与本阶段分别保留资格。

根参数 `parameters.dusty_gas_open_pure_column.json` 冻结 T=600 K、L=0.02 m、A=0.005 m²、ε=0.3、τ=1、孔半径 1 μm、κ=3.75e−14 m²；两端 120/80 kPa，初始柱内 100 kPa。使用 N₂ 来源近似黏度与有效 Knudsen 系数，不涉及未获得的真实砖孔结构。

稳态 J=−[D_K(c_R−c_L)+κRT(c_R²−c_L²)/(2η)]/L。定义 F(c)=D_K c+κRT c²/(2η)，则 F(c(z)) 在空间上线性。比较稳态通量、中心值和真正的格平均；不把中心值自动当成格平均。按精确势函数积分求格平均，避免用输出网格自己作为连续解。

每格库存 n=εVc，通量按总截面积；边界距离是半格宽。初始是均压，随后两端恒压供排气。允许全过程库存改变，独立积分两端物质流后闭合总量。

这是 t=0 突然施加端压的理想 Dirichlet 阶跃；初值与端压在边界不相容，连续扩散问题的初始边界通量具有可积奇异性。因此初始数值边界通量随半格宽变化，不能把它称为网格无关的瞬时设备流量峰值。空间目标针对声明的末态格平均压力；全过程仍需各格积分守恒和独立时间收敛。

**等温热力学记账**：在这一固定 T 的单物种非反应算例，可明确选择 u_ref=0、s_ref=0 于参考浓度；这只移动参考零点，不声称热容或生成焓为零。由理想气体 h=u+RT，气流带入/带出焓，维持恒温所需每格热浴热流 Q̇_bath=−RT ṅ。库存 U=n u_ref，S=−Rn ln(c/c_ref)。物质库的流出入熵按流熵 s=−R ln(c/c_ref) 计算，再加热浴熵 −Q̇_bath/T；这个组合才应与全部面耗散相等。不能把单独砖体熵变化当作开放系统总熵产生。

计划依次核对：80 位稳态源式；每条接受轨迹的原通量、局部/累计物质、气流焓和热浴能量、组合熵、2/4 点时间积分；两档时间误差；稳态与连续解析格平均的空间差。浓度时间预算 1e−7 mol/m³、库存 1e−12 mol、熵 1e−10 J/K；能流来源预算 1e−10 W，局部能量 1e−9 J、累计 1e−8 J；稳态压强格平均误差 0.5 Pa，末态通量相对差 1e−8。固定预算，未通过则保留证据。

空间与时间资格完成前不声称该模块已验证。即使完成，也只适用于已声明的恒温理想气体与孔模型，不提供升温时的热容、非等温 Dusty Gas 热扩散或真实砖材资格。

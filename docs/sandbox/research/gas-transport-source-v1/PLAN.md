# 可追溯稀薄气体输运：先核对物性，再讨论多孔材料

冻结于2026-09-25 UTC，任何数值结果之前。目标是CO/CO2/O2/N2纯气黏度及一级二元分子扩散系数。采用固定Cantera v3.2.0的`GasTransport.cpp`、`MMCollisionInt.cpp/.h`和`gri30.yaml`来源，附BSD许可证。仅取所选四物种的Lennard-Jones井深、碰撞直径及零偶极碰撞积分列；不导入其NASA热化学和反应网络。摩尔质量明确来自同次读取NIST历史汇编表，不冒充Cantera整包逐位复现。

直接计算η=(5/16)√(mkBT/π)/(σ²Ω22)，Dij=(3/16)√(2π/μij)(kBT)^(3/2)/(πσij²Ω11P)。σij为算术平均，εij/kB为几何平均，μij为单分子约化质量。Ω11=Ω22/A*，Ω22/A*在ln(T*)上按来源三节点二次插值。源码还会对生成的物性拟合温度多项式；本阶段不做该拟合，不宣称与Cantera最终API数值完全一致。量纲分别为Pa·s和m²/s；D不是Onsager迁移系数，不能直接替换现有虚拟L。

根文件`parameters.nonpolar_gas_transport.json`保留十进制来源值、确切SI常数、单位换算、计算域300–1200K、三个审查压力和预算。NIST四页HTML已按表头、真实单元格和选定温度行读取，保存来源URL、参考文献和不确定度。NIST表对照仅300–1000K；所选页面未显式给出压力，不能称压力匹配实验验证。2011 PDF无法取得可用图像、Webbook下载失败，未把其文本拼接行当作已核对的新表。

分三步执行：先独立重解析来源数组与GRI条目核对根文件；再用80位Lagrange插值和独立代数表达式复算全部纯气与六对二元系数，核对Dij=Dji、D∝1/P和正性；最后逐物种比较NIST表，保留任何超出其不确定度加半末位舍入的差异。算术相对预算1e-13，对称/压力比例1e-14，在看到结果后不放宽。表值不用于拟合LJ参数。

该任务只补足自由气体来源物性。压力适用范围、混合物传输参考系、孔隙率/曲折率、渗透率、Knudsen效应以及真实砖气体迁移需要后续独立依据。`material_qualified=false`、`training_eligible=false`始终保留；来源算术通过不解除真实砖或全过程阻塞。

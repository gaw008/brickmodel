# 有界研究子进程监督器

最终内部独立审查通过：17项无EOS测试实际1.38秒，另有真实父进程SIGTERM及主子进程提前退出检查。可直接复用的 `supervisor.py` 与审查绑定源码逐字节一致；导入后调用 `run_attempt`，必须从主线程使用，尝试目录必须尚不存在。此工具用于后续可信、有限输出的离线研究，不是通用进程沙箱。

命令无shell，元数据记录输入前后哈希，stdout/stderr保存为文件，状态原子更新。超时及可处理的SIGTERM执行原进程组TERM/KILL与有界主子进程等待；取消会保存failed并传播异常。成功退出也会清理原组中的后代。主进程退出或信号发送失败不自动证明全部后代消失，相关诊断保留；同一已用目录不能重跑覆盖。

原始12测试、SIGTERM残留子进程反例、中间EPERM失败及最终修复/测试/真实进程记录在 `original-evidence.zip` 中。外部临时尝试记录按 `external-attempts/` 映射保存；清单记录归档成员大小和哈希，归档逐项读取核对原字节。历史审查WARNING与最终限定APPROVE并存。

输入哈希、创建/文件操作和清理开销不在严格内核截止保证中。SIGKILL、主机故障、不可中断任务、主动逃离原session的子进程不受此清理保证；未设置磁盘配额。argv、日志和路径原样保留，调用者不得放入凭据或秘密。输入哈希是观察值，不是不可变文件系统证明。

读取正式 `status.json`，忽略临时文件；running不能当作成功。complete只表示命令与声明输入检查完成，调用者仍必须检查实验自己的物理/数值结果，不能把进程退出0当作科学验收通过。

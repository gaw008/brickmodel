# 来源分区首根与共同正库存终点比较

基线 `b7466e3`。新增 `source_root_comparison`：从一次实际正库存推进后的参考状态
重新求值，建立第二个库存根面板，再让两条实际路径到达同一时刻进行比较。
这是限定的数值求解增量，尚未执行湿态到干态切换。

## 实现与边界

`evaluate_source_root_refinement` 从上一实际参考终点出发，用原完整政策重新运行
`SourcePrefixTrial`。即使完整前缀因负库存失败，实际起点和中点仍完整保存；只有
两条面板都支持同一个唯一液体首根时才比较。缺样本、资源停止、取消、气体先耗尽
或首根标签变化均不能升级为成功的根比较。

`compare_source_root_clocks` 保留绝对有理时钟，将两条数值根区间的间距及宽度
纳入原时间门槛。排序、正下界和比较细化共享各自原细化预算，不重新分配预算。
区间进一步收紧以原时间容差的四分之一为目标，但最终通过条件仍是原时间容差。
这两条路径不是固定 2:1 步长细化，不采用 Richardson 的除以 3，也不声称给出了
真实物理事件时刻误差。

`evaluate_source_common_endpoint` 实际求解原初态到共同终点，以及上一参考终点到
同一终点的两个新试算。共同终点严格早于双方已收紧的根下界，完整数值库存多项式
均须严格为正；两个试算各自完成原积分器参考及原 N/U 差异检查。
新增区间受原最大步长约束；完整粗路径允许跨多个参考步，每个参考步仍受原步长
上限约束。其较长仿射前缀也必须通过原来的差异检查。

比较使用两个实际参考终点的来源温度反解及压力记录，分别保留原 N/U/T/报告
温度处 P 门槛和条件压力门槛。分段路径每个接受前缀的 N/U 残差均从原始初态
累计，不能在第二段重置守恒预算。每试算回调/时间预算与全研究外层预算分开记录。
后处理或第二条路径失败时，`SourceRootStudyError` 保留所有已经返回的实际试算。
此接口尚未接入通用保存/恢复和 CLI/界面。

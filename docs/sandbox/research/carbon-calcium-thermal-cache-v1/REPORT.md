# 高温共同反应的精确热物性缓存

本阶段针对已经运行多小时的高温共同反应列，测量固定温度下压力根搜索重复计算标准态物性的成本。采用独立复制的七相对象和精确温度键；缓存容量从根参数读取，不缓存压力、库存、分相、导数或表面解，不作温度取整。现有长任务保持运行，未将缓存注入其进程。

从已保存32格细化轨迹取0、5、100、500、5000、10000、15000、21000、30000s九个完整观察，分别重建全部状态、内部面、储库、边界热气交换、辐射以及完整右端导数/产熵分项。缓存0、64、256时的物理字段全部相同，重建观察也与原记录全部相同。标准态未命中总计45910、1831、1819次；容量64已消除绝大部分重复计算。

三档带性能剖析耗时0.964424、0.895254、0.893971秒，当前有限工作量仅约7%差异，**不能把95%以上的物性调用减少解释成同等运行提速**。剖析显示主要成本转至压力和气体组成的嵌套求根，现阶段未修改这些算法。

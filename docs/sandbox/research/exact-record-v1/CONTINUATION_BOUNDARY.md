# Required boundary before exact recorded continuation

The versioned codec is a numerical-evidence format, not resume authority. A subsequent implementation must consume the fresh record returned by live binding verification, never the caller-supplied object's replaceable fields.

Resume must retain original initial state/start/end, source/case/operator identities and complete original policies. Reconstruct the actual host from frozen external inputs and validate every mode-specific source reference. Preserve all previously committed exact states/ledgers/packets; do not reinterpret exact times as binary64 absolute callbacks. A suffix solve starting with new zero correction totals is not continuation of the same run.

Before publication, recompute the entire combined prefix against the ORIGINAL initial state, including every amount/element/mass correction, represented and exact stretch and accumulated absolute quadrature, energy/work components and original cumulative correction totals. Resume cannot reset these budgets or discard prior failed/speculative work. Original global panel/rejection/wall budgets must account for earlier attempts; a separately authorized new resource plan is a new explicit experiment decision, not automatic quota renewal.

Accepted event packets require preserved or independently recomputed original all-event/common six-gate comparisons, consecutive successful refinements, genuinely distinct independent approach grid and both halved controls, source/domain-bound pressure evidence, strictly matched root/panel/correction and once-only committed transitions. Structural codec validation alone does not provide these numerical audits.

A resumed adaptive controller need not produce a bit-identical uninterrupted grid; its restart policy must be explicit and tested against the same physical solution and original tolerances. Test cancellation before/within/after a packet, original accepted-prefix retention, dry mixed-mode reconstruction, source/case changes, cumulative budget exhaustion and end-time reach before CLI/service admission. Existing legacy record refusals remain until this complete contract is implemented and verified.

# 高温开放表面：六组静态工况通过，动态尚未开发

无储量表面已经接通内外两侧CO2/N2交换、气体携焓、导热和独立辐射热库。表面T/P/气体比例由两物种和能量平衡求得，辐射不绕过表面直接输入单元中心。系数和几何仍是明确声明的虚拟值。

等态、单独热辐射、热通气、冷富CO2、压力驱动富CO2和300K冷启动共六组工况完成独立来源面率重组。最大物种余额2.71e−21mol/s、能量余额6.22e−15W、两面来源物种率差1.93e−21mol/s、能流差1.78e−15W；单元加气库/辐射库的总熵率与两面加辐射产生之和相差≤5.32e−18W/K。名义熵产生均满足原非负预算；等态流率为零。不同热边界下，表面温度与单元中心温度确实不同，例如300K冷启动/1180K热库时Ts≈835.739K。

表面根隐式导数与有限差分在原缩放误差1e−5预算内通过。首次冷启动核查失败：C扰动1e−8mol等于全部残留CO2量，负侧跨入两固相共存，较小两步仍改变气相CO2达30%/10%，不能代表局部导数。实际气量分别约4.34e−28/2e−8mol，相分支已确认。

只把冷工况差分扰动尺度改为1e−8mol，保留原导数归一化尺度1e−5mol和原1e−5误差预算，并用实际浮点库存间距作分母。三档扰动均留在原分支，误差4.926e−6、4.461e−7、5.726e−8，呈截断误差缩小。原extended-review.json失败未覆盖；最终cold-derivative-review.json全部标志通过。

第一次打印NumPy布尔值时编码失败，原stderr保留；显式转换汇总布尔值后生成单独serialized-review文件。这是记录层错误，没有修改面率或物理预算。

本阶段只授予这六组静态边界与局部导数的限定数值资格，不提供全域根存在/唯一性证明，也没有动态周期结果。下一步在此基础上接单元时间积分，再核全程来源、C/N/U、气库/辐射库和熵账。反应仍是瞬时局部平衡，真实有限速率、发射率和孔传递系数均未闭合。

推导和通用边界来源见[DESIGN](DESIGN.md)；物性仍沿用USGS相同记录、不可压固相近似和理想CO2/N2。`material_qualified=false`、`training_eligible=false`。

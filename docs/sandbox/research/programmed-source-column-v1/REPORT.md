# 来源多格模型的开放炉程边界

`ProgrammedSourceWetColumn` 已把变化的炉气温度、有效辐射环境温度、压力和完整气氛接入来源干质量 N 格模型。中心面闭合，右端为规定状态的无限气体库。外部气体扩散/压力流动携带的焓和表面传热共同进入同一个面账本；使用原 `integrate_source_column` 推进，不另建一套时间积分算法。

基线为 `e2c815a`。干物保持原 Arlabosse 低温 Cp 和固定干质量，水/气保持原来源与热量参考。材料体积、传输与表面系数仍为明确制造测试值，`material_qualified=false`。有了开放边界并不表示原泥全温域、真实干燥或烧结冷却材料模型已经齐备。

## 实际计算合同

`surface_balance.solve_surface_balance` 从旧 `ProgrammedSolidFluidHeat._surface` 提取原始端点/二分算法。旧平板、球形和当前几何调度仍提供实际面积和导热回调；原算术、残差门槛、错误类型及完整观测/身份黄金保持。共享函数本身不供应材料参数，回调的几何、连续单调性与来源由真实调用者绑定。

新来源边界使用实际外半格距离：两个数值 quarter 距离之和为最后一格宽度的一半。气体面调用已有 `evaluate_wet_face`，其中 Fourier 系数明确设为零，避免另加一条炉气到格心的导热路径。原面温度插值用于扩散焓、上游供体温度用于平流焓；面插值气温不是另行求出的固体表面温度，也不表示已解析实际边界层。

表面解满足 `Q_surface→cell = Q_convection + Q_radiation`，灰表面对有效黑体辐射环境的假设沿用原边界函数。右端面正方向朝外：

`E_out = Σ(diffusive_mol_s × h_face + advective_mol_s × h_donor) − Q_surface→cell`。

因此每格仍用左面减右面推进 U；对流和辐射不再作为第二份热源加入。接受步账本同时保存实际中点边界、表面温度、对流/辐射/入格导热积分，以及导热减两项表面热的精确差。该差与表面求根返回的浮点残差、容差分开保存；它不是材料不确定性或时间积分误差证明。

`ExactProgramView` 和 `ExactEventTime` 用于起点、中点、终点与节点排序。内部程序节点细分名义时间步，重合节点只经过一次，实际接受步数可能超过 `steps`。整段起终点先检查程序域，不将超域温度外推。炉气节点必须处于全部气体焓函数的域内；固体比热域只约束实际格内储能温度，不混同于辐射环境温度。失败或取消只保留已完成终点评价的完整步骤。

## 真实水案例

复用上一阶段三格储能和初态，真实 HEOS 水、来源气体热量函数及原逆解精度均未改。持续时间为 `1/1024 s`、一个中点步。炉气为 340→346 K，有效辐射环境为 350→355 K，压力 0.9→1.3 MPa，O₂/N₂/H₂O 从 `(0.25,0.6875,0.0625)` 变为 `(0.125,0.75,0.125)`。这些是明确的虚拟设计；表面及气体传输系数在脚本中明确作为测试输入。

先在源码路径实测一次开放评价，再非 editable 安装运行一次完整短轨迹；没有重复运行源码完整轨迹，也不声称源/安装两条完整轨迹对比。原 45 s 积分/60 s 外部硬限和精度门槛保持。过程退出码之外，主控实际核对了 completed、一个完整 ledger/终点、三次成功评价、25 检查和材料资格 false。25 检查包含逐格固定干质量、液水/三组分气体/总 U，以及边界修正后的全局 U/O₂/N₂/总水和表面热量单计。

接受中点为精确 `1/2048 s`；炉气 343 K、辐射环境 352.5 K、压力 1.1 MPa，气氛 `(0.1875,0.71875,0.09375)`。表面温度约 345.384071 K，故对流功率为 −0.238407 W、辐射入热为 0.548654 W，导入格内约 0.310247 W；表面残差约 −5.9952e−11 W，在原约 1.0055e−10 W 门槛内。总 U 账本包含气体的同参考焓，不能把总 U 变化直接称作净供热或窑炉燃料耗能。

独立保存结果审计确认：总 U 变化为 +0.08941944529942703 J，外界账本贡献 +0.089419445306534 J，差由约 −7.10698e−12 J 的接受步带符号舍入完全解释；总水变化约 −4.45951325629e−7 mol 同样等于水汽外流贡献加舍入。逐格和全局守恒余额精确为零。实际中点程序亦由原端点独立插值核对；这些检查不要求物料在开放边界下库存保持不变。

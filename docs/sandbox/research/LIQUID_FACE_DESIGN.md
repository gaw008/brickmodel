# 下一步液相面输运的闭合合同

状态：本文件为已核读方程支持的待实施设计，不是液水迁移已实现。整体固液气储能和动态边界现已接通，但SolidFluidHeat内液相面通量仍为零。目标是接通真实液水库存与携带焓，而不是新增一条不反馈总U/P/T的水分曲线。

## 已读取的方程来源

现有原始快照`data/sandbox/transport/moose-governing-equations.md`的Advection/eq:darcy（约80–104行）明确每相使用自己的P、rho、mu和相对渗透率；Heat flux/eq:heat_flux（约230–244行）使用相质量通量乘相比焓。来源元数据、官方公开URL、版本快照hash和许可证在同目录equation_sources.json，核读的是该已存快照，不冒称现行版本。它支持方程形式，不能证明污泥的渗透率、饱和度关系或黏度数值。

水平一维固定bulk、忽略重力和毛细压的受限分支，可用每格实际平界面液压P_l。两侧半格串联：mobility_i=k_i*krel_l_i/mu_l_i，Qvol=A*(P_l,left−P_l,right)/(dx_left/(2*mobility_left)+dx_right/(2*mobility_right))。任侧mobility=0时面通量严格0；不得用epsilon替代。Darcy通量以bulk面积计，不能再乘孔隙率。摩尔通量Ndot=Qvol/v_l,donor，携带能量Edot=Ndot*h_l,donor，使用储能相同水参考、实际供体T/P的摩尔体积/焓。不得用气相库温度、h=u或另加pQ重复压力流功。

上述半格mobility谐和串联加单一供体密度，是冻结系数有限体积/上风离散；真实可压缩液水两侧密度不同时，不是沿两半格保持质量流恒定的精确稳态解析解。后者需沿程密度/压力关系。应通过网格收敛评估这一离散误差，独立手算验证仅针对声明的面离散式。

同一个面mol/J值在左右单元符号相反，加入现有Rates面数组对应液列和能量列；下一trial的真实全库存U反解自然反馈液体占积、气孔体积、气压和温度。源项不人为补偿库存或热量。禁止各侧独立计算后以平均值掩盖不守恒。

## 必须明确的适用域

仅靠P_l=P_g的平界面分支不覆盖毛细主导湿砖干燥。相对渗透率必须按饱和度/材料或明确制造fixture声明，不能照搬气体相对渗透率或默认1。常数相对渗透率只能是预先声明的局部冻结近似/制造极限，不可直接称整个干燥过程的物性。液水孔网连接性是额外模型假设，不能从两个格子有水自动证明连通。

首个实现需同时提供来源/基准/域与可检查的连接条件。若接纳冻结mobility作为制造测试，应把这一路单独标出；真正材料路径必须调用有据的状态依赖关系。没有有据毛细P_c(S)或活度关系时，不可把平界面压力流描述为完整干燥。毛细模型将改变P_l/P_g及储能/界面功闭合，需要单独推导，不能在旧机械根后随意减一个压力。

活跃面遇到无液相、非连通、孔体积耗尽或水EOS域外，分别记录域退出/缺项；不能臆造干孔浸润、成核、吸附或残余饱和度。完全干燥后的气相路线仍需要显式状态分支。对于边界进液，应另外定义有源的液体库温压/连通条件，不能把现有气氛reservoir当液库。

## 验证和接入次序

先给共享面算子写独立手算压力梯度、半格串联、符号、供体mol/h及零mobility极限测试；实际IAPWS状态只提供有源v/h，不作为被测face公式的自证。再用两格完整固液气host做真实积分：水总量、固体/气体库存、全系统U逐步与前缀守恒，液体转移改变两格压力/温度，有限库存超步由积分器拒绝且不clip。需将含源参数的结果与制造数值验证分开。

与外层WaterPhaseTransfer及ProgrammedSolidFluidHeat组合时保留完整evaluation链和程序节点；不要增加一种互斥演示路径。液面算子最好在SolidFluidHeat的共享face层通过显式配置接入，避免再次复制整套host解码。实现前审查接口，完成后独立物理与代码审核。数值通过以后仍须补同材料的热湿本构、空间/时间收敛与公开留出预测。

# 两固体两气体的独立解析参考

运行前登记。该案例为明确制造的惰性不可压固体与理想气体，不包含真实泥料性质或水。它用不依赖新求解器的Decimal代数检查固体占积、储能、库存变化和恒功温度响应；固液气闭合还须单独验证有液水的非线性状态。

固定Vbulk=1e-4 m³，p0=1e5 Pa。固体a/b库存2/1 mol，摩尔体积1e-5/2e-5 m³/mol，Cp=30/50 J/(mol K)，h0=Cp*T+(-100000/-200000) J/mol。气体g1/g2库存0.001/0.002 mol，Cp=30/40 J/(mol K)，h=Cp*T+(-1000/-2000) J/mol，R=8.31446261815324 J/(mol K)。所有浮点配置先按其精确二进制表示转Decimal，精度60位。

Vs=ΣNs vs，Vg=Vbulk−Vs，P=ΣNg RT/Vg；U=ΣNs(h0−p0vs)+ΣNg(h−RT)。常热容C=ΣNs Cp_s+ΣNg(Cp_g−R)，恒功输入250 J的终温Tfinal=300+250/C。

比较三个前向状态：原库存300/350 K、固体库存减半后的300 K；并比较原库存加250 J后的温度反解。原始参考同时给出P、U、总H=U+PVbulk、C和体积。实现前向比较门槛预设P绝对1e-5 Pa、U/H绝对1e-7 J、C绝对1e-9 J/K、体积绝对1e-15 m³。温度反解及恒功实际积分终温比较门槛1e-4 K；生产inverse应继续满足其自身更完整的条件误差政策。

这些门槛是数值检查，不是物性精度或实际砖验收。脚本最初只生成独立参考；新模块完成后可追加候选实现比较，参考计算不得调用它来得到真值。保留脚本和输出身份，失败不调宽门槛。

## 为什么不能从现有数据唯一识别动态物理关系

1. **观测没有分开各类应变。** Fig4 是单一10°C/min空气升温下的总轴向长度。即使名义曲线记为 `e_obs(T)=e_thermal(T)+e_chemical(T)+e_sinter(T)+e_load(T)`，对任何满足初始零点的函数f，令 `e_thermal'=e_thermal+f`、`e_sinter'=e_sinter−f`，所得观测完全相同。现有材料热膨胀、化学收缩及探针载荷资料不足，不能确定该分解。测得高温总长度不等于自由烧结应变。
2. **参数组合不等于每个物性参数。** 若采用一个明确的黏性烧结假设，速率可能由驱动力/黏度与孔隙、粒径因子的乘积决定。只有收缩观测时，同时按c放大驱动力和黏度可保持相同速率；缺独立载荷/粒径/孔结构信息，不能分别声称测得表面能、黏度及其孔隙依赖。这里是一般不可识别性的数学说明，不新增MIA3物理定律。
3. **单一热历史没有检验路径迁移。** 对已知模型形式、已知其他物性，一条精确曲线有时可以拟合A/E；本结论不是否认这种条件可识别性。MIA3当前未知的是这些前提以及模型形式。沿一条热历史拟合到的温度函数，无法验证改变升温速度、保温或气氛后的响应。13个稀疏长度点的差分还带相关读图误差，不能当原始瞬时速度数据。
4. **四个冷态终点不能补出未知的路径。** Table6 限定30°C/min、5min保温，但未给冷却T(t)、实际芯温或试件历程。冷却阶段继续致密化、相变及可逆应变的分配未明。把整个收缩都归于5min恒温会引入未经证实的假设。最终孔隙、密度和吸水率彼此相关且不是热态孔结构轨迹；有限终点不能唯一确定多个未知函数。

因此，不应把当前Fig4直接求导后称为“黏度”，也不能用已测终态反设几何再比较同一终态。一个有用的后续模型可以只识别**有效致密化速率组合**，但必须先确定/约束热化学应变、实际T(t)及其模型形式，而非强求各微观系数都从同一长度曲线获得。

## 下一步怎样最少地推进真实机制验证

保留本次经验基线及固定分组。下一物理收缩模型应先限定同批MIA3、原薄试件、明确气氛/载荷和热历史，目标是总长度或有效致密化速率；尚不宣称分开识别全部微观物性。

- 取得同配方的实际试件T(t)、初始干质量/体积、探针载荷/几何，以及至少另一个独立升温或保温历程，另留一个完整热历史不参与调参。所需数量最终取决于灵敏度矩阵秩和参数相关性，不承诺“两条曲线就够”。
- 对重要相组成匹配的阶段建立可逆热膨胀基线，独立约束化学失重/收缩。已烧成样的二次热循环只能支持其稳定相组成，不能不加论证地从初次全程曲线逐点相减。
- 在上述约束下选择有材料机制依据的单一有效速率形式，联合拟合其少量参数并检查可识别性；如使用Arrhenius温度因子，应报告可识别的有效速率幅度/活化能组合、联合范围和模型形式误差，不能拆成未测黏度/表面能。原有自由主机的能量、几何和孔气接口继续使用，新增材料关系须自己通过热历史留出检查。
- 收缩源与模型预测在相同“干燥后长度为参考、加热态或冷态”的观测定义上比较。只有实际输运/连通关系补齐，才允许将密度或总孔隙变化转成渗透率反馈。

这些是新增科学证据的要求，不把当前软件基础设施当作阻塞理由。软件反应/热量耦合、真实资料的分机制对照和应用可以并行推进；本次没有升级任何材料资格。

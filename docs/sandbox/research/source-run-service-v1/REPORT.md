## 实际软件与失败处理

配置闭合列出物性、初值、空间参数、传递条件、数值政策和 17 个来源资产；
原生物性与 Arlabosse 干质量热容通过安装包直接构造，不再执行研究脚本。
初始能量和真实初始源项由运行器计算，据实际净液体损失推导试算时段。
原水摩尔质量、源参数和全部门槛保持；液体表绑定本次配置，形成新的运行身份。

正式观察钩子按任务作用域工作。每次输入、实际返回、阶段结果和失败原因都有
证据，数值验证前的返回也会保存。原 HEOS 内核和批准 manifest 未改变；
观察层使 Python wrapper 实现 hash 改变，该变化已实际进入新的运行身份。

独立审查发现并修复：合法 unsupported/numerical_failure 状态导出被拒；取消
或超限使上一条成功 capture 被误标失败；第二个湿压力请求取消时带入上一水态；
返回写盘失败时实际返回数被漏记；初始能量失败通知掩盖原 DomainExit；失败摘要、
终态或运行种类改动后重封清单绕过验证。原 RED、修复、真实控制反例及报告保留。
配置、观察层、运行服务和验收脚本分别完成独立代码审查，不能称为外部材料认证。

# 下一项：真实来源轨迹的受控继续与应用接线

本阶段完成配置到真实来源试算的执行入口，不再把记录导入器当作运行器。
下一阶段应沿当前接口推进实际轨迹，而不是继续扩充被动摘要框架。

1. 从本阶段实际保存的配置、资产和数值状态设计受控继续：明确可接受的检查点、
   实际已接受步、原始初值和时钟、已经消耗的计算预算、模式与算子绑定。
   重建真实来源对象后校验这些绑定；不要从旧进程 object id 构造恢复权限。
2. 验证取消后继续与不中断运行的对应关系，保存原始历史、父子关系及累计账本。
   若目前事件求解器无法给出可继续的状态，明确补齐其接口，不将从头 replay
   改名为 resume。保持原始政策和容差，不通过重置预算获得额外尝试。
3. 将来源配置、运行/取消、真实失败、全部观测和逐字段查询接到本地中文界面，
   明确显示制造几何/输运和真实来源物性的不同依据。
4. 原污泥材料工作根据 GNEST Tables 4/5 的已核差异继续：需要相容的产物计量、
   相关误差与热效应证据。当前打印产物不能闭合，LHV 推导热量不能直接变成
   动态反应热。不要任意归一化、补负产物或拼接另一种材料的动力学参数。

原 Goal 的同材料反应—烧结—几何—冷却、三机制公开实测留出预测、空间和时间
收敛、完整周期、多代来源模型搜索及完整应用验收全部仍未豁免。当前 N3
微秒级单事件比较不能冒称完整湿坯干燥或烧成。

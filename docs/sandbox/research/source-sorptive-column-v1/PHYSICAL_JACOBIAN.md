# 非反馈收支变量与数值Jacobian

2026-09-22，128格长算例stderr出现SciPy数值Jacobian扰动因子乘法溢出/invalid警告，原stderr和接受前缀保留。没有把警告静默屏蔽，也没有直接声称当前物理状态已经失效或不存在。

原系统的最后4个变量是外界O2/N2/H2O/U累计收支，任何面率都不依赖这些累计量。原稀疏结构中这4列严格为零。已安装SciPy 1.18.1的`_sparse_num_jac`对零列取argmax得到第0行，再与该行的非零率尺度比较，可能不断放大这些没有反馈的扰动；这一结构解释了观察到的警告机制，但未读取原运行进程的内部factor数组来逐项证明警告来源。

新增明确选择的`--jacobian-parameters parameters.sorptive_physical_jacobian.json`：只对各物理单元的N/U计算数值Jacobian，沿用同一SciPy差分方法、容差和稀疏邻接；外界账本列精确为零，账本行由对应物理行的负和给出。这是`d(external)/dt=−Σ d(cell)/dt`的导数，不改面通量、状态方程、U参考或物理参数，不裁剪扰动因子。

实现明确依赖锁定SciPy的两个内部函数`num_jac`、`group_columns`，版本和选择策略保存到轨迹；未来升级依赖需重新核对，不能当成稳定公开API。未选该根文件的旧计算路径保留。

四格基础完整过程与原物理U路径的最大温差3.48150e−5K、总水差4.05273e−13mol、含水事件差2.03369e−6s，达到原时间预算。随后紧容差、来源/守恒/熵和32格计算的实际结论另补，不能仅凭结构推导声称细网格运行已无警告或性能一定提高。

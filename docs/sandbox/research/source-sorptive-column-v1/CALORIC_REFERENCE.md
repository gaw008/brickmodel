# 干物热容量和能量零点的适用边界

2026-09-22补充解释，不改变本窗口任何数值或冻结轨迹。根`parameters.sorptive_caloric_interpretation.json`登记下列来源/模型区别。

Arlabosse2005给的是干物Cp随温度的关系。现行`dry_energy_difference_j_kg`将其积分作为固定干质量的U增量，并用同一函数除以T积分形成S。这对应无干物热膨胀/压缩功的定体积储热近似；它在声明模型内部相容，但**没有测得实际污泥的Cv，也未证明实际Cp=Cv。**

一般简单可压缩物质满足`cp−cv=T α_v²/(ρ κ_T)`。[IAPWS G12-15第6页Eq16](https://www.iapws.org/relguide/Supercooled.pdf)明确给出这一恒等式；本次读取出版方索引中的公式文本，直接PDF打开失败。这里仅引用热力学关系，未把过冷水系数用于污泥。[Cantera的定体积不可压缩物质说明](https://cantera.org/3.2/cxx/d3/d50/classCantera_1_1StoichSubstance.html)也明确区分参考焓、内能和固定体积近似。这些来源都不证明该污泥不可压缩。

该干物的热膨胀、压缩率及相容密度关系未给出，不能填零后声称是实测事实，当前近似的材料误差保持未知。“固定N/V下dU=T dS核对通过”说明当前储能构造自洽，不能逆向证明它正确表示真实干固体。

另外，干物能量以根参数330K为相对参考；固定干质量时参考常数抵消，可以核算换热、气体携焓和脱水。发生反应或干物质量变化后，该常数不再无条件抵消，必须取得同一热化学基准的有效原料/产物能量。不能把当前相对零点当生成焓，也不能因Cp有来源就声称高温反应能量已闭合。

这项说明适用于本窗口全部来源吸附单元/柱/湿度循环及读图情景。水相仍使用其IAPWS体积/内能；没有将水的Cp直接替作Cv。固定表面腔中的石英储热体有自己的原阶段解释，不由本文件授予实际砖坯材料资格。

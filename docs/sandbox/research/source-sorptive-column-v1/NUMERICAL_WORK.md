所有改动保持物理模型、来源节点、守恒方程和误差目标。

1. 低W水库存使用已有解析根；高W仍用原来源曲线求根，见[推导](PARTITION.md)。单元与四格完整对照温度/总水/事件达到原时间预算。84个声明T/P/W组合的充分单调因子为正：最小气相体积分数.9918328，最小`1-p0*aw*v/RT`约.99983446；这是采样条件核查，非全域EOS界。

3. 固定T压力求根的多次调用共享相同Chebyshev温度投影及蒸气标准化学势，不舍入T或P，不新增拟合。在341点来源比较中达到原预算；四格2401个保存观测、目标事件与未共享投影的同设置轨迹逐值一致。
4. `parameters.source_sorptive_column_fine.json`明确选择最大步长10s、精确状态缓存8192项。积分容差不变；四格与原2s设置最大温差5.073e−5K、总水差3.376e−12mol、目标时刻差5.252e−6s，达到原时间预算。完整2/4点熵核算仍通过。

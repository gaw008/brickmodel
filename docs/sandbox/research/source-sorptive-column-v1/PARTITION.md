# 同一水库存方程的分段求解

在固定T/P下，纯水标准给出`p0(T,P)`、凝聚水摩尔体积`v`；过量势给出`aw(T,W)`，其中`W=M*Nc/md`。水库存方程为

`F(Nc)=Nc + p0*aw(T,M*Nc/md)*(V-Nc*v)/(R*T) - Ntotal = 0`。

低W段的aw与Nc严格成正比，F为二次式，其稳定小根已在低W宿主使用。先求此解析根：若根≤接点Nc，则它也是完整分段模型的根；否则在[接点Nc, min(Ntotal, md*Wmax/M)]上求来源段根。接点两边aw相同，未改热力学势、水量或活动度，也没有数值失败后改用另一物理模型。

该选择依赖单调支：`F'=1-p0*aw*v/(RT) + p0*(∂aw/∂W)*(M/md)*(V-Nc*v)/(RT)`。来源分段化学势斜率为正，低W斜率也为正；在声明的正气体体积和`p0*aw*v/(RT)<1`条件下F严格递增。物性条件的采样核对单独记录，不能把若干点当作全域EOS误差界。

该修改旨在避免低W区重复数值求根。保留旧完整来源段Brent轨迹，与新分段求解的完整单元及四格轨迹比较，并重做来源/完整熵核算。实现差异可能产生舍入和自适应步差异；达到原误差目标后才供更细网格使用。旧轨迹参数/来源快照不宣称冻结了Python代码或逐位重算环境。

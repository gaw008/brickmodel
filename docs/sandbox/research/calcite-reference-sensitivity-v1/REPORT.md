# 参考热力学数据灵敏度不能替代外部验证

针对薄膜onset的10–15K偏差，单独考察USGS已打印的298.15K参考H/S宽度，固定所有Cp多项式、体积和实验读图区间，不改运行模型、不拟合数据。实际执行了8组焓端点和32组焓/非零熵端点的平衡求根，并用直接改变来源相参考值再重组G作算术复核，最大根残差4.475e−10J/mol。

[USGS原PDF](https://pubs.usgs.gov/bul/2131/report.pdf)打印p3明确：给定不确定度适用于298.15K，量热报告惯例是均值的两倍标准差。来源打印H宽度为CaCO3/CaO/CO2各1.3/.9/.1kJ/mol，S宽度为.2/.4/0.0J/(mol K)。CO2打印0.0不能认定真实不确定度为零，本次熵扫描只变化前两相。高温Cp误差及协方差未提供，不能把扫描结果命名为高温置信区间或预测范围。

因为Cp固定，反应势的变化严格为δH−TδS：焓扫描反应δH在±2300J/mol，另加熵扫描δS在±0.6J/(mol K)。这是来源参考数值的矩形情景集合，不是有联合概率解释的误差分布，也不把G的报告宽度再次独立叠加到H/S以重复计数。

- 只变焓时，6点中5点的读图区间与各自情景范围相交；.012atm点仍不相交。
- 焓加非零熵扫描时，6/6逐点范围相交。这不意味着存在同一组物性同时解释全部6点。
- 同一组δH/δS的共同可行性计算无解。独立消元给出的必要条件分别为δS≥3.077135和δS≤−0.794241J/(mol K)，相互矛盾，分别来自第3/2及第3/4点读图区间。即使不考虑此处±0.6的源宽度，也不能同时满足这两个条件。

上述条件由每点平衡根落在[TL,TH]推出f_nom(TL)+δH−TLδS≥0、f_nom(TH)+δH−THδS≤0；f在选定域随温度递减。线性规划和直接逐对消去δH得到相同结论，完整约束证据在elimination-review.json。

原始实验的不确定性不只有像素读取，onset也不是平衡边界；这一无解结论仅排除“固定Cp、统一参考H/S改变即可完全解释冻结读图点”的方案，不否定热力学定律或全部实验。它不能识别动力学滞后、薄膜差异、仪器和Cp误差各自贡献。正式材料判断仍为null，资格仍为false。原先名义USGS曲线及六点偏差保留，未给它们重新命名为已验证。

可复现入口为examples/sandbox/review_calcite_reference_sensitivity.py，参数parameters.calcite_reference_sensitivity.json；原始求解记录review.json、增加独立消元的记录elimination-review.json均保留。没有新增/运行软件测试，没有生成或比较SHA。

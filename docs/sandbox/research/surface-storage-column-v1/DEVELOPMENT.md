# 固定表面储存腔：开发与首轮核对

本页只记录实现与首轮结果，最终网格、熵、续算和物理尺寸敏感性结论见后续报告。物理定义和执行前目标在[CONTRACT](CONTRACT.md)，选择依据在[ADR](ADR.md)。

## 实现

`equilibrium_water_column_setup.py`将均匀单宿主改为显式的逐单元宿主、体积、石英量、角色和面连接。原均匀模式沿用同一几何；新模式有一类内部宿主和一类固定储存腔宿主。隐式缓存加入宿主身份，显式/隐式驱动和来源核算使用各自单元体积。记录包含全部几何，来源快照续算可恢复新根输入。没有加入新的液水源项、相变热项或液体输运关系。

面气体交换沿用左右距离加权的现有质量框架扩散和Darcy项，热传导使用串联阻力。外表仍解对流/辐射/壁内传导平衡，并保留单独的气体携焓。新比较器只把内部网格作体积重映射，腔温度单独对齐并纳入原温差预算；几何平均温度是观测比较，不是混合平衡态。

## 已实际完成的首轮证据

- 旧均匀4格重跑，在全部321个保存时刻的格温、外表温、总水差为0；见`initial-comparisons.json`。
- 15内部格加1腔与旧16格完整70s轨迹相比，561时刻的上述观测差为0，冷凝和蒸干事件差也为0；见`equivalent-geometry-review.json`。
- 4内部格加1腔在70s全过程完成。直接IAPWS/理想气体/石英公式重建2805个保存状态，最大能量差4.93e−13J量级；原能量、压力、化学势预算均通过，2800保存面的名义熵产生无负值。
- 该完整轨迹的2/4点BDF多项式熵积分最大平衡残差分别3.65e−10和3.69e−10J/K，均小于原1e−7预算。它复用宿主状态反解和IAPWS后端，独立重算熵表达式/面关系，不是独立EOS认证或全域第二定律证明。
- 4和16内部格两条冷凝轨迹的12320个保存面，独立标量公式与生产计算最大组分率差7.80e−20mol/s、能流差1.89e−14W，根输入重建几何差为0。16格初始腔库存/U放进两种宿主后同为330K，但压力分别101556.17与95208.91Pa；这直接表明相同N/U不可跨宿主缓存。

## 尚不合格及待完成

4→8内部格腔温最大差0.4892K超0.2K；8→16温度/总水通过，但最终蒸干事件差约0.05476s仍超0.02s。因此当前不能声称空间精度已通过。32/64格、收紧时间容差及续算仍在执行。

首批轨迹根输入快照沿用旧数值说明文字，未文字列出新增宿主缓存键；实际执行实现已包含宿主身份。本次仅更正后续根文件文字，原轨迹不重写。旧复制的停止点名称也改为对应冷凝/干燥阶段的明确名称；没有改变已运行的物理数值、积分程序或比较预算。

以上均为声明参数的条件装置，尚无真实砖、实际表面液膜或任意尺寸储存腔的实验资格。原均匀冷凝模型未通过的空间比较继续保留。

# ADR: 表面储存采用独立固定体积控制体

**Status:** Accepted for conditional research implementation

**Date:** 2026-09-22

**Deciders:** 用户已授权自主推进；助手在本阶段限定范围内选择并记录

## Context

旧冷凝细化中，最外格体积不断减小，但其液水库存并未相应缩小。局部液体滞留、表面通量与该离散控制体的关系需要先明确。原数据仅支持库存集中迹象，未证明连续方程含边界奇异质量。

## Options Considered

| 方案 | 所需新物理信息 | 本阶段影响 |
|---|---|---|
| 独立纯液膜，允许移动自由面 | 液膜压力、几何/机械功、干湿切换及界面载气条件；若有排液还需相应关系 | 更接近自由表面膜，但不能只添加液量而忽略压力与储能 |
| 体内液体输运 | 液相连通、毛细/相对渗透或其他有依据的输运关系 | 真实砖需要材料证据；不能用任意数值扩散平滑库存 |
| 固定体积表面储存腔 | 显式指定的腔体积、热储和连接阻力；沿用已有气液物性 | 最少新关系，可独立核库存/U、相平衡和网格误差；只是一种条件装置 |

## Decision

选择第三项。表面腔具有固定的总气液体积，压力由库存和热力学决定。内部通道网格可加密，腔的物理参数不随之变动。腔内采用单一温度/压力和局部相平衡；连接段采用准稳态阻力，未解析腔内循环与梯度。这是新模型假设，不把固定一个旧网格单元而不作解释视为物理证明。

控制体中的总库存和U守恒与开口系统能量关系一致；刚性总体积使外边界体积功为零，出入气体仍携带焓。依据见[Cantera控制体科学说明](https://cantera.org/stable/reference/reactors/controlreactor.html)的质量、组分与能量式。这里只引用基本控制体关系，不声称Cantera实现了本项目液汽模型。

内部面使用相邻中心距离，非均匀接合处按左右距离插值物性、串联导热阻力。控制体积分与面通量的离散依据见[NIST FiPy有限体积说明](https://pages.nist.gov/fipy/en/latest/numerical/discret.html)。两份原始维护方文档于本窗口在线核读；运行不依赖网络，不添加Cantera或FiPy依赖。

## Consequences

- 可把随网格变化的外侧库存容量从数值离散中分离，并复用已有物性、气体交换、事件和续算。
- 腔的集总假设、指定阻力/体积仍是条件设置；内部网格通过不等于真实液膜或砖坯通过。
- 后续若材料证据要求毛细迁移或真实液膜，应另立物理合同，不把本腔体系数命名为已实测材料参数。

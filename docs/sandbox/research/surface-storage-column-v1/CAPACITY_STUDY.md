# 固定腔容量敏感性：执行前声明

本项在主模型网格研究之外，仅考察所指定表面储存容量是否影响答案。根文件为`parameters.surface_storage_condensation_half_capacity.json`和`parameters.surface_storage_condensation_double_capacity.json`。

仅把腔流体体积从0.625mL分别改为0.3125、1.25mL。内部9.375mL通道、0.02mol总石英热储、所有气体/导热连接距离、面积、传输系数、外边界程序和初始浓度保持不变。因此总流体体积及初始库存随装置容量变化；不能把其结果差记为网格误差，也不把较有利的结果选作材料拟合。它对应改变与固定连接段相接的腔容量，仍采用理想集总近似，未解析真实腔形及内部循环。

先运行16内部格，再运行32内部格，使用主模型的0.2K、1e−6mol、0.02s空间比较目标核对各自离散误差。物理容量变化本身不设置需要“通过”的答案；输出冷凝/蒸干时刻、腔与总液水和温度，且与数值误差分开报告。若某容量不能在原物性域完成，保留失败，不为获得完整结果扩域。

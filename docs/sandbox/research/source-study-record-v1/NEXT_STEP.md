# 接下来完成来源运行服务

完整被动记录是查询与审阅接口；下一项应接入实际运行和取消，而不是继续扩展文件摘要框架。

1. 复用已有来源 N3 求解入口与运行服务，显式保存运行前的数值政策、初态、几何、边界、
   物性/固体配置、来源版本和湿干模式。区分真实来源、制造固体与虚拟设计条件。
   不能由旧进程 object id 或被省略的 adapter/storage 生成恢复权限。
2. 将完整记录写入成功、取消及异常出口，保留所有已经发生的捕获和返回结果。
   运行时保留单次构造、调用和时间上限；被动完整校验不应在每次求值后重复。
3. 根据可重建配置实现新的受控恢复入口，并实际验证当前源文件/参数/模式匹配、
   已消耗预算继承、异常退出、父子关系及累计账本。旧资料缺少关键配置时明确拒绝。
   验证实际执行过的有限来源模型范围，再连接中文界面的运行/取消/失败/查询。
4. 材料工作从已有 Areias2019/2025 提取继续，优先追查同身份材料的产物计量和热效应、
   高温结构演化及冷却本构。TG稀疏曲线与膨胀仪配方连接只作为可核查观测，
   不先拟合一套无法闭合质量/能量的完整反应参数。

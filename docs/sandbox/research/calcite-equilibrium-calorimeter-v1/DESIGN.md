# 等压纯方解石热化学循环：事前定义

目的：将已核对的同USGS热化学接入组成变化与开放CO2流焓的能量方程，检查受热分解、纯CaO再受热、冷却再碳酸化和最终冷却的连续路径。它是纯相瞬时平衡极限，不是含污泥砖动力学；未填补反应速率或目标矿相库存。

固定总压1bar，纯固相活动度1，CO2分压1bar；气体化学库在交换时与单元同温。外部热库温度分段常量，明确虚拟传热系数UA，单元空间均温。等压焓而非定容内能为主变量，因此无需假定高温固体定体积或将298K体积外推。单元本身没有虚构气体储量。

初始n0摩尔CaCO3。H_a=n0 h_CaCO3(Teq)、H_b=n0 h_CaO(Teq)。H低于H_a为纯CaCO3热储；介于两者间时T=Teq、ξ=(H-H_a)/(h_CaO-h_CaCO3)；高于H_b为纯CaO热储。三部分是本同源正热容/正反应焓域的平衡图；含迟滞和有限速度的实际材料不由此推得。

Q=UA(Twall-T)，反应区 dξ/dH=1/(h_CaO-h_CaCO3)，故 Hdot=Q/(1+h_CO2*dξ/dH)，CO2外流=ξdot。负流表示再碳酸化时的CO2输入；生成焓为负的外流焓也可为负，禁止删去参考焓或重复加入反应热。显热区ξdot=0。

积分H、外部热量、CO2摩尔及流焓/流熵和热库熵，核对Ca/C/O、H+流焓−外热、S+流熵−热库输入；传热熵产生Q(1/T-1/Twall)非负。每个相区边界与分段热库时刻记录，稠密多项式独立积分在相区根处分开。保持原运行失败、事前阈值和两档误差对照，达标后才声明本条件循环数值资格。

输入均来自根文件；来源误差按上一阶段保留。适用性只到共同298.15–1200K，不接低温污泥相对能量零点，不声称真实分解起始温度、速率、烧结或砖质量预测。

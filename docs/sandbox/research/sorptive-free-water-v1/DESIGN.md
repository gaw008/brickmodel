# 来源吸附支与自由水的相容条件衔接

状态：条件模型开发；尚无新轨迹/现实材料资格。2026-09-24。

## 来源与问题

[Arlabosse2005](https://www.scielo.br/j/bjce/a/mxGLvLxqCvys7VX4DpCyNvM/?ilang=es&lang=en)的Sorption Isotherm段描述自由/结合水转变接近W=.9。已重新查看原Fig1/2，现有可读曲线节点止于W=.8；Fig2高W总解吸热不直接等于本项目采用的理想汽/实际液水参考焓差。这是有限数据/水参考/量热解释的未闭合问题，不能自动修正原曲线或说文献给出了饱和材料本构。

采用[平衡时约束自由能最小化](https://cantera.org/stable/python/thermo.html)的一般热力学原则。这里的条件延拓是本项目推导，不是该来源提供的污泥关系，不运行Cantera平衡来替代未知材料。

## 决定与其他方案

保留W≤.8的旧源关系和干端能量/熵参考。对更高的**吸附水**Wb，用最后两个源节点的m0=Rs T0 ln aw、b0=L0−q0斜率作明确的线性条件延拓，积分构造同一个过量势。总凝聚水W可在吸附水Wb与自由水Wf间分配。

直接把aw(.8)截成1会使化学势跳变；固定Wb=.9又同时保留非零偏摩尔过量焓，不能保证跨温度热力学相容。两种方案均不采用。当前决定不需要添加经验拟合系数，但“延续最后斜率”本身仍有未知材料误差。

## 推导

令We=.8，δ=Wb−We。最后源段给出m_e、b_e及m′、b′。

```
H_ex = H_e + b_e δ + b′ δ²/2
G_ex(T0) = G_e + m_e δ + m′ δ²/2
S_ex = (H_ex−G_ex(T0))/T0
F_ex(T) = H_ex−T S_ex
A(T) = (T/T0)m′ + (1−T/T0)b′
B(T) = (T/T0)m_e + (1−T/T0)b_e
∂F_ex/∂Wb = B+A δ
Ws(T) = We−B/A
```

在声明温域内核对A>0及Ws>We后，最小化F_ex(T,Wb)，约束0≤Wb≤W，得Wb=min(W,Ws)、Wf=W−Wb。自由水无过量势；两者共享同一纯液标准、同一体积与能量参考。

未出现自由水时保留原μ_ex；自由水存在时μ_ex=0、aw=1来自最小化条件。保存H_ex(T,Wb)和S_ex(T,Wb)，不丢弃饱和后的过量储能。Wb随T变化，包络关系给出：

```
dWs/dT = b(Ws)/(T A)
C_ex,saturated = b(Ws)²/(T A) ≥ 0
```

因此旧“固定组成过量Cp=0”不等于新共存分支的平衡过量Cp=0。相界F/H/S连续，但对总W的H/S导数可跳变；不得为使曲线光滑人为抹去这种相出现性质。原源区与低W支保持原式。

总W恰等于Ws(T)时，固定总水的温度导数有两个单侧值，过量热容量字段为null；不能将任一侧数值当作相界唯一导数。`saturation`内的热容量值专指自由水共存一侧。

1. 根文件明确选择新schema、延拓策略、总W计算域及虚拟初态；冻结源记录并单独实现新provider。旧provider不更改其材料含义。

3. 接入同一刚性N/U水/载气单元。自由水存在时先解pv=pure_pressure的解析库存关系；不发生自由水时保留原单调库存根。分别记录吸附水与自由水，二者之和等于总凝聚水。
4. 实际运行高W→来源W→低W干燥及反向加湿，再做时间/空间、来源、局部能量和完整熵核查。失败原记录保留。

所有输运/几何继续为虚拟参数。无毛细压力、液体迁移、迟滞、溶解盐或化学反应。该阶段只完成可审查的条件相共存内核；不能因此认定Arlabosse真实材料或实际砖坯高含水关系已验证。

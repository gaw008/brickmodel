# 吸附水与自由水连续干燥：条件模型阶段

本阶段新增更高含水下的自由水/吸附水平衡分配，并实际接入已有一维水、O2/N2、内能共享面过程。**四格3600s干燥和单格8400s冷湿—再干燥循环已完成限定验证；4→8→16格的空间精度尚未达标，现实高含水来源曲线对照未通过。**

**追加原图对照未通过：** 新增独立读取Fig2的W=.9、1、1.5、2、2.5五处高含水曲线；纯自由水分支的95°C总解吸热2.281135MJ/kg水，比原图名义读数低约49.98–69.02kJ/kg水，五处均在相应像素/坐标读图区间之外。`high-moisture-source-comparison.json`保存所取原像素、坐标约束与每项差异。这否定当前延拓的高W原曲线一致性；不能用内部守恒通过覆盖它，也不能用未知实验误差宣称通过。没有重拟合或改动水参考。该分支继续只作为明确条件模型，真实高含水材料准入仍未完成。

来源与公式见[设计和推导](DESIGN.md)。W≤.8原关系未改；更高吸附含水的末段斜率延拓是明确材料假设。自由水份额由同一势函数最小化得到，随温度变化的饱和吸附量与过量热容量被保留。没有直接钳制旧aw、丢弃过量能量或扩大原液水/压力计算域。

## 反向加湿与空间比较

根文件 `parameters.sorptive_free_water_cycle.json` 给出独立虚拟边界：W=.3开始干燥，600–620s转入310K、10%水汽的冷湿环境，4800–4820s恢复333K、1%水汽。单格均值W在600s约.0746912，4800s约1.24101，最高1.241451于约4804.08s，终值约.0184879。源区、低W、延拓及自由水四分支实际经过，7个同身份跨界事件被保存。

基础/紧容差的事件差最大2.2991e−5s；进一步收紧后的事件差2.9611e−6s。紧容差全程局部U残差1.1647e−6/1.1699e−6J，超过原1e−6J预算；使用 `parameters.sorptive_free_water_cycle_precision.json` 再收紧10倍后，独立7203个源状态审查及两阶局部N/U/熵核算通过，U残差2.8794e−7/2.8543e−7J，能量积分阶差3.1831e−9J，熵残差3.6225e−10/3.5749e−10J/K，无超预算负熵步。进一步细化两轨迹最大温差2.33284e−6K、总水差1.11008e−12mol、均值W=.1时刻差1.70746e−6s。它只证明这个单格条件循环的相应计算，不能作为空间循环验证。

## 重现与证据

根文件 `parameters.sorptive_free_water.json` 选择新模型；`source-continuation.json` 冻结原来源与条件延拓。运行入口沿用 `run_sorptive_gas_column.py`，例如：

```sh
.venv/bin/python examples/sandbox/run_sorptive_gas_column.py --parameters parameters.sorptive_free_water.json --mesh four --tolerance refined --jacobian-parameters parameters.sorptive_physical_jacobian.json --output /tmp/free-water-new.jsonl
.venv/bin/python examples/sandbox/audit_sorptive_gas_column.py --parameters parameters.sorptive_free_water_audit.json --trajectory /tmp/free-water-new.jsonl --local-balance-parameters parameters.sorptive_local_balance_review.json --calorimetry-state-parameters parameters.sorptive_free_water_calorimetry.json --output /tmp/free-water-new-audit.json
```

七条完整原始轨迹与stderr保留；`first-archive.json` 和 `second-archive.json` 保存有序gzip分块清单，全部逐字节往返相同、末态completed。压缩存储约148MB，不使用SHA。首次JSON编码失败及额外量热探针越界见[失败记录](FAILED_CHECKS.md)。原编码失败前缀保留未完成的行尾空格，因此Git空白核查只对代码/参数/报告执行；不为满足格式检查改变失败原件。

# 液耗尽写回：选择有界存储舍入而非逐操作精确浮点相等

实施前计划，数值部件不是完整事件定位器。选择上轮方案(b)：独立成对±δ的精确事件账本，加单独实际存储舍入残差及不可取消的累计绝对预算。δ是终端panel剩余液量，不是任意epsilon切换；先以panel液初值和已保存液通量/源项的Fraction总和重建末量，必须与输入状态一致且非负。负值不clip。

δ同时不得超过4倍局部液列ULP和、显式绝对mol限、1e-8倍本panel独立记录的正向蒸发积分量。后两项允许显式更严格政策；系数是数值选择，不是物理定律。大气水库存ULP不能扩大δ。原理想液→汽增量为−δ/+δ；实际气水写回由精确旧float+δ只舍入一次，实际差与理想增量之差记录为storage_roundoff，不能再次计作蒸发。它应不超过最终气水float的半ULP，并另受绝对mol预算约束；液列最终0，U及其他列逐位不改。

累计器同时保留有符号残差、绝对残差总和与总数值修正量，用Fraction累计。每事件和全前缀分别检查水摩尔、H/O元素摩尔和质量误差，使用显式同相水摩尔质量和各自单位预算。累计预算不能因正负抵消而失去作用，政策更换不能沿用旧累计器。此模块不声称验证传入的蒸发积分来自真实速率；后续事件积分器必须传其本panel独立诊断，不能用液净流出冒充蒸发。

先RED，再验证：δ=ulp(.01)/2、气水=.1时，实际汽增量为0但−δ存储残差被准确记账；不能因为逐位无法配对而拒绝一个在预登记误差预算内的正常事件。对应预算1e-18mol局部、2e-18mol累计、H元素2e-18/4e-18mol、质量4e-20/8e-20kg；本制造算例水M=.018kg/mol只是质量转换测试，不是原生水物性准入。3次同号丢失超过累计限必须失败。改变大气水库存不能提高δ许可，微小蒸发但面流主导的δ需因相对限被拒绝；负panel末量/与状态不一致/同列/非法值/预算变更都拒绝。正常可表示δ另核对实际增量相等；U/惰性列不变，输入不可变。

完成只关闭事件写回的表示与预算选择，不证明事件时刻、横穿方向、程序节点、共同后续时刻误差或完整湿干轨迹。那些必须由后续完整事件panel和多格主机实际验证，不能由此辅助函数替代。

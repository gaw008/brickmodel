## 2. 连续方程、离散方程与初值投影

用 `⟨f⟩=(1/L)∫₀ᴸ f dz`、`b=Mα²=10 J m⁻³ K⁻²`，有

`e=α(⟨T⟩−Tr)`，`σ=Mα(⟨T⟩−T)`，

`(C−2bT) ∂tT + 2bT ⟨∂tT⟩ = k ∂zzT`，`∂zT(0)=∂zT(L)=0`。

这是非局部、非线性的热弹方程；虽然 k、M、α、C 常数，热矩阵随 T 变化。不得用线性余弦衰减或 α=0 导热解当作它在 t>0 的解析真值。声明温度域给 `93800≤Ce=C−2bT≤94200`，远离近奇异域。

离散 `w=(1/N,…,1/N)`，令 `r=Tdot`，`m=wᵀr`：

`A(T) r=K T`，`A=diag(C−2bT)+2bT wᵀ`。

这里 **A(T) 是热矩阵，不是参考面积**；K 的单位为 W m⁻³ K⁻¹。K 是 `k/h²` 乘以 Neumann 三对角矩阵：两端主对角−1，内部−2，邻对角+1。内部共享面 `F_(i+1/2)=kA(T_i−T_(i+1))/h`，两边界面严格为零；`Q_i=V(KT)_i`。面积在体积热率中约去，在能量／功账中仍必须保留。

初始化必须取 **同一个连续函数的精确格平均**：

`T_i(0)=302 + (2N/π)[sin(π(i+1)/N)−sin(πi/N)]`

`=302 + 2 sinc(π/(2N)) cos(π(i+1/2)/N)`，i=0,…,N−1，`sinc(x)=sin(x)/x`。

使用后一式可避免相邻正弦相减；保存原公式、二进制实际初值及计算方法。严禁中心采样替代格平均、逐网格平移温度或调整总能量。相邻两格算术平均是保守限制算子 `R_(2N→N)`；数学上 `R T_(2N)(0)=T_N(0)`，数值上应只剩舍入量级，归一最大差须≤第5节的 R_T。初始化检查不能用这个恒等式反填一档初值以掩盖独立公式实现错误。

离散自由能闭合使用 u(T_i,e)，不等于每个有限格内连续 u 的精确平均。连续格平均热方程含 `2b cov_cell(T,∂tT)`；冻结算子忽略该格内协方差，光滑解时它为 O(h²)。中央面通量同样有 O(h²) 一致性误差。初值的偶镜像延拓兼容绝热边界，避免边界首格破坏该阶数。由这些局部展开预期二阶，而不是因为网格比恰好为2就预设结果必须通过。

半板总内能的独立连续表达式为

`U=AL { C(⟨T⟩−Tr) − b[⟨T²⟩−⟨T⟩²] }`。

连续初始均值302 K、方差2 K²，故 `U_cont(0)=39.996 J`。对 N≥2，精确格平均的离散初始值则为

`U_N(0)=40 − 0.004 sinc²(π/(2N)) J`，

`U_N(0)−U_cont(0)=0.004[1−sinc²(π/(2N))] J=O(h²)`。

这项投影差必须显式保留。每个绝热离散轨迹守恒的是自己的 U_N(0)；不同网格的恒定总 U 之差主要是已知投影差，**不是动态空间精度证据**。不能让每格或每网格补热来消除此差。长期均匀极限 `T∞,N=302−0.0002 sinc²(π/(2N)) K` 仅作解析背景，不将10秒末态当作已经达到该极限。

## 3. 独立初始连续耦合参照

增加一个无需时间积分的独立参照，避免三档共享同一个错误方程仍表现网格收敛。设 a=2 K、m₀=302 K、`κ=k(π/L)²`、`d₀=C−2bm₀`、`d₁=2ba`，初始 `q(z)=−κa cos(πz/L)`。

由共同模式方程与 `⟨1/(d₀−d₁ cos θ)⟩=1/√(d₀²−d₁²)` 得

`ṁ_cont(0)=⟨q/Ce⟩/[C⟨1/Ce⟩]`

`=−2bκa² / { C[d₀+√(d₀²−d₁²)] } < 0`。

最后形式避免 `d₀−√(d₀²−d₁²)` 的相消。它说明绝热温差松弛中均温因热弹储能变化而下降；普通线性导热的均温恒定不满足此参照。

在各 N 的实际初始点，将候选返回的 `mean(Tdot)` 与该连续值比较。参照从声明常数和独立高精度 π／平方根计算，至少50位十进制工作精度，不能调用候选热矩阵或先读候选均值来构造参照；保存精度和输入表达式。报告三档绝对误差及相邻误差比。误差可分辨时两相邻观察阶均应在 `[1.8,2.2]`，且三档初始均温率均为负。速率尺度固定 `4 K/10 s=0.4 K/s`，速率舍入停止量取 `128·2⁻⁵³·max(1 K/s,max_i|r_i(0)|)/(0.4 K/s)`；若任一归一速率误差不超过其100倍，记录该点参照的 `roundoff_stop`，不编造阶数或将它当作失败的物理定律。

该点检查不能代替10秒动态空间比较；它也不是实验数据。可在正式积分前完成其纯算术审查，但不得根据它反向微调制造参数。

## 4. 解析 Jacobian 与累计状态

对扰动 δT，w、C、b、K 均固定，而

`δA=−2b diag(δT)+2b δT wᵀ`，

`(δA)r=2b diag(m·1−r) δT`。

由 `δ(A r)=K δT`，**提议的导数成立**：

`J=∂r/∂T=A⁻¹ [ K−2b diag(m·1−r) ]`。

符号和因子2不得反转。J 通常是稠密矩阵，不能因为 K 三对角便申报 J 三对角稀疏。构造时独立组装完整 A 并解多右端线性方程，不复用被测源码的低秩回代；N最大64，且只在实际 Jacobian 回调中构造。它是数学 RHS 的导数，不拟合浮点舍入修正的微小跳变。保存真实 `njev/nlu`，不可给 RHS 调用伪造 Jacobian 计数。

为保留同一次积分中的独立热／功／熵账，采用最小扩展状态

`y=[T_N, H_N, W_N, Z]`（3N+1维；N=64时193维），

`Hdot=Q=VKT`，`Wdot=P=2Vb(μ·1−T)m`，`Zdot=Π`，

其中 `μ=wᵀT`，`Π=Σ_faces G(T_i−T_j)²/(T_iT_j)`、`G=kA/h`，H/W 初值为0 J，Z初值为0 J/K。不得由端点 u 或 s 差值反填累计量。绝热外热／热库熵严格为零，记录它们为停用边界的恒等量，无需增加两个恒零状态。

扩展 Jacobian 的非零部分只在 T 对应列：

`J_y = [[J,0],[V K,0],[J_P,0],[J_Π,0]]`，

`J_P=2Vb { m(1 wᵀ−I)+(μ·1−T)(wᵀJ) }`。

对一个内部面 (i,j)，其熵产导数仅加到两列：

`∂Π_face/∂T_i=G(T_i−T_j)(T_i+T_j)/(T_i²T_j)`，

`∂Π_face/∂T_j=−G(T_i−T_j)(T_i+T_j)/(T_iT_j²)`。

用实际块结构构造 CSC Jacobian，避免把所有累计分量作为互相耦合的稠密193维问题处理；但不能删去稠密热块或 P 的全局导数。检查初始非均匀点及预定均匀302 K点的解析方向导数，使用常量、第一／第二／最高余弦方向的独立中心差分和一次半步差分；这是短点审查，不是新增时间轨迹。检查不得仅与调用同一 J 的 helper 自比。若扩展导数写错，应在运行前修复并审查，不降级为错误的稀疏结构。

## 5. 预先固定的空间比较、尺度与停止规则

所有比较先使用每个网格的细时间档。定义在同一16格表示上的两级差：

`d₁₆(t)=T₁₆(t)−R_(32→16)T₃₂(t)`，

`d₃₂(t)=R_(32→16)T₃₂(t)−R_(32→16)R_(64→32)T₆₄(t)`。

限制只作相邻两格等体积平均，不作插值、平滑或重新解本构；不比较不同格中心的点值。所有101时刻均保留，t=0应只有初值舍入差。主度量使用两个独立范数：

`D∞=max_(t,i)|d_i(t)|/4 K`，

`D₂=sqrt[(1/101)Σ_t (1/16)Σ_i d_i(t)²]/4 K`。

分别得到 D₁₆、D₃₂ 和 `p=log₂(D₁₆/D₃₂)`。报告粗时间档的同一计算及每个时刻的差，但不能用其中较好的一档替换预定细档结论。预登记如下：

| 项 | 固定判据与理由 |
|---|---|
| 温度尺度 | `ΔTscale=4 K`；不能用已经衰减的末态幅度作分母 |
| 能量尺度 | 半板 `Escale=CAL×4=80 J`；与已有两格研究相同，不随 N 改分母 |
| 应力／应变尺度 | `Mα×4=400000 Pa`、`α×4=4e−4`；按同一限制算子报告差 |
| 单网格时间细化 | 所有101点 `max|T粗−T细|/4≤1e−7`，沿用原时间门槛 |
| 时间与空间分离 | 对每种主范数，令 E_N 为该网格粗细差的同类归一范数；要求 `E16+E32≤0.02 D16`、`E32+E64≤0.02 D32` |
| 主空间观察阶 | 两个主范数均要求 `1.8≤p≤2.2`；二阶一致性给目标2，有限网格高阶项与已控制的时间／算术污染允许0.2区间 |
| 条件性最细误差估计 | 二阶观察和分离门均通过后报告 `D32/3`，并要求其 `≤1e−4`；这是投影到16格的 Richardson 估计，绝非已知连续真解误差界 |
| 逐格／全局热账 | 所有保存的接受点与比较点，`max_i|V[u_i(t)−u_i(0)]−H_i−W_i|/80≤1e−8`；`|U(t)−U_N(0)|/80≤1e−8`；保持原8e−7 J绝对门槛 |

`E粗细` 是时间细化证据，不是已证明的细档误差上界。其与空间差2%的分离规则避免把时间误差主导的结果报告成空间阶；保守限制在 L₂/L∞ 下不放大差，因此可用相邻 E 的和检查。二阶主项给两级差比4；单边约2%的污染只造成约0.06的阶数变化，0.2窗口不承诺任何材料准确度。若阶数或估计未过，保留实际结果，不能扩大窗口。

对比较后处理采用预定二进制64分辨率尺度

`R_T=128·u·Tmax/ΔTscale`，`u=2⁻⁵³`、`Tmax=310 K`。

最多两次相邻平均、一次相减及补偿范数累加的误差远小于该128u余量；它是输出比较的保守算术分辨率，不是整个 ODE 的严格误差界。每种范数必须满足 `min(D16,D32)>100 R_T` 后才能解释 p，确保此比较舍入占比低于约1%。否则记录 `roundoff_stop/no_resolved_spatial_order`，不增加网格或解释为零误差通过。若时间与空间分离失败，记录 `temporal_contamination`；时间差已经处于舍入尺度也不能删除100R_T要求。任一必须检查未解决，该研究不得报告整体通过。

限制后的应力必须同时与 `σ=Mα(μ−T)` 独立重建值比较。由于该映射线性且平均保守，应力空间差继承温度差的阶数，但这不是第二份独立物理验证。报告均温、方差、自由能、熵、最大拉／压应力及局部机械功；不要把“应力总和为零”当作每格应力或功正确。

## 6. 全期域、独立阶段核验与精简证据

本次不要求保存每次 RHS 的完整点本构 JSONL。每次真实 RHS 均执行候选域守卫，同时只更新在线摘要：真实调用数、温度与 Ce 最小／最大值、应变余量、各独立残差最大值及其时刻／格号／具体输入。失败时保存触发状态和错误；不得吞掉域外试探后继续，或只检查漂亮的输出点。

独立摘要直接从冻结常数与 T/r 构造 K、σ、u/s 导数和功，不调用候选场输出作为参照：逐行 `A r−KT`、`edot−αmean(r)`、逐格 `V udot−Q−P`、`T sdot−q`、ΣP，以及导热面平方形式 Π。避免每 RHS 做稠密求解；这些检查本身只需 O(N) 计算。记录实际残差及固定尺度，不把设置为零的摘要当作核验。

每个网格／时间档仅保存：输入及身份；全部接受时刻与 `[T,H,W,Z]`；101共同点；真实 `nfev/njev/nlu`、RHS包装器计数、终止原因、墙钟时间；上述阶段摘要、独立重算的各接受点／比较点账本和比较结果。接口输出的扩展字典无需每阶段重复序列化。接受状态来自求解器实际接受点，不能将 `t_eval` 的101点冒称所有接受点。

全期同域不能由101个采样点证明。除了所有实际 RHS／接受点的守卫，检查每个已接受 BDF 稠密插值段在完整时间区间内的温度包络：使用实际插值多项式的系数，对每个线性因子作区间界，再逐项区间乘加，得到保守温度范围；保存各段范围或最坏段与其多项式证据。必须包含浮点向外舍入，不能仅等距采样声称区间界。区间包络完全位于[290,310]才确认该数值轨迹全期同域；包络不够紧时记 `unresolved_dense_domain`，本次不自动加步重跑。此项只需读取现有 BDF 连续输出的低阶多项式，不另建积分器。数学上的连续解域和数值插值段域仍是不同命题。

在这段温度域内，所有凸平均温度也在同域，所以共同应变与热本征应变绝对值≤0.001，弹性差应变绝对值≤0.002，自动严格小于0.01；仍保存候选实际应变检查。Ce≥93800有同样的域推论。无论内部迭代、接受状态还是插值，均不允许裁剪温度。

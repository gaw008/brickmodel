# 分支解析Jacobian：静态与4/16格路径已核

相同物理库存、反应平衡与面交换方程下，解析稀疏Jacobian已通过6组状态、6组交换面及4格整列导数核查。差分尺度、单位缩放和预算在运行前登记于`parameters.calcite_rigid_tangent.json`；三个差分步均满足1e−5的缩放绝对误差目标，没有只挑最小误差的步。

最粗步1e−3时，状态导数最大误差6.25e−8、交换面5.30e−7、整列8.11e−9；缩小到1e−4后分别约6.26e−10、5.27e−9、1.03e−10。所有扰动保持所选相分支。熵Hessian对称性和半负定性通过；共存态的约1e−21量级正/负零特征值按浮点残差记录，未声称严格负定。

4格和16格各完成6000s全过程。与原物理库存差分路径相比，16格最大单元温差1.03e−7K、压差.00801Pa、总CaO差2.61e−14mol，均在原时间/路径预算内。两条解析轨迹的完整来源重组、逐格C/N/U积分、熵积分和2/4阶求积一致性全部通过。原路径和原失败证据保留；没有把解析导数的通过用于覆盖空间误差。

运行时间受并行任务与机器负载影响，本记录不据此声称普遍加速。64/128格扩展在执行中，不能沿用4/16格结论提前宣布完成。

方程、分支内导数以及预算仍属于来源约束的条件模型。源固相体积恒定、气体理想混合、瞬时相平衡和虚拟输运系数的限制全部保留；没有真实反应速率、砖孔网络或实材验证结论。

## 稳定回代与守卫

修复利用 `D_i+c_i=C` 将共同模式写成逆 Ce 加权 q 均值除以 C。正权按 min(Ce) 缩放；q 同时保留补偿加权均值和中心差，分别用于共同模式与对比模式，避免先相减两个大共同项。零 q 直接退化为静止状态。

回代后仅向最低 Ce 格作一次共同模式的舍入修正，并从**实际返回的 Tdot 场**重新计算ė。随后以 q_max/C 为共同模式尺度、q_max 为逐行热方程尺度，按 `64*ulp(1)=1.4210854715202004e-14` 检查共同模式和每一格 `D_i Tdot_i+c_i mean(Tdot)=q_i`。失败明确拒绝。该界是数值可表示性政策，不是材料或轨迹容差；它没有放宽原正式研究门槛。

修正不改温度状态、外部热流、参数、内能或机械功账本；它也没有把 `u_rate` 重建成 Q+P。u/s 的导数仍独立来自势函数，局部 `2Vσė` 和含热库的熵收支仍可独立核验。因逐行原热方程在修正后再验，此操作不能仅凭总功/总能量抵消掩盖局部误差。

# 对称自由平板：实际热弹性耦合验证

**限定的温度—应力双向耦合已经实现，两条事前登记的安装版轨迹通过温度、局部／全局能量及时间细化门槛。** 这是常系数制造试件的方程与数值验证；同材料热力参数、连续空间收敛、真实砖边缘力学及完整烧成仍未由此验证。

## 实现及方程含义

新增 `CoolingThermoelasticPlate` 以半板各格温度为状态。各层共享面内应变、零膜力；本构同时计算热应力、Helmholtz 自由能、内能和熵。每次求值共同解温度与应变速率，热弹反馈不是积分完成后的应力后处理。内部共用面及外表面半格热阻复用既有导热函数，中面绝热；局部约束功与导热分别记账。

对常 M/α/C，`e=α(Tbar−Tr)`，`σ_i=Mα(Tbar−T_i)`。内能含热弹熵项：半板 `U=CΣV(T−Tr)−Mα²ΣV(T−Tbar)²`；不能把正弹性自由能直接重复加进旧热内能。每格满足 `V*udot=Q+2Vσ*edot`，宏观零膜力仅令总机械功为零。方程推导、原理来源和限定边界见 [NEXT.md](../cooling-stress-next-v1/NEXT.md)。本轮未引入水 EOS、反应或伪造的材料常数来源。

主状态单位为 K，与旧 `ConservedState.internal_energy_j` 的 J 状态分开。该新算子尚未接入旧总能量逆解服务，亦不输出厚度收缩、强度或开裂概率。

# Baloi 2025：同批污泥砖终态与热物性证据

原文：Baloi AM, Streza M, Belean B，2025，*Light microscopy image segmentation using active contours driven by local image information for environmentally friendly fired-clay bricks design and characterization*，DOI [10.1371/journal.pone.0328270](https://doi.org/10.1371/journal.pone.0328270)，PLOS One，CC BY 4.0。已核读出版商 HTML 与 JATS XML，原字节保存在 `data/sandbox/research/baloi2025/originals`。此证据补充先前来源矩阵，不将不同研究的污泥拼成一种材料。

## 可复核的配对数据

材料来自 Aquaserv Târgu-Mureș 污水处理单位，配合黄/灰黏土基料和另一种灰。Table1 为五组体积配比，污泥分别0/5/10/12/15%，灰固定15%。缺各原料实际堆积/颗粒密度，因此没有转换成干质量配比。原料90°C干燥16h，成型添加约20wt%水的分母仍不充分，不能自动作为湿基含水率。

§2.1 给出1.96MPa成型、80×40×15mm砖坯、90°C干燥约12h、2°C/min升至900°C保温5h、分段冷却。终态测试使用切取的15mm立方体；大坯与小立方体的尺度不可互换。

Table2 含五组密度、抗压、质量吸水率及不同方法的孔隙指标；原有空格/破折号与标准差单独保留。Table3 的热扩散率与热感受率来自测量/拟合，导热率由 k=e√α 推得。§3.3 的测温场约26–41°C，不能据此填充900°C烧结过程的物性。由 e/(ρ√α) 可再推导表观比热，但这是同质有效导热假设下的新派生值，不是原文直接量热实测，也不是湿坯或组成相的比热。

`extract_tables.py` 逐格保留原表文本和全部单元格属性；本文件三表没有 rowspan，空不确定度格保持为空，重算五组 k，并把其与出版值的差保存，未修改原表以强行一致。α列是带10⁷缩放的列，恢复SI时乘10⁻⁷；ρ从g/cm³乘1000。出版的±2%至±5%未说明逐量完整协方差，不能凭此生成派生比热的统计置信区间。

## 不能据此填充的必需机制

| 机制 | 本文证据与限制 |
|---|---|
| 原泥身份/初态 | 地点、预干燥和体积配比可追查；成套CHONS/矿相比例、含水基准及原料密度仍不足 |
| 热解/氧化 | §2.3/§3.2 为Ar、10°C/min的TG/DSC；正文却使用燃烧归因，不能当空气残炭氧化动力学或凭峰分配气体产物 |
| 干燥 | 只有制样温度/时长，缺水分随时间、迁移/毛细关系和热湿边界 |
| 烧结/几何 | 有炉温历史及终态，缺动态收缩、液相黏度、连通性/渗透率演化；终态孔隙不能直接当开孔输运参数 |
| 热物性 | 同批终态低温测量支持限定对照；不能跨到湿坯、高温或另一污泥 |
| 力学 | 终态强度数据可作材料终态对照；没有温度相关应力本构或破坏概率证据 |

还应保留原文内部差异：§3.1 一处MIP孔隙范围与Table2末行不一致；末段关于小于2µm孔不被MIP测得的说法，与同节列出的约3nm下限不一致。原表与陈述分别保留，不择有利者补模型。

结论：新增了同一研究五组配比—密度—热测量—终态性能的可追溯数据，可以支撑后续限定终态/导热对照；仍不构成原污泥全周期关键参数包，也没有完成独立预测验证。

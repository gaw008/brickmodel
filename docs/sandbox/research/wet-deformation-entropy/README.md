# 湿态独立熵参照与未通过的短前缀

原始源、计划、测试、失败、子进程状态、点结果和实际轨迹均在 `original-evidence.zip` 中；归档逐个读取核对字节，成员大小/哈希见 `archive-manifest.json`。临时 Python/pytest 缓存未归档。计划、结果和两份审查另有原字节可读副本。

**结论：实际短前缀组件精度失败。** 独立10%压缩端点求根成功不等于10%全过程积分。实际主机仅走原运动曲线的0→1/64秒；孔隙压力功误差2.97406436e-6J超过原1e-6J，温度/压力和总账本通过没有改变失败结论。没有删除失败或放宽门槛。

独立结果审查离线重算60个来源/产物绑定以及实际接受步的有理账本，未重跑EOS。它指出原runner虽记录子进程exit1，自身并不传播非零退出码；固定文件名没有唯一尝试ID；原生产源哈希未绑定导入的测试fixture；原始液体u/s操作数未逐个保存，因此不能只用归档离线重算所有EOS参照值。保留这些局限，不能将原报告中“唯一尝试”的叙述称为由目录独立证明。

此处使用明确制造的固体、载气、几何和固定相库存极限，以及真实来源校验的纯水物性。它不提供原污泥物性、活跃蒸发、自由烧结、材料有效性或完整砖烧成的验证。未执行的450秒提案保留在包中，后续运行需单独登记实际成本、输入和门槛。

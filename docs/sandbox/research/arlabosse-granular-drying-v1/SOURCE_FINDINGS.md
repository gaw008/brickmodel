## 与35–95°C湿热域的交集和Goal贡献

**已确认的是含水域交集0.15–0.32；没有确认Eq3速率定参时的料温落在35–95°C。** 2005工业夹套只写约6bar饱和加热蒸汽，实验室恒转速装置没有给Fig3的料温/壁温/气氛数值；不能从加热蒸汽压力倒推料温，不能将2002的120–160°C调控温度或120°C扫气温度改作2005料温。原文95°C标签属于aw/q图，不属于Fig3或Eq3的速率工况。

同篇2005没有给可用于当前材料的导热系数、内部有效扩散率、毛细迁移或渗透率方程/成套参数。2002的钢板导热率属于设备，不是污泥导热率；其热传递h又依赖接触覆盖，不能塞入砖体内部传输。本文推荐的经验F只是搅拌设备条件下的面积归一化总去水率。

因此95°C等温方案是**明确控制料温、以出版经验率作为未验证工况迁移假设的设备研究情景**，不是已证明同条件重现。应同时声明维持足够低水汽分压的开放排汽边界；若给定气相分压高于模型平衡分压，不能继续将净蒸发方向当作物理可行。尤其不能复制2002常压纯蒸汽环境，再声称95°C低活度泥可在该环境中按这条率持续蒸发。不需要为了条件研究新造传质常数，但缺气相/料温记录也不能被一个“误差unknown”字段隐藏。

该增量实质推进的是P04的**声明设备经验速率**、P05的速率—出水—物流焓/净热需求接线，以及V07的同料源曲线复算/对照准备；库存变化对q和所需功率的反馈可检查。它不关闭砖内热湿传输、温度反过来影响速率的完整双向耦合、P16整体、同料独立工况验证、M04或§11。无需将旧 `source_wet_column` 的制造输运、纯水μ或变压U路径改标签接入这个1bar定温焓案例。

## 必须保留的原公式矛盾

Eq4给 `mdot_DM*dW/dz=-(A/L)F(W)`。将Eq3代入，正确的该ODE解应为：

```text
W(z) = [Wt+b/a] exp[-a A (z-zt)/(mdot_DM L)] - b/a.
```

但出版Eq6图像打印的是 `Wt*exp[-a A(z-zt)/(mdot_DM L)]`，没有b。它对应F=aW，代回含b的Eq4留下非零残差。这个结论是代数核对，没有运行/拟合工业曲线。**不能静默把印刷Eq6叫作Eq3的解，不能为复制Fig4线而把b偷偷归零。** 允许分别保存“出版表达式复算”与“Eq3+守恒推导的解”，并比较它们；后者必须明确是派生修正，不称作者勘误。

另一个范围问题：按打印paste通量12.44、A32、mdot267、L4.08、入W1.5，paste段质量平衡在zt1.43处为 `Wt=1.5−12.44*32*1.43/(267*4.08)`，约0.98，超过Eq3打印上界0.32。工业颗粒区又明确减少实际接触面积，但没有完整面积分配数值。因而当前资料不能同时把原全长几何、所有系数和全部打印范围当成无歧义的全长模型。限制到独立指定的颗粒含水段，能够避免强行消除这些矛盾。

## 最小动态实现：先按受热面积归一化，实际时钟显式条件化

定义 `theta=A_contact*t_h/m_d`，单位m²h/kg干物；此处A是**定义清楚的归一化加热面积**，不是自动等于实时实际接触微面积。原式直接给：

```text
dW/dtheta = -(aW+b)
W(theta) = (Wi+b/a)*exp(-a*theta) - b/a
theta_stop = ln[(aWi+b)/(aWf+b)]/a
```

这个面积—时间/干质量坐标可直接计算，无需虚构初始批式装料或局部工业持料。如果需要秒为单位的时钟，必须显式提供 `lambda=m_d/A_contact`；`t_s=3600*lambda*theta`。lambda可以是明确虚拟设计选择，但不能标成2005实验实测装料。0.20m圆底面积可以作为几何推导，不能同时证明Fig3的干装料。工业5.5h整体平均停留也不直接给局部theta，除非另声明均匀持料和接触面积近似。

建议首例Wi=0.32→Wf=0.15（声明截取/研究选择），控制材料T=95°C、P=1bar，接当前 `ArlabosseWetThermodynamics`。计算：

```text
water_out_kg_s = A_contact*(aW+b)/3600
dW/dt_s = -water_out_kg_s/m_d
required_net_heat_W = water_out_kg_s*q_model(T,W)       [isothermal controller]
dH_total/dt_s = required_net_heat_W-water_out_kg_s*h_v(T)
```

净供热是为维持指定料温所需的模型输出，不是已知工业加热功率、蒸汽耗量或电耗。将该净热输入和水汽携焓放入既有H→T反解，验证其保持控制温度与完整账；不要直接覆写T来掩盖能量错误。`isothermal_drying_heat` 可提供与速度积分独立组织的有限去水热对照，但同一物性数据/假设重用不是外部热验证。

这一步新增的是**有出版系数的去水时间尺度/热功率耦合**，不是又一个q或aw getter。允许做上述条件探索；尚不能说这个95°C控制条件继承了原试验的定参工况。不得增加无出处的Arrhenius温度因子、`min(经验率,供热/q)`开关或默认传质系数来补未给出的工况响应。若转入自由料温预测，需要同协议净供热/换热边界和速率温度/气相适用关系；本轮资料未补齐。

当前公开API可复用：`evaluate(T,W)` 返回H、Cp、q和蒸气h；`inverse_enthalpy(target_j,dry_mass_kg=...,moisture=...)`；`isothermal_drying_heat(...)`。建议新增一个受域限制的 `ArlabosseGranularFlux`（来源系数、单位、原范围、误差unknown），以及一个使用现有积分/报告接口的去水热负荷案例；状态至少为W、总H、累计出水、净热和水汽携焓。停止于W=0.15或当前物性域退出，不能借负W截断继续蒸发。无需新增水EOS、孔容、砖扩散或机械主机。

## 什么能拟合/对照，什么不能叫留出

- **Fig3可用作同料速率曲线数据。** 后续若要检验Eq3，应先登记W取点、像素读界、kg/s与面积基转换及Eq3比较范围，再数字化。比较出版系数和同文曲线只是源模型复算；作者具体定参数据不明，不能把某些像素称未参与作者拟合的条件。曲线由Cp/q/电热信号推得，与当前Cp/q存在方法依赖，不是独立量热验证。
- **Fig4可用作工业空间观测。** 图点可独立提取，保存Eq6印刷表达式与含b守恒模型的实际差异。缺失的局部有效面积、料温和参数估计过程须保留；不以修正b、转换点或面积逼近原线然后称预测。若重新拟合，只能对事前留出的空间点作同一次剖面内部检查，不能称独立工况或批次验证。
- **当前同2005料没有已确认的未调参完整热历史。** 仅本篇就不能保证获得独立干燥动力学留出；事实应如此报告，而不是因此禁止条件模型。
- 若下一步明确需要一个多工况速率验证模块，而非优先同2005湿焓连接，Ferrasse2002的壁温/转速/装料曲线可另建其**厌氧消化市政泥**材料域，预先留出一个完整温度或转速条件；不能把它当当前活性混合来水污泥的直接验证。该替代域的数据提取/适用性审查尚未执行。

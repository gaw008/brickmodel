# 石墨与C/O/N气体：来源及名义热力学核查完成

新增核读USGS Bulletin2131的石墨、O2、CO原Cp系数和298.15K参考H/S，复用此前同书CO2/N2数据。原PDF第47/49/53/82/106/186页已渲染并目视核读；官网本次返回403，使用已有官方PDF缓存，未声称重新下载成功。源页、打印数字、数据选择和核查参数均保存。来源：[Robie and Hemingway1995](https://pubs.usgs.gov/bul/2131/report.pdf)。

在明确选择的298.15–1200K范围，五相名义Cp公式与50位直接Cp/Cp/T积分比较全部达到事先数值目标，最大H/S误差分别2.634e−11J/mol、4.534e−14J/(mol K)。49个原表温点的Cp、S和(H−H298)/T均落入各自.005打印半单位；这只是名义源算术，不是实验误差或拟合协方差。

另外以运行时二进制系数的精确有理数核对Cp正性：令z=√T，则z⁴Cp为8次多项式，在覆盖整个温域的z∈[17,35]上分64段计算Bernstein系数界。石墨、O2、CO、CO2、N2的全域下界分别7.7005、27.4976、27.2675、34.4190、27.3055J/(mol K)，均严格为正。覆盖区间稍宽只是证明方法，不扩大运行物性温域。

CO来源差异保留：[NIST-JANAF C-093](https://janaf.nist.gov/tables/C-093.html)在同298.15K、1bar下S=197.653J/(mol K)、Hf=−110527J/mol，而本书原行197.27、−110500。分别相差+.383J/(mol K)、−27J/mol，没有把一个数据库的S偷偷混入另一套模型；也不从该差异推断哪套真实样品误差为零。CO的本书系数表上限2500K、单相表描述2200K不一致，本阶段上限1200K落在两者内。

石墨是纯参考晶体，不能等同于污泥焦的反应性、灰分或结构。当前只具备来源势函数的名义计算基础；没有运行新平衡组成或热过程，没有有限反应速率、真实材料或训练资格。下一阶段见[限定计划](PLAN.md)。

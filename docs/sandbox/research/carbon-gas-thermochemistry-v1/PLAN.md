# 下一独立阶段：有限C/O库存的1bar平衡气氛

目标是给定纯石墨及C/O/N元素库存，在标准压力、298.15–1200K计算C固相与CO、CO2、O2、N2理想混合气的受限平衡；随后才连接同一闭合库存的定压热循环。它是有限氧/剩余碳如何改变热力学平衡的来源条件单元，不是点火或实际焦氧化速率模型。氮在本模型中惰性；其他碳物种、原子/离子、氮氧化物、非理想气体及真实焦缺失均需声明。

先采用本阶段通过核查的同书名义H/S/Cp，保留NIST差异。运行压力固定为来源标准压力，不借未知固相体积修正扩展压力。纯固相μ=g0，气体μ=g0+RT ln(p/p0)，C/O原子库存严格配平；没有反应热填零或独立重复热源。

两种分支可由Gibbs最小条件导出：定义K1对应C+O2/2→CO，K2对应C+O2→CO2，q=√(pO2/p0)。有石墨时pCO/p0=K1q、pCO2/p0=K2q²；以rO=N_O/N_N2和总压比Pbar=1，正根满足(rO+2)(K2+1)q²+(rO+1)K1q−rO Pbar=0。稳定正根可写为2rO Pbar/[b+√(b²+4arO Pbar)]；由氮库存恢复气体量，并核对剩余C非负。

若该分支所需气相碳超过总碳，则固碳耗尽。设c=N_C/N_N2、o=N_O/N_N2、z=pO2/pN2、q²=Pbar z/(1+c+z)、w=(K2/K1)q。由元素和反应平衡求c[1+w/(1+w)]+2z−o=0，再恢复nCO=N_C/(1+w)、nCO2=N_C w/(1+w)、nO2=N_N2 z。函数对z单调；用解析来源的正下界及z上界(o−c)/2括根，不截断物种、不补氧。固相不出现时核对其KKT不等式；出现时核对两反应ΔG=0。

静态验收先于热循环：独立高精度同时解元素/化学势条件，核对C/O/N守恒、气体压力闭合、相存在/不等式、各相源H/S，以及受限Gibbs凸性。理想气混合Hessian为RT[diag(1/n)−11ᵀ/n_total]，固定正氮库存排除齐次零方向，可用KKT证明所列物种集的受限最小。它不等于包含所有可能物种的全化学平衡。

之后用H(T,固定元素,p0)驱动dH/dt=Q的定压过程；初态必须已经是该模型的平衡态。氧气和碳在低温下已反应至平衡，不得把这一瞬时初始组成当作有限时间点火。升温可使CO增加并耗尽碳、冷却可重新析碳；相分支H/S连续和热容需独立核查。元素、热量、熵、相界事件和精度收敛逐项验证后再推进空间或其他耦合。热循环参数及数值预算须另立根文件冻结，当前没有热循环成功结论。

# 方解石颗粒降阶来源的执行条件

[Reineking等2023作者预印本](https://arxiv.org/abs/2311.15279)全文及PDF第3页已读并目视核对。当前版本的质量方程将正ṅ作为CO₂来源，但所印速率与(cCO₂−ceq)成正比；在分解条件c<ceq下，若其余系数取正则方向冲突。YTC的完整定义以及k₀、EA的数值未在该版本中补全，不能自行补造或反号后声称原模型复现。

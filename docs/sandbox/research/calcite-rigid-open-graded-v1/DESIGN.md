# 非均匀开放反应列：先验方案

均匀16→32格完整比较失败，表面温差最大出现在t=0。单独改变半格边界距离的17点计算显示，需要32768→65536等效均匀格数才满足原.2K表面差。这是初始不相容边界的空间分辨率问题；没有删除初始观测或提高预算。

方案采用2cm平面列，内部32等宽格，最后0.625mm用16格、相邻宽度比.6向外表面加密。之后对每个原格等分2/4/8，得到48/96/192/384嵌套格。宽度向量、生成参数、所有误差要求先登记在根JSON。最小格约1.176e-7m；它是数值长度，不是实测孔径或材料粒径。

每格元素、内能与热容量按实际体积；内面距取两个中心的距离，外表面距为最外格的一半。相邻格使用同一个交换量、异号记账；原热力学、Onsager有限力延拓、辐射和反应平衡保持。每面系数随几何重新计算，导数也使用该面系数。[NIST FiPy有限体积说明](https://pages.nist.gov/fipy/en/3.4.5/numerical/discret.html)给出体积储量及AΓ/d中心距通量；本文只采用此数值几何关系。原流焓和组分的对称平均保持，并未声称为非均匀网格上的高阶面插值。

全域均温/均压采用体积权重；细格投影回粗格也按实际体积，元素摩尔数直接相加。固定截面使长度权重等价于体积权重。log-N2的参考量只定义坐标，仍取平均格体积对应库存，不改变每格实际库存。C与U绝对误差按格体积缩放，log-N2和外部账本预算保留。

先核查三种非均匀静态场的导数、局部/全局收支、熵，再核查48格两档12000s完整路径及全程来源与2/4阶局部积分。其后做嵌套空间比较，保留原时间和空间预算。任何失败均留存，不授予实际砖坯或有限反应速率资格。

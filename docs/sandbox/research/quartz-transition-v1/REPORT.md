# 纯石英定压相变热循环：限定数值核查通过

本单元能计算0.01mol纯石英从300K受热、在847K吸收相变潜热、继续升温，再冷却并放回相变潜热的9000s过程。外界先1000K后300K，热导率参数实际为虚拟装置的总热导G=.001W/K，未赋给真实砖。采用标准压力下dH/dt=Q，未把Cp当作定容Cv，也没有体积、应力或裂纹预测。图示为[最终较紧精度轨迹](cycle.png)。

[NIST WebBook](https://webbook.nist.gov/cgi/cbook.cgi?ID=C14808607&Mask=2&Table=on&Type=JANAFS)提供两段原Cp系数；[JANAF O-037](https://janaf.nist.gov/tables/O-037.html)847K双行的焓差为728J/mol。原拟合h/S在相界不是严格同G，故本表示明确从298.15K参考积分原Cp，并以该潜热和ΔS=L/T连接两相；两相区用焓决定比例，温度固定847K，不抹平潜热。Cp系数不变，参考调整并非新的测量。

相对于原拟合h/S，α常数偏移约+3.06238J/mol、+.00324361J/(mol K)，β约+1.93534、+.00567892；这些值已逐项存档。原JANAF十个温点的最大Cp/S/焓增量差分别.00482491J/(mol K)、.00603975J/(mol K)、2.93061J/mol，并非全落入打印舍入区间。没有来源拟合误差/协方差，不能宣称这些偏差是实验允许误差。USGS1995记录844K，另行核读保留为不同来源，不混合替代NIST847K。

独立50位直接Cp及Cp/T积分、两相G相等核对通过。按运行时系数的精确有理数作导数下界，298.15–847K及847–1100K两段Cp均单调为正，下界44.5843和67.4167J/(mol K)。故单相d²S/dH²=−1/(T²Cp)<0，两相区dS/dH=1/847，接点斜率连续；这属于该名义定压热力学表示的关系，不证明真实动力学。

基础精度累计热积分最大1.2494e−7J，超过原1e−7J目标，该失败保留。后两档独立全程来源、热量/熵积分、2/4阶求积及四个相界事件全部通过：累计热差最大1.03005e−8/2.38334e−9J；4500个共同时刻最大温差1.13766e−8K、相分数差1.39443e−10。原目标未放宽。

相变在加热段持续47.581699s，冷却段13.308958s，分别对应同一7.28J潜热和不同温差产生的热流。事件时刻还用独立定压量热积分核对。无相变速率、滞回或样品传热实验资格；同材料矿相量和真实砖全周期仍缺失。三条完整记录共约8.17MB压缩，逐字节还原一致；源路径导入和NumPy布尔序列化错误及修正记录均保留，未执行软件测试或SHA操作。

## 独立算术与物理含义

仅用 Python 标准库对已有像素坐标作有理数运算；未调用原 `extract.py` 或任何模型。沿用原轴标定：

\[
t=9600(x-133)/(1125-133)\ \mathrm{s},\qquad
T=273.15+140(y-843)/(49-843)\ \mathrm{K}.
\]

中心半宽来自每条原记录，轴端半宽 1 像素；对中心和两个轴端的八种端点组合求最小/最大值，再换算 K。与旧文件保存小数的最大差分别约 4.84e−10 s、4.66e−10 K；上下界最大差约 4.99e−10 K。差异来自保存舍入，**不是模型精度或实验精度**。温度平移不改变温差读取半宽。

温度实验 SD 没有提取，保留 null/空值。原文 STDEV.P 散差、温度仪器不确定度、像素读取界是不同量；不能用约 0.705 K 的读图界宣布预测合格。数值小数位只用于复算，不增加测量有效位数。

Table 3 给出 2→1.42 cm、4→3.31 cm；从表中舍入直径复算线收缩为 29% 和 17.25%，原表的平均收缩为 29.2% 和 17.4%，两者都保留，不能把均值/舍入差擅自更正。若仅为估算而假设各向同性球形，则面积比为 0.5041、0.68475625，体积比为 0.357911、0.566635796875。**这些比值是几何假设下的推导，不是独立体积测量或动态收缩规律。** 它们说明固定几何不能被无条件当成此来源的真实过程；尚未量化其对预测温度的误差。

## 输入缺口与可辨识性

`benchmark.json` 的 `parameter_evidence` 逐项保留来源、角色及缺口。当前已知的是名义热风条件、初始几何、部分温度观测和终态几何。关键问题如下：

1. **初态/库存：** 4°C 是储藏温度，23°C 是室温，都不是逐颗粒初温测量；约 4.2/34.5 g 是按尺寸给出的概数，未按 MSJ 各次温度实验配对。Table 1 的含水数字不能在缺完整基准说明和逐样质量时生成已验证的初始水/干固体库存。
2. **边界：** 室内 23°C、50% RH 不能原样作为 138°C 热风 RH。若从室内湿度推入口水汽压，需要明确取气、加热、无增湿/漏气及压力假设。速度不是换热/传质系数；接触支撑、辐射、壁温等影响未定。每 3 min 旁通 15 s 针对称重协议，不能未经确认复制到分开的温度实验。
3. **材料本构：** 同批次的储能/比热、导热、持水/水活度、传质或其他可替代的闭合关系及其适用域未知；没有为它们指定 Arlabosse/Mäkelä/Septien 参数。是否必须逐一测量取决于后续选定方程和可辨识分析，不要求在选模型之前填满所有可能物性。
4. **几何与误差：** 终态直径不定义半径随时间变化、孔隙演化或收缩功；完整重复轨迹、温度测量不确定度及真正独立的对照仍缺。4 cm 的另一尺寸不是自动独立验证：两组都已暴露。

温度点本身不能保证本构可辨识。一个受限反例是无相变导热模型 `C_vol ∂T/∂t = k ∇²T`，边界 `−k ∂T/∂n = h(T−T∞)`：把 `C_vol,k,h` 同乘任意正数，温度解不变。这个尺度不唯一性的代数论证只针对该简化方程，不能当作湿颗粒完整模型的证明；它足以说明“拟合出温度”不能自动验证每个物理参数。未来模型必须针对自己的方程与实际可观测量另作辨识判断。

# 二元碰撞黏度：原文复算与混合数据交叉核对

实现Vogel/Bich/Hellmann2023的零密度一阶Chapman–Enskog方程13、15、17。方程页9已视觉核对；A*取其表5的非球形势计算值，仅在表列253.17–473.30K的8个温度使用，不插值、外推到600K。

生产公式消去H矩阵分子/分母共有的x₁x₂因子，因此纯组分端点具有解析极限。独立80位审查直接构建原文H矩阵求解；80组公式核对及56组极限/物种交换核对全部达到1e−13相对预算。

三类结果严格区分：

- 用表1纯气值和表5逐组成反推η₁₂回放表1：24/24达到1e−4舍入复算预算，最大1.3593e−5。表5由同一批混合测量反推，这只是来源复算，不能叫独立预测。
- 用Crusius2018独立稀薄扩散关联式，经式31和表5计算势A*转换η₁₂，再用表1纯气值预测混合值：24/24在既定0.5%筛查范围内，最大0.29960%。没有拟合混合测量。
- 换成CO₂2017/N₂2004纯气关联式：24/24在相同范围内，最大0.20195%。这是与混合黏度观测的交叉核对，但不表示全部来源彼此统计独立，也没有给出完整传播不确定度。

以摩尔质量M代替单分子质量m，式31写作ρD=(3/5)(1/M₁+1/M₂)A*η₁₂，ρ是摩尔密度。实现使用明确的Pa·s、kg/mol、mol/(m·s)，没有遗失阿伏伽德罗因子。

该一阶构造不等于原论文完整三阶多原子输运计算；没有致密气体修正，也不覆盖CO/O₂或真实砖孔。先完成限定温度的物性来源与计算核查，后续才能另立孔隙算例。数据根参数`parameters.co2_n2_chapman_enskog_source_review.json`，全部逐项结果`data/sandbox/research/co2-n2-chapman-enskog-v1/review.json`。

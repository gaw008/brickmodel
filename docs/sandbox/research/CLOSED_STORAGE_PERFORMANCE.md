# 闭合反解首个性能定位

采用 `tests/sandbox/test_rigid_storage.py` 的明确制造流体腔：2 mol 液水、0.01 mol 载气、目标为 300 K 的实际储能，温度括区 295–310 K，InversePolicy(1e-5 J, 1e-4 K, 100)。运行一次 cProfile，仅定位开销，不将带 profiler 的耗时当裸运行基准或生产吞吐保证。

实测反解报告 2 次迭代，温度 299.999999999996 K；实际总计 5 次储能前向计算、205 次 state_tp、200 次压力 trial 和 205 次 saturation_pair。记录约 752095 次调用、1.543 s profiler 总时间，具体函数与绑定源码见 `closed-storage-profile.json`。

主要开销来自每个压力试算重新调用水 EOS，其中相同温度的饱和对检查重复进行。压力闭合当前采用保留最终括区的二分法，约 40 次试算/前向计算。该测量支持下一步研究有界缓存相同温度饱和对、复用相同试算结果或保括区的加速求根；尚未实施任何缓存/算法替换，未放宽容差。

优化必须保留水来源身份、数值政策、不可变返回值、域/失败处理与原压力括区证据。缓存应有容量上限、按完整身份区分并检验实际调用量和数值一致性，不能缓存一次失败为成功或用粗温度量化替代 EOS。下一阶段先优化这一实测热点，再测多格与真实相变积分成本。

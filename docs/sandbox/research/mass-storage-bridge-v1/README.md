# kg 固体与 mol 流体的实际热反应桥接

`mass_storage_bridge.py` 将固体质量与气体摩尔库存分别保存，调用实际 RigidStorage 干气体闭合，用同一总内能反解温度与压力。固体采用明确制造的常数 Cp 和比体积；参考能量来自完整质量反应网络。人工 A+O2→2B 路径按同一质量反应进度增减库存，耗尽氧气时反应为零。化学参考热率仅作诊断，不重复加到封闭体系总内能。

原始候选有三个实际审查失败，均保留 RED 和修前源码：named O2 可被错误声明为碳；浮点残差向下舍入可误过原能量门槛；原始 q 为未知但参考锚点已辨识时诊断调用 float(None)。最终版分别绑定真实气体元素、以精确数值比较原验收边界、读取可辨识反应热泛函。原科学门槛没有放宽。

最终源码 cc98bc97、正式测试 5a612eec 获独立审查批准。独立11测试包括三原攻击及9个状态的有理数 T/P 界复核；正式portable10测试不依赖未跟踪的来源缓存。原文缓存核验另由 `data/sandbox/research/mass-storage-bridge-v1/verify_sources.py` 完成，O2/N2 的名义摩尔质量来源与未知测量不确定性保留在相邻事实文件。

Root 实际执行正式混合桥、质量参考、单位及来源注册表测试：源码68 passed / 3.05 s；非 editable 安装版68 passed / 3.01 s。安装版从 `/private/tmp` 执行，无 PYTHONPATH，86个实际安装模块与源码一致。所有候选、审查、原失败、正式测试及XML、安装身份保存于 evidence.tar.gz，逐成员及归档校验见 manifest.json。

本实现仍限定为固定刚性几何、单格、干气体、制造 Cp/体积/反应速率及名义能量参考。8/16步对独立解析反应进度和温压的比较不是空间收敛、湿相传递、输运焓基准验证或真实原污泥烧成验证。下一步必须继续输运/湿态及完整材料闭合，不能把这个测试宿主称为完整材料模型。

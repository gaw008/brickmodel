# 反应与规定变形：制造耦合验证 v1

基线 dfa30aa。此增量实现组成依赖机械储能及当前固体反应库存与规定几何的耦合；不是原污泥材料本构，也不是自由烧结运动方程。

## 实现及方程

`ManufacturedReactingSkeletonEnergy` 用 q=q0+ΣwiNi 缩放明确温度无关的参考弹性/界面内能及固定组成变形功率。q0>0、wi≥0（1/mol），完整当前固体库存非负且非全零。组成偏导 wi Eref 留在总储能内部交换中，不增加外功或第二份反应热。原固定库存 provider/host 的拒绝行为保持。

`DeformingSolidStorage` 从当前 Ns 与规定 Vbulk 计算固体占积、孔体积和总能量；减当前机械内能后仅做一次热反解。`DeformingSolidHeat` 显式 reacting_manufactured 域将原反应配置重绑到实际当前储能对象，保留原物种/来源/温区/能量基准检查。新分项账本分别记录固定组成弹性功、界面功、耗散、−p Vbulk_dot 和体力功。改变固体占积不是固定 bulk 控制体的外部压力功。

人工 A→B 的库存解析解为 NA=2 exp(−0.1t)，NB=2−NA。两相声明碳元素守恒、不同摩尔占积及形成内能；它们不是真实碳相或污泥组分。独立标量温度参考使用显式几何和第一定律，不调用生产温度反解。完整常量、参考方程、资源政策和事先门槛见 PLAN.md、REFINEMENT_PLAN.md 与 NUMERIC_REVIEW.md。

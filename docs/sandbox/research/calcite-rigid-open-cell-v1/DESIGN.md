# 开放刚性反应单元：热通气与富CO2冷却

在已核六组静态开放表面基础上，积分单元C、N2和U；Ca固定。相分配仍为瞬时平衡。0–4000s连接1180K、1bar、CO2摩尔分数.0004的N2气库和1180K辐射库；4000–8000s换为400K、1bar、CO2分数.1的N2气库和400K辐射库。该程序是虚拟输入，不能称实际炉气或工厂配方。

按内侧单元→表面、外侧表面→气库为正方向分别保存C/N/E的累积流，另存辐射输入、气库熵、辐射库熵和总熵产生。每个边界段单独启动BDF，切换时单元库存/U及所有账本连续；边界从一个预设库换到另一个，不计算外部制备这些库的设备能耗。

检查C+Cinnerout、N+Ninnerout、U+Einnerout不变；两侧累积物种相等，Einnerout+Qrad−Eouterout=0；同样从最外侧检查U+Eouterout−Qrad。气库熵率为(Eouter−μres·Nouter)/Tres，辐射库熵率为−Qrad/Twall，因此Sbody+Sgas+Swall−∫σ不变。冷却时不错误要求单元自身熵单调上升。

预算先登记于根参数文件。保存每接受步及2s观测的源状态、完整表面根与BDF稠密多项式；两精度对照，随后独立源势/面矩阵重组及2/4阶全程C/N/U和熵积分。原失败保留。当前结果和精确资格范围见[REPORT](REPORT.md)；运行边界是源温区内的条件模型。

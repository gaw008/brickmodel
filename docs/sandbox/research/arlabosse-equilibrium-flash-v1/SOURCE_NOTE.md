# 局部平衡假设的来源用途

已核读 Ben Hassine、Chesneau、Laatar (2017), *JAFM* 10(2), 651–659 的实际 PDF 及打印页653–655。页653把空气–污泥局部平衡列为假设；页654式9–10同时使用界面蒸气交换和整体干燥率。§5.2/式11仍引入经验干燥曲线，页655式12和表1给出经验平衡含水关系。

这只能支持“局部平衡是一种已有建模近似”的来源用途。它未给出本模型的孔内相变系数，未验证 Arlabosse 材料瞬时相平衡，也不支持省略全部干燥动力学。本次不引入该文任何数值系数。新 flash 是保持总水、载气、刚性体积和完整 U 的条件局部平衡；其时间尺度分离误差和跨材料误差仍为 unknown。

# 同能量与化学势的局部实现诊断

沿用已安装且来源绑定的同一储能/化学势对象。实际运行含原构造的两初态点及五个诊断点，总耗时1.465秒，执行会话88990已退出0并回收。

中心取T=333 K、Nc=.06 mol、Nv=1e-6 mol，固定总水、载气、体积。T方向±.01 K；组成方向±1e-7 mol。实际 U_x=-46331.42928336 J/mol，g−Tg_T=-46331.42926991 J/mol，两者差−1.34489e-5 J/mol；U_T=20.83958367804 J/K，与实现的Cv=20.83958367723 J/K相对差3.886e-11。预设诊断界为相对1e-4或Ux绝对1 J/mol，均通过。

原脚本先写dx=1e-5计划，在执行任何组成方向样本前发现会超过中心蒸气库存，改为1e-7，并覆盖了同路径计划文件；这次计划保存不够完整，脚本的原数值与改动注释仍保留。没有使用越域组成样本、没有观察导数后放宽阈值。后续实验计划应先确定可行库存扰动并冻结保存。

五点差分仅是局部实现诊断，不证明全域自由能恒等式、组成根误差上界或真实材料适用性；尤其不能据此把新flash的温度误差由unknown改成已认证。

# 有界单胞局部相平衡

从 `be6ac3c` 新增 `sludge_sandbox.low_moisture_equilibrium.flash`：固定总水、O2/N2载气、干质量、刚性可用体积和完整U，联解水的液汽分配及温度。实际IAPWS/NIST水物性与既有Arlabosse低含水势共同参与计算；保留干端过量能参考。该独立接口采用瞬时局部平衡近似，不需要相变速率系数，不预测达到平衡需要的时间。

每个T先由原允许压力区间构造组成候选范围，再调用真实物性检查完整压力误差区间。内外两层有括区割线与间歇二分，近根两侧实际求值。原全U残差加点误差门为1e-5 J，名义温度括区宽1e-6 K，化学势残差1e-5 J/mol、平衡分压残差1e-5 Pa、库存投影预算1e-12 mol。两层名义括区不包含未量化的内层组成/对数误差，**认证平衡温度误差仍为null**。

## 本地运行入口

在已安装本项目及water依赖、可读取仓库来源缓存的Python环境中，从项目根目录运行：

```bash
python examples/sandbox/run_low_moisture_equilibrium.py \
  --source-root "$PWD" \
  --output /private/tmp/equilibrium-example-new.json
```

输出路径必须尚不存在，父目录须存在。默认总载气为0.00032 mol，按明确的21/79虚拟设计拆分并记录浮点投影。可用`--carrier-mol`改变这一设计量；超出物性支持的工况可能失败，原输入与已完成物性记录会保存。初始温度、含水、干质量和几何均为示例设定，完整配置、数值策略及model_provenance见JSON。名义结果不支持干燥时间、材料合格判定或工厂控制。

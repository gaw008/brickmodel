# 独立气体/辐射源的连续热程序

2026-09-25 UTC预先冻结。仅在恒定独立辐射源阶段完整来源、元素/U/S与时间预算通过后启动。采用原正库存、同源热化学与虚拟输运。

30,000s程序：0–5000s升温；5000–15000s保温；15000–20000s冷却；20000–30000s保持。气体900→1100→700K，辐射950→1150→650K；气体CO2摩尔分数0.4→0.0004→0.4。参数和意义见根JSON，温度/时间不是实际窑炉工况。

先独立高精度核对边界插值和来源化学势、逐点共同能量/熵率，再两档完整积分；在所有接受步和Gauss节点重建来源、逐项积分气体/辐射能量与熵，核对2/4求积和时间预算。保存失败，不假定方解石一定耗尽或再生，不把程序观测括区冒充真实动力学或精确事件时刻。

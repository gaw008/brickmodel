# 一维低含水平衡与热湿输运

基线`10325ba`。新增`sludge_sandbox.equilibrium_transport`，把已实现的局部相平衡接入两格一维热湿输运。已完成代码审查、离线安装及12项安装回归；首次实际物性运行通过128项登记检查，推进1 s/1步。原单胞压力失败及所有旧验收门保持，当前结果只支持这一条件短段。

## 方程、初始化与来源

每个宏步从上一个接受状态计算已有导热、凝聚水迁移及外部热浴/选择性汽口的共享面。先用精确有理数求每格目标总水和完整内能：

`Nt* = Nc + Nv + Dleft − Dright + Gleft − Gright`

`U* = U + Hleft − Hright`

随后在同一干质量、载气和刚性可用体积下求局部液汽平衡；以`J = oldNc + Dleft − Dright − newNc_exact`作共同相重分配量，调用既有`_advance`完成一次最终投影。状态必须逐字段等于flash返回状态，Nc、Nv及U各项投影分别核对。没有先从微小Nv池扣到负数，也没有附加潜热、重复相变焓或刚性边界功。

零时刻相平衡是显式初始化，保留原初态、同一U和总水、初始相重分配及投影费用。也可用`project=False`核验调用者给定的平衡初态。初始化记录保存已有费用，积分入口重新核对历史费用与初始化费用的和，不能只把累计字段清零。

既有IAPWS/NIST物性与Arlabosse低W储能/化学势保持；[局部平衡模块](../arlabosse-equilibrium-flash-v1/REPORT.md)的材料转移、瞬时平衡时间尺度、对数/组成传播误差仍unknown。内部k采用Septien来源、凝聚水迁移采用Mäkelä表观失重扩散分配；跨材料与温度迁移尚未获得实验验证。内部气扩散和Darcy继续禁用。旧相变系数显式为零以关闭有限率支路，这个零值不是实测材料参数。

每次flash后，调用既有给定组成完整U反解，并在其实际温度、实际蒸气分压重新计算`μ_liquid + μ_ex − μ_vapor`及`peq−pv`。原蒸气物性对象随结果保存。给定组成反解的T界≤1e-8 K，**整体平衡组成与温度误差证书依旧为空**；更紧反解门不能自动证明化学残差合格。

## 首次实际运行

两格各干质量.01 kg、刚性可用流体体积1e-5 m³、宽度.02 m，截面积.001 m²。原初T为330/333 K、Nc为0/.06 mol、Nv各1e-6 mol；干格O2/N2为.0000714/.0002686 mol，湿格为.0000672/.0002528 mol。几何与载气是限定试验设定，不是砖厂测量。虚拟汽口`pe=0 Pa, Kv=1e-8 mol/(s Pa)`；热浴333 K、有效热导.1 W/K。

原物性范围为325–338 K、完整压力误差区间位于90–110 kPa、W在0–.15。flash原U/μ/分压/组成/库存门保持；主机算术预算为1e-8 J及1e-12 mol。初始化/积分各40 s、驱动80 s、外部监督100 s并允许5 s清理。初始U逐格由实际原初状态完整储能计算。

128项原检查均通过，包含初始化至积分连续性、完整两格结构、每格目标/库存/来源/反解对应、原U/T/P/μ门、共享面守恒、所有实际面费用及初始化费用只计一次。初始化19.109686 s、积分21.509186 s，顶层调用分别5/5与10/10完成；这不等于底层EOS迭代次数。驱动42.802158 s（计至保存观察与输入复核后，最终验收写入及stdout另由监督覆盖），监督48.086837 s；exec82056退出0并已回收。

外排水5.85452937348e-5 mol，为初始湿格蒸气库存的3.11018倍；这是本例实际跨过微小Nv池限制的观察。热浴输入.00396302610 J、外排蒸气携焓−14.0891706871 J、全列内能变化+14.0931337132 J，携焓符号沿用共同热化学参考。原始守恒等式用外面`energy_j`；按Q/H分别展示时明确扣除边界能量分解残差，并计入最终带符号投影。累计算术费用3.17690676287e-13 J与2.81633910354e-21 mol，均在原预算内。2792项登记输入前后未变。

当前仅一个宏步，没有时间或空间收敛资格，也没有全程干燥资格。湿格载气在今后接近全干时仍可能触及原压力下界，不能扩大域或删除水量来继续。

# 方解石—碳气氛耦合平衡：静态、热容及八个相界完成限定核查

现在可以在1bar、298.15–1200K下，为明确的虚拟Ca/C/O/N库存同时求解CaCO3、CaO、石墨、CO、CO2、O2、N2。方解石分解释放CO2，CO2又参加碳气体反应；反过来的CO2化学势改变方解石稳定性。因此结果不是两个独立过程曲线的叠加。

Ca=.002mol、O元素=.008mol、N2=.004mol固定，C总量选择.0035/.0045/.007mol三组虚拟值。C/O总量包括所有固相及气相，N输入是N2分子摩尔量。当前模型输入域限定Ctotal>Catotal、Ototal>3Catotal和N2>0；只报告气体体积，没有固相热胀、孔隙或机械变形。所有输入并非实际污泥砖配方。

## 物理与来源

沿用[已核对的USGS碳气体数据](../carbon-gas-thermochemistry-v1/REPORT.md)及parameters.calcite_affinity_source.json、calcite-thermochemistry-v1/facts.json中的同书方解石/CaO数据；原始来源是[USGS Bulletin 2131](https://pubs.usgs.gov/bul/2131/report.pdf)。H=h_f(298.15)+∫Cp，S=S(298.15)+∫Cp/T，所有气体用同一标准压力、同一明确保留的历史书中R作独立来源一致性计算，没有改动其他模块的常数。固相在该标准压力下活度为1，不加不存在来源的溶液活度系数。

固定方解石量a时，用有限碳氧模型求剩余C−a、O−Ca−2a的气体/石墨分配，再计算φ=gCaO+μCO2−gCaCO3。全方解石要求φ≥0，全CaO要求φ≤0，两者共存要求φ=0。石墨还同时满足其存在/耗尽单侧条件。理想混合气Gibbs Hessian在固定正N2和所列反应空间中正定，固相项线性，因此这些条件给出所选物种集合内的全局平衡。

共存热容由完整反应空间计算，而不是冻结方解石比例后加Cp：令气相计量矩阵为V，M=RT[Vᵀdiag(1/ni)V−ΔngΔngᵀ/ng]，平衡反应进度导数满足MξT=Δh/T，Cp_eq=ΣniCpi+ΔhᵀξT。石墨存在使用CaCO3→CaO+CO2、C+CO2→2CO、C+O2→CO2；耗尽后使用第一反应及CO+O2/2→CO2。每条反应和其来源组分都在根参数中明确列出。

## 已执行证据

36组状态覆盖六种相组合（全方解石/共存/全CaO，各自石墨存在或耗尽），全部通过冻结静态预算。参考是60位Cp/Cp/T直接积分和同时求解log气体摩尔量、必要的方解石比例，不复用实现的嵌套标量根。来源H最大差8.16581e−12J、S差5.64985e−15J/K，方解石互补条件差≤4.65662e−10J/mol，所有正气体最大相对误差2.08793e−13；痕量气体未被剔除。

90组同相双侧差分通过Cp=dH/dT=T dS/dT、每种组分及每个元素的温度导数核查；最大Cp差5.14162e−9J/K，组成导数差2.53868e−14mol/K。固相基础Cp也为正：这两个源多项式的dCp/dT在正T域均为正，最小Cp在298.15K；反应Hessian贡献非负。这里的高精度只控制数值误差，不替代未给出的来源拟合误差或实际材料数据。

三组库存随升温得到以下边界；均用独立温度/log气体摩尔量/必要的方解石比例联立方程求解，并核查两侧H/S连续、热容允许跳变。

较多的碳使方解石在更低温度进入分解的原因，是所选平衡中共同CO2化学势发生变化；不能把这些数值当作真实含碳砖的工艺设定。富碳的两组在石墨仍存在时有相同的开始分解温度，符合纯石墨活度为1、库存只影响固相剩余量的定义。

原八边界核查中，七组全通过；富碳方解石耗尽前的Cp接近39.95124J/K，1e−3K线性投影误差H=1.34324e−6J、S=1.29571e−9J/K，分别超原1e−6/1e−9预算，保留原失败。仅将该组偏移缩小到1e−4/3e−5/1e−5K重算，所有原预算通过；最大H/S投影误差降至1.34333e−8J/1.29580e−11J/K，呈二阶收敛。没有修改物理参数或放宽误差限值。其他七组未重复执行。

全部输入和核查入口位于parameters.carbon_calcium_*.json与examples/sandbox/review_carbon_calcium_*.py。随后完成了[恒压升降温全过程限定数值资格](../carbon-calcium-cycle-v1/REPORT.md)，原静态和相界失败证据仍完整保留。当前仍是纯相、理想气体、瞬时平衡，未考虑其他可能物种、实际焦活性与速率、反应传热限速、真实砖孔结构或烧结收缩；material_qualified=false、training_eligible=false。未新增/运行软件测试，未生成或比对SHA。

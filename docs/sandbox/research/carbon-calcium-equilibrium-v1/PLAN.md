# 方解石—碳气氛耦合：先静态资格，后时间过程

目标是在同一USGS标准状态、1bar、298.15–1200K下，把已验证的CaCO3/CaO与C/CO/CO2/O2/N2组成一个封闭Ca/C/O/N库存体系。新增耦合不是把两个独立曲线相加：气体的共同CO2化学势同时决定方解石稳定性与碳反应。

限定物种是纯方解石、纯CaO、纯参考石墨和理想CO/CO2/O2/N2。初始虚拟库存取Ctotal>Catotal、Ototal>3Catotal、N2>0，保证考察整个方解石分配区间时气相元素库存可用；不外推到其余输入域。气体体积不含固相体积。所有量均为元素库存，Ctotal包含方解石中的碳，Ototal包含固相氧。

先固定方解石量a，用既有碳氧模型解气体与石墨，再计算φ=gCaO+μCO2−gCaCO3。a=Ca时φ≥0为全方解石，a=0时φ≤0为全CaO，其他情况在0<a<Ca求φ=0。混合物G在可行元素空间凸，固定N2排除气体整体缩放零方向；单侧相稳定条件与等式一起限定所选物种集合的全局平衡。

共存区以CaCO3→CaO+CO2，及按石墨是否存在选择C+CO2→2CO/C+O2→CO2或CO+O2/2→CO2作为独立反应基。直接用气相理想混合Hessian和来源反应焓算平衡Cp，验证元素导数、Cp=dH/dT=T dS/dT与相边界两侧连续性。暂不接入时间过程，直到静态/热容资格通过。

来源不新增假定热化学值，沿用两个已核对USGS来源记录，明确使用该独立来源一致性模型的历史R。库存、求解精度和核查预算先放根参数文件。每条失败保留，物理系数不随结果调整；即使数值通过，仍为material_qualified=false、training_eligible=false。

现实的第一轮收敛目标是：同一来源材料的反应计量/热效应进入共同库存—总能量状态，继而推动同一几何/孔气模型，再对照独立热历史的总失重和总长度。四项终态不作为四个可任意独立优化的物性输入；未知强度不进入合格排名。

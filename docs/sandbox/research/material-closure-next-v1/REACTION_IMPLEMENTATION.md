# Architecture: 来源显热与已有质量反应主机的最小连接

日期：2026-09-12。只读核查基线为 `45287feafb38e92cedd9ab9b3bcf3e608f2bd1c6` 加当前工作树；读取期间 root 正在集成独立进程恢复功能。初始架构任务只新增本文；后续独立来源任务另有数据报告，仍未修改源码、测试或安装环境，也没有执行新的物性或轨迹实验。下面的验证是待实现的验收设计，不是已通过结果。

## 最终优先级裁决

**优先核实并接入明确纯物质的碳酸盐分解热化学，保留 MIA3 同批材料闭合为主问题；不要先投入 Arlabosse 惰性显热桥。** 下文保留该桥的具体最小设计，供需要检查两条主机连接时复用，但它是可选机制测试，不是完整 Goal 的必经依赖。

理由是：已有来源湿态储能已证明来源 Cp 与水共用 U，已有制造反应主机已证明组成/热量/占积/有限氧。再把来源 Cp 当惰性热容量放到制造反应旁边，能检测一个真实连接，且来源 Cp 随 T 变化而非常量；但它不会减少 MIA3 活动反应的任何关键未知，也不会证明污泥原料自身的热解或氧化。若它不能服务于已准备好的活动来源材料接口，继续优先实现它的边际价值有限。

相较之下，`CaCO3 → CaO + CO2` 对应明确纯物质的可配平分解方向；取得匹配的真实固相/气相参考热和温变显热后，可第一次将一个实际分解方向放入已有总 U 与气体释放/占积代码。它能推进烧结砖中碳酸盐反应所需的机制，但仍不能由 MIA3 的石灰石配料份数推断实际 CaCO3 库存、速率或全部热效应。详见文末的具体路线。

## Design Decisions

当前唯一优先路线是：同一本 USGS 评估中 CaCO3、CaO、CO2 的来源热化学 → 原式解析积分 → 指定反应进度的质量/产气与反应焓。随后再按实际闭合证据接已有摩尔主机。第一步不需要高温固相体积、不要求制造速率、不改 kg/mol 状态布局。

Arlabosse 惰性显热桥只保留为备选：如后续确实需要证明质量主机与固定来源显热共用一个 U，可在 `WetMixedStorage` 组合一个固定 `FixedMassCaloricStorage` 并复用既有反解。其质量不参与反应或输运，35–105°C 边界和比容未知必须保持。它既不补 MIA3 组成，也不补活动参考热，当前不为它新增类型、执行框架、P1 实现或完整测试工程。

kg/mol 反应的统一单位仍是：B 为 kg 组分/kg 明确进度，q 为产物减反应物的 J/kg 进度，速率为 kg 进度/s；气体按实际绑定摩尔质量映射到 mol/s。纯 CaCO3/CaO/CO2 本来具有明确分子式与摩尔质量，应直接使用现有摩尔物种路径，不能给原样品污泥任意赋摩尔质量。

总内能包含相容形成能与显热后，化学反应仅改变库存，不再另加 `-q*rate`。水相转移也不另加潜热。真实温度、压力、组成占积、自由几何与开放物流只在各自必要数据/参考已闭合后接入，不能以热化学函数已成功替代这些验收。

## 只知道反应焓时，是否必须知道全部 h0

**物理上不一定；现有 `WetMixedStorage` 的“零空间为空”比有些封闭问题实际需要的条件更强。但不能只删除这一检查。**

设参考约束为 `A*h0=b`，零空间为 G。某个焓组合 `c*h0` 可识别，当且仅当对每个 `g∈G` 都有 `c*g=0`；已有 `identified_value(c)` 已实现此门。

必要组合至少包括：

1. 每条**可能活动**反应的 `B[:,r]`。q 原字段为 `None` 并不自动拒绝：若由其他 q/anchors 识别出来，可以使用。反之，初始 O2=0 也不是跳过门的理由；后续面补给可能激活氧化。
2. 所有可能进入/流出的物流所需参考焓组合。独立变化的各气体通量通常要求分别识别其气相参考焓，并与实际气相曲线严格一致；只有当所有允许的通量都被约束为固定组合时，才可能仅识别该组合。必须覆盖配置允许的通量空间，不是只看当前恰好为零的流量。
3. 温度反解所用的固相参考能组合。现接口直接计算 `m_s*h0_s`，因此对允许出现的各组成状态都要有相应组合可识别。只检查 `B^T*h0=q` 后使用 `particular_h0_j_kg` 的自由坐标零值，不能满足这个要求。

封闭或仅有已锚定气相进出的系统，可以另定义**相对于初始固相参考能的坐标**。若所有气相 h0 已由实际来源锚定，而且每条活动 q 已识别，则每条反应的固相参考改变：

```text
q_s,r = q_r - sum_g(B_g,r * h0_g)
delta_E_s,ref = sum_r(xi_r * q_s,r)
```

是可识别的，无需知道各固相的绝对 h0。配合初始固相组成、同组成显热关系、已知占积项和共用气相参考，可以计算同一条可达轨迹的温度。固定而不活动的 Arlabosse 来源项正是更简单的情形：其未知绝对参考能始终是常量。

**严格实现这个放宽还需要一个当前接口没有的条件：** 保存的进度/库存必须处于被证明的同一计量可达子空间。`WetMixedState` 将质量转成 binary64，现有积分器还记录独立舍入残差。浮点质量差 `m-m0` 可能含极小的零空间方向误差；未知 gauge 没有有限范围，不能把“残差很小”当成其未知参考能误差也很小。若要支持稀疏参考约束，需要明确的相对参考坐标和精确计量进度账本、可达性检查及舍入能量处理，不能临时选择 `free_coordinates_zero` 掩盖这个问题。

当前纯物质路径取得了完整来源形成焓，因此不需要放宽 kg 主机的完整锚定门。对后续只得到反应 q 的污泥材料，这个相对坐标问题仍需单独实现与审核；以 gauge 改变前后完整轨迹不变、开放气体物流能量不变和不可达状态拒绝为硬测试。完全锚定是现有接口范围，不是自然界要求每一种材料都有绝对形成焓。

## 必须拒绝的情况

- 原样品干质量参加反应，但缺同组分完整元素构成、产物计量/产物显热、必要比容或所需参考焓组合；不能以来源 Cp 的固定质量接口支持这一调用。
- 任一可能活动方向 q 不可识别，或者其温度/压力/相态参考未桥接；HHV、低温 Cp、未校准 DTA 不能自动充当它。
- 气体消耗/生成的摩尔质量、化学身份、来源焓基准与储能/面交换不一致；有 mass balance 而无 element balance 不足以通过。
- 水参与化学生成/消耗。现有湿反应布局显式禁止该通道；蒸发/凝结只改变同一 H2O 的相库存，不等于化学反应。
- 输入要求污泥热解在无氧时继续，而配置只有当前 O2 制造反应。应报告该通道未实现/未闭合，不能把氧化关停后零速率称为热解模型。
- 来源拟合有效域以外、热容下界无法证明为正、孔体积正区间不成立、能量目标超出有效域、负库存或完整步内发生负库存。不得裁零再继续。
- 试图把固定来源项转成可变质量、跨面输运，或将制造固定排除体积作为已测来源比容发布。
- 声称已接自由烧结、真实 MIA3 全周期、排放/强度结论。上述增量的正向证明不覆盖这些目标。

### 首个可验收结果，不以未知动力学强行开跑

先核对同温同参考的：

```text
Delta_r H(T) = H_CaO(T) + H_CO2(T) - H_CaCO3(T)
Delta_r U(T) = U_CaO(T) + U_CO2(T) - U_CaCO3(T)
```

热化学优先使用同一评估参考；不能将不同来源的形成焓和 Shomate H 系数随意混合。固相身份要分清晶相与温区，不能跨相变或将不存在的高温单相支延伸。若要判断分解/逆反应在某温度和 CO2 分压下是否自发，需要相容的熵/化学势等依据；仅凭正/负反应焓不能判定平衡或反应方向。

在三种物质与有效域已闭合时，指定一个明确的非负反应进度 xi，按 `(-xi,+xi,+xi)` 更新摩尔库存，在一个刚性封闭单元固定总 U，通过既有 storage 解出新 T、P 和孔体积；独立参照按来源热量公式解同一标量方程。这个结果证明“真实来源反应能差与气体释放进入共用总能量状态”，**没有时间轴，也不宣称预报分解速率**。若实际体积关系未闭合，先停在焓/内能中可以确定的组合；采用制造体积的 U/P 检查必须继续标为混合机制测试。

可另用明确制造的 Arrhenius 时间尺度测试 `SolidReactionConfig` 与积分器接线，整体资格仍是“来源热化学 + 制造动力学”。热力学分解未必遵循现有不可逆 bulk 浓度率；没有动力学/平衡压资料时，不把制造速率或固定活化能改名为真实碳酸盐分解。原主机只支持明确不可逆质量作用率，若真实论文给表面反应/孔扩散/逆反应，应按具体法则另评接口，而不是改其单位使之勉强通过。

此起步比来源惰性显热桥更贴近活动热化学目标，且可从一个温点到少量进度点进行，避免巨额动态 EOS 预算。先用干单元、零液水、明确正气体库存；这一路不需要调用湿液水 EOS。运行次数/墙钟上限在来源完成后预注册，不能先声称耗时已测。

## MIA3 真实材料闭合的最小解题路线

纯物质包只能减少“已识别矿物的本征热化学”未知，不能自行给出 MIA3 中该矿物质量。不要继续无界重搜已经审核的同一 TG 或从 Table6 终态倒推全部参数。下一轮工作应产生以下可审查的解题产物，每一步只对实际可识别量建模。

| 问题/产物 | 先用现有资料做什么 | 只有新增同配方证据才能补的量 | 通过后解锁什么 |
|---|---|---|---|
| 初始基准向量 | 把 Table3 配料份数与干燥/熟石灰处理史、成型水的分母逐项列入约束；不将 5 份石灰石等同于 5 份纯 CaCO3 | 初始试件质量/体积、每料实际含水/灼减及分母，来源允许的定量矿相/化学组成 | 一个可审计的初始库存或明确欠定的区间，不自动生成单一“完整配方” |
| 活动计量矩阵 B | 使用已明确物种公式构成可配平方向；XRF 氧化物当量仅作约束，不能唯一反演矿相；已读 TG 保留整体失重观测 | 原样品及产品/残炭的充分元素与相组成、气/液回收量及实际 O2/气氛记录；不能加“其他物质”补账 | 确定哪些反应/组合的质量和元素方向被资料约束，哪些仍 unknown |

| 同组成显热与体积 | 对真实已识别纯相复用权威来源；处理后污泥及新生相仍保持各自身份，不迁移 Arlabosse 或 HRN Cp | 同配方/处理史的 Cp/热量关系及有效温区；足以约束骨架占积/膨胀的关系和不确定性 | 在一段明确温区内完成真实组成 U→T，而非全域外推 |
| 反应时间与有限氧 | 从已有实验只取明确的温度历史、气氛、质量观测；先证明哪些动力学参数不可由单一 TG 唯一识别 | 至少有能区分备选动力学的独立温度/气氛响应，实际供氧/产气信息；具体实验数由可识别性决定 | 有适用边界的速率方程与未参与调参条件，而不是从单曲线“确定”全部动力学 |
| 几何与冷却 | 保留 Fig4 总长度和 Table6 冷态值作为观测；纯相体积不能替代坯体烧结关系 | 分开热膨胀、失重和致密化的响应、连通输运；冷却 T(t) 与必要机械关系 | 才能接已存在自由几何/冷却主机并评估整砖结果 |

最小新增数据请求应围绕上述欠定的**组合**，而不是笼统要求数月本厂历史。例如若只有一个活动方向 q 缺失，优先找能约束该 q 的同参考热量测量；若多个产物分配同样符合 TG，则先补产品计量，追加更多相同气氛同程序的 TG 不能自动解出它们。

MIA3 目前不能声明真实全周期已可运行。可以继续完成纯物质反应源包、明确热化学方向与已有主机接线，同时把同配方不可识别项与最小补证据记录成具体结论。这比在已验证制造模型旁反复添加不会减少材料未知的部件更直接推进用户的目标。

## 当前 Build Sequence 与验收边界

1. 完成同USGS三物种原页/方程/参考核对，保留所有不确定度与高温体积未知。此数据步骤已有单独来源任务交付。
2. 实现纯热化学函数与共享CLI，直接计算原式，不导入湿态EOS，不调用制造反应率。

4. 形成一个可实际运行的真实热化学案例及源值追溯输出。只有随后获得必要体积/动力学证据，才开始反应时间轨迹或自由几何扩展。

这一步的完成名称应是“明确纯物质的来源热化学和指定反应进度”，不得标记为 MIA3 原污泥反应闭合或全砖烧成完成。

# Architecture: 来源显热与已有质量反应主机的最小连接

日期：2026-09-12。只读核查基线为 `45287feafb38e92cedd9ab9b3bcf3e608f2bd1c6` 加当前工作树；读取期间 root 正在集成独立进程恢复功能。本次只新增本文，没有修改源码、测试、安装环境，也没有执行新的物性或轨迹实验。下面的验证是待实现的验收设计，不是已通过结果。

## 最终优先级裁决

**优先核实并接入明确纯物质的碳酸盐分解热化学，保留 MIA3 同批材料闭合为主问题；不要先投入 Arlabosse 惰性显热桥。** 下文保留该桥的具体最小设计，供需要检查两条主机连接时复用，但它是可选机制测试，不是完整 Goal 的必经依赖。

理由是：已有来源湿态储能已证明来源 Cp 与水共用 U，已有制造反应主机已证明组成/热量/占积/有限氧。再把来源 Cp 当惰性热容量放到制造反应旁边，能检测一个真实连接，且来源 Cp 随 T 变化而非常量；但它不会减少 MIA3 活动反应的任何关键未知，也不会证明污泥原料自身的热解或氧化。若它不能服务于已准备好的活动来源材料接口，继续优先实现它的边际价值有限。

相较之下，`CaCO3 → CaO + CO2` 对应明确纯物质的可配平分解方向；取得匹配的真实固相/气相参考热和温变显热后，可第一次将一个实际分解方向放入已有总 U 与气体释放/占积代码。它能推进烧结砖中碳酸盐反应所需的机制，但仍不能由 MIA3 的石灰石配料份数推断实际 CaCO3 库存、速率或全部热效应。详见文末的具体路线。

## Design Decisions

1. **先复用 `WetMixedStorage` / `WetPair`，加入固定来源显热项。** 活动库存仍是既有 A、B、O2、N2、H2O；Arlabosse 原样品作为不反应、不输运、质量固定的独立显热项。这是“制造反应体系 + 真实来源显热关系 + 来源水路径”的混合机制测试，整体仍标为制造验证，不命名为 MIA3、Arlabosse 污泥氧化或真实共烧实验。
2. 来源项必须保留其原材料 ID、来源 SHA、35–105°C 适用域及物理误差未知。不给 A/B 复制 Arlabosse Cp，不给原样品编造元素分数、摩尔质量、形成焓或热解产物 Cp。来源项的固定质量恰好允许任意能量零点成为恒定偏移；活动反应组分不能使用这一理由忽略参考热。
3. 组成占积继续由 `sum(m_i*v_i)` 计算。来源项若排除一部分流体空间，使用**独立声明的制造固定排除体积**，不是从 Cp 推出密度，也不把 `excluded_volume/mass` 发布为材料比容。
4. `SourceWetStorage`、`ReactionDisabled` 和 `ExactSourceColumn` 的旧默认拒绝规则保留。首个连接不修改通用 `ConservedState`，不把 kg 塞进名为 `amounts_mol` 的数组，也不新增运行/恢复框架。已有 kg/mol 阶段积分器正是可复用的状态通道。
5. 本增量保持刚性体积和既有 A/B 制造反应。源 Cp 与自由形变的进一步连接必须在 kg 状态、组成体积导数、机械功和应变储能都明确后进行；不能把 `free_solid_slab` 的摩尔提供器换个名称就称接通。先交付来源显热确实改变反应温升及输运的实例，再扩展活动材料范围。

### 温区检查有一个实际接口冲突

现有 `WetMixedStorage.__post_init__` 要求 `lo < network.Tref < hi`。旧制造网络参考温度为 300 K，而 Arlabosse 来源域从 308.15 K 开始。直接把运行温区改成两者交集会被这个门拒绝；也不能向下外推来源 Cp 到 300 K。

有来源项时应分开检查：

- 活动 A/B 和实际气相的参考评价仍在其原参考态进行，且必须在这些提供器各自支持的参考域内；保留原气体 anchor 与实际曲线的精确相容检查。
- 共用 U 反解的运行域是旧流体/活动固体域与来源项域的交集。来源项只在交集中的 T 求值，使用其自身域内的 `T0`，例如 320 K。
- 固定来源项的 `T0` 不必等于活动网络的参考温度。其质量不变且不跨面流出，零点差只改变固定能量偏移。改变 `T0` 必须改变模型身份，并显式平移初始/保存的 U。
- 无来源项的旧分支保留原检查；不能借此无条件放开既有参考域。

这需要分离“活动参考数据评价域”和“共同运行温区”，不需要建立来源的 300 K 物性。

## State、单位和能量约定

动态状态继续使用 `WetMixedState(solid_mass_kg, liquid_water_mol, gas_amounts_mol, internal_energy_j, energy_model_identity)`。本轮固相元组严格为 A/B 两项；来源质量是 `FixedSourceSensibleTerm` 的不可变配置。原来源材料未知的元素构成不进入活动矩阵，不能因其质量固定而宣称全混合物元素组成已知；只可审核已知活动子系统的元素变化为零，以及来源项质量没有改变。

对于反应列 r：`B_ir` 为 kg 组分/kg 明确进度，`xi_dot_r` 为 kg 进度/s，`q_r` 为产物减反应物参考焓，单位 J/kg 进度。`B_s*xi_dot` 给 kg/s，`B_g*xi_dot/M_g` 给 mol/s；气体摩尔质量使用实际已绑定提供器，不用原子量约定替换其 EOS 摩尔质量。

在本轮既有不可压缩、温度不变比容的活动固相假设下：

```text
V_available = V_bulk - sum(m_i*v_i) - V_fixed_source_excluded
U_total(T) = U_fluid(T, n_liquid, n_gas, V_available)
           + sum(m_i * [h0_i + integral(Tref,T,Cp_i)dT - p_ref*v_i])
           + m_source * integral(T0,T,Cp_source)dT
```

`V_available` 是液体加气体可占空间，不是扣完液水后的气孔体积。液体占积和气体压力继续由 `evaluate_wet_fluid` 闭合。新增固定体积误差与 bulk 误差、浮点聚合误差先合并，再走已有压力和液体能量误差链；未知的真实密度误差不是零。

上述活动参考 h0 必须由 `identified_value` 对实际所需组合确认，或保持当前已重新求解且零空间为空的完整参考解。`chemical_reference_power_w = sum(q_r*xi_dot_r)` 是热化学诊断，**不再进入 U 的独立源项**。封闭刚性绝热单元的 `dU/dt=0`；温度随组成变化由同一反解得到。水相变也不另加潜热。单元间只使用同一共享面焓流的相反符号；固体不跨面。

来源 Cp 在现有明确不可压缩固定体积近似下用来计算 `du/dT`。这不等于测得真实材料 Cv，更不能将来源拟合延伸到热解或烧结温区。整个有效温区的正热容下界继续是反解所需数值条件，不能用当前热端 Cp 替代。

## 只知道反应焓时，是否必须知道全部 h0

**物理上不一定；现有 `WetMixedStorage` 的“零空间为空”比有些封闭问题实际需要的条件更强。但不能只删除这一检查。**

设参考约束为 `A*h0=b`，零空间为 G。某个焓组合 `c*h0` 可识别，当且仅当对每个 `g∈G` 都有 `c*g=0`；已有 `identified_value(c)` 已实现此门。

必要组合至少包括：

1. 每条**可能活动**反应的 `B[:,r]`。q 原字段为 `None` 并不自动拒绝：若由其他 q/anchors 识别出来，可以使用。反之，初始 O2=0 也不是跳过门的理由；后续面补给可能激活氧化。
2. 所有可能进入/流出的物流所需参考焓组合。独立变化的各气体通量通常要求分别识别其气相参考焓，并与实际气相曲线严格一致；只有当所有允许的通量都被约束为固定组合时，才可能仅识别该组合。必须覆盖配置允许的通量空间，不是只看当前恰好为零的流量。
3. 温度反解所用的固相参考能组合。现接口直接计算 `m_s*h0_s`，因此对允许出现的各组成状态都要有相应组合可识别。只检查 `B^T*h0=q` 后使用 `particular_h0_j_kg` 的自由坐标零值，不能满足这个要求。

封闭或仅有已锚定气相进出的系统，可以另定义**相对于初始固相参考能的坐标**。若所有气相 h0 已由实际来源锚定，而且每条活动 q 已识别，则每条反应的固相参考改变：

```text
q_s,r = q_r - sum_g(B_g,r * h0_g)
delta_E_s,ref = sum_r(xi_r * q_s,r)
```

是可识别的，无需知道各固相的绝对 h0。配合初始固相组成、同组成显热关系、已知占积项和共用气相参考，可以计算同一条可达轨迹的温度。固定而不活动的 Arlabosse 来源项正是更简单的情形：其未知绝对参考能始终是常量。

**严格实现这个放宽还需要一个当前接口没有的条件：** 保存的进度/库存必须处于被证明的同一计量可达子空间。`WetMixedState` 将质量转成 binary64，现有积分器还记录独立舍入残差。浮点质量差 `m-m0` 可能含极小的零空间方向误差；未知 gauge 没有有限范围，不能把“残差很小”当成其未知参考能误差也很小。若要支持稀疏参考约束，需要明确的相对参考坐标和精确计量进度账本、可达性检查及舍入能量处理，不能临时选择 `free_coordinates_zero` 掩盖这个问题。

本轮最小桥因此**不放宽活动网络的完整锚定门**。它复用已安全闭合的制造反应，将真实固定来源显热接入同一个 U。后续若材料仅给 q 而无全部 h0，再单独实现上述相对坐标；届时以 gauge 改变前后完整轨迹不变、气体开放物流能量不变和不可达状态拒绝为硬测试。完全锚定是当前接口范围，不应写成自然界要求每一种材料都有绝对形成焓。

## 必须拒绝的情况

- 原样品干质量参加反应，但缺同组分完整元素构成、产物计量/产物显热、必要比容或所需参考焓组合；不能以来源 Cp 的固定质量接口支持这一调用。
- 任一可能活动方向 q 不可识别，或者其温度/压力/相态参考未桥接；HHV、低温 Cp、未校准 DTA 不能自动充当它。
- 气体消耗/生成的摩尔质量、化学身份、来源焓基准与储能/面交换不一致；有 mass balance 而无 element balance 不足以通过。
- 水参与化学生成/消耗。现有湿反应布局显式禁止该通道；蒸发/凝结只改变同一 H2O 的相库存，不等于化学反应。
- 输入要求污泥热解在无氧时继续，而配置只有当前 O2 制造反应。应报告该通道未实现/未闭合，不能把氧化关停后零速率称为热解模型。
- 来源拟合有效域以外、热容下界无法证明为正、孔体积正区间不成立、能量目标超出有效域、负库存或完整步内发生负库存。不得裁零再继续。
- 试图把固定来源项转成可变质量、跨面输运，或将制造固定排除体积作为已测来源比容发布。
- 声称已接自由烧结、真实 MIA3 全周期、排放/强度结论。上述增量的正向证明不覆盖这些目标。

## 独立制造极限验证：具体可运行设计

### 主要案例

复用 `test_mass_storage_bridge.fixture` / `test_mass_wet_storage.setup` 的真实软件对象和显式解析液体 seam，以及 `test_mass_wet_transport` 的两单元框架。水 seam 的 `u_l=75*T-300000 J/mol`、`v_l=1.8e-5 m³/mol` 是制造测试值，不是 HEOS 水的证据；原来的 native 禁用 trap 保留。来源显热使用真实 `ArlabosseDryCaloric` 文件检查与质量适配器。

建议测试配置如下，所有改动均写入独立制造 fixture：

- 原活动网络 `A+O2→2B`、q、O2/N2 提供器和明确进度基准保持；来源固定质量取可准确表示的 `1/128 kg` 与 `1/64 kg`；来源 `T0=320 K`，共同运行温区取 `[310, 345] K`。
- 将制造 B 比容从旧 `0.0005` 改为 `0.00075 m³/kg`；A 比容仍 `0.001`。旧组合 `-v_A+2*v_B=0` 恰好不改变固体总体积，不能用它验证占积反馈。新组合每 kg 进度增加 `0.0005 m³` 固体体积，必须反馈气孔压力。
- 固定来源排除体积每格声明为 `1/65536 m³`、数值误差零，理由明确为制造几何；这不是原样品实测体积。
- 初始 T 使用 320/325 K，保留正液水/气体库存。初始总 U 每格只由完整储能模型评价一次；运行中不重置 U 来强制指定 T。
- 先运行面输运和水相转移系数为零的封闭绝热极限，再在同配置中启用原非零共享面和相转移系数。取 `duration=1/64 s`、4/8 个 midpoint 步，两档共 36 次每种案例的 `WetPair.evaluate`；所有比较把反解误差单独计入。

### 独立参照与判据

封闭极限中的速率是 `dx/dt=k*(a-x)*(b-x)/(M_O2*n_ref)`，其中 `a=m_A0`、`b=M_O2*n_O2,0`，可以使用独立解析进度解；分别由计量得到 A、B、O2。独立能量函数直接展开制造固相/解析液体/气体显热，再加来源多项式积分：

```text
Delta u_source(T,T0)
  = 1434*(T-T0)
  + (3.29/2)*[(T-273.15)^2-(T0-273.15)^2] J/kg
```

参照使用该原文方程的独立展开式，不调用被测 `WetMixedStorage.evaluate/invert`、桥 `evaluate` 或生产 RHS。涉及水蒸气的既有来源理想气显热叶可共用，但要明确它是共用输入，不能声称独立验证了来源曲线。由独立一元求根算 T、由独立体积式算 P。非零面案例扩展已有 `test_independent_full_coupled_ode` 的 `solve_ivp(DOP853)` 参照，只增加来源二次显热项与改变后的固相体积，保持参照不调用生产面交换/储能/积分方法。

必须同时证明：

1. 全闭系统总 U 恒定，活动子系统 C/O/N 和全系统总质量保持；来源固定质量逐格不变。氧化参考热非零，独立能量源仍为零；来源显热项确实改变温升。
2. `n_O2=0`、共享面供氧为零时速率精确为零；有供氧时后续阶段才可能活动；总消耗不超过初始加共享面净输入。速率为连续库存乘积，有限时间不必恰好降到零，不能做库存截断。
3. 采用变化比容时，压力与真实更新后体积一致；冻结原孔体积的负控制必须失败。
4. 每格 `Delta U` 等于同一共享面焓积分的相反符号，封闭整体系数相消；各气体摩尔变化包含反应与同一面流。这个案例验证开放**子单元**的能量账本，不冒称已经实现对外炉气边界。
5. 4→8 步对独立解的误差降低，误差低于数值分辨率时报告该事实而非硬造阶数；绝对量采用已有制造回归门（质量/气体/能量/T/P）作为起点，不能为绿灯任意放宽。新体积和来源项需要先确认这些门是否能被当前反解预算分辨。
6. 漏加来源显热、额外加 `-q*rate`、不扣 O2、将反应前体积冻结和破坏气相参考的负控制分别失败；来源文件变更及 308.15 K 以下请求在物性回调之前拒绝。

### 预算与验证分层

纯软件/解析极限给每个 4/8 步组合统一 30 s 上限，参照求解另计并封顶；失败保存实际前缀和调用计数。这是预注册资源政策，不是已测耗时。不开大型 2/4/8 网格完整湿干事件搜索。

纯测试通过且 root 解除安装冻结后，再做一个明确受监督的真实 HEOS 两格 RHS/反解冒烟：正液水、正 O2、有效温区，最多一次完整 `WetPair.evaluate`，30 s worker/45 s supervisor 上限，记录实际水后端、构造/调用数及原始结果。若预算不足则保留 resource_limit，不给解析 seam 改名为 native 成功。真实水路径的新增证据只到这个点；完整真实轨迹须以后独立验收。

### 首个可验收结果，不以未知动力学强行开跑

先核对同温同参考的：

```text
Delta_r H(T) = H_CaO(T) + H_CO2(T) - H_CaCO3(T)
Delta_r U(T) = U_CaO(T) + U_CO2(T) - U_CaCO3(T)
```

热化学优先使用同一评估参考；不能将不同来源的形成焓和 Shomate H 系数随意混合。固相身份要分清晶相与温区，不能跨相变或将不存在的高温单相支延伸。若要判断分解/逆反应在某温度和 CO2 分压下是否自发，需要相容的熵/化学势等依据；仅凭正/负反应焓不能判定平衡或反应方向。

在三种物质与有效域已闭合时，指定一个明确的非负反应进度 xi，按 `(-xi,+xi,+xi)` 更新摩尔库存，在一个刚性封闭单元固定总 U，通过既有 storage 解出新 T、P 和孔体积；独立参照按来源热量公式解同一标量方程。这个结果证明“真实来源反应能差与气体释放进入共用总能量状态”，**没有时间轴，也不宣称预报分解速率**。若实际体积关系未闭合，先停在焓/内能中可以确定的组合；采用制造体积的 U/P 检查必须继续标为混合机制测试。

可另用明确制造的 Arrhenius 时间尺度测试 `SolidReactionConfig` 与积分器接线，整体资格仍是“来源热化学 + 制造动力学”。热力学分解未必遵循现有不可逆 bulk 浓度率；没有动力学/平衡压资料时，不把制造速率或固定活化能改名为真实碳酸盐分解。原主机只支持明确不可逆质量作用率，若真实论文给表面反应/孔扩散/逆反应，应按具体法则另评接口，而不是改其单位使之勉强通过。

此起步比来源惰性显热桥更贴近活动热化学目标，且可从一个温点到少量进度点进行，避免巨额动态 EOS 预算。先用干单元、零液水、明确正气体库存；这一路不需要调用湿液水 EOS。运行次数/墙钟上限在来源完成后预注册，不能先声称耗时已测。

# 来源矿物热化学：实现与实测

基线096b428，2026-09-12。已实现 `calcite_thermochemistry.calculate_calcite_thermochemistry`，CLI `calcite-thermochemistry`调用同一函数；[使用方法](USAGE.md)，[原始来源与推导](REPORT.md)。这是原式求值与纯物质指定进度的计量计算，不是动态烧制模型。

三个物种采用同一USGS评估的原始Cp式与298.15 K形成焓。用解析积分构造每相的同参考储能焓，再计算反应焓和热容差；没有调用高温形成焓列替换储能，没有另加反应热。结果保留原不确定度、原系数/省略项、版本、相态及温区。每项来源依赖都能在结果JSON中解析，最后对应原书页码及原文件SHA。

固定80位十进制上下文防止调用方舍入策略改变结果；位数属于计算策略。来源提取和元数据按核读版本校验，仅限量读取普通文件；FIFO与其符号链接不会在打开处阻塞。原始PDF、截图和元数据中的外部路径不被执行或自动读取。高温体积、动力学、平衡与MIA3库存保持unknown。

实际验证：

- 先保存缺模块的真实RED，然后新22项通过0.40s；来源路径补全后相同22项再次通过。独立数值积分对照使用SciPy求积Cp，检查350/650/900/1200 K显热；这不是实验误差门槛。
- 新功能及受影响的两组旧CLI回归合计68项通过2.20s。非editable离线重装只更新本项目包，154源码模块/161包文件与冻结版本逐字一致；安装后相同68项通过2.26s。
- 独立代码审核6项通过0.052s，覆盖真实FIFO、所有依赖路径、极端数守恒、Decimal陷阱隔离、反应焓导数及CLI输出。名为red的第一份审查日志实际已是GREEN，未虚称修复前执行过失败探针。[代码结论](review/code/REVIEW.md)。
- 独立科学审核实际查看9张原页，以原图手工合并的反应Cp系数重算4个温点；原值/相态/单位与实现范围一致。[来源结论](review/source/REVIEW.md)。同书温点是编译计算值，用于原式复算，不能称为独立实测留出。
- 安装后实际CLI分别运行298.15 K/1 mol和800 K/0.1 mol，进程返回0，约0.048/0.046秒。输出完整保存于 `execution/installed-examples01`，源模块SHA为04c798663f31e2cd5314f34d0ee7904a81643f0cc4c1164759fb6a829533bf33。800 K名义反应焓173414.756906 J/mol进度，0.1 mol指定消耗对应0.004401 kg CO2。

源码/安装日志、XML、初次RED、冻结及安装匹配记录全部保存在 `execution`。其中 `recompute-source-facts.py` 是来源作者当时执行的原脚本归档，仅供审核；它有原硬编码路径并会覆盖派生检查文件，不作为用户运行入口。[归档脚本审查](review/code/ARCHIVED_CHECKER.md)。没有为该功能重跑已通过的湿水原生实验。

共同上限1200 K=926.85°C，低于MIA3的1150–1180°C烧制峰值，接口拒绝外推。它减少了明确矿物热化学的未知项，但未给出砖中实际矿物库存、分解时间、自由烧结、完整一维湿坯到冷却或三个机制的外部验证。Goal完成条件不变；下一步优先公开干燥工况预测及有数据约束的物理耦合。

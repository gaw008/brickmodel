The script imports only standard-library Decimal, filesystem, hashing and JSON modules. It does not execute source text, import unfamiliar/application code, invoke a shell or call an EOS. It verifies the PDF bytes/hash and the facts hash against recorded metadata, evaluates the original coefficients, and preserves polynomial-versus-printed discrepancies. It does not fit, adjust or replace physical coefficients. Its positional coefficient/species unpacking relies on the actual archived JSON order; it should not be treated as a general schema-independent calculator.

The inspected unit conversions are consistent: formation enthalpy kJ/mol is multiplied by 1000; sensible enthalpy is the analytic Cp integral in J/mol; the printed enthalpy function is compared with that integral divided by T; J/kg calcite divides by formula weight converted from g/mol to kg/mol. The NIST Shomate comparison uses T/1000 and converts its enthalpy increment from kJ/mol to J/mol. NIST values remain a separate comparison and are never substituted into the USGS reaction calculation. The solid-volume difference is explicitly limited to the printed 298.15 K values in cm³ per mole of extent.

# 动态固液气主机的独立干燥极限解析检验（预登记）

本例只作制造数值验证。固体Cp=50 J/(mol K)、库存2 mol，理想载气Cp=30 J/(mol K)、库存0.01 mol；液水和水汽库存均0，气体跨面迁移关闭。R取现有明确值8.31446261815324。固定bulk=1e-4 m³，固体恒摩尔体积1e-6 m³/mol；A=0.01 m²、dx=0.01 m、k=10 W/(m K)、膜h=100000 W/(m² K)，辐射关闭。它不提供泥料参数或实际干燥预测。

外界气温节点(t秒,T开尔文)=(0,300),(10,305),(20,305),(40,295)。初始T=300 K。各段线性，保温为斜率0。完整状态逆解温域仍295–310 K。半格导热与膜串联G=A/(dx/(2k)+1/h)，C=2*50+0.01*(30−R)，a=G/C。单段起始炉温B、斜率b、起始芯温T0时：

T(t)=B+b*t−b/a+(T0−B+b/a)*exp(−a*t)。

独立参考只用60位Decimal解析式，不导入主机、积分器或被测表面求解器。任意保存时刻按分段传播计算参考，Q=C*(T−300)，表面Ts=(2*k/dx*T+h*Tb)/(2*k/dx+h)。所有原输入按对应Python二进制float的精确Decimal值表示。

先生成参考再执行候选。固定最大步0.4、0.2、0.1 s，统一较松自适应误差政策以观察实际步长；若实际拒步/变步不符合均匀细化，不宣称固定步收敛，保存真实情况。最细网格最大轨迹温差≤1e-3 K、每步U变化对同权重面热账本≤1e-7 J、全前缀≤1e-6 J、库存精确不变；最终两个相邻最大轨迹误差比≥2.8且误差单调下降。以SSPRK2的二阶时间离散为依据，反解/表面数值误差须比观察误差小，不把浮点噪声解释为收敛。

温度上升、保温接近平衡、最终冷却以及节点精确落步也需检查。逐轨迹与解析Q比较不代替独立面账本。该有界测试不包含水蒸发、实测验证或空间收敛，后者单独验收。门槛在候选运行前登记，不因失败改写。

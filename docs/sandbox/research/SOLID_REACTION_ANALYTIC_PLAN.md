# 固体→气体反应全库存/U/P独立解析极限（预登记）

制造验证，非真实碳热解/污泥反应：等元素等摩尔质量的X(s)→X(g)，一阶k=1s⁻¹、Ea=0、bulk归一化c_ref=1mol/m³、A=1mol/(m³s)。X的元素计数取C:1及摩尔质量.012kg/mol只是计量测试。气体另有.01mol载气N2，初始固体.01mol，初始X(g)=0，液水=0。无外热、面流或水相变。固定bulk=1e-4m³，固体v=1e-5m³/mol、p0=1e5Pa，T0=300K。

制造热曲线采用同一298.15K标准焓锚：固体Cp=50J/(mol K)、hf=0，产气Cp=30、hf=−1000J/mol，载气Cp=30、hf=0；R=8.31446261815324。对应Shomate A=各Cp、其余温度项0、F=hf/1000−Cp*298.15/1000、H=hf/1000。实际输入F按Python float原值记录，参考使用这些二进制输入的精确Decimal表示，不假装F计算无舍入。此反应热是明确制造值，不称碳升华或真实热解热效应。

解析Ns=.01 exp(−t)，Ng,X=.01−Ns；载气不变。每个T的固体u_s=Cps*T+1000Fs−p0vs，气体u=(Cpg−R)T+1000Fg。初始总U由这些独立公式得出；反应期间U保持，故T(t)=(U0−ΣN_i*const_i)/ΣN_i*Cv_i。Vgas=bulk−Ns*vs，P=Ng,total*R*T/Vgas。该公式独立于候选storage inverse、reaction rate、面主机和integrator。

预登记运行时长2s，t=0,.25,.5,1,2保存参考。三档二进制精确最大步1/16、1/32、1/64s，实际记录步列、拒步、节点，不预报固定步。最细全轨迹固体库存误差≤1e-6mol，温差≤.02K，压力差≤100Pa；最大库存误差相邻细化比≥2.8、单调下降且uniform。逐步与全前缀总U误差≤1e-7J，C/N元素和质量相对1e-12、绝对1e-12mol/1e-14kg；完整reference各输入及源码hash保存。无O2的此反应不得被氧化开关误关；有限O2库存由另一有氧host测试单独验证。

数值资格：这是常速一阶制造极限和固体占积/总U反馈验证；不验证Ea温度敏感反应刚性、不提供污泥伪组分/产物/动力学/形成能来源。压力/温度误差门槛只用于数值对照，不能解释为实验置信区间。每档积分墙钟上限120s、最多5000step/100拒步；先生成参考再运行候选，不因失败改门槛。

# 来源多格净库存的时间插值与全区间最小值

2026-09-10 UTC，基线 `8b6ef80`。本增量将已求出的来源多格液/气/总能量面流接入既有精确库存多项式，为净液流耗尽定位提供输入。完整 Goal 继续 active。

## 计算含义

`source_net_panel.SavedSourceSample` 保留实际 `ConservedState` 与完整 `SourceExactEvaluation`。`build_source_panel` 接受起点和严格内部采样时刻，以及明确的上界时间；内部采样不必位于一半，全部时刻和时间差保持 Fraction。来源、固定干质量 kg、流体 mol 布局和能量身份分别检查，源状态与压入数组逐项对应。

每份记录保留 N+1 个共享面。实际液水/三种气体/总能量面流及液汽相转移，与通用 Rates 数组逐项核对；干固体质量不进入摩尔数组。以两个采样时刻相差 hm 为例，面流或局部源的数值插值为 r(t)=r0+(rm−r0)t/hm。逐格先用左面减右面加局部源形成净变化，再积分：

N(t)=N0+r0·t+(rm−r0)·t²/(2hm)。

液水净导数包含 J_left−J_right−phase。即使 phase 为零或代表凝结，净液流仍可能造成库存下降。气态水具有相反的 phase 项；总 U 只使用同一总能量面流，无重复相变热。库存多项式索引沿四列流体数组：0液水、1O2、2N2、3H2O气体；不能当作旧A/B主机的gas下标使用。

直接复用 `mass_wet_exact_stage.InventoryPolynomial.minimum` 检查端点及必要的区间内部极小值，没有复制最小值或根隔离算法。总 U 可为负，未对能量错误施加正性要求。`check` 从原样本重建全部派生多项式、共享面流历史和时间域，拒绝改变派生项后继续沿用旧样本绑定的情况。

输出资格明确为 `saved_numerical_affine_panel_not_stage_or_event_acceptance`。该多项式是采样速率的数值插值，不是新的材料本构，也不能证明两个采样点之间的真实物理轨迹。调用者声明的上界不是两个样本自动证明的有效区间；最小值可用于下一层数值候选检查，但此处没有自动接受正性、选择耗尽根、修正库存、切换干态或接入旧事件记录。

- 临时候选只核对输入样本，替换派生库存/U/面流历史后仍可通过检查。实际RED复现五类篡改，现由共用构建公式重算及精确类型检查关闭；旧候选和失败保留。

- 独立Python审查实际证明 `SourceExactEvaluation.material_qualified` 可被修改而不触发原检查。现对求值记录与原始列记录都要求严格 False，不能通过改标记升级材料资格；原独审失败保留。

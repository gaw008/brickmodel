# 低含水隐式排湿与热湿输运

从 `8d104d9` 实现局部 backward Euler 相变/排汽，再与来源凝聚水输运、导热和热浴按一阶 Lie 分步耦合。两个子算子各用 h，物理时间只前进 h。局部相变和外排水共享精确 J/E/H，慢算子关闭重复的相变/排汽，保持共同能量参考，不增加第二份潜热。实际写回舍入与面通量费用计入原预算。

`implicit_local_moisture.py` 是保持库存非负的线性局部算法；`low_moisture_split_column.py` 每个接受步使用两次真实物性解码，检查原 T/P/U、来源绑定和低含水域。取消或超时保留已接受前缀及最后完成的物性结果。独审发现的两个真实失败（取消丢失已返回结果、末尾超时仍提交）已修复，原失败与修复测试保留。

# 可选水物性后端：两点可行性证据

这里只保存隔离研究，生产后端仍为来源校验的 Python iapws 1.5.5。没有安装或启用生产 CoolProp 适配器。

`original-evidence.zip` 保存 20 个原始文件及成功快照，归档时逐项读取校验字节相等；`archive-manifest.json` 记录各成员的大小和 SHA-256。未复制临时虚拟环境或依赖缓存。原安装二进制的身份在包内 `installed-assets.json` 中，归档本身不含该二进制，也不是离线可安装发布包。MIT 许可原文随证据保留。

当前报告与独立审查另提供可直接阅读的副本。成功探测实际约 1.037 秒，在两个 300 K 液态点比较热物性。原始 flash 计时不包含完整来源、相态、Helmholtz、Gibbs 和反解验证，不能作为完整模型加速倍率。

独立审查保留两个 MEDIUM 限制：原 SIGALRM 是协作式超时；固定结果文件名可能在后续失败重跑时遗留旧结果。当前成功记录未发现混用，但不将其 runner 作为今后有界运行工具。原成功报告/脚本/结果快照保留；纠正后的报告没有倒写原始证据。

`ADAPTER_DESIGN.md` 是下一步设计，要求显式选择、完整实现身份、相同物理域和验证门槛、明确的质量到摩尔转换及可变后端实例隔离。它不是实现或验收通过证明。真实原污泥材料参数、湿态全程精度和烧结机制均没有因这份证据得到验证。

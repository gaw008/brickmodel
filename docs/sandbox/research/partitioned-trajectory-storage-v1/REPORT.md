# 大轨迹分片直接保存

为继续256格而不保留几十GB的重复原文缓存，现可在计算时直接写入分片gzip，并逐片用临时原文作字节回读。每片最多约64MiB完整JSON行；已完成片回读相同后移除该片临时原文。不是抽样、精度截断或删除接受步。

现有已验证八格精细轨迹的103540721字节、3709条完整记录，经新写入器保存为两片25104605字节。全部原始字节回读相同，新的清单读取器对全部记录、全部字段和顺序比较相同。没有重复运行物理模型、没有新增或执行软件测试、没有SHA。

闭合高温列运行器新增显式 `--archive-parameters parameters.partitioned_trajectory_storage.json`；其 `--output` 此时为JSON清单，清单按顺序给出相对路径。原完整审计、时间汇总和空间比较通过相同记录迭代接口读取清单，科学方程、记录内容和原预算不变。普通JSONL路径仍按原格式读取。异常退出保留已经写出的前缀并明确标记，不把缺少完成记录的文件说成完整过程。

仅证明记录传输与保存未丢失信息，不能代替256格尚未运行完毕的物理与数值资格。

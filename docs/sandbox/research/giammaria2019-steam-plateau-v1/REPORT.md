# 有出处的方解石有限速率与恒温反应供热

新增能力是在**固定文献试样、初始稳态速率平台**下，计算水蒸气对CaCO₃分解速率的影响，并将净反应量连接到相容热化学。它不再要求反应瞬时达到平衡，但也不是任意材料、任意温程的动力学。

[Giammaria与Lefferts 2019论文](https://doi.org/10.1016/j.jcou.2019.06.017)对应内容在[作者2020博士论文](https://doi.org/10.3990/1.9789036549431)第二章及附录A2中完整公开。实际下载并核读博士论文；PDF第54/55/173/174页已目视核对式、表、实验数字及作者脚本。全文和页图未重新分发，来源定位和本研究需要的事实记录在`source.json`。

来源不是天然砖料：抗坏血酸钙制得CaO、筛分250–300µm，约3mg CaO当量与70mg SiO₂填充物组成固定床；先经历40次循环老化，后续实验还有作者的老化修正。气流90mL/min，590/610/630/650°C、Ar中0–1.25%水蒸气，观察初期分解平台。缺少相同实际砖的表面积/孔结构/库存迁移规则。

速率的单位已经分清。表2.1的k₂/k₃明确是`10⁻³ m²/s`，乘以文中位点密度`8.1×10⁻⁶ mol/m²`后得到整份试样的`mol/s`。附录脚本直接拟合这种试样总速率。新类保留两个mol/s极限值和Pa⁻¹吸附系数，不能再将这些系数当成s⁻¹、单位面积本征常数，或任意乘以砖质量。表中的温度点分别使用，没有自造温度插值或前因子。

590°C的13组实验点和横纵误差已逐项转录。固定印刷标称值复算有11/13条曲线与实验误差矩形相交，两点不相交，最大中心相对差11.11%；失败保留。逐点参数范围都可覆盖，不代表一个共同参数组必然覆盖，故另外进行了共同可行性计算：写成`R=(a+b·p)/(1+K·p)`后，所有误差矩形和原参数范围给出线性不等式。一组共同解为干气速率1.2089×10⁻⁸mol/s、饱和水汽速率4.67277×10⁻⁸mol/s、K=2758.05bar⁻¹，60位算术复查不等式的最小松弛仅有−7.86×10⁻¹⁶的数值残差。**这是利用原拟合数据寻找的可行组，不是独立验证、统计置信区间或作者确认参数；没有替换标称模型。**

后续恒温计算仍使用原标称参数。为清楚显示有限库存和能量关系，声明1bar、无气体积累、全部流股与固体同温的20s平台条件；52组情况使用四个来源温度、13个水分压。初始碳酸盐库存借用文献630°C老化样品约0.27g CO₂/g CaO的容量，3mg当量按纯CaO计，是明确近似，非逐工况实测库存。最多消耗25.95%的初始碳酸盐，处于所声明的前半段平台假设内。该20s是平台中的积分窗口，不重建有约30s管路滞后的加湿启动。

等压供热包含固相焓变化和生成CO₂的流出焓：`Q=ξ ΔrH(T)`。USGS同源CaCO₃/CaO/CO₂物性与原参考基准保持；载气和水汽无净消耗、进出口同温，其标准焓抵消。没有将反应活化能当成反应热。熵同时计入固相变化、出流CO₂、载气稀释及热浴熵；同源反应亲和力给出独立表达式。

52组结果：

- 恒温供热0.03912–0.81954J；均为模型计算，没有文献量热验证。
- 出口CO₂分压16.93–355.37Pa，逐工况均低于对应同源平衡压力；正向亲和力8.195–18.568kJ/mol，熵产生全部非负。
- 完整出口流量为载气加生成CO₂；源实验换算使用近似固定流量，对应本计算的相对差最多0.3566%。速率仍按来源入口水分压评估，未误称精确局部蒸汽边界。
- 元素残差最大1.36×10⁻²⁰mol，独立积分的反应量差8.47×10⁻²²mol、热量差1.10×10⁻¹⁴J、熵差3.25×10⁻¹⁹J/K，均低于预设数值预算。速率60位复算最大差2.65×10⁻²³mol/s。

# 化学平衡、温度与封闭孔隙运动

已将 CO+H₂O⇌CO₂+H₂ 的受限理想气体平衡接入变温黏性球孔，N₂ 为惰性载气。采用已核对的 USGS 1995 气相焓、熵及热容；力学关系继承有限不可压缩牛顿流体球壳。初始几何、气体配比、恒定黏度、表面张力、基体热容和热导均为根参数文件中明确标记的虚拟条件，未作为真实砖坯材料参数。

该反应的气体总摩尔数变化为零，理想气体平衡组成与体积无关。因此气体平衡内能仅随温度变化，可以使用包含组成变化贡献的平衡 Cv：

(Cv,eq+Cm) Ṫ = Q̇ − pg V̇ + D。

反应能已经包含在组成焓和 Cv,eq 中，没有另加一份反应热。总内能包括气体、基体和 γA，满足 U̇=Q̇−pout V̇。气体与基体、热浴的总熵产生为 D/T+Q̇(1/T−1/Tb)；受限瞬时平衡下反应亲和力为零，不提供有限反应速率。气体在时间零点以前已达到初始温度下的平衡，制备过程的热量不在运行收支内。

54 个静态组合全部通过冻结预算。独立参考直接读取来源系数，以 60 位计算和反应程度二分求解重建组成；由反应商多项式微分得到平衡热容，并以总 U、S 的五点温差进一步核对。力学采用两侧法向应力联立求解和径向耗散积分。最大能量变化率差 8.026e−25 W，熵变化率差 1.298e−27 W/K，元素差 1.578e−30 mol。

四种 20,000 s 情形各计算两档容差：初始孔压 100/300 kPa，分别绝热或经历 1100→750→1000 K 热浴程序。初始孔半径 10 μm、温度 800 K。8 条轨迹的 34,020 个记录状态及 52,008 个接受步内求积状态通过独立来源重建、局部/累计积分、机械功、热量和熵核查；记录组成也完成元素守恒与平衡亲和力核对。

时间比较共 64,538 个联合节点，最大温度差 1.703e−8 K、孔半径差 1.471e−14 m、孔压差 8.134e−4 Pa。最大整体能量收支差 2.446e−18 J、熵收支差 4.196e−18 J/K。这里的数值差不代表实物预测误差，也不是连续时间误差上界。

绝热收缩终态为 800.018598 K、8.348401 μm；绝热膨胀终态为 799.957435 K、12.674364 μm。独立联立 U+poutV 守恒及机械平衡得到一致终态，温度差小于 6.4e−10 K。热循环终态分别约为 994.752531 K、9.066842 μm 和 994.744588 K、13.734596 μm。

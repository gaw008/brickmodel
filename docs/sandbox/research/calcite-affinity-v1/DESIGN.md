# 方解石反应方向的下一来源增量（同源名义模型）

已有USGS同源CaCO3/CaO/CO2的Cp和形成焓，但原入口只求给定反应进度的热量，不计算反应方向。本次重新取得官方原书并目视核对PDF187/188/274页，记录三相11个温点的形成G和logK以及更细打印的298.15K熵。旧来源文件和含SHA旧执行器保持不动，不执行旧摘要计算。

在恒定总压力1bar、纯固相活动度1、CO2理想气假设下，下一最小开发是用同源Cp/T积分得到S、同源Cp积分得到h，计算配平CaCO3→CaO+CO2的ΔG°，再加RT ln(pCO2/p°)。输入pCO2必须是明确情景；不提供有限时间反应速度，不把平衡温度当实验起始分解温度。反应的元素参考项可以相消；单物质高温形成G列不得直接充作储能。

使用域限于三相共同298.15–1200K。新数据根文件 `parameters.calcite_affinity_source.json` 保留源页、原打印字符串和两位熵参考选择。拟先与形成G/logK的配平表组合比较，打印末位传播只约束算术一致性，不是材料不确定度或实验验证。非理想CO2、高温固体体积、目标配方矿物量和速率仍未知。

本增量已完成限定实现与来源算术核查；不启动整砖高温动力学，不替换M1目标。标准态h/S的积分定义另参见 https://cantera.org/stable/reference/thermo/species-thermo.html 。

# 方解石同源反应自由能：限定核查完成

实现CaCO3→CaO+CO2的标准反应焓、熵、自由能及CO2分压对应的亲和势。Cp、298.15K形成焓、绝对熵及11温点G/logK均来自同一USGS1995资料；新入口只读取事实JSON，不执行旧SHA加载器。纯固体活动度1、总压1bar、CO2理想气及298.15–1200K共同域明确保留，原始数据与高温误差未知项未更改。

Ca/C/O计量及原书打印摩尔质量严格配平。33组相/温度的解析Cp及Cp/T积分与独立自适应积分一致；5温点dG/dT=−S及van’t Hoff关系通过预先声明的预算。15个原书熵点、11组反应形成G和logK均在打印末位传播的算术包络内；最大反应G差124.45J/mol。该包络包含输入形成焓/熵和Cp系数的打印舍入，**不是物理误差上限或实验置信区间**。

CO2分压40/1000/10000/100000Pa（声明虚拟气氛）对应名义平衡温度约805.414/920.404/1026.281/1161.544K。它们只表示所选纯相/气氛在平衡模型中的反应方向分界，不能当作砖坯实验起始分解温度、升温速率或烧成制度。在1200K名义平衡CO2压力超过总压1bar，结果明确标注此气氛下该平衡压力不可实现，不把它当作真实气体分压。

`source-review.json`保留初版算术，`extended-source-review.json`另增加计量及单相原书熵对照，未覆盖历史记录。执行根文件 `parameters.calcite_affinity.json` 与 `parameters.calcite_affinity_source.json`。来源页 https://pubs.usgs.gov/bul/2131/report.pdf ，已核读PDF187/188/274页；本报告没有把浏览工具403当作已读PDF，使用的是单独实际取得并目视核读的官方文件。

下一项可独立开发的是纯方解石的等压、瞬时相平衡热量驱动分解/再碳酸化极限。它可检验组成热储与CO2流焓和热量的共同账，仍不提供实际有限速率、矿相库存或烧结收缩。目标砖材料资格与training_eligible均为false。

## 2. 从第一定律到带明确符号的整体锚

全封闭刚性量热弹内容物包含样品、袋/燃线、氧和缓冲液。定义 (Q_{out}>0) 为内容物放给量热器的热，(W_{on}>0) 为外加点火功；忽略动能、位能且无泄漏，则实际过程

\[
\Delta U_{bomb,actual}=-Q_{out}+W_{on}.
\]

等温反应能还要扣去初末不等温的储能项；量热器温升到 Q_out 的归算亦需校准/漏热处理。**论文没有给出上述原始 Q_out，15MJ/kg 是已报告 HHV，不应重新当作未扣袋、未修正的原始弹热。** 燃线燃烧的化学能和外加点火功也不能混为同一项重复扣除。

先明确一个目标整体反应 (F+O^*\to P^*\)，所有项在同一 (T_r,p_r\) 和共同元素参考下；(P^*\) 包含所选择的完整燃烧气/液/酸/矿物终态。相同的额外 N₂、过量 O₂及不变试剂在前后抵消。以原模型“1kg报告样本”为账本单位，定义：

- (q_{rep}=15.0\times10^6\) J/kg（原文报告分母）；κ 是该单位样本对应的报告分母 kg 数，尚未证实其严格基准转换。名义共基准可声明 κ=1，但不能称已证实干基。
- **(C_U:=\Delta U_* -(-\kappa q_{rep})=\Delta U_*+\kappa q_{rep}\)**，单位 J/该单位样本。它是相对“已报告 HHV”的**剩余净内能校正**，包括目标终态、参考温度/压力及作者已有处理与目标处理之差，不是再加一遍全部常见校正。

于是严格有

\[
\Delta U_*=-\kappa q_{rep}+C_U,\qquad
\Delta H_*=-\kappa q_{rep}+C_U+\Delta(pV)_*,
\]
\[
\boxed{H_F(T_r)=H_{P^*}(T_r)-H_{O^*}(T_r)
       +\kappa q_{rep}-C_U-\Delta(pV)_*.}
\]

该式是整体原料焓约束，不要求原料为单一分子。C_U 正表示目标 ΔU 比 −κq_rep 更大，即目标放热较少；所以在固定产品/氧化剂焓时，它降低反推出的 H_F，符号不能反转。若报告量已经是同一目标的 −ΔH，则 (C_U=-\Delta(pV)_*\)，两项自动抵消；不能再把理想气体 pV 换算重复加到已经换算过的 HHV。本文尚未说明属于哪种情况。

参考温度变换属于 C_U 的组成：在反应各物种及相已明确且路径连续时，目标同一反应的 (\Delta U_*(T_r)-\Delta U_*(T_B)\) 可由各产物/反应物的储能差计算；跨相变必须含实际相变能。不能只拿气体 Cp 代替凝聚污泥、水、缓冲液或矿物的变化。当前 (T_B\) 本身未给。

## 3. 能独立算出的计量与 pV 项

采用现有**条件 CHONS 子池**、凝聚原料、气体理想、同温，定义参照产品 CO₂(g)/H₂O(l)/SO₂(g)/N₂(g)。它不是原弹的实测终态，也暂不处理灰/Cl/Br参与反应。由同一实际原子量得到

\[
D=b_C+b_H/4+b_S-b_O/2,
\]
\[
\Delta n_g=b_C+b_S+b_N/2-D
           =\boxed{b_N/2-b_H/4+b_O/2}.
\]

相同额外 N₂和未变的过量 O₂在前后抵消；液态产品水不计入气体 mol。若改用 H₂O(g)，Δn_g 会增加 (b_H/2\)，同时产品焓/燃烧能的液汽转换也要一致，不能仅改变计数。

实际 stdlib Fraction 算术（原子量/R来自已保存且通过的 source RESULT，无新物性调用）给：

| 可计算项 | 值与含义 |
|---|---|
| 原报告 HHV | 15,000,000 J/kg；打印±量为300,000 J/kg，未赋予置信含义 |
| HHV×名义0.5g aliquot | 7500 J，打印±量缩放为150 J；不是原弹总热或实际单次读数 |
| 原 Eq1 的扣项/LHV | 1.2525 / 13.7475 MJ/kg，与p9四舍五入13.75相容 |
| 条件 D / Δn_g | 36.5225395092 / −4.13651427425 mol，仍按1kg报告样本 |
| 理想气体 pV 系数 RΔn_g | −34.3928933027 J/K |
| 选择 (T_r=298.15K\) 的气体 pV 项 | −10254.2411382 J，仅为指定温度的计量示例；不是已知弹温 |

全目标转换始终为 (\Delta(pV)_*=\sum_P pV-\sum_R pV\)。对上述理想气体示例，仍需加入凝聚体 (p_r\Delta V_{cond}\)；真实反应若涉及酸/盐/碳酸盐及不同氮硫终态，还会改变气体计量，并可能有非理想气体 pV 项。它们未被 −10.254kJ 这一小项覆盖，数值较小也不能证明整个校正可忽略。此处不计算 H₂O(l) 的标准焓，不越过现有 TP 合同的800–1200K域去求298.15K物性。

## 4. 余项对应哪些实际物理缺口

**终态及酸修正。** 必须先选定并元素配平目标。弹中硫/氮未必进入 SO₂/N₂；可能进入溶液、盐或矿物，氯溴捕集又涉及碳酸盐试剂的碳/钠库存及中和过程。将目标终态与实际弹终态连接的反应内能进入 C_U。袋 HHV“已知”只说明作者有辅助燃料信息，不能从本文确定其质量或软件是否已扣；同样不应再用总 S/Cl 含量乘一个猜测修正系数。需要的是作者原方法选择及量热输出/终态记录，不是另一泥的校正数。

**基准。** κ只处理质量分母对应关系，不能纠正不同预处理后已经改变的化学组成。若以后证实差异仅为明确数量的自由水，则用 (H_F=m_dh_d+m_wh_w\) 配套转换，并同时改元素账；不能只除以 (1-w\) 就让现有湿/干分母问题消失。现有TP池不再补加.024kg水；严格干基和各aliquot一致性仍未知。

**灰与整体/子池的区别。** 上式可锚整体 F，但不能把整个15MJ直接当.704kg CHONS子池的已知形成焓。若明确划分初始外置相和终态外置相，子池锚还含 (H_{outside,final}-H_{outside,initial}\)。在同温且前后完全相同、无相互作用改变的惰性外置相近似下，其参考常数可抵消；不需要先知道这一常数。当前灰是操作性残渣，不足以证明该近似。升温到另一温度即使化学不变，其储能也不再自动抵消，仍需相容热储数据。

**已能推进的范围。** HHV已经约束一个总括标量组合 (H_F-H_{P^*}+H_{O^*}+C_U+\Delta(pV)_*=\kappa q_{rep}\)，上述计量/单位项可真实计算，后续可沿这个单一方程加入实际已核的校正与产品焓。所需最小证据是可解读的 C5000 报告/所选校正规程、量热分母/参考温度，以及足够定义酸/矿物终态的记录；不需要穷举全部原始有机分子。在同一已知量热参考温度下锚 H_F 不先要求原料 Cp 或 S；转移到另一初温需热储，HP只需相容初态H与终态h，不能因缺原料S误判所有能量路径不可做。本轮不把 C_U 或灰 Cp 设零，不合成H_F数值，不称已闭合HP/UV/实际热耗；原固定TP组成探索继续有效。

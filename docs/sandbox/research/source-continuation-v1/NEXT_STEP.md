# 本阶段之后的实际入口

本阶段完成同一会话的完整提交步暂停与继续。原生新段的所有状态静止，因此下一验证必须
增加有状态变化的来源案例，不能把同一案例运行更久当成动态材料验证。355项安装测试和
唯一原生运行均已结束；已有结果无需重跑。

1. 从已存在的来源开放边界/液流数值案例中选择适用的非零驱动，先检查当前
   `source_run_config_v1`和混合湿干算子能否原样表达。单独登记测试配置、初态、边界、来源域、
   原数值门槛与计算成本；任何制造几何/输运参数继续显式标记为测试值。保留本阶段原静止案例。
   若配置或准入尚不支持该驱动，先完成所需接线与针对性测试，不静默绕过配置验证。
2. 用同一原政策比较非静止普通段的连续运行与已提交步暂停/继续，核对实际状态变化、
   完整回调前缀、步长/拒步、原资源消耗和从原湿初态累计的守恒残差。先确定有界计算计划，
   失败则保留原结果并分析；不得用放宽误差、删除失败或把新的初态当作恢复来取得通过。
3. 在已有`ExactIntegrationCheckpoint`和`SourceTrajectorySession`基础上定义闭合、版本化的
   持久化控制器协议。保存原问题、原政策/成本、下一步长、完整实际回调及来源身份；
   读回先被动核对，随后真实重建算子。仅完整提交边界准入；中途失败或不匹配保持明确拒绝。
   对进程间时间记账明确约定，不能清空已耗预算。JSON落盘本身不代表具备恢复能力。
4. 把这一经验证的入口接到共享运行服务、CLI和现有中文界面，并保留原研究/新段的关系。
   同一次保存结果用于查询、图表和导出，材料状态、来源适用范围与失败均如实显示。

科学路径同时继续：依据[GNEST基准审计](../gnest2021-basis-audit-v1/REPORT.md)寻找同材料、
矿物在内的元素库存和独立凝液/气体产物及热效应证据。差值凝液不充当独立配平验证，
不同论文的材料不自动视为同一原料，25°C热值差不直接充当动态反应热。缺失项维持unknown。

以上是下一实现顺序，不是对完整Goal的缩减。同材料湿坯到反应、烧结/几何、冷却的全流程，
三个机制公开留出预测、时空收敛、完整周期、多代实验/搜索和应用验收仍是必需范围。

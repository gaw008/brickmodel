# 缺碳与富碳循环：不同相顺序的完整限定核查

继[中等碳库存循环](../carbon-calcium-cycle-v1/REPORT.md)之后，本阶段沿用已通过静态/热容/相界核查的另两组虚拟库存，不增加新物性或反应速率。Ca=2mmol、O=8mmol、N2=4mmol不变，总C分别3.5和7mmol；元素量包括固相与气相。初态300K、总压力1bar、换热系数.005W/K，1150K热源保持2400s，再切换350K直到4800s。加长保持时间用于完整越过各自相边界，并非实际窑炉程序。

[缺碳图](limited.png)显示约0.5mmol初始石墨先在170.134192s耗尽，方解石在215.838375s开始分解、1143.382036s全部分解。冷却时方解石重新出现和恢复全量分别在2406.155672、2509.303745s，石墨在2521.613924s重新出现。末态350K、方解石2mmol、石墨约0.5mmol。

[富碳图](excess.png)显示约4mmol初始石墨始终有剩余。方解石在258.628695s开始分解，1120.240208s耗尽；冷却时2449.031215s重新出现、2631.485462s恢复全量。末态350K、方解石2mmol、石墨约4mmol。这些是允许的纯相/理想气体体系的瞬时平衡路径；不能把时间直接解释为真实焦炭燃尽或真实砖坯再碳酸化速度。

两组各两档轨迹均完成所有原数值预算：独立源参数H/S重组、Ca/C/O/N守恒、分压与互补相条件、每接受区间2/4阶热量和熵积分、两档2400个观测时刻，以及所有六个/四个相事件。缺碳基础/精细最大累计热量残差5.78018e−7/2.37184e−7J；富碳8.34211e−7/1.50458e−7J，均低于原1e−6J。四条路径最大累计熵残差≤8.07790e−10J/K，低于1e−8J/K；气体正、固相非负、热接触熵产率非负。

缺碳两档最大温差8.56497e−7K、物种差2.88924e−12mol；富碳4.62143e−7K、4.57488e−12mol，均通过1e−4K/1e−10mol预算。精细路径的独立60位同时元素/化学势方程与32/64阶Cp热量时间积分分别给出最大事件差2.14165e−7/4.96711e−8s，最大Cp差2.65172e−12/1.01849e−11J/K；求积阶差≤1.48037e−17s。源数据的物理不确定性不由这些数值误差界替代。

缺碳/富碳循环结束净吸热16.7590805/18.4092459J、系统和外界总熵增1.52737974/2.42418811J/K。净热量含升温后又冷却的抵消，不是燃料耗量。

# 高温组成循环的辐射边界增量

在已核对的1bar纯方解石瞬时平衡循环上增加A ε σ(Twall^4−T^4)，与原UA(Twall−T)共享同一恒温热库，复用既有boundary_heat因式分解的四次方差。热量、化学平衡、CO2流焓和来源温域不变。新1e−3m²面积是声明虚拟几何，ε=1是理想黑体定义，不是方解石或砖的实测发射率。NIST2022 σ打印值/单位/精确性以及由kB/h/c推导关系保留根参数，有限小数是数值表示。

质量、焓和组合熵沿用原预算，仍用1s最大步长，两档ODE精度。审查用独立展开四次方差复算热率；Cp/Q温度积分和相平衡平台热量继续给出独立事件时间。黑体辐射场不作储能状态，计算的是物体+外热库整体熵改变Q(1/T−1/Twall)，不能把热库−Q/Twall误称辐射光子的熵流；真实灰体有限腔体或参与介质仍未纳入。

该增量不添加有限速率，不解除原材料数据依赖；不执行软件测试、SHA或子代理。参数与来源在parameters.calcite_radiative_calorimeter.json。

# 连续分段边界程序

`src/sludge_sandbox/boundary_program.py` 提供独立的 `ScalarProgram` 和 `BoundaryProgram`。输入定义外部设计条件，不提供原料物性，也不证明这些条件在某窑炉可实现。

## 输入与输出

`ProgramIdentity` 必须显式提供程序 ID、版本、来源类别和非空且不重复的来源 ID。类别限 `virtual_design_choice`、`measured_public_data`、`derived_from_evidence`。这是输入身份记录，不会自动解析源文件或核准材料适用域；`provenance_status` 明确为 `input_identity_only_not_material_admission`。复合来源可列多个 ID，外部证据注册表仍需保存各字段的具体出处与派生过程。依据实测节点构造线性插值时，应将程序本身列为派生值，保留实测节点上游来源。

`BoundaryProgram` 使用所有通道共享的至少两个严格递增节点 `knot_times_s`。各节点指定：

- `gas_temperature_k`：外部炉气温度，K；不是砖芯温度。
- `radiation_temperature_k`：外部辐射环境温度，K；不自动等于炉气温度。
- `total_pressure_pa`：外部总压力，Pa。
- `species_order` 与 `mole_fractions`：显式完整组分顺序，以及每个节点的全部摩尔分数；零也需给出。

绝对温度、压力必须为正且有限。时间为有限秒，可采用负的时间原点。摩尔分数须在 [0,1]；总和只允许 `8*ulp(1.0)` 的二进制表示误差，绝不归一化。该误差界是软件数值政策，不是测量误差。输入列表及输出组成会复制为不可变结构。

`at(t)` 返回各通道线性插值结果、实际查询时间和程序身份。节点上返回原始浮点输入值，不外推；域外抛出 `BoundaryProgramError`。查询与插值不检查物性数据库的温压域，调用方仍须核查。组分集合是否与求解器全部活跃气体一致，也由耦合层核查。

`ScalarProgram` 用于独立标量通道，显式携带 SI 单位；当前允许 `1, K, Pa, W, s, m, mol/s, kg/s, W/m^2, W/m^2/K`，不自动转换单位。通用标量允许正负值，物理正性由具体通道约束；完整边界程序施加温压正性。

## 连续性与积分器

任意相邻节点均定义线性段；相同值给出保温/恒压/恒气氛段，下降值给出冷却段。首版拒绝相同时刻的重复节点，不能用它表达真实跳变，也没有隐式平滑跳变的行为。

`knot_times_s` 含起止端点；`breakpoints_s(start,end)` 返回指定合法区间内严格位于内部的节点，可传给 `integration.integrate(..., breakpoints_s=...)`。端点不重复传入。斜率改变但数值连续，满足当前积分器的连续边界限制。实际跳变需按左右侧边界分别重启积分，不能把重复时间节点塞入此 API。

本模块尚未将动态外部气体状态接入 `GasHeatModel.outer_reservoir`；该字段目前是静态 `GasState`。也不能把炉气温度直接传为材料表面 Dirichlet 温度来替代必需的对流/辐射换热。边界程序、换热系数、气体状态方程、材料有效域和面交换应由后续耦合层明确连接。

## 浮点政策与验证

对有限 binary64 节点和数据使用其精确有理数计算插值权重与凸组合，最后一次舍入为 float。这避免 `t1-t0`、`v1-v0` 在极端有限输入时溢出，也避免巨大时间原点使正常节点间距丢失。相邻可表示时间可以定义段，但不存在内点时不虚构中点；积分器仍可能因其最小时间表示要求拒绝实际推进。

测试先运行并记录模块缺失错误，再实现。当前验证命令：

```sh
PYTHONPATH=src .venv/bin/python -m pytest tests/sandbox/test_boundary_program.py -q
```

测试涵盖升温/保温/冷却、独立辐射温度与压力、全组分插值、原始节点保留、无归一化、域外拒绝、严格节点次序、输入及输出不可变、极端正温/压力、异种组成、巨大与相邻浮点时间、通用标量与输入身份校验。上述属于程序数值验证，不属于烧结砖实测验证或完整边界耦合验证。

另有实际 `integration.integrate` 集成案例：把边界温度程序连接到明确的制造外功率 `Q=(1 W/K)*(T_design-300 K)`，传入实际内部节点，用不整除节点的 7 s 起步/最大步长推进。独立分段二次解析积分检查每个保存状态、每步外功账本和末端 15000 J，并要求积分器实际停到所有节点、无拒绝步。该构造仅验证程序与积分器的连接，不代表对流定律或材料物性。当前独立测试总数为 41。

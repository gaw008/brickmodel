## 逐阶段准确性准入（2026-09-12 用户要求）

本补充适用于独立 V0 及后续验证 Goal；开发与验证按 [STAGED_GOALS](STAGED_GOALS.md)分别结束，不追认已有结果通过，也不修改下文原数值门槛。阶段开始前在已有记录固定必需机制、输出、材料与工况域、独立参照、误差指标、准确性门槛及依据；验证完成时在验收矩阵逐项给出结论和实际证据。

| 必需检查 | 准入所需证据 | 不能替代它的结果 |
|---|---|---|
| 物理化学一致性 | 有来源及适用假设的方程/推导；量纲和计量正确；质量、元素、包含物流焓与必要功项的能量平衡；对适用过程核对热力学势及其导数的一致性、含热和物流熵流的熵产生、平衡/非平衡条件、有限库存与极限行为。开放系统不能要求系统熵变化本身非负。明确忽略项及可检验的适用依据。 | 单个守恒恒等式、来源文件 hash、软件退出 0、未经证明的瞬时平衡假设。 |
| 材料与参数适用性 | 追至原始表/图/公式和制样、质量基准、温湿、气氛、尺度；说明借用与外推的依据，验证其对目标输出的影响；参数组合和不确定性不伪造。 | 有 DOI 即算适用，纯物质数据直接替代污泥，人工测试系数改名，给未知模型误差标 null 后仍声称准确。 |
| 数值正确与精度 | 对应方程/边界的独立解析、制造解或参考计算，实际时空细化及误差分辨，逐段守恒、反解/积分/投影误差和失败处理；数值误差满足事前规定的用途精度。 | 用同一求解器生成真值、只比一对网格、几步短例代替全段、把更多小数位当实验精度。 |
| 独立现实对照 | 对本阶段声称准确的关键输出，以材料/工况相容且未用于校准及模型选择的数据实际预测；报告观测与预测、误差序列和残差结构，对照事前准确性门槛。纯物性模块可使用权威参考数据，其资格不外推至污泥过程。 | 拟合数据自证、三种不同材料拼成同材料验证、用同一模拟器生成训练和验证数据、仅凭另一代理同意。 |

准确性门槛基于可得测量不确定性和明确的研究用途精度要求，并区分实验、参数、模型形式与数值误差。没有完整实验不确定性时仍可报告实际偏差，但不得制造置信区间或“落在实验误差内”的结论。无法论证准入门槛则保持未验证，不事后按结果挑阈值。

校准和模型选择使用过的数据不再是独立留出。若用失败的留出结果选择新模型，须明确其角色变化并另找适当独立数据；历史失败不得抹去。声明新适用域是新案例，不能冒充原失败案例通过。某项检查不适用于纯软件或常数模块时须写出理由和限定范围，物理预测中的必需检查不得以“不适用”跳过。

任何必需检查失败或缺证据，本阶段都不能以“已验证物理过程”进入后续材料预测。可保留代码和数值基准，复用有效证据，不为证明准确无限重跑。验证报告完整交付可以结束验证任务，即使结论包含失败；只有依赖验证通过才允许下一开发，否则转具体修复/补证据及再验证。各窗口按当前独立 Goal 的执行边界收尾，不沿用旧完整合同的持续执行指令。

## 新内核数值基准（运行前约定）

所有人工给定系数均进入 manufactured 模式。不能用它们完成真实材料案例验收。

| 案例 | 独立参照 | 比较与初始门槛 |
|---|---|---|
| 绝热封闭无反应 | 库存、温度、总内能保持初值 | 库存相对固定初始总量误差≤1e-10；温差≤1e-8 K |
| 封闭配平反应 | 计量消耗上界；独立能量求根 | 元素/质量归一残差≤1e-9；相同平衡问题温差≤1e-6 K |
| 内部面气体交换 | 两格逐物种交换严格互反 | 元素/质量误差≤1e-10；扩散总质量通量残差≤1e-12倍非零通量尺度 |
| 惰性板导热 | 独立 Fourier 级数，比较格平均 | 最细网格温升归一最大误差≤1e-3；空间三档细化显示渐近收敛 |
| 无反应扩散 | 定义对应边界的独立级数解 | 最细网格浓度尺度归一最大误差≤1e-3，空间三档细化 |
| 压差流 | 等压零流、压差反向、串联 Darcy 阻力解析式 | 符号正确；解析热物性域内相对误差≤1e-10 |
| 蒸发/凝结 | 固定水库存和能量的独立相平衡或有据速率积分 | 无水量/能量双计；在对应模型建立后先补具体有效域和oracle再运行 |
| 形变 | 已知相容伸长映射与体积功解析式 | 体积/共享面代数误差≤1e-12；封闭压缩能量≤1e-8归一误差 |
| 冷却力学 | 均匀自由热胀零应力、完全受限解析弹性解 | 同一材料假设下应力尺度归一误差≤1e-8 |
| 全周期耦合 | 同步账本独立重算、空间/时间各三档 | 各阶段元素/质量≤1e-8；能量≤1e-6；状态收敛另登记后运行 |

残差尺度使用初始非零总库存、公开定义的反应潜力或温升能量尺度；不得仅用可能抵消的绝对生成能作分母。零尺度案例使用事前定义的绝对量纲阈值，不在观察失败后挑分母。时间阶取实际方法的渐近阶，并报告误差序列；不能只看最后一档。

上表是工程数值门槛，不是实验误差。若合理模型变化要求调整，先记录独立理由与新版本，旧输入/失败/门槛都保留。

## 公开数据对照

Wang 2021 干燥数据：现有12工况、186条记录，其中174个非初始实验符号读数、12个MR=1定义初值。原登记用40°C与60°C校准、50°C预先留出；此后已执行D1对照并暴露失败，后续若依其选择模型，50°C不能再称新的独立留出。历史误差与角色变化见[报告](research/wang2021-drying-holdout-v1/REPORT.md)。来源热边界、含水率基准和薄层几何必须复现，不能直接用它验证整砖。

Wang 对照报告 MR 的 MAE、RMSE、最大绝对误差及到达事件时间，另列数字化读图范围。论文未提供完整测量不确定性，因此不设伪造的“实验精度内 PASS”或置信概率；报告实际误差、残差结构与适用性，工程可接受标准须有独立依据。

Nowicki 残炭与 Mohajerani 烧结终态当前只允许来源/内部一致性核对。前者气氛基准问题未解，后者动态本构及部分指标语义未闭合，不能先计算再挑参数配合结果。为各组补齐可识别关系、工况、拟合/留出和误差定义后才做模型对照。

寻找同一原污泥/基料/成型/热历史的成对耦合观测，实际查到/查不到均记录。三个不同材料的模块对照不能自动形成一个整砖验证域。

## 集成与复现

完整内核出现后，从锁定依赖的非 editable 安装环境实际执行输入校验、来源查询、单例、失败案例、批量、多代谱系、导出、重放、取消/恢复和中文界面。性能上限依据初期实测设置；测试失败和资源超限区分。CLI/Python/UI 使用同一解析对象与内核，比较实际输入与状态，不依赖截图证明数值一致。

当前本机 Python 3.12 的 editable `.pth` 受到文件隐藏标志影响；开发测试临时显式设置 `PYTHONPATH=src`。最终可安装性必须用干净非 editable 安装另测，不能把该开发路径当作已通过安装验收。

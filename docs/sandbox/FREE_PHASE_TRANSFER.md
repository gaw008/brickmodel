# 自由形变下的液汽转移

`WaterPhaseTransfer` 显式接纳 `ClosedFreeSolidCell`，通过实际库存布局定位液水/蒸汽。参考储能模板仅用于物性、参考能、方法和来源哈希的匹配；每一阶段用于转移计算的温度、压力、气相体积来自当前形变和总能量反解。

转移仍按已实现的压力差动力学：`rate = k * (equilibrium_partial_pressure - actual_vapor_partial_pressure)`。当前蒸汽分压由实际蒸汽摩尔数及当前气相体积计算。液水减少rate、蒸汽增加rate；底层相参考能已经包含在总能量，不增加另一份潜热。原外压功/body分量和两个机械伸长率逐项保留。顶层输出汇总当前基础评价、水化学和动力学来源，不能只保留边界标签。

本阶段采用的k=1e-7 mol/(s Pa)、骨架黏度1e6 Pa s及其余试件参数均明确为制造验证设定，不是污泥实测或论文校准。实际水物性与理想水蒸气热量/化学桥接须通过原有方法、参考能、R、物性资产哈希核查；新自由模型仍拒绝错误H2O caloric provider，也要求制造模型显式opt-in。

实际测试包含源项等摩尔、非负相变熵产生、机械/外功不变、thermal inverse与当前thermal state对象一致、来源全集及错误桥接拒绝。湿态短轨迹从液水1 mol、载气.01 mol、蒸汽1e-5 mol、固相2 mol及300K开始，积分0→.001秒，k及边界恒定。保留1e-11 mol水量残差、1e-6J积分能量容差、2e-6J独立恒外压功残差门槛；最多4接受4拒、每次积分30秒、整次真实测试60秒硬限。

普通RK可以随水分转移演化，但尚不认证或切换液相耗尽事件。耗尽积分器继续明确拒绝机械状态，直至两个终端算法、机械比较、相切换和全路径累计审计全部实现。多格输运、反应、真实污泥烧结/冷却和公开验证仍属完整Goal的必需工作。

# 显式液体端点压力求解策略

本阶段根据实际湿态剖析降低压力闭合的物性评价次数。新 `PressurePolicy.strategy` 只有明确的 `guarded_liquid_endpoint_interpolation_v1` 可选；缺省 `None` 保留原二分法，公开编码不新增默认字段。案例可在 `numerics/pressure_policy/strategy` 显式声明该策略，其余物理参数与误差门槛不变。

新策略用已评价端点的液体体积生成压力候选。候选只是一项试算建议：每个候选仍调用实际水物性及来源守卫，按实际残差符号更新区间，并检查单调性。若候选不能充分缩小区间则回到二分；最终仍须通过原区间宽度、体积/压力残差、可表示精度和分压总和门槛。所有内部试算共用原最大次数预算。

成功状态包含不可变的试算账本；求解异常附同样的已尝试账本。上层若已把异常转为失败状态且未保存异常对象，不能声称这些丢失的对象仍可追查；本阶段点探针保存完整异常链，但尚未修复所有服务异常序列化路径。

独立解析根、单调区间、失败调用、试算预算、干态以及默认二分序列等测试已通过。66 项源码与非 editable 安装组合测试通过，65 个安装模块与源码相同。新 dataclass 字段改变内部模型身份，因此默认数值路径/公开编码兼容不等于旧实现 SHA 或模型身份不变。

实际点比较使用原完成轨迹 accepted state 1 的同一 N/E/伸长数组，验证两策略及原记录的初态 N/E/伸长相同，再为各自数值模型显式重绑身份。这是受控点比较，不是跨版本断点续算。实际两格最终根从 38 次内部试算降至 3 次；单次未剖析 host 评价为 0.80005s 与 0.13375s。温差约 2.27e-13/5.68e-14K，压力差约 9.67e-7/1.46e-6Pa，均在原独立界内。该单对顺序样本不证明全轨迹加速比例；计数仅指最终返回根，不包含中间所有热反解。

完整两耗尽事件服务复验已实际通过：30步、2事件、592次评价、70个尝试panel、24个比较端点，继续至原终点0.50032s。两次事件时刻与旧策略保存结果相同。服务用时67.69s；旧策略历史运行353.65s，二者不是随机重复基准。

复用原独立审计脚本，逐prefix N/E/伸长与完整外压功账本通过；最大含外压功残差9.993e-11J、累计绝对约束功不抵消量2.139e-20J，均低于原2e-8J门槛。六组事件比较的原六维门槛及65源码身份经独立只读复核通过。证据见 [pressure-endpoint-strategy-v1](research/pressure-endpoint-strategy-v1/README.md)。

新策略的实际取消/续算/重放、空间收敛、真实原污泥材料及全周期外部验证仍需继续，不能把上述单例通过升级为完整Goal验收。

# 球形公开实验与同一耦合主机的空间几何

本分支为Nylen2024的球形试样提供可检验的空间离散，复用现有`RigidFluidHeat`/`SolidFluidHeat`和库存/总能量积分器。最终砖坯仍以板状厚度模型为必需域；球形验证不能代替板状砖全周期。实现和实际验证状态见`GOAL_STATUS.md`。

## 从控制体积分得到的几何

固定球对称域0≤r≤R，界面r_i递增。每格体积V_i=4π(r_{i+1}³−r_i³)/3，面面积A_i=4πr_i²；中心面面积严格为零，无物质或热源时通量为零。体积不能用表面面积乘径向厚度替代。计算代表点选在每格径向中点，这属于数值离散选择，不是测得的试样微观结构。

Fourier定律的球对称积分为Q=−4πr²k dT/dr。半格内k为常数、稳态径向通量相同的条件下，热阻为(1/r_a−1/r_b)/(4πk)。相邻两代表点之间的共享面导热率为：

```
G = 4*pi / ((1/r_left - 1/r_face)/k_left
            + (1/r_face - 1/r_right)/k_right)
Q_left_to_right = G * (T_left - T_right)
```

仅在正半径路径上计算倒数；中心无流面不计算1/0。任一半格k=0时通路绝热，采用明确的零导热分支。外表面给定温度时，最外格至表面的热阻同样使用球壳积分。对流/辐射、液体输运或几何变化尚未接入这一分支时必须明确拒绝，不能借用原板状半厚度近似而静默继续。

现有气体面接口用面积和距离表示Fick/Darcy传递。球壳每个半格可用等效距离d_eq=A_face∫dr/A(r)接到同一接口，保持同一共享通量在两格账本中正负相反。该等效严格再现半格常系数的几何阻力；气体浓度、温度、黏度和密度仍遵循现有局部面平均假设，不宣称整个可压缩Darcy问题具有精确解析解。

以上是守恒控制体和球几何的推导，不提供污泥k、Cp、孔隙或渗透率。有限体积共享面方法可参见[NIST FiPy数值方法示例](https://pages.nist.gov/fipy/en/stable/examples/diffusion/index.html)；软件文档只支持离散方法背景，不是材料参数证据。

## 独立数值检验目标

几何必须与实际储能宿主的每格体积一致，不能传入球面积却沿用板体积。所有导热、气体面焓以及边界功率继续进入原积分账本。

可用常系数热方程的独立解析模态检验同一主机的空间误差：外表面固定T_ref时，T(r,t)=T_ref+A sin(qr)/(qr) exp(−αq²t)，q=π/R。中心取连续极限。其格均值由积分r²T得到；若数值状态按代表点赋值而非格均值，测试须明确，两者相差属于离散误差。使用制造Cp/k仅验证离散，不赋予Nylen材料适用性。时间误差要单独控制，不能把两个网格都未收敛的差异当作空间精度。

默认板状分支的数值运算应保持原行为。新增几何字段属于模拟器版本变化，身份中必须包含其完整内容；旧保存实验保留原版本，不承诺跨版本续算或混用评分。不得为保持旧摘要而从身份中遗漏实际影响物理的球几何。

## 固定球形表面对流与辐射合同

令R为外半径，r_c为最外格温度代表点，A_s=4πR²。半格导热系数为正且格内视为常数时，G=4πk/(1/r_c−1/R)。质量可忽略的表面温度T_s由下式闭合：

G(T_s−T_c) = A_s h(T_g−T_s) + A_s εσ(T_rad⁴−T_s⁴)。

左侧为表面流向最外格的功率，求解器外向面能量账本记相反号；气体携带的焓继续单独由同一供体规则计算。k=0由既有绝热分支处理，不计算1/k。表面不额外存储能量，此近似不能用于需要独立表皮热容的材料域。

对正温度，残差对T_s的导数为G+A_s h+4A_s εσT_s³，非退化时为正；min(T_c,T_g,T_rad)与max(...)构成物理根括区。因此复用已有表面二分求根与原瓦特残差门槛，不改变门槛以适应新几何。h=ε=0时无外部热输入；同时k=0时表面温度未确定，延用显式标记。流动仍可带来气体焓。

这里的灰体辐射采用现有等效黑体环境/视角因子1定义。T_rad是独立环境边界，不能未经证据设成炉气温度。h、ε、k均不是由球几何推出的材料参数。固定几何程序边界不授予径向液水输运、收缩或任意材料资格。

独立可检验极限：R=.02 m、r_c=.01 m、k=.5 W/(m K)、h=20 W/(m² K)、T_c=300 K、T_g=310 K、ε=0时，T_s=304.444444444444… K。此数值仅为制造测试；错误使用板状半径厚度将产生302.857142857… K。常数容量单格的整体温度有指数解析解，分段线性气温也有逐段解析积分，可检查实际时间推进与边界能量账本。实际实施/测试状态另见GOAL_STATUS和阶段报告。


多格对流极限另有独立解析模态：ε=0、均匀常数α与外部T∞下，T−T∞=A sinc(μr/R) exp(−αμ²t/R²)，其中μcotμ=1−Bi，Bi=hR/k。取Bi=1得到μ=π/2，无需求解特征根。该关系由球对称热方程及−k∂T/∂r=h(T−T∞)直接得到；可用4/8/16格验证实际内部共享面与表面平衡的联合空间收敛，同时另作时间步减半。制造常数容量与h不因解析解成立而成为污泥证据。

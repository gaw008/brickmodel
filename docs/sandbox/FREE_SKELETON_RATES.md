# 从规定形变到自由牵引闭合

第一接口只解决单均匀单元的瞬时机械速率。采用既有制造骨架能量，未接入真实污泥烧结参数，也未构成湿砖全周期积分器。

令对角伸长为(n,t,t)，J=n*t²。既有界面能与t²成正比，有方向性，因此分别求法向和横向速率。使用拉应力为正的Piola约定，孔压p、外压pe均取正压强：

`Pelastic_i + Pinterface_i + eta*lambda_dot_i/lambda_i² - p*J/lambda_i = -pe*J/lambda_i`

据此直接解每个速率，保留既有储能梯度和耗散定义；不改变界面能的物理身份。接口只接受单单元、固定固相库存、严格正黏度的DiagonalSkeletonEnergy，压力必须有限非负；越出已有伸长/速率域时报错。

必须保留的功率核验为：

`elastic_rate + interface_rate + D - p*Vdot = -pe*Vdot`

返回实际表示的速率重新计算的骨架状态、三方向牵引残差和功率残差；数值区间只包围对应算术，不代表本构不确定性。若后续采用含弹性/界面储能的总能量变量，耗散不可再作为额外外部热源重复叠加。

这里p是调用者提供的状态量，没有自行求EOS或确认当前孔体积。因此本接口不能单独运行一块湿砖。下一步必须让(n,t,N,E)进入每个积分阶段和误差控制、拒步回滚、域终止、轨迹及checkpoint，再利用当前状态的温压反解闭合；多单元还需共同横向伸长与空间力学相容，不能把本接口逐格套用后宣称完整连续砖体平衡。

来源核读见data/sandbox/research/free-sintering-source-v1。Olevsky教程给出包含有效烧结应力的连续体关系；压力辅助镍粉研究可在其条件下忽略烧结应力，这不适用于直接定义无压污泥烧结。当前制造骨架不能因引用这些资料自动成为真实材料模型。

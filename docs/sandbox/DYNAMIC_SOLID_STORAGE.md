# 当前形变下的储能与自由单格推进

`DynamicSolidStorage` 直接接收法向与共同切向伸长，不构造时间曲线。当前体积及固相库存决定孔体积，零速率骨架评价提供温度独立恢复能；从总能量扣除恢复能后调用现有固液气储能反解，最后用实际解出的孔压求自由速率。同次反解的原始 thermal_inverse 继续对外保留。

完整固相provider、原始体积、模板、势能、来源和误差域进入模型身份；当前温度、伸长和库存不改写参考身份。仍只准入显式制造的单格固定固相模型。速率的数值界条件于表示出来的孔压，不包含全部压力/几何/本构不确定性；保留该限定，不能把小残差当真实材料精度。

`ClosedFreeSolidCell` 把该点模型接入已实现的机械RK状态：每一阶段从同一库存/总能量/伸长解出温压和自由速率，库存本身无源无通量。总能量功分量只有 `external_traction` 和 `body`，独立schema禁止与储能/耗散热混用；恒外压时应满足 ΔE = -pe ΔV + body_power Δt。机械储能转换和耗散只在点状态中作为诊断，避免重复供热。孔体积/伸长等适用域退出和数值表示失败保留已接受前缀。

干态使用禁止水EOS的独立Decimal/Fraction压力、热能/恢复能验证，以及独立DOP853自由形变轨迹；验证能量账本也进入checkpoint审计。湿态使用同一真实水EOS下独立brent压力求根和能量构造，因此验证的是耦合算法，不是水EOS本身。

湿态初次采用原较宽固相比容误差试件，按既定1e-6J/1e-6K要求实际拒绝，失败保留。成功数值验证使用仓库已有 `exact_volume_wet_model`：固相体积明确定义为1/50000 m³/mol，表示误差一ULP。它是另一个明确制造试件，不能收紧原材料误差冒充实测；原较宽误差的拒绝测试仍保留。两独立湿点n/t=.97/.99及.9/.95；短固定相湿轨迹0→.001秒，.001/.0005秒步长分别运行，事前门槛外功残差2e-6J、两档温差2e-6K、伸长差2e-7；每档15秒/最多4接受4拒、整次45秒硬限。

下一必需工作仍包括相间水分转移与耗尽事件、多格空间相容及传热传质、反应骨架、真实原泥物性/烧结冷却来源和公开实验验证。本接口的固定相短轨迹不能替代湿坯到冷却的完整烧制过程。

实际资源修订：首轮湿轨迹测试31.27秒后返回wall_time_limit，外层正常回收，总35.32秒，原失败XML/日志保留。基于该实测成本将每档wall15→30秒、整次硬限45→75秒；物理时间、两个步长、最多步数/拒步及所有精度门槛不变。新增每档立即记录status/评估次数/实际耗时，避免只保留末尾断言而缺少成本证据。

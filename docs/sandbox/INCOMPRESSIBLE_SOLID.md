# 恒定摩尔体积的单相固体 provider

实施前合同：独立固体 Shomate 单段热量源，保持原 A–H、生成焓及单相域；不使用气体 u=h−RT。以显式参考压力 p0、恒定 v0 定义 u=h0(T)−p0v0，h(T,p)=u+pv0。仅在这个零热膨胀/零压缩近似中 Cv=Cp；不是一般实固体定律。体积来源、方法、版本、分类与声明 u/v 误差必须显式，制造来源需测试门禁。原系数的分项 Fraction 区间下界认证正 Cp；不能从有限采样认定全域单调。原单段温域外拒绝，不跨石英 847 K 真实相变。

预登记：常 Cp=5 J/(mol K)（小于气体 R 仍是合法固体）精确验证 u/h/标准压力；两个压力下 u 相同、h差=Δp v，绝对门槛 1e-9 J/mol。多项式含非零 E/T² 的升降微步积分与独立 Decimal 50位参考比较（相对 2e-15）；Fraction全域Cp下界用独立密网格检查仅作测试而非证明。测试域/未知来源、误差负数、来源门禁、非正Cp、不可表示值拒绝及不可变。真实石英原资产由根代理另行归档后接入，不用制造系数声称石英来源已准入。

实现提供不可变 `SolidShomateCaloric` 和 `IncompressibleSolidPhase`。前者保留晶相 ID、数据集版本、原系数、生成焓、来源分类/标识/资产哈希；单段 Cp 的每项 Fraction 范围下界若不确定则细分，最多16层，不能认证就拒绝。公开向下取整的 `cp_lower_bound_j_mol_k` 供单调路径使用；这只证明所表示单段多项式的性质，不证明真实相稳定或物性精度。`enthalpy_difference_j_mol` 对原系数积分，微温差不从已舍入的大 h 值相减。没有气体常数、gas Cv 或跨段连续化接口。

固体 provider 的摩尔体积、标准压力、压力域和摩尔质量必须显式；体积和误差合同各自有分类及来源，任何制造分类都会传到 PhaseMetadata 并要求 opt-in。`identity` 是整个不可变模型的语义值，包含全部系数、参考、体积、版本、来源和误差字段；不是内存地址。`metadata` 可供既有 PhaseStorage 求和，生成能参考固定为声明物种在298.15K的标准元素生成基准。此处没有对任意输入系数自动完成外部来源核验，哈希也不是自动批准文献模型或材料配方。

`declared_u_error_j_mol` 必须覆盖原 h0 误差、p0*v 的参考修正（包括常量/体积误差及数值舍入）；构造器至少严格检查其不小于 p0*declared_v_error。其余误差覆盖仍是显式声明的条件合同，不是独立全域证书。也不能在将来总体积误差传播时忽略同一体积误差的压力贡献。本模块不传播这些界到 PhaseStorage 的逆解政策：现有 PhaseStorage 反解仍仅有其原单调路径/数值分辨率资格，整体 rigid 闭合误差扩展另行实现。

测试先于代码落盘，正确 PYTHONPATH 下首次收集因模块不存在失败。首版20项中18通过、2因制造预算1e-7低于精确表示的 p0*1e-12 而拒绝；该严格比较保留，制造输入改为显式2e-7余量，数值误差门槛未放宽。随后23项通过（0.05s），包括真实 `PhaseStorage.evaluate/temperature_from_energy` 单相求和/反解，以及从 `data/sandbox/solids/quartz/facts.json` 选取原石英第一温段和独立 Decimal 积分参考。石英资料的未知体积仍使用制造输入，整体分类保持制造，绝不把Quartz事实当作泥料含量或密度准入。后续补充来源/超范围及独立误差制造门禁测试的最终结果由审核报告记录。

该接口仅实现惰性单相储能 provider，尚未把 solid N、占积与 rigid fluid 机械/储能反解接通。石英847K两支的热量/熵跳跃保留为域边界；第一分支端点可查询不等于宣布该分支在任意压力下稳定。压力域是常体积近似的明确声明域，未包含实际晶体状态方程或热膨胀。

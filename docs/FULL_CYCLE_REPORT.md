.venv/bin/python examples/run_full_cycle.py parameters.full_cycle.json --out runs/full-cycle
# 一个配置：基准 + 时间步减半 + 网格加倍
.venv/bin/python examples/run_full_cycle.py parameters.full_cycle.json --out runs/full-cycle --acceptance

.venv/bin/python examples/run_full_cycle.py parameters.full_cycle.json --out runs/full-cycle --calibrate docs/FULL_CYCLE_SYNTHETIC_OBSERVATIONS.json

运行离线，只需现有Python/NumPy/SciPy。原始场文件不入Git，用后删除；上述命令可再生成。汇总、失败记录和小体积合成观测保存在本目录。所有质量、残碳等广延量均对应**半厚度计算域**；对称整砖为两倍。密度、孔隙率、收缩、干基烧失量不变。

## 方程与简化

| 过程 | 采用关系与边界 |
|---|---|
| 干燥/传热/冷却 | 一维随材料移动的有限体积；中心对称，表面半单元导热与对流/灰体辐射串联。面积固定、厚度可收缩；无应力或三维预测。 |
| 气体交换 | 各单元充分通气、准稳态、无气体存储，压力取外压。有限载气和供氧，出口组成由计量收支计算。不是Darcy流、气体扩散或压力积聚模型。 |
| 反应 | H2O(l)→H2O(g)；Al2Si2O9H4→Al2Si2O7+2H2O；CaCO3→CaO+CO2；CH2O+O2→CO2+H2O；C+O2→CO2。CH2O和C分别为有机物及炭的假设组分。 |
| 动力学 | 有效一级Arrhenius速率，乘非负亲和力驱动；按有限氧气与排气容量共同缩放。用未抑制产气速率推导产物分压上界、供氧/排气容量推导氧分压下界。保守驱动力会延迟反应；不是已验证砖坯速率。 |
| 烧结 | `Vp=Vbulk-sum(n*v)`；`Es=3γVp0/r0*(Vp/Vp0)^(2/3)`；`dVbulk/dt=-k_s(T)Vp`。等效孔数固定的耗散近似，反应改变孔体积的表面能也计入。 |
| 热力学 | 同一参考态：`h=h_ref+Cp(T-T_ref)`、`s=s_ref+Cp ln(T/T_ref)`；理想气体加`RT ln(yP/P_ref)`。正的常数Cp为假设，凝聚相不可压缩、零热膨胀，未包含石英转变。 |

储存量为`H_condensed+Es`，右端只有共享面热流、边界换热与进出气流焓；反应热和汽化热由组分生成焓自然产生，不额外重复叠加。气体在准稳态近似中不计储存。改写为内能时，`U=H_condensed+Es-P Vs`；外压功`-P dVbulk`与孔气压力功`+P dVp`合计`-P dVs`，两项分别输出。

反应物剩余量与孔体积使用对数变量。化学亲和力包括孔表面能导数；表面收缩释放能量进入温度。记录整体熵收支及采样熵产。参数使用处检查单位，计量矩阵检查元素平衡；量纲恒等式见结果文件。不以这些检查冒充真实量热/材料验证。

## 实际验收

[FULL_CYCLE_RESULTS.json](FULL_CYCLE_RESULTS.json)保存基准12单元/最大步60s、时间12单元/30s、空间24单元/60s三次完整运行。

- 全程及每个工艺段的质量、元素、完整能量残差均低于0.1%。基准全程相对误差分别约**0.0000364%、0.0008544%、0.0000560%**；阶段最大约0.000743%。
- 时间加密关键量最大变化约**0.00274%**，空间加密最大约**0.04297%**，均低于2%。残碳为零时用预先定义的1e-7kg绝对尺度；其他零值尺度也在参数中登记。
- 三次结果的凝聚相库存非负、孔隙率正、采样熵产非负。干燥段末最高单元剩余水量为初始的**0.0945%**，最终冷却约298.16K。反应可跨炉温时段重叠。
- 示例半砖终态约**0.200964kg、1352kg/m³、孔隙率0.4858、厚度收缩0.916%、干基烧失量10.683%、峰值温差18.83K**。这些是近似模型结果。

## 不确定性与标定

[FULL_CYCLE_UQ.json](FULL_CYCLE_UQ.json)：标准、降低峰温、延长保温三个方案，共用8组独立均匀参数抽样，共24次全流程。当前采样6项：导热率、换热系数、烧结速率、炭氧化A、碳酸盐分解A及初始含水比；其他参数固定在配置值，结论仅针对这个声明子集。全部阶段守恒通过，正式一轮约69.8s。输出均值、5/50/95%分位数、逐指标排名、配对胜率与Wilson下界；不合并相互冲突的指标。小样本尚不足以支持“至少90%胜率”的稳健性结论，当前标为**稳健性未证实**，不等于已经证明不稳健。

[FULL_CYCLE_CALIBRATION.json](FULL_CYCLE_CALIBRATION.json)及[FULL_CYCLE_SYNTHETIC_OBSERVATIONS.json](FULL_CYCLE_SYNTHETIC_OBSERVATIONS.json)：已用七类明确合成观测完成两个指定参数拟合。换热系数真值26、拟合26.06375W/(m²K)，误差0.245%；烧结速率真值3.2e-6、拟合3.200437e-6/s，误差0.0137%。局部Jacobian秩2，正式合成拟合约82.5s；另从实际JSON文件导入完成约20s的接口演示。参数仍为assumed并记录synthetic_fitted。真实测量驱动的合格拟合才更新为measured，同时保留原值与测量出处；这仍是测量反演参数，不冒称直接测得本构常数。

观测文件逐行指定kind、value、unit、scale；曲线还指定time_s。TG为相对初始干质量；DSC为每初始干质量的表观热需求（含显热、反应及表面能），正号吸热；dilatometry为`L/L0-1`，当前主要表示不可逆收缩；kiln为炉温；成品为吸水率、强度、缺陷指标。scale只用于归一化残差，不自动代表仪器不确定度。全部拟合残差逐行输出。

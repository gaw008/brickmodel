## 架构决定

采用一维半厚度有限体积，中心对称，表面与给定炉温/气氛交换。沿用VME的模型/CLI/uq/inverse边界，在这些模块内增加完整热化学路径；旧L0/L1结果不改写。必需的sandbox关系按需使用，不整体迁移研究宿主。

关键修正是统一组分库存及含生成能的总内能；气体交换同时传递物质和能量，相变及反应由组分变化改变温度，不再另外叠加同一反应热。孔隙收缩必须同时登记外压功及表面能。采用有限库存、热力学亲和力相容的近似动力学；有效热物性与动力学的文献借用、温区延拓均明确登记。

旧VME的有效热容热账、仅四种产气组分和累计可用氧限制不能直接升级为完整物理收支。旧sandbox包含可复用的守恒账本与球孔力学推导，但其逐状态来源展开和极高精度审计不是本次执行路径。

采用普通浮点、适量网格和工程容差。只安排一次时间步加密和一次网格加密，判定实际残差及关键量变化。不做高精度数字扫描，不新增软件测试。

### 方程与明确简化

- 沿厚度传热：共享面有限体积热流，中心对称，表面串联半单元导热与对流/灰体辐射。横截面积固定，厚度收缩；不声明各向同性自由收缩或应力预测。
- 充分通气近似：各单元有给定的有限载气摩尔流量，气体准稳态、无存储，压力等于外压。出口组成由进气和反应计量得到；氧消耗不超过配置供氧比例，总产气不超过配置排气能力。不是Darcy流、扩散或压力积聚模型。
- 反应：H2O(l)→H2O(g)；Al2Si2O9H4→Al2Si2O7+2H2O；CaCO3→CaO+CO2；CH2O+O2→CO2+H2O；C+O2→CO2。CH2O和C是分别声明的有机物、炭近似，不代表污泥所有组分。剩余反应物采用对数变量，避免进度越过1而产生负库存。
- 统一热力学：`h=h_ref+Cp(T-T_ref)`，`s=s_ref+Cp ln(T/T_ref)`，气体化学势包含`RT ln(yP/P_ref)`。全部Cp为正的常数近似；硅质惰性相不包含石英相变，高温物性延拓均为assumed。物理自洽不等于量热准确。
- 孔隙：`Vp=Vbulk-sum(n*v)`，`Es=3 gamma Vp0/r0*(Vp/Vp0)^(2/3)`，`dVbulk/dt=-k_s(T)Vp`。这是固定等效孔数的耗散收缩近似，反应引起孔体积变化的表面能代价也计入。凝聚相不可压缩、热膨胀系数为零；当前热膨胀曲线接口主要拟合不可逆收缩，不能表示石英转变。
- 能量：储存`H_condensed+Es`；导热、外部换热及进出气流焓只计一次，反应热和汽化热由组分生成焓产生，不再额外叠加。系统边界是凝聚物加表面能，准稳态气体不在储存量中。用`U=H_condensed+Es-P Vs`复核时，外压功`-P dVbulk`加孔气压力功`+P dVp`等于`-P dVs`，两项分别输出。
- 亲和力：以未抑制产气速率给出的产物分压上界、供氧/排气容量给出的最小氧分压计算保守反应驱动力，包含表面能导数；只允许非负亲和力方向。这会延迟反应，但避免经验动力学驱动吸熵反应。熵账本与采样的总熵产一并输出。

### 已执行验收

基准12单元/最大步60s；时间对比12单元/30s；空间对比24单元/60s。各阶段及全程质量、元素、含表面能的能量收支均通过0.1%。关键输出最大变化为网格对峰值温差的0.04316%，其余均低于2%。残碳为零时采用运行前参数文件中1e-7kg的绝对尺度，不用相除零值。三次运行的最小凝聚相库存非负，采样总熵产为正。此处只授予声明近似下的数值一致性，不授予实材预测准确性。

基准运行约3.31s，加密运行耗时见JSON证据（当前机器、当次结果）。开发耗时随Git交付记录在对话中报告。参数清单、UQ、标定及迁移/20GB整理尚未交付。

低温干燥段结束时，最高单元含水量为0.000142kg/kg初始干料，约为初始水量的0.0945%；后续反应段完全蒸发。最终室温保温后温度298.159–298.161K。工艺段名称是炉温时段，反应可重叠，不人为强制相互分离。

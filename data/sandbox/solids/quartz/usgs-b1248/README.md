# USGS Bulletin 1248：石英体积与密度的有限来源事实

实际核读官方报告封面/题名页、印刷第2–3页方法、印刷54页石英两行，并查看该页渲染图核对数值、±符号、自然样品星号和引用号。印刷54页对应 PDF **从0计数的索引59，即从1计数的第60页**，避免将“PDF59”误当第59页。作者、1967年、报告编号和DOI也与官方落地页元数据核对。

α石英在25°C的摩尔体积22.688±0.001 cm³/mol、X射线密度2.6483±0.0001 g/cm³；β石英在575°C的对应值23.718±0.013、2.533±0.002。两行公式量均60.085 g/mol，均带自然样品星号。SI换算单独记录，没有改写历史原数或重新计算成现代常数值。两温度不同，体积之差不能解释成同温相变跃变。

报告由晶胞体积、Z及历史阿伏伽德罗常数计算摩尔体积，再以公式量计算密度。采用1963原子量和当时常数；与其他热化学包摩尔质量直接拼接前需要明确基准转换。编者重新评估的误差不一定等于原论文误差；晶胞体积采用以晶格参数估计误差为标准误差的传播法。密度误差明确不含公式量和阿伏伽德罗常数误差，因此不能解释成完整严格区间或现有EOS的数值误差预算。原文还提醒实验室间差异及早期晶格长度换算的限制。

方法中关于理想气体参考态的1 atmosphere不是石英测量压力。所核读的表行和方法未确定石英压力，记录为null。原引用53/90/131/242仅核对了本报告参考文献条目，未读取原论文。资料未给本项目所需的污泥矿物含量、高温恒体积近似有效性、热膨胀/压缩状态方程或严格误差证书；这些值没有自动进入运行时材料包。

# 水元素质量的明确名义约定

CIAAW 2024简表的H/O原子权重已实际核读，原±值保留于facts.json。用H₂O计量比归一化为元素质量分数；液水与蒸气共用此分数，摩尔质量始终取同一实际水后端。归一化公式量18.0150不替换IAPWS摩尔质量，也不宣称二者精确相同。

这为制造数值验证固定可查的质量记账坐标；不是本厂水同位素测定。当前水仅跨相/跨面移动，不准用本约定证明涉及水生成/分解的原子计量反应闭合。未知样品同位素、协方差和概率分布不补造；后续现实材料不确定性须单独论证。

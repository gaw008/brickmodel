# Fig3 六次实验的矢量标记提取

原文与CC BY4.0署名见父目录README。page5.svg由父目录未改动source.pdf的第5页经pdftocairo26.07.0导出；SVG是格式转换，不是新的测量。PLAN.md在结构检查后、数据坐标转换前登记，未声称盲提取。

observations.json保存六次运行共180个标记：料温15/16/17/20，墙温18/19，各30个点。按颜色及图例形状保持身份，记录SVG文档顺序path_indices（源path没有XML ID）、原始包围框、坐标轴带宽及转换结果。每组最后的图例标记单独保存并排除；TGA虚线是设定热历史，不是实测系列。

区间包含原始标记fill/outline路径的全部端点和Bezier控制点，以及四个坐标轴校准线的厚度。用Fraction穷举仿射标定角点，保存精确分数和向外六位小数。区间中点只是绘图位置代表值，不是仪器输出。隐藏于重叠下的矢量对象仍属于PDF几何，不声称每点均可从可见像素辨认。末端30min标记包络超出绘图区，6项明确flag，没有截断。

这些是条件读图包络，不包括温度计误差、试件变异、原图数据处理误差或图形格式转换的独立精度证明；不作为实验置信区间。也不把不同运行墙/料温组合成同步边界与响应。同一温曲线反推的alpha/Bi不能独立验证Cp。

重放：`python data/sandbox/research/agar2018-heat/figure3/extract.py`。只解析已保存SVG，不需要EOS、安装新科学依赖或网络。改变PDF或导出程序后需重新核查图例/坐标与版本，不能套用旧身份。当前输出未拟合、未插值、未用来证明模型通过外部验证，材料及训练准入均false。

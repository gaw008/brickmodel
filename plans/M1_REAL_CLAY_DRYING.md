# M1：真实黏土砖坯完整干燥预测与验证

2026-09-21。状态：**阶段计划，尚未启动执行 Goal**。用户已选择“先验证公开黏土砖坯”；最终含污泥配方的完整烧砖目标保持不变。本文件只制定下一大阶段，不宣布 D1、材料适用性或真实精度已经通过。

## 1. 唯一目标与完成后的用途

针对一种身份明确的真实黏土砖坯，在明确的几何、初始状态和热风条件下，完成从湿初态到预先定义干燥终点的连续计算；在未参与参数校准的合格实验记录上，对总质量与指定表面位置温度给出完整曲线、误差及适用范围。终点有观测支持时，同时评价达到目标含水率所需时间。

成功后可在已经验证的材料和工况范围内研究干燥制度。只有跨工况对照也成立，才有依据比较该范围内的不同制度；这不赋予新配方、高温反应、烧结收缩、强度或整窑能耗的预测资格。内部温湿场可以输出为模型结果，没有相应观测就保持未验证标记。

本阶段的成果单位是“一种材料的一段完整过程及真实误差”，不是累计模块、守恒等式或短算例数量。开发与验证仍交替进行，已准入的内部步骤连续推进，不再为每一个局部函数单独扩张项目目标。

## 2. 已有基础与不能继承的结论

- 起点为 `23008b2`，D-B2/V-B2 已完成；当前分支 `codex/physics-sandbox-v1`，本次规划前工作区干净。
- 可评估复用：水物性、显式库存和储能、共同气体边界、物流携焓、离线参数及来源记录。
- 当前低温单元固定液态水量，不发生蒸发。其借用污泥比热与虚拟几何、扩散、渗透参数不能直接作为黏土砖参数。历史其他湿态模块也不因本计划而自动合格。
- 首选 Silva 2018 Compensator 07 工业黏土块。已有 70°C 质量/表面温度及尺寸记录；主干燥段为 0–990 min，后续两个处理端点不能混为同一恒温干燥轨迹。
- 该来源仍存在真实边界、取出测量扰动、材料关系、几何解释和观测误差缺口。原论文与其同源期刊论文不是独立实验。现有资料未证明完整干燥预测可通过。
- 原污泥/MIA3 结果、Wang 干燥失败及旧数值失败均保留；不能拼接不同材料的参数后命名为同一真实砖坯。

## 3. 材料与证据选择

优先用 Silva 2018。第一步只处理影响本目标的明确缺口，不重复核对已通过的移录与算术。公开、可追溯且定义足够的数值表可作证据，不要求全部仪器原文件或重新收集全厂数据。

若首选材料不能在本轮资料投入内形成可判定问题，最多评估一个有实质新增证据的公开黏土砖坯备选。Silva 2009 已知风速冲突等不能作为“换一个就解决”的理由。不改变为纯污泥或虚构材料；更换必须在校准前记录原因、材料身份和新的数据分工，不能看验证误差后挑选容易通过的材料。

允许有依据的有效参数、等效边界和跨来源近似，但须说明有效域、识别方法及其对目标误差的影响。不要求所有微观参数唯一可辨识；无法区分的参数只能报告为有效组合或范围。对影响精度的未知量，必须量化可支持的范围或明确无法判断，不能填零或采用未声明默认值。

## 4. 内部执行顺序与准入

| 步骤 | 实际工作与交付 | 进入下一步的条件 |
|---|---|---|
| A：冻结预测问题与证据 | 材料/试件身份；几何和测温位置；初始质量、含水基准；实际或有误差依据的等效边界；观测协议；需要的材料关系；校准/验证数据角色；完整起止时间、终点与误差指标。形成一份合同和逐项缺口决定。 | 存在可运行、可辨识且能评价误差的问题；关键未知不被任意参数掩盖。未达到则停在资料缺口，不进入宣称真实预测的开发。 |
| B：实现必要的干燥耦合 | 复用适用物性与交换机制，解除固定液量约束，落实水迁移、蒸发/凝结及相应能量交换、固体储热和边界；采用足以描述所选试件的最简空间模型。交付离线入口和完整过程运行。 | 连续完成合同规定的过程；没有删除剩余水、跳过失效时段、扩大物性域或重复加入潜热来完成轨迹。实现完成单独记录，不等于真实精度通过。 |
| C：物理与数值核验 | 冻结 B 的实现；独立核算总水/质量/能量及相变能量约定，检查量纲、输运方向和所用热力学假设；分别做覆盖完整过程的时间与必要空间细化。保留失败及误差。 | 所用方程在声明条件下自洽；数值误差对观测输出足够小，能够与材料/边界误差区分。不能用一个短时点或仅有全局守恒代替。 |
| D：校准与独立工况评价 | 只用预定校准记录识别必要的少数有效参数；冻结参数和实现，再比较预定验证记录的质量、表面温度及合格终点时间。给出误差曲线和敏感性/不确定度分析。 | 合格验证记录上的预定指标满足要求，且证据误差足以支持该结论。只有拟合通过不算完成。 |
| E：交付与阶段裁定 | 交付来源/参数、离线复现命令、完整曲线、失败记录和四类结论：物理一致性、数值精度、材料适用性、现实对照。写明可用范围及下一高温阶段尚缺条件。 | 只有全部必要条件通过，才把 M1 标为成功；否则如实报告失败、未完成或证据不足。 |

若校准后参数改变了最初核验的数值范围，应在最终冻结参数上重新核验受影响的完整轨迹。验证发现实现缺陷时，只修复已定位的问题，再复核受影响内容；不无关扩展功能。

空间维度不能先验锁死为一维。Silva 试件有宏观孔道，一个表面测点不能证明内部均温。可采用经尺度和误差论证支持的等效模型；若需要更高维描述而首轮投入不足，保留该实现缺口，不以不成立的简化强行通过。

测得的几何变化若用于驱动计算，就属于输入，不能再次当作独立收缩预测成绩。相变采用局部平衡或有限速率关系须有适用性依据；统一各相能量基准和界面携能。物理第二定律要求与有限数值节点的熵检查应分别描述，不宣称普适熵证明。

## 5. 建议验收指标与数据独立性

下列数值是**规划提出的工程目标**，不是来源实测精度、文献定律或已经达到的结果。A 步结合观测质量和用途冻结最终数值；如需改变，必须在校准前说明原因。不能看到结果后放宽标准。本次规划不把这些数值写成已生效运行参数。

| 主要输出 | 建议首轮目标 | 限定 |
|---|---|---|
| 总质量曲线 | RMSE / 初始水质量 ≤ 5%；最大绝对误差 / 初始水质量 ≤ 10% | 用初始水量而非占比很大的干固体质量归一化，避免“总质量接近”掩盖失水误差；干质量和水量基准须成立。 |
| 指定表面位置温度 | RMSE ≤ 2 K；最大绝对误差 ≤ 5 K | 观测算子须对应红外测点/测量协议；表面温度不能当核心温度。 |
| 达到预定干燥终点的时间 | 相对误差 ≤ 10% | 终点和含水基准在 A 步预定；观测实际跨过终点且时间采样能支持该误差判断。未覆盖则不评分，也不得声称完整终点预测通过。 |

初始水质量采用与干质量协议相容的 `m_w0 = m0 - m_dry`，须说明干燥段干固体不流失等前提及该操作性干质量的适用性。不能直接采用有定义冲突的作者归一化曲线替代原始有量纲质量和温度。

RMSE 按观测时间间隔采用预定梯形权重，模型只在实际观测时刻取值；最大误差单列。明确计分时间窗、单位、权重、插值方法和缺测处理，不选择性删除难以拟合的点。不同验证工况分别报告，不以总体平均掩盖某一工况不合格。

数值核验以完整轨迹的同一观测输出为对象，预先分配数值误差预算；建议细化差不超过对应现实误差限的 10%，并有趋势、反解残差和端点行为的支持。细化差只是证据，不自动成为严格误差上界。误差限和参考尺度须显式定义，不用零残差次数替代。

A 步必须登记各记录此前是否被查看、拟合或用于选择模型。70°C 已参与来源和候选评估，不能标作盲留出。优先用兼容材料的不同试件/工况作未校准记录；同一曲线抽点不是独立工况验证，同一实验的两篇出版物也不是两次实验。

若只是此前见过、但未用于调参的记录，应准确命名为“非盲、未用于参数校准的工况评价”，说明模型选择偏差。作者用验证数据拟合得到的经验系数也不能作为独立物性输入。若已看验证误差后再调模型，该记录随之转为开发证据，最终需要新的合格验证记录；没有就不宣称独立预测通过。

实验不确定度未知时仍可计算和报告观测差，但不能伪造置信区间或把仪器分度当完整误差。不要求误差资料完美；需要论证现有证据是否足以判定所选精度。若不足，阶段结论为证据不足。数据覆盖不到预定干燥终点时，只能交付观测窗口内结果，M1 的完整过程目标保持未完成。
